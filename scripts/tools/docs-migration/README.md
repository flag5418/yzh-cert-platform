## 关键设计

### `migrate.py` 的 MAPPING 三元组

```python
MAPPING = [
    ("源路径", "目标目录"),            # 移动到目标目录下（保留文件名）
    ("源路径", "目标完整路径", True),   # True = rename 式移动（目标即最终路径）
]
```

`True` 标记用于目录改名场景（如 `60-AI工程设计/YZH-知识库` → `30-项目规则/知识库`），
避免被套成 `30-项目规则/知识库/YZH-知识库`。

### `update_refs.py` 的规则顺序敏感

```python
RULES = [
    ('docs/60-AI工程设计/YZH-知识库/', 'docs/30-项目规则/知识库/'),  # 长前缀必须在前
    ('docs/60-AI工程设计/', 'docs/30-项目规则/'),
    ...
]
```

**前缀长的规则必须排在前面**，否则短前缀会先吃掉长前缀。
