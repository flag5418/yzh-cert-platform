> **`cert_standard_directory_file` / `_config` 的「非企业行」标记，代码 / DB 注释 / C# 注释 / 数据 四方各说各话；且「具体机构」维度在撤列后只剩物理路径里的残留。**

## 二 设计

### 2.1 企业列判据统一

**唯一判据入口**（新增在 `Shared/Domain/Scope/OrgScope.cs`，与既有 `IsBackendBuilt` / `IsEnterpriseOwned` 同址）：

```csharp
/// <summary>
/// 该行是否属于某个<b>具体企业</b>（`EnterpriseCode` 列的唯一判据入口）。
///
/// <para>判据 = <c>EnterpriseCode</c> 非空白。<b>空 = 不属于任何企业</b>（后台/机构行）。</para>
///
/// <para>⛔ 禁止把机构维度的值（<c>CoreOrgCodes.StdEnv</c>）填进企业列做标记 ——
/// 两者是<b>不同维度</b>（机构列 vs 企业列）。守卫 <b>A-R11</b>。</para>
/// </summary>
public static bool IsEnterpriseRow(string? enterpriseCode)
    => !string.IsNullOrWhiteSpace(enterpriseCode);
```

**改写规则**：

| 原形态 | 新形态 |
|---|---|
| `x.EnterpriseCode == CoreOrgCodes.StdEnv`（认模板行） | `!OrgScope.IsEnterpriseRow(x.EnterpriseCode)` |
| `f.EnterpriseCode != CoreOrgCodes.StdEnv`（拒绝非模板行） | `OrgScope.IsEnterpriseRow(f.EnterpriseCode)` |
| `payload.EnterpriseCode == CoreOrgCodes.StdEnv` | ⚠️ **单独核**（见 §3.3 #18） |

### 2.2 `cert_standard_directory_config` 新增「机构 Code」专用列

**列定义**：

```sql
ALTER TABLE cert_standard_directory_config
  ADD COLUMN OwnerOrgCode varchar(50) NOT NULL DEFAULT ''
  COMMENT '具体机构 Code（= sys_organization.Code）。空 = 不特指机构（平台通用模板）'
  AFTER OrgCode;
```

**语义**（与 `OrgCode` 的两值模型**同构但不同维度**）：

| 列 | 回答的问题 | 值域 |
|---|---|---|
| `OrgCode` | 这行属于**后台域**还是**企业域**？ | `yzh-std-env` \| `<企业 Code>` |
| `EnterpriseCode` | 这行**属于哪个企业**？ | `''`（无企业）\| `<企业 Code>` |
| **`OwnerOrgCode`**（新） | 这行**属于哪个机构**？ | `''`（不特指）\| `<机构 Code>` |

**回填**（仅 1 行，覆盖全部 23 个文件）：

```sql
UPDATE cert_standard_directory_config
   SET OwnerOrgCode = '906e8b2a962c4062b21144af4cc4abc0'
 WHERE Code = 'b27945be5e1b44f28bcf8fc19852d92d';
```

**唯一键调整**：

| 项 | 前 | 后 |
|---|---|---|
| 唯一键 | `uk_enterprise_std_stage(OrgCode, EnterpriseCode, StandardCode, StageCode)` | `uk_owner_std_stage(**OwnerOrgCode**, EnterpriseCode, StandardCode, StageCode)` |
| `OrgCode` 索引 | （含在 uk 首列） | 补 `idx_org_code(OrgCode)`，避免丢失该列索引 |

**`PathBuilder` 口径**（3 处：`StandardDirectoryService.cs:1519 / 2507 / 2665`）：

```csharp
// 身份段 = 具体机构；未指定机构（平台通用模板）⇒ 兜底 yzh-std-env
var ownerSeg = string.IsNullOrWhiteSpace(config.OwnerOrgCode)
    ? CoreOrgCodes.StdEnv
    : config.OwnerOrgCode;
var storagePath = PathBuilder.StandardFile(ownerSeg, standardCode, phaseCode, parentDir, fileName);
```

⇒ 存量那 1 行回填后 ⇒ `/standard-directory/906e8b2a…/…` **与存量 23 行完全一致** ✓
⇒ 新建平台通用模板 ⇒ `/standard-directory/yzh-std-env/…`（自洽）✓

**`_file` 不加列**：23/23 文件均有 `ConfigCode` 指向 config，机构归属**经 `ConfigCode` 继承**即可（避免同语义两处存）。
