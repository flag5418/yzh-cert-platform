## 二、★ 键口径（实现前必须统一，共 3 处）

| 键 | 企业侧（`cert_enterprise*`） | 目录模板侧（`cert_standard_directory_*`） | 结论 |
|---|---|---|---|
| **标准** `StandardCode` | `cert_enterprise_stage.StandardCode` = `cert_iso_standard.Code`（GUID） | `config.StandardCode` = `cert_iso_standard.Code`（GUID） | ✅ **同域**，可直接关联 |
| **阶段** `StageCode` | `cert_enterprise_stage.StageCode` = `cert_cert_stage.**StageCode**`（业务码 `jd01`/`jd02`/`03`） | `config.StageCode` = `cert_cert_stage.**Code**`（GUID） | ⚠️ **必须换算** |
| **机构** `OrgCode` | `cert_enterprise.OrgCode` = **专家工作区**（`Sys_Organization` 中 `OrgType='VirtualOrg'`、`OrgLevel=2` 节点 Code） | `config.OrgCode` = `cert_certification_body.Code`（= `Sys_Organization` 中 `OrgType='CertBody'` 节点 Code） | ⚠️ **需映射** |

**换算实现（P0 收口，禁止散落）**

```
StageCodeResolver : cert_cert_stage.Where(StageCode == 业务码).Select(Code)   // 业务码 → GUID，带缓存
CertBodyResolver  : Sys_Organization[工作区Code] 沿 OrgPath/ParentCode ↑ 找 OrgType=CertBody 的祖先 Code
                    解析不到 → 取 (StandardCode, StageCode) 下唯一模板(EnterpriseCode IS NULL) 并写告警日志
```

**实测佐证**

- `cert_cert_stage`：`c42582d5… = jd01(初审)`、`fa7931c8… = jd02(预审)`、`29c1bcc3… = 03(复审)`
- 有内容的模板 `config.StageCode = 29c1bcc3…`（复审 GUID）⇒ 前端若直传业务码 `03` 而**不换算**，**必然查不到模板**
- `Sys_Organization.Code = 906e8b2a962c4062b21144af4cc4abc0` 的节点 `OrgType = CertBody`，与 `cert_certification_body.Code` **完全一致** ⇒ 可作映射锚点

## 四、企业行写入规则（ensure 幂等，核心）

**触发时机**：左树选中阶段（需求 1"必须选阶段"）→ 对该阶段的**每个关联标准** ensure 一次；或首次上传时对涉及标准 ensure。

**算法（单标准）**

```
1. 解析：机构 = CertBodyResolver(企业.OrgCode)；阶段 GUID = StageCodeResolver(阶段业务码)
2. 找模板：config(OrgCode=机构, StandardCode=标准GUID, StageCode=阶段GUID,
                 EnterpriseCode IS NULL OR = 'YZH-STD-ENT', IsValid=1)
   ├─ 找不到 → 返回"未配置模板"（前端按 §常5.2 文案提示），不建企业行
   └─ 找到多条 → 取 Sort/CreateTime 最前者 + 写告警
3. 找企业 config：先查**含已删**行 (EnterpriseCode=企业, StandardCode, StageCode)
   ├─ 存在且 IsDeleted=1 → 就地复活（IsDeleted=0, IsValid=1, UpdateTime=now）
   ├─ 存在且有效      → 直接使用（幂等，不再建）
   └─ 不存在          → Insert：Code=new GUID(36)、OrgCode=机构、EnterpriseCode=企业、
                              StandardCode/StageCode=模板值、RootFolderName=模板值、Status='active'、IsValid=1
4. 复制文件行（仅当"该企业 config 下文件行数 < 模板文件行数"时补差）：
   逐模板文件行 t → 企业行 e：
     e.Code = GUID；e.FolderCode = t.FolderCode（模板文件夹）；e.ConfigCode = 企业 config.Code
     e.EnterpriseCode = 企业；e.StandardFileCode = t.Code；e.FileName/FileType/FilePattern/IsRequired/SortOrder = t.*
     e.StoragePath = NULL；e.UploadStatus = 'pending'；e.ConvertStatus = NULL；e.IsValid = 1；e.FullPath = t.FullPath
   命中已有行（同 ConfigCode+FullPath）→ 跳过（幂等）
5. 文件夹行不建（共享模板）
```

**幂等要求**：重复调用不产生重复行；判据 `uk_cfg_fullpath(ConfigCode,FullPath)`；并发下靠唯一键兜底（先查后插 + 1062 重查）。

## 五、查询口径（禁止省略 `EnterpriseCode` 过滤）

```sql
-- ① 模板行（标准侧，机构维度）
WHERE OrgCode = :机构Code AND StandardCode = :标准GUID AND StageCode = :阶段GUID
  AND (EnterpriseCode IS NULL OR EnterpriseCode = 'YZH-STD-ENT') AND IsValid = 1;

-- ② 企业行（企业侧）
WHERE EnterpriseCode = :企业Code AND StandardCode = :标准GUID AND StageCode = :阶段GUID AND IsValid = 1;

-- ③ 页面主数据：某标准模板文件夹树 + 文件定义 + 企业就位状态（左连接）
SELECT f.Code AS TemplateFileCode, f.FileName, f.FileType, f.IsRequired, f.FullPath,
       d.Code AS FolderCode, d.FolderName, d.Depth, d.SortOrder,
       e.Code AS EnterpriseFileCode, e.StoragePath, e.FileSize,
       e.UploadStatus, e.ConvertStatus, e.MarkdownStatus,
       e.PreviewPdfPath, e.MarkdownPath, e.ConvertMessage
FROM cert_standard_directory_folder d
JOIN cert_standard_directory_file f
  ON f.FolderCode = d.Code AND f.ConfigCode = :模板ConfigCode AND f.IsValid = 1
LEFT JOIN cert_standard_directory_file e
  ON e.EnterpriseCode = :企业Code AND e.StandardFileCode = f.Code AND e.IsValid = 1
WHERE d.ConfigCode = :模板ConfigCode AND d.IsValid = 1
ORDER BY d.Depth, d.SortOrder, f.SortOrder;

-- ④ 就位率（卡片进度）
应上传 = COUNT(模板文件行 IsRequired=1)
已就位 = COUNT(企业行 StoragePath<>'' AND ConvertStatus='completed')
转换中 = COUNT(企业行 ConvertStatus IN ('pending','converting'))
```

## 八、验证 SQL（防假阴/假阳，随 P1/P2 出口门执行）

```sql
SET NAMES utf8mb4 COLLATE utf8mb4_general_ci;

-- ① 模板行口径正确（应能命中唯一有内容模板）
SELECT COUNT(*) FROM cert_standard_directory_config
WHERE OrgCode='906e8b2a962c4062b21144af4cc4abc0'
  AND StandardCode='846dec4b-c534-4983-94e6-8cf04982b7d9'
  AND StageCode='29c1bcc3a18942e1865b2497a0262504'
  AND (EnterpriseCode IS NULL OR EnterpriseCode='YZH-STD-ENT') AND IsValid=1;   -- 期望 1

-- ② 企业行幂等（重复 ensure 后企业 config 行数应为 1）
SELECT EnterpriseCode, StandardCode, StageCode, COUNT(*)
FROM cert_standard_directory_config WHERE EnterpriseCode IS NOT NULL
GROUP BY EnterpriseCode, StandardCode, StageCode HAVING COUNT(*) > 1;          -- 期望 0 行

-- ③ 企业文件行与模板文件行数一致
SELECT g.Code AS EnterpriseConfigCode, COUNT(e.Code) AS EntFiles,
       (SELECT COUNT(*) FROM cert_standard_directory_file t
         WHERE t.ConfigCode = :模板ConfigCode AND t.IsValid = 1) AS TplFiles
FROM cert_standard_directory_config g
LEFT JOIN cert_standard_directory_file e ON e.ConfigCode = g.Code AND e.IsValid = 1
WHERE g.EnterpriseCode = :企业Code GROUP BY g.Code;                            -- 期望 EntFiles = TplFiles

-- ④ 存储路径库前缀正确
SELECT COUNT(*) FROM cert_standard_directory_file
```
