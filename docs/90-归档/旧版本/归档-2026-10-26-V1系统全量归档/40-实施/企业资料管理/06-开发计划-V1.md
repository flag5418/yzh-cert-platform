## 二、通用纪律与完成定义（DoD）

**每个任务完成必须全过**：① `dotnet build CertPlatform.sln` 0 错误；② 改了后端 ⇒ `./scripts/backend/restart-backend.sh`；③ `cd src/certplatform-web && node scripts/guards.mjs` **0 违规**（含 R12）；④ 动了菜单/路由 ⇒ 先 `./scripts/db/verify/sync_menu_urls.sh` 再 guards；⑤ `npm run typecheck` + `npm run build` 通过；⑥ 该任务的**验收 SQL/断言**全绿。

**编码红线**（违反即返工）：PascalCase 三处一致 / 只用 `Code` 定位 / 无 `Enable` 列 / 禁止裸 `ControllerBase`（本模块用 `WebControllerBase`）/ `.vue` 内禁 `fetch(` / 禁 `axios` 与 Vol 组件 / 存储路径只走 `PathBuilder`。

## 九、并行性与依赖

```
P0 ──> P1 ──> P2 ──> P3 ──> P4 ──> P5        ← 期与期串行，每期独立出口（可停在任意期不留半成品）
P0:  T0.1 ∥ T0.2 ∥ (T0.3 依赖 A3/A4 种子)
P1:  T1.5 前端骨架 ∥ T1.1–T1.4 后端（前端可先接 mock）
P2:  T2.4 下载/预览 ∥ T2.1–T2.3 上传主链
P3:  T3.1/T3.2 匹配器（纯函数，可先单测） ∥ T3.6 前端弹窗
P4:  T4.3 版本抽屉 ∥ T4.1/T4.2 后端
```

**关键路径**：T0.1（键口径）→ T1.1（ensure）→ T2.1/T2.2（泛化上传）→ T3.3/T3.5（分发）→ T5.3。
**风险最高的三处**：① 键口径两处不一致（T0.1）；② 四段式泛化（T2.1，触碰 Admin 已跑通代码）；③ 分发匹配准确率（T3.2，依赖文件名规范化）。
