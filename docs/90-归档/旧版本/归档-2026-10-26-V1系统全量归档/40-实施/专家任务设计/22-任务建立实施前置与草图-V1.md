> `c42582d5f95f4318a1a5548eee7ed463` = `cert_cert_stage.Code`（`StageName='初审'`，业务码 `jd01`）

**症状（不报错，但结果全错）**：


**这是项目最忌讳的一类失败**：不报错、结果看起来正常、实际是空的。

**与 02 号旧版的差异**：

| 步骤 | 旧版 | 新版 |
|---|---|---|
| ① | `TaskStatus='draft'` | **三层状态**：`ExecStatus='draft'` + `ReviewStatus='not_started'` + `LifecycleStatus='active'` |
| ① | 无 `TaskSource` | ✅ 加 `TaskSource`（D25）+ `ScopeSnapshot` |
| ③ | `INSERT cert_expert_task_item`（**表不存在**） | `cert_expert_nc_item` / `_report_section_item`，**且先查后插复用** |
| ④⑤ | 队列 + 队列项 | 保留，但 `TaskItemCode` 语义改为**指向实体层行** |
| ⑥ | 回写计数 | 保留 |

**为什么 ③ 要"先查后插"**：`cert_expert_nc_item` 是**企业级长期实体**（11 号 §4 实测同一检查项跑过 **15 轮**）。第二次建任务时**不能重建** —— 重建会丢掉 `CurrentResultCode` 和 `LastAuditedTime`，D30「沿用项保留上次检查时间」就失效了。

### 3.4 范围解析（★ 修正版签名）

```csharp
// 输入
//   taskType    : NC_CHECK | REPORT_GENERATE
//   scopeType   : FULL | PARTIAL
//   standardCodes : FULL 时 = 企业该阶段已分配的全部标准；PARTIAL 时 = 从勾选项反查
//   selectedItemCodes : PARTIAL 时的勾选 Code（规则 Code 或章节 Code）
//
// 输出：List<(StandardCode, List<ItemCode>)>
IEnumerable<(string Std, List<string> Items)> ResolveScope(
    string taskType, string scopeType, string enterpriseCode, string stageCode,
    List<string> standardCodes, List<string> selectedItemCodes)
{
    // ① 候选集合
    //    NC_CHECK        → cert_validation_rule   WHERE IsValid=1
    //                        AND OrgCode=? AND StandardCode IN(...) AND StageCode=?
    //    REPORT_GENERATE → cert_report_section    WHERE IsValid=1
    //                        AND OrgCode=? AND StandardCode IN(...) AND StageCode=?
    //
    // ★ 两个 OrgCode 不同义（02 号 §9.1 口径表）：
    //     规则表的 OrgCode = 【认证机构 CbCode】（规则是企业无关的全局配置）
    //     任务表的 OrgCode = 【专家工作区 OrgCode】
    //
    // ★ 这里必须传 GUID（= cert_expert_task.StageCode），
    //   依赖 §1.1 修完 —— 否则 PhaseCode='03' 永远查不到
    var candidates = LoadActiveRules(taskType, standardCodes, stageCode);

    if (scopeType == "FULL")
        return candidates.GroupBy(r => r.StandardCode)
                         .Select(g => (g.Key, g.Select(x => x.Code).ToList()));

    var picked = candidates.Where(r => selectedItemCodes.Contains(r.Code)).ToList();
    if (picked.Count != selectedItemCodes.Distinct().Count())
        throw new BizException("PARTIAL_ITEM_NOT_FOUND",
            "勾选项中包含无效或不属于该企业该阶段的检查项/章节");

    return picked.GroupBy(r => r.StandardCode)
                 .Select(g => (g.Key, g.Select(x => x.Code).ToList()));
}
```

**⚠️ 修正点**：02 号 §1.2 写的是 `PhaseCode=?` → 06 号已改 `StageCode`。**如果 §1.1 不做，这里就是那个"静默空任务"的发生点。**

### 5.2 任务控制 → ✅ 裁决：**分类型串行锁**

> 「关于任务的控制，如果**企业 阶段 分类（nc 还是报告）**，还未结束，不允许开启新的任务，**我不允许同一个阶段下，一个 nc 任务还没完成，又开启另一个 nc 任务**」
