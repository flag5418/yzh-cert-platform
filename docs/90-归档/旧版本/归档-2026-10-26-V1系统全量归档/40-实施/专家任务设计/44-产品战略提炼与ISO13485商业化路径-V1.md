# 44-产品战略提炼与 ISO 13485 商业化路径 V1

> 来源：2026-10-21 战略讨论全记录提炼。定位：把"已研发 3 个月的功能资产"与"2026 法规红利"对齐，形成可执行的单人开发者商业化路径。
> 关联：28~43 号文档（专家任务设计系列）· 42 号（产品可信性验证）· 43 号（ACM 分析与 13485 规划）

## 1. 出发点与约束（写下来防止忘记）

- 技术资产已完成：文档四元组定位与提取、规则引擎（受限 AI + 提示词约束 + 条件配置）、工作流 + Skill + AI 节点、企业资料规范化、智能 NC、智能报告。
- 约束：单人开发、无行业积累、无销售团队、无品牌；决心走"精准配置、精确执行"路线，AI 只做受限执行者，不做判定者。
- 铁律：不做项目定制（可谈 1-2 家但不可普及）、一个工具只解决 1-2 个痛点、付费前可自助试用。
- 合规红线（不可触碰）：认证决定必须人工；不得生成无原始依据的事实（时间·地点·人物·数值四要素）；审核员/专家不得向企业推荐产品（《条例》第 13/14 条、第 58 条撤资质、《人员办法》第 8 条）；认证机构不得代编企业体系文件与记录（国认监发〔2025〕9 号文第（四）条）。

## 3. 四方买方分析与淘汰逻辑

| 买方 | 痛感 | 付费力 | 结论 |
|---|---|---|---|
| 机构（约 1200 家，清理后约 1000 家） | 极强（处罚标识、资质延续、清理） | 强，但采购周期长、要案例 | 第二层（工具矩阵后进入） |
| 审核员个人 | 强（报告、180 天记账） | 弱（50-100/月无感；13485 专家可到 150-300/月） | 漏斗层，非利润层 |
| 咨询公司 | 中（交付效率） | 弱且群体萎缩 | 按项目/白牌，不做系统销售 |
| **企业（获证组织 80 万+）** | **Registration + 飞检刚需** | **中（13485 企业愿付）** | 长期最大，第二阶段 |

**淘汰"大平台"路线的四条结构性理由**：无买家画像、无渠道入口、无定价锚、无信任状。

## 4. 战略收敛结论：ISO 13485 垂直单点

**为什么是 13485（五条件交集）**：

1. 客单价高：认证总费用 2 万–15 万（普通体系的 5-10 倍），工具定价可锚定；
2. 刚需绑定：NMPA 注册、生产许可、出口 MDR/IVDR 全压在体系上；
3. 知识密度高：ISO 13485/YY 0287 + 医疗器械 GMP + 注册法规三轨交叉，通用 AI 进不来；
4. 专家稀缺：具备专业领域资质的 13485 审核员是稀缺资源，圈子小、可达（≥1 位专家朋友在手）；
5. 检查表可预制：条款×过程×法规映射收敛，垂直专属红利。

**三层结构（同一 13485 引擎）**：

- 第一层·审核员端「13485 审核助手」：检查单自动生成（过程模板预制）+ 报告草稿 + 180 天/人日仪表盘。定位：专业圈层漏斗，月费 150-300；
- 第二层·企业端「13485 合规管家」（变现主力）：资料预处理 + NC 预检查 + 监督时钟（证书/注册/GMP 飞检三表合一）。年费 3000-10000；
- 第三层·机构端「13485 发证前复核」（最后进入）：违规成本极高 + 机构名录制，客单几万/年；前两层案例即谈判筹码。

**起步品类纪律**：先从案例成熟的"第一类/简单器械"跑通（尚龙案例），高客单的 Ⅱ/Ⅲ 类第二阶段进入；单一时段只打一个品类。

## 5. 证据链闭环逻辑（产品核心，含三处关键修正）

数据流：**入场计划（过程×时段×审核员×陪审人×检查项）→ 手机端检查项驱动采集 → 证据归档 → 要求×证据双向夹逼 → 候选 NC → 人工确认 → 报告草稿 → 全程留痕**。

三处关键修正（直接做会翻车的地方）：

1. **必须补"应然侧"**：NC 判定 = 要求（条款+法规+企业文件）× 证据（现场+记录）→ 差距。没有规则库做判断基准，AI 只能归档照片，判不了符合性；
2. **AI 只做"归位·比对·提示缺口"，不做"生成证据链"**：证据链是采集+结构化产物，AI 不得制造证据（幻觉红线）；
3. **NC 永远是候选，拍板必须是人**：输出"证据摘要 + 条款依据 + 差距描述草稿"，人工确认/否决/改写。合规+尽职留痕+专家信任三重收益。

**手机端硬设计**：检查项驱动（非通用相册）；四要素绑定（时间/地点/对象/来源方式）；离线采集（车间洁净区无信号）；录音先授权（员工声音需单独同意）。

## 6. 案例资料验证结论（docs/90-归档/案例资料）

已验证的两侧真实素材：

- **企业端（尚龙医疗，第一类器械）**：四层文档树（质量手册 → 25 个程序文件 → 三阶制度 → QR/TR/PR/OR 四类记录 100+ 表单）；《第一类医疗器械适用法律法规目录》27 项带版本号与受控状态（规则库法规层现成种子）；风险管理报告、设计开发历史文档清单、验证台账；陪审人员安排表；
- **审核端（邝敏威/李雪霞）**：真实结合审核检查表，按"过程/区域 → 负责人 → 审核员 → 条款（Q/E/H 前缀）→ 要求 → 审核证据 → NC/OFI"组织——**证实检查表应预制到"过程级"而非流水账条款级**，证实"条款×过程"模型与 28-36 号设计一致；
- ACM 国际认证合同 50 页（机构端商务条款样本，第三层参考）。

**意外发现**：朋友主业为 Q/E/H 三体系结合审核，13485 只取其法规强绑定部分切入；尚龙为第一类（低风险）案例，Ⅱ/Ⅲ 类深水区样本待补。

## 7. 商业模式与定价

- 按项目/按年付费，拒绝定制合同；自助注册试用；老带新；行业社群 + 内容获客（审核员是最爱转发的群体）；
- 审核员月费锚点 = 一次人日费的零头；企业年费锚点 = 认证费与飞检风险的零头；
- 收入预期现实化：第一站为几百到几千付费用户、年收入几十万量级、毛利近 100%；工具矩阵逐个复制，不做融资故事；
- 12 个月现实预期：先跑通"13485 审核员漏斗 + 首批企业付费"，再谈矩阵。

## 8. 行动计划

**明天拜访专家（弹药已备）**：
1. 请其逐条校 13485 检查单原型——**他改过的每条检查项都是护城河**；
2. 要 Ⅱ/Ⅲ 类高风险企业的检查表与不符合报告样本；
3. 要其工作模板原件（审核计划/检查单）；
4. 问三个钩子：五年后审核员像手艺人还是飞行员 / 预制检查单是抢饭碗还是配仪表 / 准备时间占多少；
5. **只请教、不拉单**（合规边界：不请其推荐客户）；可请其引荐 1-2 个审核员社群。

**90 天节奏**：

| 阶段 | 动作 | 验收 |
|---|---|---|
| 1-2 周 | 功能收敛为单点；落地页 + 试用 demo | 陌生人 5 分钟走完核心流程 |
| 3-4 周 | 检查单按尚龙案例灌入；专家校订 v1；混 3-5 个审核员社群 | ≥10 人完成真实试用 |
| 2 个月 | 上线付费；企业端资料树体检功能 | 首月 ≥50 付费 |
| 3 个月 | 内容起量 + 老带新 | 月增 ≥100 用户 |

## 9. 待验证清单与风险登记

**待验证**（明天/近期向专家或公开渠道核实）：
1. 全国 13485 有效证书量、械企自建需求占比（认 e 云/认可名录）；
2. 可做 13485 的机构数量（名录制，决定第三层上限）；
3. 13485 注册审核员规模（决定漏斗大小）；
4. Ⅱ/Ⅲ 类企业的检查表与 NC 样本；
5. 一个 13485 咨询项目的人力消耗（企业端定价依据）。

**风险**：
1. 规则库四层知识（标准/GMP/法规/经验）共建周期数月到一年——是护城河不是风险，但要按最长时间规划；
2. 产品分类放大模板量（无菌/有源/IVD/植入/软件器械）——只切 1-2 品类；
3. NMPA 法规是活的——产品必须内建法规更新机制（这恰是速度优势）；
4. 圈子小起量慢——专家背书 + 逐条校规则 = 质量换数量；
5. 责任敏感——AI 辅助每步留痕（既是合规也是卖点）。

## 10. 法规/术语速查

认证 vs 审核 / 一阶段·二阶段 / 监督审核（间隔 ≤12 个月，超期暂停证书）/ NC（严重·一般）/ 应然·实然 / 认证决定（专职、非审核组成员）/ 获证组织 / 180 天（全体系合并计）/ 周期年（滚动 12 个月）/ Q/E/H 三体系前缀 / 过程导向检查表 / DHF-DMR-DHR / UDI / YY/T 0287（等同 ISO 13485:2016）。
