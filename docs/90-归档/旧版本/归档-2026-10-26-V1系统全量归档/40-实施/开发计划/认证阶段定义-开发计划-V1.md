# 认证阶段定义 — 开发计划

> **版本**：V1.1 | **日期**：2026-09-12 | **状态**：🔨 开发完成，待用户执行手动步骤后验收
>
> **功能范围**：认证阶段定义（`PhaseDefinition`）—— Foundation 域静态主数据
> **定位**：通用五阶段定义（S1/S2/Surv1/Surv2/Recert），ISO 17021 标准流程阶段
> **关联表**：`cert_phase_definition`、`cert_org_stage`、`cert_standard_phase_config`

## 〇、两条架构铁律

### 铁律① 关联一律走 `Code`

> 定位每条记录的核心字段是 `Code`。所有跨表关联使用 `Code`（业务编码），而非 `Id`（自增主键）。

**当前状态**：
- `cert_org_stage.phase_code` → 引用 `cert_phase_definition.phase_code`（正确）
- `cert_standard_phase_config.phase_id` → 应改为引用 `phase_code`（⚠️ 待确认）
- `audit_task.phase_code` → 应引用 `cert_phase_definition.phase_code`（⚠️ 待确认）

### 铁律② `Code` 与业务编码分离（双键设计）

> `Code` 是系统生成的 **随机 32 位 GUID**（`Guid.NewGuid().ToString("N")`），作为内部关联键；业务编码（`PhaseCode`）是**普通属性**，用于显示和外部引用。

| 表 | `Code` 规范 | 业务编码（独立属性） |
|----|------------|---------------------|
| `cert_phase_definition` | **随机 32 位 GUID**（框架自动填充） | `PhaseCode`（如 S1/S2/Surv1，用户可配） |

## 一、结论摘要

**认证阶段定义是 Foundation 域的单表 CRUD 模块，无树形结构。**

| 维度 | 方案 |
|------|------|
| 控制器基类 | `YzhControllerBase<PhaseDefinition>` |
| 表选择 | 统一使用 `cert_phase_definition`（废弃 `cert_cert_stage`） |
| 实体基类 | 迁移至 `BaseEntity`（非 `EntityBase`） |
| 视图 | 创建 `v_cert_phase_definition` 视图，含状态翻译 |
| 后端工作量 | **~120 行**（实体修正 + 控制器 + JSON 配置） |
| 前端工作量 | **1 API 文件 + 1 Logic 文件 + 1 页面** |
| 数据库工作量 | 重建表（snake_case 化）+ 创建视图 + 插入初始数据 |
| 废弃工作量 | 删除 `CertStage` / `CertStageView` 实体、前端旧 API 和页面 |

> **V1 决策**：统一使用 `cert_phase_definition`（PhaseDefinition 实体），不保留 `cert_cert_stage`。历史关联通过数据库视图兼容，不新增迁移脚本。

## 三、数据库设计

### 3.1 现有表结构分析

#### cert_phase_definition（当前）

| 列名 | 类型 | 说明 | 问题 |
|------|------|------|------|
| `id` | bigint PK | 主键 | PascalCase，不符合 snake_case 规范 |
| `phase_code` | varchar(20) UNIQUE | 阶段编码 | ✅ 已正确 |
| `phase_name` | varchar(100) NOT NULL | 中文名称 | ✅ 已正确 |
| `sequence_order` | int | 顺序 | ✅ 已正确 |
| `description` | text | 阶段说明 | ✅ 已正确 |
| `created_at` | timestamp | 创建时间 | ❌ 缺少审计字段（`create_by`、`update_by` 等） |

**结论**：需重建表，补齐 `BaseEntity` 五件套（`is_valid`、`is_deleted`、`create_by`、`update_by`、`delete_by`），列名改 snake_case。

#### cert_cert_stage（当前，废弃）

| 列名 | 类型 | 说明 | 处理 |
|------|------|------|------|
| `id` | bigint PK | 主键 | 不重建，保留作为兼容视图数据源 |
| `phase_code` | varchar(20) | 阶段编码 | 同上 |
| `phase_name` | varchar(100) | 中文名称 | 同上 |
| `sort_order` | int | 排序 | 同上 |
| `category` | varchar(50) | 分类 | 同上 |

**结论**：不删除，通过视图兼容迁移。`cert_cert_stage` 数据迁移到 `cert_phase_definition` 后，建立 `v_cert_phase_definition` 视图（UNION ALL 或直接 SELECT FROM cert_cert_stage）。

### 3.2 新建表结构（snake_case 化，纯 Code 关联）

> **铁律**：表内不含任何 `*_id` 关联字段，所有关联通过 `Code` 字段。

```sql
-- ============================================================
--  cert_phase_definition（重建，snake_case + 补齐审计字段）
--  来源：docs/20-体系认证/02-数据库设计/数据库表设计-V2.md §A-04
--  约束：不含任何 Id 型关联字段，仅用 Code 关联
-- ============================================================
CREATE TABLE IF NOT EXISTS cert_phase_definition (
    id              bigint       NOT NULL AUTO_INCREMENT PRIMARY KEY,
    code            varchar(36)  NOT NULL UNIQUE COMMENT '业务编码(Guid)，内部关联键',
    phase_code      varchar(20)  NOT NULL UNIQUE COMMENT '阶段编码(S1/S2/Surv1/Surv2/Recert)，业务标识',
    phase_name      varchar(100) NOT NULL COMMENT '中文名称',
    sequence_order  int          NOT NULL DEFAULT 0 COMMENT '顺序(1=S1, 2=S2, 3=一监, 4=二监, 5=再认证)',
    description     text         COMMENT '阶段说明',
    is_valid        int          NOT NULL DEFAULT 1 COMMENT '有效标志(1=启用, 0=停用)',
    create_time     datetime     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    create_by       varchar(50)  COMMENT '创建人编码',
    update_time     datetime     COMMENT '更新时间',
    update_by       varchar(50)  COMMENT '更新人编码',
    delete_time     datetime     COMMENT '删除时间',
    delete_by       varchar(50)  COMMENT '删除人编码',
    is_deleted      tinyint      NOT NULL DEFAULT 0 COMMENT '软删除标志',
    UNIQUE KEY uk_code (code),
    UNIQUE KEY uk_phase_code (phase_code),
    KEY idx_is_valid (is_valid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='认证阶段定义（通用五阶段，ISO 17021）';
```

### 3.3 创建视图（v_cert_phase_definition）

```sql
-- ============================================================
--  v_cert_phase_definition（含 StatusName 字典翻译）
--  用于列表查询，LEFT JOIN 字典翻译
-- ============================================================
CREATE OR REPLACE VIEW v_cert_phase_definition AS
SELECT
    p.id,
    p.code,
    p.phase_code,
    p.phase_name,
    p.sequence_order,
    p.description,
    p.is_valid,
    p.create_time,
    p.create_by,
    p.update_time,
    p.update_by,
    p.delete_time,
    p.delete_by,
    p.is_deleted,
    CASE p.is_valid WHEN 1 THEN '启用' ELSE '停用' END AS status_name
FROM cert_phase_definition p;
```

### 3.4 旧表清理（cert_cert_stage）

> **架构铁律**：所有关联字段只用 `Code`，禁止保留 `Id` 型关联字段（含冗余）。

| 旧表 | 处理策略 | 关联字段清理 |
|------|---------|-------------|
| `cert_cert_stage` | **删除**（数据已废弃，无活跃引用） | 删除表本身 |
| `cert_org_stage` | 保留，修正关联 | `stage_id`（如有）→ 删除，只用 `phase_code` |
| `cert_standard_phase_config` | 保留，修正关联 | `phase_id`（如有）→ 删除，只用 `phase_code` |
| `audit_task` | 保留，修正关联 | `stage_id`（如有）→ 删除，只用 `phase_code` |

**执行顺序**：
1. 先确认 `cert_cert_stage` 无数据（或已迁移）
2. 执行删除脚本
3. 检查下游表，修正所有 `*_id` 关联字段为 `*_code`

### 4.2 控制器（PhaseDefinitionController.cs）

**路径**：`src/certplatform-api/CertPlatform.Admin/Controllers/Foundation/PhaseDefinitionController.cs`

```csharp
using CertPlatform.Shared.Entities.Cert;
using YZH.Core.Api.Controllers;
using YZH.Core.Api.Services;
using YZH.Core.Stand.Helpers;
using YZH.Core.Stand.Models;

namespace CertPlatform.Admin.Controllers.Foundation;

[ApiController]
[Route("api/Foundation/[controller]")]
public class PhaseDefinitionController : YzhControllerBase<PhaseDefinition>
{
    public PhaseDefinitionController(
        EntityService<PhaseDefinition> entityService,
        IUserContext userContext)
        : base(entityService, userContext) { }

    /// <summary>
    /// 新增前校验：PhaseCode 唯一性
    /// </summary>
    protected override async Task<(bool ok, string? msg)> OnBeforeAdd(PhaseDefinition entity)
    {
        var exists = await Entity.ExistsAsync(p => p.PhaseCode == entity.PhaseCode);
        if (exists.Data)
            return (false, $"阶段编码【{entity.PhaseCode}】已存在");
        return (true, null);
    }

    /// <summary>
    /// 修改前校验：PhaseCode 唯一性（排除自身）
    /// </summary>
    protected override async Task<(bool ok, string? msg)> OnBeforeUpdate(PhaseDefinition entity)
    {
        var exists = await Entity.ExistsAsync(p =>
            p.Id != entity.Id && p.PhaseCode == entity.PhaseCode);
        if (exists.Data)
            return (false, $"阶段编码【{entity.PhaseCode}】已存在");
        return (true, null);
    }

    /// <summary>
    /// 查询后：翻译状态
    /// </summary>
    protected override void OnQueried(PagedResult<PhaseDefinition> result)
    {
        foreach (var item in result.Items)
            item.StatusName = item.IsValid == 1 ? "启用" : "停用";
    }
}
```
