## 1. 设计基线（本轮确认的修正）

| # | 修正项 | 界面设计处置 |
|---|---|---|
| 1 | 关注核心是企业，不是任务 | 工作台/企业列表以**企业为行维度**，每家企业显示**最近一个任务的状态**（刚开启/执行中/已结束） |

## 4. 核心页面设计

### 4.1 工作台（企业维度关注视图）

**设计要点**：以企业为行维度，每个企业卡片显示**最近一个任务的状态**；顶部待办聚合条汇总需人工介入的状态。

```
┌──────────────────────────────────────────────────────────────┐
│ 工作台                                                        │
│                                                              │
│ [待办聚合条]                                                  │
│   待复核 1 | 排队中 2 | NC逾期 1 | 资料待确认 3 | 失败重试 1   │
│                                                              │
│ 我的企业（最近活跃排序）                                       │
│ ┌────────────────────────────────────────────────────────┐  │
│ │ 企业A   ISO9001 + ISO14001     企业编号 ENT-2026-001   │  │
│ │ 最近任务：NC检查 · 待复核       阶段：初次认证·进行中    │  │
│ │ 资料 12/15 | 剩余次数 8                                │  │
│ │ [进入企业] [发起任务]                                   │  │
│ └────────────────────────────────────────────────────────┘  │
│ ┌────────────────────────────────────────────────────────┐  │
│ │ 企业B   ISO9001               企业编号 ENT-2026-002   │  │
│ │ 最近任务：报告 · 已完成        阶段：监督审核·进行中    │  │
│ │ 资料 8/8 | 剩余次数 8                                 │  │
│ │ [进入企业] [发起任务]                                   │  │
│ └────────────────────────────────────────────────────────┘  │
│ [+ 新建企业]                                                │
└──────────────────────────────────────────────────────────────┘
```

**字段说明**

| 区块 | 内容 | 交互 |
|---|---|---|
| 待办聚合条 | 各状态数量，点击跳对应列表（按企业过滤） | 无待办时折叠 |
| 企业卡片-最近任务 | 任务类型 + 状态徽标（排队/执行/成功/待复核/失败/已完成） | 点击进入对应任务 |
| 企业卡片-阶段 | 阶段名 + 阶段状态 | — |
| 资料进度 | 已归档/清单总数 | 点击进入资料库 |
| 进入企业 | 进入企业详情 | 主操作 |
| 发起任务 | 下拉：NC检查 / 报告（仅进行中阶段） | 余额不足时拦截 |

**空态**：无企业时展示引导新建企业。

```
┌──────────────────────────────────────────────────────────────┐
│ NC检查任务详情   状态：待复核   企业：企业A   标准：ISO9001     │
│ 概览 | 资料管理 | 检查结果 | 溯源 | 执行轨迹 | 变更记录        │
│ ┌────────────────────────────────────────────────────────┐  │
│ │ 自动结果区（队列产出，只读 + 来源标注）                 │  │

│ │ 7.5 成文信息          不符合 ✗ → 建议开NC              │  │
│ │ 9.1 监视测量          警告 ⚠ → 资料不全，建议补充      │  │
│ └────────────────────────────────────────────────────────┘  │
│ ┌────────────────────────────────────────────────────────┐  │
│ │ 人工复核区                                            │  │
│ │ [逐条确认] [修正判定] [开NC] [调整严重度] [补充证据]    │  │
│ │ [打开企业资料库]（直达并定位引用文件）                 │  │
│ └────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘
```

- Tab 概览：任务基本信息、状态机、扣次信息（已扣/退回）
- Tab 资料管理：该任务引用的资料（企业基础资料 + 阶段资料两段）
- Tab 检查结果：自动结果 + 人工修订对照（diff 展示，修订留痕）
- Tab 溯源：结论 → 证据文件 → 条款链路
- Tab 执行轨迹：队列步骤、AI 调用、失败原因
- Tab 变更记录：操作日志时间线

**NC 整改**（结论确认后）：NC 列表 → 状态 open → rectifying → rectified → pending_verification → closed；整改证据回传（协同系统上线前审核员代传）。

## 6. 关键交互规则

1. **余额不足拦截**：发起 NC/报告时若剩余次数为 0，弹窗提示并引导个人中心充值（充值预留，提示"开发中"）；≤3 次顶栏弱提醒
2. **异步状态刷新**：任务状态 MVP 轮询刷新（间隔可配置），刷新后自动更新徽标；无实时推送依赖
