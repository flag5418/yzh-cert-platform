## 一、阶段全景与 3 年周期事件序列

### 1.1 一次认证从申请到颁证（初次认证）

```
申请/建档 → 申请评审 → 一阶段审核（文件/策划审核） → 二阶段审核（现场审核）
        → 认证决定（CD） → 颁发证书（CE，3 年有效期）
```

### 1.2 3 年周期内的事件序列（ISO 9001 类标准流程）

```
第 0 年  6月  一阶段审核 S1（文件审核）
       9月  二阶段审核 S2（现场审核）
      11月  认证决定 CD / 颁发证书 CE（3 年有效期）
第 1 年  6月  首次监督审核 SV-1
第 2 年  6月  第二次监督审核 SV-2
第 3 年  6月  第三次监督审核 SV-3（若有）
第 3 年  9月  再认证 RC（= 一阶段 + 二阶段合并，完整审核）→ 新周期开始
```

> 数据与轮次口径见 `11-认证周期业务全景图-V1.md`（3 年 ≈ 24 个任务 / 企业 / 标准）。
> 该文 §6 周期模型（方案 A/B/C）状态为「本期不做、预留字段」，与本文不冲突。

## 二、★ 阶段 × NC × 报告产出矩阵（核心结论）

> 用户 2026-10-08 确认：**现场审核阶段（二阶段 / 监督 / 再认证 / 特殊审核）出 NC + 各自审核报告**；
> 一阶段只出「发现 / 关注事项」，不构成正式 NC；认证决定是决定记录，不出 NC。

| # | 阶段 / 事件 | 17021 阶段口径 | 出 NC？ | 产出报告 / 记录 | 标准依据（待原文复核） |
|---|---|---|:---:|---|---|
| 1 | 申请 / 建档 | 流程（非审核活动） | 否 | 申请评审记录 | — |
| 2 | 申请评审 | 流程 | 否 | 评审记录（受理/不受理） | — |
| 3 | 一阶段审核（S1，文件与策划审核） | 初审第一阶段 | **否**（只出发现/关注事项，**不叫 NC**） | 一阶段审核报告 / 发现清单 | 17021-1 §9.3.1.2.3 |
| 4 | 二阶段审核（S2，现场审核） | 初审第二阶段 | **是** | **初审审核报告**（含 NC 清单） | 17021-1 §9.3.1.3 |
| 5 | 预审（可选，行业实践） | 非 17021 强制 | 通常不作正式 NC | 预审发现记录（不作认证决定依据） | 行业实践 |
| 6 | 监督审核（SV） | 认证周期内至少 12 个月一次 | **是** | **监督审核报告** | 17021-1 §9.6.2 |
| 7 | 再认证审核（RC） | 证书到期前完成（= S1+S2 合并） | **是** | **再认证审核报告** | 17021-1 §9.6.3 |
| 8 | 特殊审核（有需求时临时加场） | 现场审核 | **是** | **特殊审核报告** | 17021-1 §9.3.3 |
| 9 | 认证决定（CD） | 决定活动 | 否 | **认证决定记录**（推荐/不予推荐） | 17021-1 §9.5.3 |
| 10 | 颁发证书（CE） | 证书签发 | 否 | 证书（3 年有效期） | 17021-1 §8.5 |
| 11 | 暂停 / 撤销 / 注销（证后监管） | 行政处置 | 否 | 证书状态变更记录 | 17021-1 §8.7 / §8.8 |
| 12 | 申诉 / 投诉处理 | 独立过程 | 否 | 投诉处理记录 | 17021-1 §9.7 |

**读矩阵的三条规则**：

1. **「出 NC」= 现场（或等效远程）审核活动**；一阶段是文件/策划审核，其发现只能记为「发现 / 关注事项」，**不得写成 NC**。
2. **「出报告」= 每次审核活动都出报告**，但报告类型随阶段不同（初审 / 监督 / 再认证 / 特殊），**不得合并成一份通用报告**。
3. **非审核活动（申请、决定、颁证、状态变更、投诉）只出记录，既不出 NC 也不出审核报告。**

### 2.1 NC 与报告的条款约束（衔接同层文档）

| 约束 | 要点 | 参见 |
|---|---|---|
| NC 必含四要素 | 审核准则 / 不符合描述 / 客观证据 / 严重度（major·minor·observation） | [`ISO体系认证NC与报告标准约束-V1.md`](./ISO体系认证NC与报告标准约束-V1.md) §2.3 |
| 报告必含七要素 | 目标 / 范围 / 准则 / 日期地点 / 审核组 / 发现 / 结论 | 同上 §3.1（17021-1 §9.4.6） |
| NC 生命周期 | 发现 → 记录 → 企业整改 → 跟踪验证 → 关闭（或升级） | 同上 §2.5 |
| 报告章节沿用 | 「审核准则」等章节跨事件 80% 相同 → 必须支持沿用 | `11-认证周期业务全景图-V1.md` §5 |

## 三、时限与强制覆盖规则

| 规则 | 数值 | 适用阶段 | 标准依据（待原文复核） |
|---|---|---|---|
| 初审 NC 整改与验证时限 | **≤ 3 个月**（超期须重新安排相关阶段审核） | 初审（S2 后） | 17021-1 §9.6.2 |
| 监督 NC 整改与验证时限 | **≤ 2 个月** | 监督 | 17021-1 §9.6.2 |
| 首次监督审核时限 | 颁证后 **≤ 12 个月**（认证周期内至少一次） | 监督 | 17021-1 §9.6.2 |
| 再认证时限 | 证书到期前完成；**过期 6 个月**未完成 → 至少重做二阶段 | 再认证 | 17021-1 §9.6.3.2.5 |
| 监督审核强制覆盖 | **上次全部 NC 的验证 + 内部审核 + 管理评审 + 投诉处理 + 上次遗留事项**（范围可缩小，但这些不可省） | 监督 | 17021-1 §9.6.2 / 认证实施规则 |

> 对设计的直接影响：监督审核的检查范围**「可缩小」是常态、不是例外**，但必须**强制包含**上述 5 类项
> —— 任务中心「范围推荐」功能（11 号 B6）即以此为依据。

## 六、术语（本页口径）

| 术语 | 含义 | 本平台 |
|---|---|---|
| 阶段（Stage） | 认证过程中的一个环节（审核活动或流程环节） | `cert_cert_stage` 行 |
| 分类（Category） | 阶段所属大类：流程 / 审核 / 证后 | `stage_category` 字典值 |
| 发现 / 关注事项 | 一阶段的输出，**不构成 NC** | 尚未建模（Q1/Q3 范围） |
| NC（不符合项） | 未满足要求，必含四要素 | NC 规则 / NC 检查结果模块 |
| T+V | 读写分离：读视图 `v_cert_stage`、写物理表 `cert_cert_stage` | `CertStageView` + `CertStage` |
