# 用户权限统一接口设计（V1）

> **版本**：V1.0 | **日期**：2026-09-09 | **状态**：设计定稿
>
> 本文档定义：认证平台用户权限统一接口的完整设计方案，提供用户可见数据范围的统一查询入口。
> **核心目标**：避免业务接口重复实现权限过滤逻辑，前端通过统一接口获取权限相关数据。
> **本文件为用户权限接口相关开发的唯一权威表述**；权限接口代码必须对齐本文。

---

## 〇、设计背景与问题

### 0.1 当前问题

在体系认证系统中，不同角色的用户可见数据范围不同：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           问题场景                                       │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  场景 1：维护人员只能看到自己维护的标准                                  │
│  ─────────────────────────────────────────────────────────────          │
│  - ISOStandardController.GetList() → 需要过滤标准                     │
│  - ISOClauseController.GetList() → 需要过滤条款                       │
│  - PhaseDefinitionController.GetList() → 需要过滤阶段                 │
│  ─ 重复实现相同的权限过滤逻辑                                          │
│                                                                         │
│  场景 2：审核员只能看到自己所在机构的企业                                │
│  ─────────────────────────────────────────────────────────────          │
│  - EnterpriseController.GetList() → 需要过滤企业                      │
│  - AuditTaskController.GetList() → 需要过滤任务                       │
│  ─ 重复实现相同的权限过滤逻辑                                          │
│                                                                         │
│  场景 3：前端下拉选择框需要限制可选范围                                  │
│  ─────────────────────────────────────────────────────────────          │
│  - 选择标准：只能选维护人员可维护的标准                                 │
│  - 选择审核员：只能选本机构的审核员                                     │
│  - 选择企业：只能选本机构的企业                                         │
│  ─ 每个页面都要重复实现权限过滤                                        │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 0.2 解决方案

**引入统一的用户权限接口**，前端通过一个统一入口获取所有权限相关数据：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        统一权限接口方案                                   │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  前端调用                                                                │
│  ─────────────────────────────────────────────────────────────          │
│  GET /api/UserPermission/accessible-standards    → 获取可见标准         │
│  GET /api/UserPermission/accessible-orgs         → 获取可见机构         │
│  GET /api/UserPermission/accessible-auditors     → 获取可见审核员       │
│  GET /api/UserPermission/accessible-enterprises  → 获取可见企业         │
│                                                                         │
│  后端统一处理                                                            │
│  ─────────────────────────────────────────────────────────────          │
│  UserPermissionController                                                  │
│       ↓                                                                  │
│  UserPermissionService (权限过滤逻辑只实现一次)                           │
│       ↓                                                                  │
│  返回结果给前端                                                          │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 一、架构设计

### 1.1 分层架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           架构分层                                       │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│   YZH.Core（通用框架，不修改）                                           │
│   ─────────────────────────────────────────────────────────────         │
│   ▪ UserContext（基础用户上下文）                                        │
│   ▪ JwtHelper（Token 生成/校验）                                         │
│   ▪ YzhAuthFilter（认证中间件）                                          │
│                                                                         │
│   CertPlatform.Shared（项目层）                                          │
│   ─────────────────────────────────────────────────────────────         │
│   ▪ CertUserContext（继承 UserContext，扩展业务字段）                    │
│   ▪ IUserPermissionService（权限服务接口）                               │
│   ▪ DTO 定义（OrgDto, StandardDto, AuditorDto 等）                     │
│                                                                         │
│   CertPlatform.Admin（业务层）                                           │
│   ─────────────────────────────────────────────────────────────         │
│   ▪ UserPermissionController（统一权限接口控制器）                       │
│   ▪ UserPermissionService（权限服务实现）                                │
│   ▪ 业务 Controller（复用权限服务）                                      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 1.2 核心原则

| 原则 | 说明 |
|------|------|
| **统一入口** | 所有权限相关数据通过 `/api/UserPermission/*` 获取 |
| **不修改 YZH.Core** | 框架保持通用性，所有扩展在项目层实现 |
| **代码复用** | 权限过滤逻辑只实现一次，多处复用 |
| **按需加载** | 前端只请求需要的数据，避免冗余 |
| **前后端分离** | 前端不关心权限逻辑，只关心数据范围 |

#### 2.2.2 获取可见机构列表

```csharp
// GET /api/UserPermission/accessible-orgs
[HttpGet("accessible-orgs")]
public async Task<IActionResult> GetAccessibleOrgs()
{
    var user = _userContext.GetCurrent() as CertUserContext;
    var orgs = await _permissionService.GetAccessibleOrgsAsync(user);
    return Ok(ApiResponse.Ok(orgs));
}

// 权限逻辑
public async Task<List<OrgDto>> GetAccessibleOrgsAsync(CertUserContext user)
{
    // SuperAdmin/Admin：返回全部机构
    if (user.RoleIds.Contains(RoleIds.SuperAdmin) || user.RoleIds.Contains(RoleIds.Admin))
    {
        return await _db.Queryable<SysOrganization>()
            .Where(o => o.Enable == 1 && o.IsDeleted == 0)
            .Select(o => new OrgDto { Code = o.Code, Name = o.OrgName, ParentCode = o.ParentCode })
            .ToListAsync();
    }
    
    // 其他角色：返回本机构及子机构
    if (user.OrgCodes != null)
    {
        return await _db.Queryable<SysOrganization>()
            .Where(o => user.OrgCodes.Contains(o.Code))
            .Select(o => new OrgDto { Code = o.Code, Name = o.OrgName, ParentCode = o.ParentCode })
            .ToListAsync();
    }
    
    return new List<OrgDto> { new OrgDto { Code = user.OrgCode, Name = "" } };
}
```

```csharp
public async Task<IActionResult> GetAccessibleStandards()

                Category = s.Category

            .ToListAsync();

        .Select(s => new StandardDto

            Code = s.StandardCode, 
            Name = s.StandardName,
            Category = s.Category
        })
```

#### 2.2.4 获取可分配审核员列表

```csharp
// GET /api/UserPermission/accessible-auditors
[HttpGet("accessible-auditors")]
public async Task<IActionResult> GetAccessibleAuditors()
{
    var user = _userContext.GetCurrent() as CertUserContext;
    var auditors = await _permissionService.GetAccessibleAuditorsAsync(user);
    return Ok(ApiResponse.Ok(auditors));
}

// 权限逻辑
public async Task<List<AuditorDto>> GetAccessibleAuditorsAsync(CertUserContext user)
{
    // 审核组长：只返回本组审核员
    if (user.RoleIds.Contains(RoleIds.TeamLead) && !string.IsNullOrEmpty(user.TeamCode))
    {
        return await _db.Queryable<AuditorProfile>()
            .Where(a => a.TeamCode == user.TeamCode)
            .Select(a => new AuditorDto 
            { 
                Code = a.Code,
                Name = a.AuditorName,
                TeamCode = a.TeamCode,
                ProfessionalField = a.ProfessionalField
            })
            .ToListAsync();
    }
    
    // 机构管理员：返回本机构及子机构审核员
    if (user.IsOrgAdmin() && user.OrgCodes != null)
    {
        return await _db.Queryable<AuditorProfile>()
            .Where(a => user.OrgCodes.Contains(a.OrgCode))
            .Select(a => new AuditorDto 
            { 
                Code = a.Code,
                Name = a.AuditorName,
                TeamCode = a.TeamCode,
                ProfessionalField = a.ProfessionalField
            })
            .ToListAsync();
    }
    
    return new List<AuditorDto>();
}
```

### 5.2 Composable 封装

```typescript
// 文件位置：src/certplatform-web/admin/src/composables/useUserPermission.ts
import { ref, computed } from 'vue';
import { userPermissionApi } from '@/api/userPermission';
import type { UserInfoDto, StandardDto, AuditorDto } from '@/types/api';

export function useUserPermission() {
  const userInfo = ref<UserInfoDto | null>(null);
  const accessibleStandards = ref<StandardDto[]>([]);
  const accessibleAuditors = ref<AuditorDto[]>([]);
  
  // 加载用户信息
  const loadUserInfo = async () => {
    const res = await userPermissionApi.getUserInfo();
    userInfo.value = res.data;
  };
  
  // 加载可见标准
  const loadAccessibleStandards = async () => {
    const res = await userPermissionApi.getAccessibleStandards();
    accessibleStandards.value = res.data;
  };
  
  // 加载可见审核员
  const loadAccessibleAuditors = async () => {
    const res = await userPermissionApi.getAccessibleAuditors();
    accessibleAuditors.value = res.data;
  };
  
  // 判断是否有编辑权限
  const canEdit = computed(() => {
    return userInfo.value?.roleIds.some(r => r === 10 || r === 1) ?? false;
  });
  
  // 判断是否有发布权限
  const canPublish = computed(() => {
    return userInfo.value?.roleIds.some(r => r === 10 || r === 1) ?? false;
  });
  
  return {
    userInfo,
    accessibleStandards,
    accessibleAuditors,
    loadUserInfo,
    loadAccessibleStandards,
    loadAccessibleAuditors,
    canEdit,
    canPublish,
  };
}
```

## 九、与现有架构的关系

### 9.1 与 CertUserContext 的关系

```
CertUserContext（数据权限体系设计）
    └── 提供：用户角色、机构编码、维护范围等上下文信息
          ↓
UserPermissionService（本设计）
    └── 使用：CertUserContext 中的信息进行权限过滤
          ↓
返回：可见数据列表（供前端使用）
```

### 9.2 与数据权限扩展的关系

```
DataScopeExtensions（SqlSugar 查询扩展）
    └── 用于：业务查询时的数据行过滤
          ↓
UserPermissionService（本设计）
    └── 用于：前端下拉选择时的数据范围限制
```

**两者互补**：
- `DataScopeExtensions`：后端查询时过滤数据行
- `UserPermissionService`：前端获取可选数据范围
