## 开发指引

### 后端开发

1. **认证/授权**：参考 `多角色复杂权限体系设计-V1.md`
2. **数据查询**：使用 `DataScopeExtensions` 扩展方法
3. **前端数据接口**：实现 `IUserPermissionService` 接口

### 前端开发

1. **权限判断**：使用 `usePermission()` Composable
2. **下拉选择**：调用 `/api/UserPermission/*` 接口获取可选范围
3. **按钮控制**：使用 `v-permission` 指令

---

## 注意事项

- ✅ 所有权限相关代码不得修改 YZH.Core
- ✅ 扩展方法在 `CertPlatform.*` 项目中实现
- ✅ 新角色/新权限需同步更新三文档
- ✅ 接口变更需同步更新前端 API 封装
