## 二、需要做的改动

### 2.1 编码规则简化

**文件编码简化：**
```csharp
// 原版（CodeGeneratorService.cs 第84-91行）
public string GenerateFileCode(string folderCode, string fileName, string fileType)
{
    var hash = ComputeFileNameHash(fileName);
    return $"FL-{folderCode}|{hash}|v1";
}

// 简化版
public string GenerateFileCode(string folderCode, string fileName)
{
    return $"FL-{folderCode}|{fileName}";
}
```

**存储路径简化：**
```csharp
// 原版（CodeGeneratorService.cs 第96-108行）
public string GenerateStoragePath(string standardCode, string phaseCode, 
                                   string cbCode, string folderCode, 
                                   string fileName, string fileHash, int version)
{
    var versionDir = $"{fileName}-{fileHash}-v{version}";
    return $"/{standardCode}/{phaseCode}/{cbCode}/{cleanFolder}/{versionDir}/{fileName}";
}

// 简化版
public string GenerateStoragePath(string standardCode, string phaseCode, 
                                   string folderCode, string fileName)
{
    var cleanFolder = folderCode.Replace("|", "-");
    return $"/{standardCode}/{phaseCode}/{cleanFolder}/{fileName}";
}
```

## 四、页面功能说明

### 4.1 左栏：机构-标准-阶段树

```
树结构:
├── 🏢 CB001-某认证机构
│   ├── 📋 ISO 9001:2015
│   │   ├── 📅 初审 (PH01)
│   │   ├── 📅 监督审核1 (PH02)
│   │   └── 📅 再认证 (PH03)
│   └── 📋 ISO 13485:2016
│       └── 📅 初审 (PH01)
└── 🏢 CB002-另一机构
    └── ...
```

**交互：**
- 点击阶段节点 → 右侧加载该阶段的文件夹和文件
- 节点显示统计徽章（文件数量）

### 4.2 右栏：文件管理区

**顶部操作栏：**
- 新建文件夹
- 上传文件（支持拖拽）
- 导出打包
- 全选/删除
- 使用帮助

**文件列表：**
- 文件夹图标 + 名称
- 文件图标 + 名称 + 大小 + 修改时间
- 操作按钮：替换、下载、删除、重命名

**底部状态栏：**
- 共 X 项 | 文件夹 X 个，文件 X 个
- 总大小 XX MB

## 五、API对接说明

### 5.1 获取机构-标准-阶段树

**请求：**
```
GET /api/standard-directory/organization-tree
```

**响应：**
```json
{
  "status": 0,
  "data": [
    {
      "code": "CB001",
      "name": "某认证机构",
      "type": "organization",
      "children": [
        {
          "code": "ISO9001",
          "name": "ISO 9001:2015",
          "type": "standard",
          "children": [
            {
              "code": "PH01",
              "name": "初审",
              "type": "phase",
              "directoryCode": "SDC-ISO9001|PH01",
              "fileCount": 24
            }
          ]
        }
      ]
    }
  ]
}
```

### 5.2 获取文件夹列表

**请求：**
```
GET /api/standard-directory/configs/{directoryCode}/folders
```

**响应：**
```json
{
  "status": 0,
  "data": [
    {
      "code": "FD-SDC-ISO9001|PH01|L01|S001",
      "name": "企业基础资料",
      "parentCode": null,
      "depth": 1,
      "childCount": 3,
      "fileCount": 5,
      "children": [...]
    }
  ]
}
```

### 5.3 获取文件列表

**请求：**
```
GET /api/standard-directory/folders/{folderCode}/files
```

**响应：**
```json
{
  "status": 0,
  "data": {
    "rows": [
      {
        "code": "FL-FD-SDC-ISO9001|PH01|L02|S001|营业执照正本.pdf",
        "fileName": "营业执照正本.pdf",
        "fileType": "pdf",
        "fileSize": 2411724,
        "storagePath": "/standard-directory/CB001/ISO9001/PH01/企业基础资料/营业执照正本.pdf",
        "createDate": "2024-03-10T14:22:05"
      }
    ],
    "total": 3
  }
}
```

### 5.4 批量上传（实际使用 upload-init / upload-file-v2 / upload-confirm / upload-cancel 四段式）

```
POST /api/standard-directory/upload-init       # 提交清单，返回增强清单（含 fileCode/storagePath/taskId）
POST /api/standard-directory/upload-file-v2    # 按清单逐个上传文件（FormData: file/fileCode/storagePath/taskId）
POST /api/standard-directory/upload-confirm    # 确认完成，激活 IsValid，.doc/.xls 自动入转换队列
POST /api/standard-directory/upload-cancel     # 彻底清理本次上传（DB + MinIO，取消=彻底清理）
```

### 5.5 导出打包

**请求：**
```
POST /api/standard-directory/configs/{directoryCode}/export
```

**响应：**
返回ZIP文件流
