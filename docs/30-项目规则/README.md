### 规范速查

| 规则 | 内容 |
|------|------|
| 属性名 | = 数据库列名 = PascalCase JSON 字段名（YZH 铁律） |
| 业务主键 | 一律用 `Code`；`Id` 仅用于自增排序 |
| 三层同构 | Controller 路径 = 前端 API 路径 = 前端 Pages 路径 |
| 文档命名 | 强制 `-V1` 后缀 |
| 业务实体 | 不得与框架内置实体同名（`Sys_User` 等，见框架 `BizNamingRules`） |
| 数据库脚本 | 统一放 `scripts/db/`，禁止散落 |

## 四、维护约定

1. **规范类文档**修改需谨慎——它们被 AI 与开发者直接依赖，改动前确认影响面。
2. **踩坑记录**按 `YYYY-MM-DD_简述.md` 命名，追加不修改。
3. 发现规范与实现不一致时，**先更新规范**，再改代码（文档即宪法）。
4. 规范失效后**不删除**，移入 [`90-归档/旧版本/`](../90-归档/旧版本)。
