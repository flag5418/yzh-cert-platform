# YZH 知识库

**用途**：YZH.Core 新架构开发的知识底座，为 AI 编程助手和开发者提供结构化参考（接口签名、边界约束、踩坑经验、速查表）。
**维护原则**：随发现持续补充，每条目自包含、有接口签名、有代码示例。
**层级定位**：`10-YZH架构/` 讲框架的设计原理，`30-项目规则/` 根级规范讲编码时必须遵守的规则，本目录只放"按需查阅"的知识条目（层入口见 [`../README.md`](../README.md)）。

## 使用约定

每个知识条目必须包含：
- **文件位置**：项目中的具体路径
- **接口签名**：方法名 + 参数 + 返回值
- **依赖**：依赖哪些模块
- **约束**：调用前提、副作用
- **示例**：最小可用代码片段
- **状态**：[DONE] / [TODO:P1] / [PLAN]

禁止只写概念不写接口签名。
