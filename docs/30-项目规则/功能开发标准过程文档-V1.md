## 三、数据库变更流程

### 3.1 变更原则

1. **新建表**：必须包含审计字段（`create_date`、`modify_date`、`delete_time`、`create_by`、`update_by`、`delete_by`）
2. **外键关联**：统一使用 `code` 字段关联（非 `id`）
3. **软删除**：通过 `enable` 或 `delete_time` 实现，不物理删除
4. **字典支持**：下拉选项必须对应 `Sys_Dictionary` / `Sys_DictionaryList`

### 3.2 SQL 脚本存放

```
DB/mysql/
├── {module}_create.sql           -- 建表脚本
├── {module}_view.sql             -- 视图脚本
├── {module}_init_data.sql        -- 初始数据（字典、配置）
└── {module}_fix_{version}.sql    -- 修复脚本
```

### 3.3 执行流程

```bash
# Step 1: 连接数据库
mysql -u root -p certplatform < DB/mysql/iso_standard_view.sql

# Step 2: 验证
mysql -u root -p certplatform -e "SELECT COUNT(*) FROM v_iso_standard;"

# Step 3: 确认字典存在
mysql -u root -p certplatform -e "SELECT * FROM Sys_Dictionary WHERE DicNo IN ('iso_category', 'standard_status');"
```

## 四、后端开发流程

### 4.1 控制器开发

#### 文件位置

```
src/certplatform-api/CertPlatform.Admin/Controllers/{Domain}/{Type}Controller.cs
```

#### 标准模板

```csharp
extern alias SharedEntities;

using Microsoft.AspNetCore.Mvc;
using YZH.Core.Api.Controllers;
using YZH.Core.Api.Services;
using YZH.Core.Stand.Helpers;
using YZH.Core.Stand.Models;
using YZH.Core.Stand.Models.Config;
using YZH.Core.Stand.Interfaces;

namespace CertPlatform.Admin.Controllers.{Domain};

[ApiController]
[Route("api/{Domain}/[controller]")]
public class {Type}Controller : YzhControllerBase<SharedEntities::YZH.Entity.Admin.Platform.{Domain}.{Type}>
{
    public {Type}Controller(
        EntityService<SharedEntities::YZH.Entity.Admin.Platform.{Domain}.{Type}> entityService,
        IUserContext userContext)
        : base(entityService, userContext)
    {
    }

    /// <summary>
    /// 加载 EntityConfig 配置
    /// </summary>
    protected override EntityConfig LoadConfig()
    {
        return EntityConfigHelper.GetConfig<SharedEntities::YZH.Entity.Admin.Platform.{Domain}.{Type}>();
    }

    // 可选：覆盖钩子方法
    // protected override async Task<(bool ok, string? msg)> OnBeforeAdd(...) { ... }
    // protected override async Task<(bool ok, string? msg)> OnBeforeUpdate(...) { ... }
    // protected override async Task<(bool ok, string? msg)> OnBeforeDelete(...) { ... }
}
```

#### 路由规范

| 控制器 | 路由前缀 | 说明 |
|--------|---------|------|
| `Controllers/System/UserController.cs` | `/api/System/User` | 系统域 |
| `Controllers/Foundation/ISOStandardController.cs` | `/api/Foundation/ISOStandard` | 基础信息域 |
| `Controllers/Workflow/EnterpriseController.cs` | `/api/Workflow/Enterprise` | 工作流域 |

#### 添加 extern alias

新控制器需在 `.csproj` 文件中添加：

```xml
<ItemGroup>
  <Reference Include="CertPlatform.Shared">
    <Aliases>SharedEntities</Aliases>
  </Reference>
</ItemGroup>
```

### 4.2 EntityConfig JSON

#### 文件位置

```
src/yzh-core/YZH.Core.Web/Assets/EntityConfigs/{Domain}/{Type}.json
```

#### 字段说明

| 属性 | 类型 | 说明 |
|------|------|------|
| `Title` | string | 页面标题 |
| `FillMode` | string | 弹窗填充模式（`AutoFix` / `Manual`） |
| `FormCols` | int | 弹窗表单列数 |
| `Columns` | array | 列/字段配置数组 |

#### Column 配置

| 属性 | 类型 | 说明 |
|------|------|------|
| `FieldName` | string | 实体属性名 |
| `DesName` | string | 显示名称 |
| `Type` | string | 控件类型（`TextBox` / `Number` / `DropDownList` / `Memo` / `DateTimePicker`） |
| `Sxh` | int | 排序号 |
| `XsFlag` | bool | 是否表格显示 |
| `BcFlag` | bool | 是否持久化（参与保存） |
| `Yxk` | bool | 是否可编辑（false=只读） |
| `Width` | int | 列宽 |
| `Row` / `Col` | int | 表单网格位置 |
| `RowSpan` / `ColSpan` | int | 表单网格跨度 |
| `GroupIndex` | string | 分组索引（`0`=隐藏，`1`=业务字段，`9`=审计字段） |
| `Mrz` | string | 默认值 |
| `Placeholder` | string | 占位提示 |
| `DataKey` | string | 字典编号（DropDownList 类型） |

## 十、常见问题

### Q1: EntityConfig JSON 放在哪里？
**A**: `src/yzh-core/YZH.Core.Web/Assets/EntityConfigs/{Domain}/{Type}.json`

### Q2: 新实体使用什么基类？
**A**: `BaseEntity`（位于 `YZH.Core.Stand/Models/Entity/BaseEntity.cs`）

### Q3: 树形结构页面用什么组件？
**A**: `YzhTreeTable`（前端） + `TreeTableControllerBase<T,V>`（后端）

### Q4: 数据库视图如何迁移？
**A**: 在 `DB/mysql/` 创建 `{name}_view.sql`，手动执行后验证

### Q5: 唯一性校验写在哪里？
**A**: Controller 的 `OnBeforeAdd` / `OnBeforeUpdate` 钩子中
