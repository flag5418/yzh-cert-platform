## 使用约定

每个知识条目必须包含：
- **文件位置**：项目中的具体路径
- **接口签名**：方法名 + 参数 + 返回值
- **依赖**：依赖哪些模块
- **约束**：调用前提、副作用
- **示例**：最小可用代码片段
- **状态**：[DONE] / [TODO:P1] / [PLAN]

禁止只写概念不写接口签名。
