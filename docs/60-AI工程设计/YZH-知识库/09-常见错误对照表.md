## 十、快速诊断命令

```bash
# 1. 检查后端是否运行
curl -s http://localhost:9992/api/Sys_Dictionary/GetVueDictionary -H "Authorization: Bearer xxx" | head -c 200

# 2. 检查端口占用
lsof -i :9990  # 前端 admin
lsof -i :9991  # 前端 auditor
lsof -i :9992  # 后端 API

# 3. 检查 Redis 缓存
redis-cli -p 6380 KEYS "vol:*" | head -20

# 4. 清除菜单缓存
redis-cli -p 6380 DEL "vol:menu:*"

# 5. 检查 MySQL 表结构
mysql -h 127.0.0.1 -P 3307 -u root -p -e "DESCRIBE cert_xxx_table;" cert_platform

# 6. 检查前端路由是否匹配组件
ls -la vol.web/src/views/cert/*/index.vue

# 7. 后端编译检查
cd src/server/Vue.NetCore && dotnet build vol.api/VOL.WebApi/VOL.WebApi.csproj 2>&1 | grep -E "error|warning" | head -20

# 8. 前端编译检查
cd vol.web && npx vite build 2>&1 | tail -20
```
