## 〇、一句话结论

**样式体系不是没有，而是"建好了但没有牙齿"**：`tokens.css` 107 个令牌 + 三层穿透 + 规范文档一应俱全，
但 `guards.mjs` 21 条规则里 **0 条查样式、无 stylelint、无 pre-commit 拦截**，
导致 96 个 `.vue` 中 **70 个（73%）带硬编码、504 处裸 hex、93 个跨文件重复 class、3 个共享组件 0 使用**。

> **治理三步**：① 装牙齿（stylelint + R18）→ ② 消色毒（EP 调色板 → 令牌）→ ③ 收口组件（共享组件强制启用）。

## 五、治理方案

### 阶段 P0 · 装牙齿（0.5 天，最高 ROI）

**① 引入 stylelint**（`src/certplatform-web/.stylelintrc.json`）
- 扩展 `stylelint-config-recommended-vue`
- `declaration-property-value-disallowed-list`：`font-size` / `padding` / `margin` 禁裸 px
- `selector-class-pattern`：BEM-ish + `is-*` + `el-*`

**② `scripts/guards.mjs` 新增 R18「硬编码样式守卫」**，三档：

| 档 | 范围 | 处理 |
|---|---|---|
| **blocking** | 模板内联 `style="color:#…"`、`color="#…"` props、`<script>` 字面量传色 | 立即报错 |
| **warn** | `yzh.vue.core/**` 裸 hex（框架层零容忍） | 随版本消化 |
| **baseline** | 业务页面 scoped 裸 hex | 建基线，**只准减不准增** |

**③ scripts**：`"lint:style": "stylelint \"**/*.{vue,css}\""`，`guard` = `guards.mjs && lint:style`

### 阶段 P1 · 消色毒（2–3 天，机械替换）

按 §四映射表批量替换，优先级：
1. 内联/props/`<script>` 传色（9 + 16 + 16 = **41 处，最扎眼**）
2. **`yzh.vue.core` 框架层 95 处**（框架先干净，业务层才有样可抄）
3. `workflow/directory/index.vue`（57 处最大户）+ `ai-usage` + `enterprise-fill-params`
4. auditor 侧栏/登录绿色系 → **要绿就覆盖 `--yzh-color-primary` 令牌，不许散落 hex**
5. 顺手补 **17 条失效 scoped 规则**的 `:deep(`

### 阶段 P2 · 收口组件（3–5 天）

| 动作 | 收益 |
|---|---|
| 强制启用 `YzhStatusBadge` / `YzhEmptyState` / `YzhCard`，guards 禁止新增裸 `el-empty` / 手写状态色 class | 状态色 4 套→1；空态 3 套→1 |

## 六、新页面写样式标准流程

1. **布局交给框架**：`YzhPageLayout`（`#search`/`#toolbar`/`#pagination`）、`YzhTable`、`YzhFormDialog`、`YzhTreeTableLayout`，不自造条
2. **容器用组件**：`YzhCard` / `YzhEmptyState` / `YzhStatusBadge`，不手写
3. **颜色/间距/字号一律令牌 + 必带兜底**：
   ```css
   .my-block {
     padding: var(--yzh-space-4, 16px);
     background: var(--yzh-color-bg-card, #fff);
     border: 1px solid var(--yzh-color-border-light, #f1f5f9);
     border-radius: var(--yzh-radius-md, 8px);
     color: var(--yzh-color-text-regular, #606266);
     font-size: var(--yzh-font-size-md, 14px);
   }
   ```
4. **覆盖 Element Plus 只能 `:deep()` + 局部 `--el-*`**，且后代选择器必须 `:deep()` 包裹
5. **只有宿主能改主题**，且只改 `main.css` 的 `:root`（R-S11）
6. **用 LESS 必须声明** `<style lang="less" scoped>`（`&` 嵌套否则静默失效）
7. **自检**：`node scripts/guards.mjs` + `npx stylelint "**/*.{vue,css}"` + `npm run build`
