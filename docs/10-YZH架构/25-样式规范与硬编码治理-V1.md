## 五、治理方案

### 阶段 P0 · 装牙齿（✅ 已完成 2026-10-03）

**① 引入 stylelint**（`src/certplatform-web/.stylelintrc.js` —— 必须 `.js`，`.json` 放不下说明注释）
- 扩展 `stylelint-config-recommended-vue`，启用 6 条规则，**全部现状 0 违规**（跑法 `npm run lint:style`）

| 规则 | 拦什么 |
|---|---|
| `selector-class-pattern` | BEM-ish / `is-*` / `el-*`，新增 `.Bad_Class` 立即红 |
| `no-duplicate-selectors` | 同文件重复选择器（后写的静默覆盖前写的） |
| `no-descending-specificity` | 高特异性写在前、低特异性写在后（后一条永远不生效） |
| `unit-no-unknown` | `1bogus` 之类未知单位 |
| `function-no-unknown` | 拼错的函数名（放行 `v-bind` / `var`） |
| `declaration-property-value-keyword-no-deprecated` | `word-break: break-word` 等弃用值 |

> ⛔ **故意不开 `color-no-hex`**：它把 `var(--yzh-color-danger, #f56c6c)` 的兜底值也算违规，而「令牌 + 兜底」正是本项目要求写法 → 颜色归 R18。
> ⛔ **故意不开 `declaration-no-important`**：本项目仅允许 `:deep()` 覆盖 Element Plus 时用 `!important`（现状 7 处均属此类）。

**② `guards.mjs` 新增 R18「硬编码样式守卫」** —— 单一计数器、两类命中、基线制

| 命中 | 内容 |
|---|---|
| 裸 hex | `<style>` 中不在 `var(--x, #hex)` 兜底里的 hex；模板 `style="…#hex…"` / `color="#hex"`；`<script>` 字面量 `'#hex'` |
| 裸 px | `font-size` / `padding*` / `margin*` 的字面量 px（`width`/`height`/`border-radius` 不计，结构尺寸令牌未全覆盖） |

- 基线 `scripts/style-baseline.json`（file → 违规数），**只准减不准增**：不在基线而 >0 = 红；> 基线 = 红；< 基线 = 放行并提示收基线
- 当前基线 **78 个文件 / 1283 处**；收基线 `node scripts/guards.mjs --update-style-baseline`（只在批量消毒后跑一次）
- 白名单 `STYLE_ALLOW`：LogicFlow 画布色（颜色是数据的一部分）

**③ `guards.mjs` 新增 R19「结构性 CSS 门禁」** —— 守卫内直接 spawn `node_modules/.bin/stylelint --formatter=json`
（⚠️ stylelint 的 JSON 输出走 **stderr**，stdout 为空）。这样 **pre-commit 钩子一行不用改** 就能拦样式问题；
stylelint 未安装时 `skipped` + 告警，**不阻断提交**。

**④ scripts**（`src/certplatform-web/package.json`）
- `"lint:style": "stylelint \"{cert,yzh.vue.core}/src/**/*.{vue,css}\""` —— 独立跑，glob 已排除 `dist/`
- `"guard": "node scripts/guards.mjs"` —— 内部已含 R18+R19，**不要**再链 `lint:style`（会跑两遍）

> **为把 stylelint 基线拉到 0 而做的启动期修复**（随 P0 一并提交）：
> 5 处 `word-break: break-word` → `overflow-wrap: anywhere`；删 1 处重复 `.eo-opt`；
> 3 处 `no-descending-specificity` 调整选择器书写顺序（`prompt-template` / `enterprise-fill-params` / `YzhToolbar`，纯顺序调整，渲染语义不变）。

## 六、新页面写样式标准流程

1. **布局交给框架**：`YzhPageLayout`（`#search`/`#toolbar`/`#pagination`）、`YzhTable`、`YzhFormDialog`、`YzhTreeTableLayout`，不自造条
2. **容器用组件**：`YzhCard` / `YzhEmptyState` / `YzhStatusBadge`，不手写
3. **颜色/间距/字号一律令牌 + 必带兜底**：
   ```css
   .my-block {
     padding: var(--yzh-space-4, 16px);
     background: var(--yzh-color-bg-card, #fff);
     border: 1px solid var(--yzh-color-border-light, #f1f5f9);
     border-radius: var(--yzh-radius-md, 8px);
     color: var(--yzh-color-text-regular, #606266);
     font-size: var(--yzh-font-size-md, 14px);
   }
   ```
4. **覆盖 Element Plus 只能 `:deep()` + 局部 `--el-*`**，且后代选择器必须 `:deep()` 包裹
5. **只有宿主能改主题**，且只改 `main.css` 的 `:root`（R-S11）
6. **用 LESS 必须声明** `<style lang="less" scoped>`（`&` 嵌套否则静默失效）
7. **自检**：`npm run guard`（内含 R18 硬编码 + R19 stylelint）+ `npm run build`
