### 4.2 S01 · S02 —— 颜色 / 字号 / 间距令牌

**规定**：`<style>` 内颜色、字号、间距、圆角**一律 `var(--yzh-*, 兜底值)`**；⛔ 裸 hex、⛔ `font-size/padding/margin` 字面量 px。
**守卫**：R18（基线 `scripts/style-baseline.json`，只准减不准增）。

**正例**：
```css
.my-block {
  padding: var(--yzh-space-4, 16px);
  background: var(--yzh-color-bg-card, #fff);
  border: 1px solid var(--yzh-color-border-light, #f1f5f9);
  color: var(--yzh-color-text-regular, #606266);
  font-size: var(--yzh-font-size-md, 14px);
}
```

**反例**：`.foo { color: #409eff; padding: 12px; }` —— 双违规，R18 拦截。
**映射表**：见 §五 5.1 / 5.2（`#409eff`→`--yzh-color-primary`、`13px`→`--yzh-font-size-sm`、`16px`→`--yzh-space-4`）。

### 4.3 S03 —— 按钮语义色（三档制）

**规定**：按钮 `type` 只允许三档，**按动作语义取色，不按视觉喜好取色**：

| 档 | type | 适用动作（穷举） |
|---|---|---|
| 主操作 | `primary` | 新增、保存、提交、确定、生成、执行 |
| 危险 | `danger` | 删除、批量删除、清空、移除、驳回 |
| 中性 | `default` | 查询、重置、刷新、取消、导出、导入、展开、折叠、全选、测试、列设置 |

⛔ **禁止**：`type="info"`（灰 = 视觉上像禁用，语义模糊）、`type="success"` / `type="warning"`（绿/橙是**状态色**，属 S08 徽章，不属按钮）。

**正例**：
```ts
btns.push({ key: 'add', text: '新增', type: 'primary' })
btns.push({ key: 'delete', text: '批量删除', type: 'danger' })
btns.push({ key: 'export', text: '导出', type: 'default' })   // 中性 → 显式 default
```
```vue
<el-button type="primary" @click="handleSave">保存</el-button>
<el-button type="danger" @click="handleDelete">删除</el-button>
<el-button type="default" @click="handleRefresh">刷新</el-button>
```

> ⚠️ **TS 侧中性必须显式写 `type: 'default'`，不能省略**：省略会落到组件兜底 ——
> `YzhToolbar` 是 `?? 'default'`（中性 ✓），但 `YzhTable.vue:724` 行内按钮是 `?? 'primary'`
> （变蓝 ✗），同语义在工具栏/行内会分裂成两副面孔（违反 S04②）。

**★ 类型系统级根因（已修 2026-10-03）**：`YzhActionType` 原为
`'primary'|'success'|'warning'|'danger'|'info'` —— **缺中性值 `'default'`**，
而 EP `buttonTypes` 首值恰是 `'default'`。联合里没得选，调用方只能挑 `info`
（最接近"无色"的灰），这就是全项目灰钮的**真正来源**（不是谁手滑，是类型逼的）。
现已补 `'default'`；同时新增 `YzhTagType` 收紧 `tagType`/`tagTypeMap` ——
`el-tag` **不接受** `'default'`（默认 `'primary'`），两者不能共用一个联合。

## 七、新页面写样式标准流程

1. **布局交给框架**：`YzhPageLayout`（`#search`/`#toolbar`/`#pagination`）、`YzhTable`、`YzhFormDialog`、`YzhTreeTableLayout`，不自造条
2. **容器用组件**：`YzhCard` / `YzhEmptyState` / `YzhStatusBadge`，不手写
3. **颜色/间距/字号一律令牌 + 必带兜底**：
   ```css
   .my-block {
     padding: var(--yzh-space-4, 16px);
     background: var(--yzh-color-bg-card, #fff);
     border: 1px solid var(--yzh-color-border-light, #f1f5f9);
     border-radius: var(--yzh-radius-md, 8px);
     color: var(--yzh-color-text-regular, #606266);
     font-size: var(--yzh-font-size-md, 14px);
   }
   ```
4. **覆盖 Element Plus 只能 `:deep()` + 局部 `--el-*`**，且后代选择器必须 `:deep()` 包裹
5. **只有宿主能改主题**，且只改 `main.css` 的 `:root`（R-S11）
6. **用 LESS 必须声明** `<style lang="less" scoped>`（`&` 嵌套否则静默失效）
7. **按钮/空态/确认框/弹窗/标签/图标先查 §四 条款号**：`type` 只写三档（S03/S04）、空态 `YzhEmptyState`（S05）、
   确认框 `confirmOrFalse`（S06）、弹窗 `YzhDialog`/`YzhFormDialog`（S07）、状态 `YzhStatusBadge`（S08）、
   图标 `@element-plus/icons-vue`（S09）、左树右表 `YzhTreeTableLayout`（S10）、`!important` 只进 `:deep()`（S11）
8. **自检**：`npm run guard`（内含 R18 硬编码 + R19 stylelint + **R20 法条**）+ `npm run build`
