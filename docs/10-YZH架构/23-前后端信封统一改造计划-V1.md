## 一、三个决定一切的结论

### 1.1 结论①：现状是「静默失败」，P0 单独上线会退化成「假成功」

| 阶段 | 业务失败时（以 `submitForm` 为例） |
|---|---|
| **现状**（后端 HTTP 400） | `client.ts` throw → `SingleTableCore:736` **无 catch** → 弹窗不关、**零提示**、`submitting` 复位 = **静默失败** |
| **只做后端 P0**（200 + `success:false`） | 不 throw → `add()` 返回 `undefined` → `:743 onAfterAdd` 执行 → `insertRow(undefined)` → **`:757 ElMessage.success('保存成功')` + 关弹窗 = 假成功** |
| **F0 先行**（后端未改） | throw 进 `submitForm` 新增的 catch → **真提示 + 弹窗保持打开** → 立即改善 |
| **F0 + P0 同批** | `expectOk` 拦下 → 同上（真提示、不关窗） |

### 1.2 结论②：上线顺序约束（不可违背）

```
F0 ──可独立先上线──▶ 立即收益：静默失败 → 真实报错
P0 ──必须在 F0 之后或同批──▶ 否则：静默失败 → 假成功（更糟）
```

**本次执行顺序**：`文档 → F0 → P0 → P1 → P2 → F1 → F2 → P3/F3 → 全面验证`。
F0 与 P0 **分两个逻辑批次**，但**在同一次验收内完成**（避免中间态合入主干）。

### 1.3 结论③：最严重的 3 处「无条件成功」

| # | 位置 | 后果 |
|---|---|---|
| 1 | `SingleTableCore.ts:796` | `delete()` 结果被丢弃 → `ElMessage.success('删除成功')` + `removeRowByCode` = **假删除**（行消失、服务端还在） |
| 2 | `TreeTableCore.ts:662` | `deleteTreeNodeWithConfirm` 同上 = **假删除树节点** |
| 3 | `TreeTableCore.ts:685-690` | `res.data` 为空时用请求体兜底构造节点 → **追加幽灵节点** |

**页面自定义 handler 是"对的但会失效"**：`iso-standard:161,172`、`report-rule:222`、`skill-manage:135,146`、`ConfigTab:76` 共 **6 处**已是 `try { await…; success } catch { error }` 正确形态，**但 catch 只靠 HTTP 400 触发**。P0 后 catch 永不进入 → 照样弹"保存成功"。⇒ 必须与 P0 同批改造（F1）。

## 三、四条铁律（F-1 ~ F-4，前端改造红线）

| 铁律 | 内容 |
|---|---|
| **F-1 判定唯一** | 写操作返回的 `ApiResponse` **必须**经 `expectOk()` 判定通过，才允许触发副作用（弹成功 / 关弹窗 / 插行改行删行 / 调 `onAfter*` 钩子） |
| **F-2 失败必 throw** | 业务失败 → `throw BizError`，**不返回 `null`/`false` 给流程层**（否则每个调用点都要再判一次，必然遗漏） |
| **F-3 谁 catch 谁弹** | 提示唯一出口见 §四 分工表。底层方法**只 throw 不提示**；**绝不双弹** |
| **F-4 取消不是错误** | `ElMessageBox.confirm` 的 `cancel`/`close` 必须就地吞掉，**不得**进失败分支、不得弹错 |

### 3.1 分层模型

```
L-1 校验层   YzhForm.onSubmit:188   校验失败 → emit('validate',false) → 不发请求
L-2 请求层   client.ts              网络/HTTP 异常 → throw ApiError
L-3 结果层   expectOk()（新增）      success:false → throw BizError(err)
L-4 流程层   Core 流程方法           try/catch → 状态门禁 +（BizError 时）提示
```

### 3.2 提示出口分工表（F-3 落地细则）

| 错误来源 | 谁弹 | 说明 |
|---|---|---|
| 校验失败 | Element Plus 字段标红（可选 `validateMessage` warning） | `YzhForm:188-197` |
| **`ApiError`**（L1 网络 / L2 HTTP） | **Core 流程方法 / 页面 handler / `YzhTable.loadData` 的 catch** | client 的 `onError` **不弹**（D6） |
| **`BizError`**（L3 `expectOk`） | **同上**（同一个 catch） | `expectOk` 只在 Core 内抛，client 不感知 |
| `init()` / 读路径 | `init` 的统一 catch；表格由 `YzhTable:303` 既有 catch | |
| **无人 catch 的漏网** | `app.config.errorHandler` + `unhandledrejection` 兜底 → `ElMessage.error` 一次 | 宿主注入，带 `handled` 标记防重 |
| `client.ts` `onError` | **不发提示**（D6） | 只做 401 清 Token/跳登录副作用 |

> **双弹防护**：Core catch 内弹完后设 `e.handled = true`；兜底监听 `if (!e.handled)` 才弹。

```ts
async submitForm(): Promise<boolean> {
  this.submitting.value = true
  try {
    const isAdd = this.dialogMode.value === 'add'
    isAdd ? this.onBeforeAdd(this.formData) : this.onBeforeUpdate(this.formData)
    const payload = this.normalizeBeforeSubmit({ ...this.formData })
    const saved = isAdd
      ? unwrap<V>(await this.apiPost<ApiResponse<V>>('/add', payload), '新增失败')
      : unwrap<V>(await this.apiPost<ApiResponse<V>>('/update', payload), '修改失败')
    // —— 以下全部在 expectOk 通过之后 ——
    if (isAdd) {
      this.onAfterAdd(this.formData)
      this.insertRow(saved)
    } else {
      this.onAfterUpdate(this.formData)
      this.replaceRowByCode(saved[this.primaryKey], { ...this.editingRow.value, ...saved } as V)
    }
    ElMessage.success('保存成功')
    this.dialogVisible.value = false
    return true
  } catch (e: any) {
    if (!e?.handled) { e.handled = true; ElMessage.error(e?.message || '保存失败') }
    return false                      // 弹窗不关、行不插、钩子不跑
  } finally {
    this.submitting.value = false
  }
}
```

### 7.1 `ApiResponse` 目标形态（P0-a）

```csharp
public class ApiResponse<T>
{
    [JsonPropertyName("success")] public bool Success { get; init; }
    [JsonPropertyName("message")] public string Message { get; init; } = string.Empty;  // 成功提示，失败时 ""
    [JsonPropertyName("err")]     public string Err     { get; init; } = string.Empty;  // ★ 新增，失败时必非空
    [JsonPropertyName("data")]    public T? Data { get; init; }
    [JsonPropertyName("code")]    public int Code { get; init; }
    [JsonPropertyName("timestamp")] public DateTime Timestamp { get; init; } = DateTime.Now;

    private ApiResponse() { }                                   // ★ 封闭：唯一 new 站点只剩过滤器（改为工厂）

    public static ApiResponse<T> Ok(string message = "操作成功");      // success:true, code:200, err:""
    public static ApiResponse<T> Ok(T data, string message = "操作成功");
    public static ApiResponse<T> Fail(string err, int code = 400);     // success:false, message:"", err:err
    public static ApiResponse<T> BizFail(string err);                  // P1 起，HTTP 恒 200
    public static ApiResponse<T> Error(string err, int code = 500);
    public static ApiResponse<T> FromOperationResult(IOperationResult<T> result);
}
// 非泛型同构，★ P0-a 补 Code（现状缺失）
```

**不变量由工厂保证**（不在调用点手工拼）：
- `success:true` ⇒ `err:""` ②
- `success:false` ⇒ `err` 非空 ① 且 `message:""`
