## 一、设计目标

| 目标 | 说明 |
|------|------|
| **自动化** | 无需人工维护接口表，代码变更自动同步 |
| **稳定性** | ApiCode 基于接口特征生成，重命名/重构不影响已有权限绑定 |
| **一致性** | 单一数据源（代码），数据库表为衍生数据 |
| **增量更新** | 支持 Insert/Update/Delete 三种操作，不破坏历史数据 |
| **虚拟树** | 按路径层级自动构建树，无需人工分类 |

## 二、ApiCode 生成算法

### 2.1 算法定义

```
ApiCode = SHA256(
    Route.ToLower() + "|" +
    HttpMethod.ToUpper() + "|" +
    ActionName.ToLower() + "|" +
    Parameters.OrderBy(p => p.Name).Select(p => p.Name + ":" + p.Type.Name).Join("|")
)
```

### 2.2 算法特性

| 特性 | 说明 | 示例 |
|------|------|------|
| **确定性** | 相同输入 → 相同输出 | ✅ |
| **唯一性** | 不同输入 → 不同输出（概率上） | ✅ |
| **稳定性** | Controller 重命名不影响 ApiCode | ✅ 路径不变则 Hash 不变 |
| **敏感性** | 参数变化 → ApiCode 变化 | ✅ 新增参数会生成新 Code |
| **不可逆** | 无法从 ApiCode 反推原始信息 | ✅ 单向 Hash |

### 2.3 计算示例

```csharp
// 示例：UserController.Filter 方法
// Route: api/System/User
// Method: POST
// Action: Filter
// Parameters: request:FilterRequest

var input = "api/system/user|POST|filter|request:FilterRequest";
var apiCode = Sha256Hash(input);
// apiCode = "a1b2c3d4e5f6..."（固定 64 位十六进制）

// 验证：多次计算结果一致
Debug.Assert(Sha256Hash(input) == Sha256Hash(input));

// 验证：参数变化导致 ApiCode 变化
var input2 = "api/system/user|POST|filter|request:FilterRequest|showDisabled:boolean";
Debug.Assert(Sha256Hash(input) != Sha256Hash(input2));
```

## 三、虚拟树形结构设计

### 3.1 设计思路

采用**路径层级自动解析**方式，无需人工分类特性，系统自动构建树形结构。

```
接口路径示例：
/api/System/User/filter        → 树形结构：System → User → filter
/api/System/Role/list          → 树形结构：System → Role → list
/api/Foundation/ISOStandard/page → 树形结构：Foundation → ISOStandard → page
```

### 3.2 路径解析规则

```csharp
// 从路径提取层级
var path = "/api/System/User/filter";
var parts = path.Split('/').Where(p => !string.IsNullOrEmpty(p) && p != "api");
// parts = ["System", "User", "filter"]

// 构建树节点
TreeNode root = new TreeNode { Label = "api", Children = new List<TreeNode>() };
var current = root;
foreach (var part in parts)
{
    var node = current.Children.FirstOrDefault(c => c.Label == part);
    if (node == null)
    {
        node = new TreeNode { Label = part, Children = new List<TreeNode>() };
        current.Children.Add(node);
    }
    current = node;
}
```

### 3.3 树形结构示例

```
📁 api
  📁 System
    📁 User
      ⚪ GET  /api/System/User        (UserController.Index)
      ⚪ POST /api/System/User/filter (UserController.Filter)
      ⚪ POST /api/System/User/add    (UserController.Add)
      ⚪ POST /api/System/User/update (UserController.Update)
      ⚪ POST /api/System/User/delete (UserController.Delete)
    📁 Role
      ⚪ GET  /api/System/Role
      ⚪ POST /api/System/Role/filter
  📁 Foundation
    📁 ISOStandard
      ⚪ GET  /api/Foundation/ISOStandard
      ⚪ POST /api/Foundation/ISOStandard/filter
```

### 3.4 优势

| 优势 | 说明 |
|------|------|
| **自动构建** | 无需人工维护分类特性，路径决定树结构 |
| **清晰直观** | 路径层级即树层级，易于理解 |
| **动态响应** | 新增 Controller 自动出现在树中 |
| **减少配置** | 无需标注 `[ApiCategory]` 特性 |

### 5.2 ApiScanner（接口扫描器）

```csharp
// 位置：src/yzh-core/YZH.Core.Api/Services/ApiScanner.cs
using System.Collections.Concurrent;
using System.Diagnostics;
using System.Reflection;
using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.Mvc.Controllers;
using Microsoft.Extensions.Logging;
using YZH.Core.Api.Attributes;
using YZH.Core.Api.Models;

namespace YZH.Core.Api.Services;

/// <summary>
/// 接口扫描器
/// 通过反射自动发现所有 Controller 接口，生成 ApiDescriptor
/// </summary>
public class ApiScanner
{
    private readonly ILogger<ApiScanner> _logger;
    
    public ApiScanner(ILogger<ApiScanner> logger)
    {
        _logger = logger;
    }
    
    /// <summary>
    /// 扫描所有程序集中的 Controller 接口
    /// </summary>
    /// <returns>接口描述符列表</returns>
    public List<ApiDescriptor> Scan()
    {
        var stopwatch = Stopwatch.StartNew();
        var apis = new List<ApiDescriptor>();
        var seen = new HashSet<string>(); // 去重
        
        // 扫描所有程序集
        var assemblies = AppDomain.CurrentDomain.GetAssemblies()
            .Where(a => !a.IsDynamic 
                     && (a.GetName().Name?.StartsWith("YZH") == true 
                         || a.GetName().Name?.StartsWith("CertPlatform") == true));
        
        _logger.LogInformation("开始扫描 {Count} 个程序集", assemblies.Count());
        
        foreach (var assembly in assemblies)
        {
            try
            {
                var types = assembly.GetTypes();
                foreach (var type in types)
                {
                    // 只处理 Controller 类型
                    if (!typeof(ControllerBase).IsAssignableFrom(type) 
                        || type.IsAbstract 
                        || type.IsGenericType)
                        continue;
                    
                    // 获取控制器路由前缀
                    var routeAttr = type.GetCustomAttribute<RouteAttribute>();
                    var routePrefix = routeAttr?.Template ?? "";
                    
                    // 扫描公共方法
                    var methods = type.GetMethods(BindingFlags.Public | BindingFlags.Instance)
                        .Where(m => m.DeclaringType == type);
                    
                    foreach (var method in methods)
                    {
                        // 获取 HTTP 方法特性
                        var httpMethodAttr = method.GetCustomAttributes(false)
                            .OfType<HttpMethodAttribute>()
                            .FirstOrDefault();
                        
                        if (httpMethodAttr == null) continue;
                        
                        // 生成 ApiCode
                        var apiCode = GenerateApiCode(
                            routePrefix,
                            httpMethodAttr.HttpMethod.ToUpper(),
                            method.Name,
                            method.GetParameters()
                        );
                        
                        // 去重检查
                        if (seen.Contains(apiCode))
                        {
                            _logger.LogWarning("重复接口 ApiCode: {ApiCode}, 跳过", apiCode);
                            continue;
                        }
                        seen.Add(apiCode);
                        
                        // 获取接口说明
                        var descAttr = method.GetCustomAttribute<ApiDescriptionAttribute>();
                        
                        apis.Add(new ApiDescriptor
                        {
                            ApiCode = apiCode,
                            ControllerName = type.Name.Replace("Controller", ""),
                            ActionName = method.Name,
                            Method = httpMethodAttr.HttpMethod.ToUpper(),
                            Path = FormatPath(routePrefix, method.Name),
                            TreePath = ParseTreePath(FormatPath(routePrefix, method.Name)),
                            Description = descAttr?.Description ?? "",
                            Author = descAttr?.Author ?? "",
                            CreatedAt = descAttr?.CreatedAt ?? DateTime.UtcNow,
                            UpdatedAt = descAttr?.UpdatedAt ?? DateTime.UtcNow,
                            Parameters = method.GetParameters()
                                .Select(p => new ParamDescriptor
                                {
                                    Name = p.Name ?? "",
                                    Type = p.ParameterType.Name,
                                    Required = !p.HasDefaultValue,
                                    Description = p.GetCustomAttribute<ParamDescriptionAttribute>()?.Description ?? "",
                                    Default = p.DefaultValue
                                })
                                .ToList()
                        });
                    }
                }
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "扫描程序集 {Assembly} 失败", assembly.GetName().Name);
            }
        }
        
        stopwatch.Stop();
        _logger.LogInformation("扫描完成，发现 {Count} 个接口，耗时 {Elapsed}ms", 
            apis.Count, stopwatch.ElapsedMilliseconds);
        
        return apis;
    }
    
    /// <summary>
    /// 生成 ApiCode（基于路径+方法+参数）
    /// </summary>
    private string GenerateApiCode(string route, string httpMethod, string actionName, ParameterInfo[] parameters)
    {
        var sortedParams = parameters
            .OrderBy(p => p.Name ?? "")
            .Select(p => $"{p.Name}:{p.ParameterType.Name}")
            .Join("|");
        
        var input = $"{route.ToLower()}|{httpMethod}|{actionName.ToLower()}|{sortedParams}";
        return Sha256Hash(input);
    }
    
    /// <summary>
    /// 从路径解析树结构
    /// </summary>
    private string[] ParseTreePath(string path)
    {
        // path: /api/System/User/filter
        // return: ["System", "User", "filter"]
        return path.Split('/')
            .Where(p => !string.IsNullOrEmpty(p) && p != "api")
            .ToArray();
    }
    
    /// <summary>
    /// 计算 SHA256 Hash
    /// </summary>
    private static string Sha256Hash(string input)
    {
        using var sha256 = System.Security.Cryptography.SHA256.Create();
        var bytes = sha256.ComputeHash(Encoding.UTF8.GetBytes(input));
        return BitConverter.ToString(bytes).Replace("-", "").ToLower();
    }
    
    /// <summary>
    /// 格式化路径
    /// </summary>
    private static string FormatPath(string route, string actionName)
    {
        var path = $"{route}/{actionName}".Replace("//", "/");
        return path.EndsWith("/") ? path[..^1] : path;
    }
}
```

```csharp
// 位置：src/yzh-core/YZH.Core.Api/Repositories/ApiRepository.cs
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks;
using Microsoft.Extensions.Logging;
using SqlSugar;
using YZH.Core.Api.Interfaces;
using YZH.Core.Stand.Models;

namespace YZH.Core.Api.Repositories;

/// <summary>
/// 接口仓储实现
/// </summary>
public class ApiRepository : IApiRepository
{
    private readonly IDbOrm _dbOrm;
    private readonly ILogger<ApiRepository> _logger;
    
    public ApiRepository(IDbOrm dbOrm, ILogger<ApiRepository> logger)
    {
        _dbOrm = dbOrm;
        _logger = logger;
    }
    
    public async Task<List<SysApi>> GetAllAsync()
    {
        return await _dbOrm.QueryAsync<SysApi>("SELECT * FROM sys_api ORDER BY path");
    }
    
    public async Task<SysApi?> GetByCodeAsync(string code)
    {
        return await _dbOrm.QuerySingleAsync<SysApi>("SELECT * FROM sys_api WHERE code = @code", new { code });
    }
    
    public async Task<int> InsertBatchAsync(List<SysApi> apis)
    {
        if (!apis.Any()) return 0;
        
        var sql = @"
            INSERT INTO sys_api (code, method, path, tree_path, name, author, enable, create_date)
            VALUES @apis";
        
        return await _dbOrm.ExecuteNonQueryAsync(sql, new { apis });
    }
    
    public async Task<int> UpdateBatchAsync(List<SysApi> apis)
    {
        if (!apis.Any()) return 0;
        
        var sql = @"
            UPDATE sys_api SET
                name = @name,
                author = @author,
                update_date = NOW()
            WHERE code = @code";
        
        var count = 0;
        foreach (var api in apis)
        {
            count += await _dbOrm.ExecuteNonQueryAsync(sql, api);
        }
        return count;
    }
    
    public async Task<int> DeleteBatchAsync(List<string> codes)
    {
        if (!codes.Any()) return 0;
        
        var sql = "DELETE FROM sys_api WHERE code IN @codes";
        return await _dbOrm.ExecuteNonQueryAsync(sql, new { codes });
    }
    
    public async Task<int> ExecuteNonQueryAsync(string sql, object? param = null)
    {
        return await _dbOrm.ExecuteNonQueryAsync(sql, param);
    }
}
```

### 5.6 ApiSyncService（接口同步服务）

```csharp
// 位置：src/yzh-core/YZH.Core.Api/Services/ApiSyncService.cs
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks;
using Microsoft.Extensions.Logging;
using YZH.Core.Api.Interfaces;
using YZH.Core.Api.Models;
using YZH.Core.Stand.Models;

namespace YZH.Core.Api.Services;

/// <summary>
/// 接口同步服务
/// 负责将扫描到的接口同步到数据库
/// </summary>
public class ApiSyncService
{
    private readonly IApiRepository _apiRepo;
    private readonly IPermissionCacheService _permissionCache;
    private readonly ILogger<ApiSyncService> _logger;
    
    public ApiSyncService(
        IApiRepository apiRepo,
        IPermissionCacheService permissionCache,
        ILogger<ApiSyncService> logger)
    {
        _apiRepo = apiRepo;
        _permissionCache = permissionCache;
        _logger = logger;
    }
    
    /// <summary>
    /// 同步接口到数据库（增量更新）
    /// </summary>
    public async Task<SyncResult> SyncAsync(List<ApiDescriptor> discoveredApis)
    {
        var result = new SyncResult();
        
        if (discoveredApis == null || !discoveredApis.Any())
        {
            _logger.LogWarning("没有发现接口，跳过同步");
            return result;
        }
        
        try
        {
            // 1. 获取数据库现有接口
            var existingApis = await _apiRepo.GetAllAsync();
            var existingDict = existingApis.ToDictionary(a => a.Code);
            
            // 2. 创建发现接口的字典
            var discoveredDict = discoveredApis.ToDictionary(a => a.ApiCode);
            
            // 3. 计算需要删除的接口
            var codesToDelete = existingDict.Keys.Except(discoveredDict.Keys).ToList();
            if (codesToDelete.Any())
            {
                await _apiRepo.DeleteBatchAsync(codesToDelete);
                _logger.LogInformation("删除废弃接口 {Count} 个: {Codes}", 
                    codesToDelete.Count, string.Join(", ", codesToDelete.Take(5)));
                result.Deleted = codesToDelete.Count;
            }
            
            // 4. 计算需要新增的接口
            var codesToAdd = discoveredDict.Keys.Except(existingDict.Keys).ToList();
            if (codesToAdd.Any())
            {
                var newApis = discoveredApis.Where(a => codesToAdd.Contains(a.ApiCode))
                    .Select(MapToEntity).ToList();
                await _apiRepo.InsertBatchAsync(newApis);
                _logger.LogInformation("新增接口 {Count} 个: {Codes}", 
                    codesToAdd.Count, string.Join(", ", codesToAdd.Take(5)));
                result.Added = codesToAdd.Count;
            }
            
            // 5. 计算需要更新的接口
            var codesToUpdate = existingDict.Keys.Intersect(discoveredDict.Keys)
                .Where(code => 
                    existingDict[code].Name != discoveredDict[code].Description
                    || existingDict[code].Author != discoveredDict[code].Author)
                .ToList();
            if (codesToUpdate.Any())
            {
                var updateApis = discoveredApis.Where(a => codesToUpdate.Contains(a.ApiCode))
                    .Select(MapToEntity).ToList();
                await _apiRepo.UpdateBatchAsync(updateApis);
                _logger.LogInformation("更新接口 {Count} 个: {Codes}", 
                    codesToUpdate.Count, string.Join(", ", codesToUpdate.Take(5)));
                result.Updated = codesToUpdate.Count;
            }
            
            // 6. 刷新权限缓存（关键：确保权限数据一致）
            await _permissionCache.RefreshAllAsync();
            
            _logger.LogInformation("接口同步完成：新增 {Added} 个，更新 {Updated} 个，删除 {Deleted} 个",
                result.Added, result.Updated, result.Deleted);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "接口同步失败");
            result.Error = ex.Message;
        }
        
        return result;
    }
    
    /// <summary>
    /// 映射到数据库实体
    /// </summary>
    private SysApi MapToEntity(ApiDescriptor descriptor)
    {
        return new SysApi
        {
            Code = descriptor.ApiCode,
            Method = descriptor.Method,
            Path = descriptor.Path,
            TreePath = string.Join("|", descriptor.TreePath),
            Name = descriptor.Description,
            Author = descriptor.Author,
            Enable = true,
            CreateDate = descriptor.CreatedAt,
            UpdateDate = descriptor.UpdatedAt
        };
    }
}

/// <summary>
/// 同步结果
/// </summary>
public class SyncResult
{
    public int Added { get; set; }
    public int Updated { get; set; }
    public int Deleted { get; set; }
    public string? Error { get; set; }
    public bool Success => string.IsNullOrEmpty(Error);
}
```

### 5.7 PermissionCacheService（权限缓存服务）

```csharp
// 位置：src/yzh-core/YZH.Core.Api/Services/PermissionCacheService.cs
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks;
using Microsoft.Extensions.Logging;
using YZH.Core.Api.Interfaces;

namespace YZH.Core.Api.Services;

/// <summary>
/// 权限缓存服务
/// 负责维护用户权限缓存和展开表
/// </summary>
public class PermissionCacheService : IPermissionCacheService
{
    private readonly ICacheManager _cacheManager;
    private readonly IApiRepository _apiRepo;
    private readonly ILogger<PermissionCacheService> _logger;
    
    public PermissionCacheService(
        ICacheManager cacheManager,
        IApiRepository apiRepo,
        ILogger<PermissionCacheService> logger)
    {
        _cacheManager = cacheManager;
        _apiRepo = apiRepo;
        _logger = logger;
    }
    
    /// <summary>
    /// 获取用户权限列表
    /// </summary>
    public async Task<List<string>> GetPermissionsAsync(string userCode)
    {
        var cacheKey = $"user_perm:{userCode}";
        return await _cacheManager.GetOrAddAsync(
            cacheKey,
            async () =>
            {
                var sql = "SELECT api_code FROM sys_user_permission WHERE user_code = @userCode";
                return await _apiRepo.ExecuteNonQueryAsync(sql, new { userCode });
            },
            TimeSpan.FromMinutes(5)
        );
    }
    
    /// <summary>
    /// 刷新所有用户权限缓存
    /// </summary>
    public async Task RefreshAllAsync()
    {
        _logger.LogInformation("开始刷新所有用户权限缓存");
        
        // 1. 清空所有权限缓存
        _cacheManager.RemoveByPrefix("user_perm:");
        
        // 2. 重新展开权限到 sys_user_permission 表
        await ExpandPermissionsAsync();
        
        _logger.LogInformation("权限缓存刷新完成");
    }
    
    /// <summary>
    /// 刷新指定用户权限缓存
    /// </summary>
    public async Task RefreshAsync(string userCode)
    {
        _logger.LogInformation("刷新用户 {UserCode} 权限缓存", userCode);
        
        // 1. 清空缓存
        _cacheManager.Remove($"user_perm:{userCode}");
        
        // 2. 重新展开权限
        await ExpandUserPermissionsAsync(userCode);
    }
    
    /// <summary>
    /// 展开权限到 sys_user_permission 表
    /// </summary>
    private async Task ExpandPermissionsAsync()
    {
        // 清空旧数据
        await _apiRepo.ExecuteNonQueryAsync("DELETE FROM sys_user_permission");
        
        // 重新展开
        var sql = @"
            INSERT INTO sys_user_permission (user_code, api_code, create_date)
            SELECT ur.user_code, ra.api_code, NOW()
            FROM sys_user_role ur
            JOIN sys_role_api ra ON ur.role_code = ra.role_code
            WHERE NOT EXISTS (
                SELECT 1 FROM sys_user_permission up 
                WHERE up.user_code = ur.user_code AND up.api_code = ra.api_code
            )";
        await _apiRepo.ExecuteNonQueryAsync(sql);
    }
    
    private async Task ExpandUserPermissionsAsync(string userCode)
    {
        // 清空用户旧权限
        await _apiRepo.ExecuteNonQueryAsync(
            "DELETE FROM sys_user_permission WHERE user_code = @userCode",
            new { userCode });
        
        // 重新展开
        var sql = @"
            INSERT INTO sys_user_permission (user_code, api_code, create_date)
            SELECT ur.user_code, ra.api_code, NOW()
            FROM sys_user_role ur
            JOIN sys_role_api ra ON ur.role_code = ra.role_code
            WHERE ur.user_code = @userCode
            AND NOT EXISTS (
                SELECT 1 FROM sys_user_permission up 
                WHERE up.user_code = ur.user_code AND up.api_code = ra.api_code
            )";
        await _apiRepo.ExecuteNonQueryAsync(sql, new { userCode });
    }
}
```

```csharp
// YzhWebBuilder.cs 中注册

public class ApiSyncHostedService : IHostedService
{

        {
            _logger.LogError("接口权限同步失败：{Error}", result.Error);
        }
    }
```

## 八、PermissionFilter 实现

### 8.1 修改后的 PermissionFilter

```csharp
// 位置：src/yzh-core/YZH.Core.Api/Filters/PermissionFilter.cs
using System.Threading.Tasks;
using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.Mvc.Filters;
using Microsoft.Extensions.Logging;
using YZH.Core.Api.Interfaces;

namespace YZH.Core.Api.Filters;

/// <summary>
/// 权限校验过滤器
/// </summary>
public class PermissionFilter : IAuthorizationFilter
{
    private readonly IPermissionCacheService _permissionCache;
    private readonly IUserContext _userContext;
    private readonly ILogger<PermissionFilter> _logger;
    
    public PermissionFilter(
        IPermissionCacheService permissionCache,
        IUserContext userContext,
        ILogger<PermissionFilter> logger)
    {
        _permissionCache = permissionCache;
        _userContext = userContext;
        _logger = logger;
    }
    
    public void OnAuthorization(AuthorizationFilterContext context)
    {
        // 1. 检查是否跳过授权
        var methodInfo = (context.ActionDescriptor as ControllerActionDescriptor)?.MethodInfo;
        if (methodInfo?.IsDefined(typeof(AllowAnonymousAttribute), true) == true)
            return;
        
        // 2. 检查用户是否已登录
        if (!_userContext.IsAuthenticated)
        {
            context.Result = new UnauthorizedResult();
            return;
        }
        
        // 3. 检查接口权限
        var requirePermission = context.ActionDescriptor
            .GetMethodAttribute<RequirePermissionAttribute>();
        
        if (requirePermission != null)
        {
            var hasPermission = CheckPermission(_userContext.UserCode, requirePermission.PermissionCode);
            if (!hasPermission)
            {
                _logger.LogWarning(
                    "用户 {UserCode} 无权限访问接口 {Action}",
                    _userContext.UserCode,
                    context.ActionDescriptor.DisplayName
                );
                context.Result = new ForbidResult();
                return;
            }
        }
    }
    
    private async Task<bool> CheckPermission(string userCode, string permissionCode)
    {
        // 超级管理员放行
        if (_userContext.RoleId == RoleIds.SuperAdmin) return true;
        
        // 从缓存获取权限列表
        var permissions = await _permissionCache.GetPermissionsAsync(userCode);
        return permissions.Contains(permissionCode);
    }
}
```

## 十一、注意事项

1. **ApiCode 稳定性**：避免在 Hash 输入中包含容易变化的信息（如时间戳、GUID）
2. **同步时机**：启动时同步是必须的，建议增加手动触发接口（`POST /api/System/ApiSync/sync`）
3. **权限缓存**：同步完成后必须刷新权限缓存，否则新接口权限不生效
4. **回滚机制**：同步失败时应保留原有数据，不破坏现有权限绑定
5. **密钥安全**：JWT SecretKey 和 PasswordSecret 不应硬编码，建议使用环境变量
