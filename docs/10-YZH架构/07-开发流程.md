> **说明**：
> - `GroupIndex` 用于控制字段在不同编辑模式下的可编辑性，由 `CrudPageLogic.formGroupIndex` 决定
> - `formGroupIndex='0'`（新增模式）：所有字段可编辑，GroupIndex 不生效
> - `formGroupIndex='1'`（编辑模式）：仅 `GroupIndex='1'` 的字段可编辑
> - `formGroupIndex='99'`（查看模式）：仅 `GroupIndex='99'` 的字段可编辑（通常全部只读）
>
> **示例**：
> ```json
> {
>   "Columns": [
>     { "FieldName": "UserName", "DesName": "用户名", "Type": "TextBox", "GroupIndex": "0", "BcFlag": true },
>     { "FieldName": "RoleName", "DesName": "角色名称", "Type": "Other", "GroupIndex": "1", "BcFlag": true },
>     { "FieldName": "CreateTime", "DesName": "创建时间", "Type": "Other", "GroupIndex": "99", "BcFlag": false }
>   ]
> }
> ```
> 新增时 `formGroupIndex='0'` → 所有字段可编辑；编辑时 `formGroupIndex='1'` → 只有 GroupIndex=0 和 1 的字段可编辑；查看时 `formGroupIndex='99'` → 所有字段只读。

## 四、常见开发场景

### 4.1 添加启用/禁用开关（IsValid + toggle-valid）

**方式一：使用内置 toggle-valid 端点（推荐）**

基类已提供 `/toggle-valid` 和 `/tree/toggle-valid` 端点，无需额外后端代码：

```vue
<template #column-actions="{ row }">
  <el-button v-if="row.IsValid === 1" text type="warning"
    @click="logic.toggleIsValid(row.Code)">禁用</el-button>
  <el-button v-else text type="success"
    @click="logic.toggleIsValid(row.Code)">启用</el-button>
</template>
```

**方式二：自定义行操作（需要额外逻辑时）**

```csharp
// 注册行操作
RegisterRowAction("disable", DisableAsync);
RegisterRowAction("enable", EnableAsync);

// 实现
private async Task<Result<ApiResponse<object?>>> DisableAsync(V entity)
{
    var result = await Entity.GetByCodeAny(entity.Code);
    if (!result.Success || result.Data == null)
        return Result<ApiResponse<object?>>.Fail("记录不存在");
    result.Data.IsValid = 0;
    await Entity.Update(result.Data, UserContext.ClientIp);
    return Result<ApiResponse<object?>>.Ok(ApiResponse<object?>.Ok("已禁用"));
}
```

### 4.3 树节点递归禁用

```csharp
// OrganizationController 中的典型实现
private async Task<object?> DisableOrgRecursiveAsync(Sys_Organization entity)
{
    var result = await TreeEntity.GetByCodeAny(entity.Code);
    if (!result.Success || result.Data == null) return "机构不存在";

    var org = result.Data;
    org.IsValid = 0;
    await TreeEntity.Update(org, UserContext.ClientIp);

    // 递归禁用子机构
    var childCount = await DisableChildrenRecursive(org.Code);
    return $"已禁用机构及其 {childCount} 个子机构/用户";
}

private async Task<int> DisableChildrenRecursive(string parentCode)
{
    int count = 0;
    var children = await TreeEntity.GetChildren(parentCode);
    foreach (var child in children)
    {
        child.IsValid = 0;
        await TreeEntity.Update(child, UserContext.ClientIp);
        count++;
        count += await DisableChildrenRecursive(child.Code);

        // 禁用该子机构下的所有用户
        var users = await Entity.GetListAsync(u => u.OrgCode == child.Code);
        if (users.Success && users.Data != null)
        {
            foreach (var user in users.Data)
            {
                if (user.IsValid == 1)
                {
                    user.IsValid = 0;
                    await Entity.Update(user, UserContext.ClientIp);
                    count++;
                }
            }
        }
    }
    return count;
}
```

protected override void OnQueried(PagedResult<Sys_User> result)
{
    foreach (var item in result.Items)
    {
        // 角色名称
        item.RoleName = item.RoleId switch
        {
            1 => "超级管理员",
            10 => "总管理员",

            22 => "普通审核员",
            30 => "企业账号",

## 六、常见错误速查

| 错误现象 | 根因 | 修复 |
|---------|------|------|
| 表格列为空 | 未调 `logic.init()` 或 JSON 中 `XsFlag=false` | 检查 init() 调用、检查 JSON 配置 |
| 表单字段不显示 | JSON 中 `BcFlag=false` | 改为 `BcFlag=true` |
| `/filter` 报 400 | 实体无 `Code` 属性 | 确保实体继承 `BaseEntity` |
| 树节点点击后表格不刷新 | 未调用 `logic.onNodeClick(node)` | 在 `@tree-node-click` 中调用 |
| 删除后表格数据重复 | 未使用 Split 方法 | 改用 `removeRowByCode(code)` |
| 新增后表格无新行 | 未使用 Split 方法 | 改用 `insertRow(row)` |
| 前端 TypeScript 报类型错误 | 使用了 camelCase 访问 PascalCase 字段 | 统一使用 PascalCase，不做转换 |
| 树节点表单不显示 | 未设置 `TreeFormConfigName` | 在构造函数中设置 `TreeFormConfigName = "Domain/Name"` |

## 七、完整检查清单

新增页面时逐项检查：

- [ ] 后端实体继承 `BaseEntity`
- [ ] 后端 Controller 继承 `YzhControllerBase<V>` 或 `TreeTableControllerBase<T,V>`
- [ ] EntityConfig JSON 已创建，`XsFlag`/`BcFlag` 配置正确
- [ ] **视图字段**：`[NotMapped]` 属性与 `Type=Other` 字段对应
- [ ] **Other 字段保存控制**：`Type=Other` 字段不应有 `BCFlag=true`（除非是只读展示）
- [ ] 后端路由 `[Route("api/{Domain}/[controller]")]` 正确
- [ ] 前端 API 文件路径与后端路由一致
- [ ] 前端 Pages 文件夹路径与后端 Controller 域一致
- [ ] 路由已注册到 `router/index.ts`
- [ ] 前端 Logic 继承 `CrudPageLogic` 或 `TreeTableLogic`
- [ ] `controllerName` 已设置
- [ ] `logic.init()` 已在 `onMounted` 中调用
- [ ] 树形页面已设置 `TreeConfig` 所有必填字段
- [ ] 自定义操作已注册（`RegisterRowAction` / `RegisterTreeAction`）
- [ ] 行按钮配置正确（`GetRowButtons()` 需 override 才显示 Enable；CustomButtons 从 RegisterRowAction 自动注入）

## 八、禁止清单（2026-09-18 新增）

> **以下行为在新架构中严格禁止，违反即为架构越界。**

### 8.1 禁止的 API 调用

| 禁止行为 | 原因 | 替代方案 |
|----------|------|----------|
| `getPageData` | 旧 Vol 框架端点 | 使用 `/filter` 端点 |
| `getList`（返回裸数组） | 响应格式不统一 | 使用 `/filter` 返回 `Page<T>` |
| `{code: 200, data}` 手动包装 | 响应格式混乱 | 使用 `ApiResponse<T>` 或框架自动包装 |
| `http.ts`（axios 实例） | 双 HTTP 客户端 | 使用 `yzhApi`（`@yzh-core/api/client`） |

### 8.2 禁止的前端写法

| 禁止行为 | 原因 | 替代方案 |
|----------|------|----------|
| 页面内硬编码 `columns` 数组 | 配置不统一 | 使用 EntityConfig JSON 驱动 |
| 页面内硬编码 `searchFields` 数组 | 配置不统一 | 使用 EntityConfig JSON 驱动 |
| 手动管理 `dialogVisible`/`dialogMode`/`formData` | 重复代码 | 使用 `CrudPageLogic` 基类 |
| 手动实现 `ElMessageBox.confirm` 删除确认 | 重复代码 | 使用 `logic.confirmDelete()` |
| 手动调用 `/filter` 加载数据 | 重复代码 | 使用 `logic.dataLoader(params)` |

### 8.3 禁止的后端写法

| 禁止行为 | 原因 | 替代方案 |
|----------|------|----------|
| Controller 继承 `ControllerBase`（无业务实体） | 丧失基类能力 | 继承 `YzhControllerBase<V>` |
| 自定义 `getList`/`getPageData` 端点 | API 不统一 | 使用基类 `/filter` 端点 |
| 手动包装 `{code: 200, data}` 响应 | 响应格式混乱 | 使用 `ApiResponse<T>` |
| Entity 继承 `ControllerBase` | 不符合架构 | 继承 `BaseEntity` |

### 8.4 合法的例外（B 类模块）

以下模块允许使用自定义端点，但响应必须统一为 `ApiResponse<T>`：

- NC 设计器 / 报告内容设计器（画布 + 解释器）
- 文档提取规则页（左树 + AI + 预览）
- 标准文件目录（树 + 上传 + 转换队列）
- 机构-标准 / 机构-阶段勾选（关联分配）
- 队列监控 / AI 用量（运维面板）
