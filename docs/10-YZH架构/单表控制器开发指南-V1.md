## 二、后端开发步骤

### 2.1 第一步：确认实体类

**要求**：
- 实体继承 `BaseEntity`（必须）
- 命名空间符合 `YZH.Entity.Admin.Platform.{模块名}`（建议）
- Code 字段作为业务主键（用于 Update/Delete）

```csharp
// 示例：新建 src/certplatform-api/CertPlatform.Shared/Models/Cert/MyEntity.cs
namespace YZH.Entity.Admin.Platform.Cert;

public class MyEntity : BaseEntity
{
    public string Code { get; set; } = string.Empty;
    public string Name { get; set; } = string.Empty;
    public int Status { get; set; }
}
```

### 2.2 第二步：创建控制器

**路径规则**：
- `CertPlatform.Admin/Controllers/{模块名}/`
- 如：`Foundation/`、`Workflow/`、`System/`

**代码模板**：

```csharp
using extern alias SharedEntities;
using YZH.Core.Api.Controllers;
using YZH.Core.Api.Services;
using YZH.Core.Stand.Models.Config;

namespace CertPlatform.Admin.Controllers.Foundation;

/// <summary>
/// 【功能描述】
/// 路由：/api/Foundation/MyEntity
/// </summary>
[ApiController]
[Route("api/Foundation/[controller]")]
public class MyEntityController : YzhControllerBase<SharedEntities::YZH.Entity.Admin.Platform.Cert.MyEntity>
{
    public MyEntityController(
        EntityService<SharedEntities::YZH.Entity.Admin.Platform.Cert.MyEntity> entityService,
        IUserContext userContext)
        : base(entityService, userContext)
    {
    }

    // ========================================================
    // 配置加载（必须）
    // ========================================================
    protected override EntityConfig LoadConfig()
    {
        return EntityConfigHelper.GetConfig<SharedEntities::YZH.Entity.Admin.Platform.Cert.MyEntity>();
    }

    // ========================================================
    // 业务校验（可选）
    // ========================================================
    
    /// <summary>新增前校验</summary>
    protected override async Task<(bool ok, string? msg)> OnBeforeAdd(MyEntity entity)
    {
        // 返回 (true, null) 表示通过，(false, "错误信息") 拒绝
        var exists = await Entity.ExistsAsync(e => e.Code == entity.Code);
        if (exists.Data)
            return (false, $"Code【{entity.Code}】已存在");
        return (true, null);
    }

    /// <summary>修改前校验</summary>
    protected override async Task<(bool ok, string? msg)> OnBeforeUpdate(MyEntity entity)
    {
        var exists = await Entity.ExistsAsync(e => e.Code != entity.Code && e.Code == entity.Code);
        if (exists.Data)
            return (false, $"Code【{entity.Code}】已存在");
        return (true, null);
    }

    // ========================================================
    // 其他可选钩子
    // ========================================================
    // OnAfterAdded、OnAfterUpdated、OnBeforeDelete、OnAfterDeleted
}
```

### 2.3 第三步：创建 EntityConfig JSON

**路径规则**：
- `src/yzh-core/YZH.Core.Web/Assets/EntityConfigs/{模块名}/`
- 文件名与实体类名一致（不含命名空间）

**JSON 模板**（参考 ISOStandard.json）：

```json
{
  "Title": "我的实体管理",
  "TableCaption": "数据列表",
  "Columns": [
    { "prop": "Code", "label": "编码", "width": 120, "fixed": "left" },
    { "prop": "Name", "label": "名称", "width": 150 },
    { "prop": "Status", "label": "状态", "width": 80, "dict": "StatusDict" }
  ],
  "SearchFields": ["Code", "Name"],
  "ActionButtons": ["add", "edit", "delete", "export"],
  "DialogWidth": "600px",
  "DialogTitleAdd": "新增记录",
  "DialogTitleEdit": "编辑记录"
}
```

## 三、前端开发步骤

### 3.1 创建 Vue 页面

**路径规则**：
- `src/certplatform-web/cert/cert-admin/src/pages/{模块名}/{entity-name}/index.vue`
- 如：`pages/foundation/iso-standard/index.vue`

**代码模板**：

```vue
<template>
  <YzhCrudPage
    ref="crudRef"
    api-client="api"
    title="ISO标准管理"
  />
</template>
```

## 四、核心钩子说明

| 钩子 | 签名 | 调用时机 | 用途 |
|------|------|----------|------|
| `OnBeforeAdd` | `Task<(bool, string?)>` | 新增前 | 业务校验、唯一性检查 |
| `OnAfterAdded` | `Task` | 新增成功后 | 关联操作、发通知 |
| `OnBeforeUpdate` | `Task<(bool, string?)>` | 修改前 | 业务校验、乐观锁 |
| `OnAfterUpdated` | `Task` | 修改成功后 | 清理缓存、记录日志 |
| `OnBeforeDelete` | `Task<(bool, string?)>` | 删除前 | 关联检查、软删除保护 |
| `OnAfterDeleted` | `Task` | 删除成功后 | 清理关联数据 |

## 五、常见场景实现

### 5.1 字典绑定

在 EntityConfig JSON 中声明字典字段，框架自动加载：

```json
{
  "Columns": [
    { "prop": "Status", "label": "状态", "dict": "StatusDict" },
    { "prop": "Category", "label": "分类", "dict": "CategoryDict" }
  ]
}
```

控制器需注册字典（在构造函数后调用）：

```csharp
public MyEntityController(...) : base(entityService, userContext)
{
    DictService.Register("StatusDict", () => new List<DictItem>
    {
        new() { DictValue = "1", DictLabel = "启用" },
        new() { DictValue = "0", DictLabel = "禁用" }
    });
}
```

### 5.2 自定义操作按钮

在 EntityConfig JSON 中配置：

```json
{
  "CustomButtons": [
    { "name": "启用", "action": "Enable", "icon": "Check" },
    { "name": "禁用", "action": "Disable", "icon": "Close" }
  ]
}
```

控制器中实现对应方法：

```csharp
[HttpPost("action/Enable")]
public async Task<ApiResponse> Enable([FromBody] MyEntity entity)
{
    entity.Status = 1;
    var result = await Entity.UpdateAsync(entity, UserContext.UserId, UserContext.UserName);
    return result.Success 
        ? ApiResponse.Ok("已启用") 
        : ApiResponse.Fail(result.Message ?? "操作失败");
}
```

### 5.3 左树右表（复杂场景）

若需树形结构，继承 `TreeTableControllerBase<T,V>`：

```csharp
public class OrganizationController : TreeTableControllerBase<Sys_Organization, Sys_User>
{
    public OrganizationController(EntityService<Sys_Organization> orgService, 
                                   EntityService<Sys_User> userService,
                                   IUserContext userContext)
        : base(orgService, userService, userContext)
    {
    }
}
```
