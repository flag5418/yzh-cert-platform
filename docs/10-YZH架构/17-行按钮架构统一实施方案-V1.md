# 行按钮架构统一实施方案-V3

## 一、核心设计原则

| 原则 | 说明 |
|------|------|
| **文件合并** | `ToolbarConfig.cs` 和 `ToolbarConfigDto.cs` 合并为单一文件 `ToolbarConfig.cs` |
| **消除 DTO 变体** | 删除 `ToolbarConfigDto` / `RowButtonConfigDto`，前后端共用同一个 class |
| **RowButtons 永不为 null** | `EntityConfig.RowButtons` 默认 `new RowButtonConfig()`，JSON 不写也有默认值 |
| **默认值合理** | 编辑=有、删除=有、禁用=无（需显式开启），继承类按需 override |
| **后端 Controller 零冗余** | 基类 `ToggleIsValid` 已完整实现，禁止各 Controller 重写 |
| **前端动态标签** | 行按钮固定显示"禁用/启用"，确认弹窗按钮文案动态显示 |
| **状态列配置驱动** | IsValid 列通过 `slot: true` 由前端自定义渲染状态标签 |

## 四、前端架构适配

### 4.1 TypeScript 契约

```typescript
export interface RowButtonConfig {
  Edit?: boolean
  Delete?: boolean
  Enable?: boolean
  CustomButtons?: Record<string, string>
}
```

### 4.2 CrudPageLogic 基类

- `columns` getter：自动标记 EnableField 列为 `slot: true`
- `rowButtons` getter：根据 `rb.Enable === true && enableField` 自动注入 `toggle-valid`
- `onRowClick`：处理 `toggle-valid` case，调用 `toggleRowIsValidWithConfirm`

### 4.3 TreeTableLogic 基类

- `columns` getter：同上
- `rowActionButtons` getter：统一注入 `toggle-valid`

### 4.4 YzhTable 组件

```typescript
function getRowActionType(key: string) {
  const map = {
    disable: 'warning',
    enable: 'success',
    'toggle-valid': 'warning',   // ← 新增
    delete: 'danger',
    edit: 'primary',
  }
}
```

### 4.5 表格状态标签渲染约定

```vue
<template #column-IsValid="{ value }">
  <el-tag :type="value === 1 ? 'success' : 'info'" size="small">
    {{ value === 1 ? '启用' : '禁用' }}
  </el-tag>
</template>
```

## 八、数据流

```
JSON EntityConfig → 后端 EntityConfig → ConfigDtoConverter → HTTP GET /config
→ CrudPageLogic.rowButtons → YzhTable → getRowActionType
→ 用户点击 → onRowClick('toggle-valid') → toggleIsValid API → 行状态更新
```
