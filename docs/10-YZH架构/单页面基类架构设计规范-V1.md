# 后端基础设施与单页面架构设计规范 V3

> 本文档定义了认证平台后端**基础设施层**和**单页面架构**的完整设计规范。
> 所有新增功能 **必须严格遵循本规范**。

---

## 一、架构总览

### 1.1 设计参考

本规范深度参考 **YZH.WPF.Core** 架构 + **Vol 框架** 的设计思想，适配到 ASP.NET Core + Dapper/EF Core + Vue 3 技术栈。

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **基础先行** | 先建设无状态工具服务（导入导出、配置加载、字典服务），再构建 Controller |
| **组合优于继承** | Controller 通过 DI 组合基础服务，而非全部靠继承链 |
| **配置驱动 UI** | GridConfig（JSON）完整定义表格列、表单字段、搜索条件、工具栏 |
| **事务回调模式** | 实体操作默认不提交，通过事务回调统一提交，结构紧凑 |
| **轻量 SQL 拼接** | 数据过滤/分页采用 SQL 拼接 + Dapper，避免 LINQ 表达式树复杂度 |
| **生命周期钩子** | 增删改查前后均可插入自定义逻辑 |

### 1.3 关键数据模型约定

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | `int` | **物理主键**，数据库自增（AUTO_INCREMENT） |
| `Code` | `string` | **业务唯一键**，GUID（`Guid.NewGuid().ToString("N")`），用于业务查找、导入匹配 |

> 所有业务实体遵循此约定。`Id` 仅做物理主键；业务逻辑（导入去重、跨系统交互）统一用 `Code`。

### 1.4 分层架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                         前端 (Vue 3)                                │
│  YzhListPage / YzhFormDialog / YzhSearchBar / YzhToolbar           │
└──────────────────────────────┬──────────────────────────────────────┘
                               │ HTTP
┌──────────────────────────────▼──────────────────────────────────────┐
│                      控制器层                                        │
│  PageBaseController<T>（组合引用基础设施服务）                        │
├─────────────────────────────────────────────────────────────────────┤
│                  基础设施服务层（无状态）                              │
│  ExcelExporter / ExcelImporter / GridConfigLoader                   │
│  DictService / EntityHelper / WorkUnit / EntityService<T>           │
│  SqlBaseService（SQL 拼接 + Dapper 查询）                            │
├─────────────────────────────────────────────────────────────────────┤
│                    数据访问层                                        │
│  IRepository<T> / BaseRepository<T> / BaseDbContext                 │
└─────────────────────────────────────────────────────────────────────┘
```

## 二、基础设施服务层设计

> **核心理念**：所有与具体业务 Controller 无关的通用能力，抽取为独立服务注入 DI 容器。
> 未来 Controller 通过 **构造函数注入** 这些基础服务，快速组合构建功能。

### 2.1 基础设施清单

| 服务 | 职责 | 对应参考架构 |
|------|------|-------------|
| `EntityService<T>` | 通用实体 CRUD 操作（无 Controller 依赖） | `BaseEntityController` + `IDbOrm` |
| `ExcelExporter` | 基于 GridConfig 的 Excel 导出 | `ExcelController` |
| `ExcelImporter` | 基于 GridConfig 的 Excel 导入 | `IDbOrm.InsertList/UpdateList` |
| `GridConfigLoader` | 从 JSON 文件加载/缓存 GridConfig | `GridConfig.GetGridConfig<T>` |
| `DictService` | 字典数据查询（下拉框数据源） | 字典表查询封装 |
| `EntityHelper` | 实体元数据获取（表名、字段名、类型） | `ReflectionHelper` |
| `WorkUnit` | EF Core 事务工作单元 | `db.Session.BeginTransaction` |
| `AuditService` | 审计日志记录 | `LogHelper` |

### 2.2 EntityService<T> — 实体操作服务

> 对标参考架构的 `BaseEntityController` + `IDbOrm` + Vol 框架的 `RepositoryBase`。
> 
> **三个关键设计**：
> 1. **saveChanges 模式**：所有 Add/Update/Delete 都有 `saveChanges` 参数（默认 true），设为 false 后在事务中不自动提交
> 2. **Code 是业务键**：`FindByCode`、`GetByCode` 是主要查找方式，导入时通过 Code 判断新增或更新
> 3. **纯服务层**：不依赖 HTTP 上下文，任何 Controller / 后台任务 / 队列处理器都可以调用

```csharp
namespace YZH.Core.Services;

/// <summary>
/// 通用实体操作服务（与 Controller 无关）
/// 提供标准 CRUD、批量操作、分页查询等原子操作
/// 任何上层组件（Controller / 队列 / 导入导出）都可组合引用
/// 
/// 设计要点：
/// - 所有写操作支持 saveChanges 参数（默认 true），事务中设为 false
/// - 业务查找以 Code（GUID）为主键
/// - 审计字段自动填充
/// </summary>
public class EntityService<T> where T : BaseEntity
{
    private readonly IRepository<T> _repository;

    public EntityService(IRepository<T> repository)
    {
        _repository = repository;
    }

    // ==================== 原子查询操作 ====================

    /// <summary>根据物理主键 Id 获取实体</summary>
    public virtual T? GetById(int id) => _repository.GetById(id);

    /// <summary>根据业务 Code 获取实体（主要查找方式）</summary>
    public virtual T? GetByCode(string code) => _repository.GetByCode(code);

    /// <summary>获取单个实体</summary>
    public virtual T? GetOne(Expression<Func<T, bool>> predicate)
        => _repository.GetOne(predicate);

    /// <summary>获取列表</summary>
    public virtual List<T> GetList(Expression<Func<T, bool>>? predicate = null)
        => _repository.GetList(predicate);

    /// <summary>分页查询（使用 SQL 拼接在 Repository 层实现）</summary>
    public virtual (List<T> items, int total) GetPage(PagerOptions options)
        => _repository.GetPage(options);

    /// <summary>统计数量</summary>
    public virtual int Count(Expression<Func<T, bool>>? predicate = null)
        => _repository.Count(predicate);

    /// <summary>判断是否存在</summary>
    public virtual bool Exists(Expression<Func<T, bool>> predicate)
        => _repository.Exists(predicate);

    /// <summary>根据 Code 判断是否存在</summary>
    public virtual bool ExistsByCode(string code)
        => _repository.Exists(x => x.Code == code);

    // ==================== 原子写操作（含 saveChanges 参数） ====================

    /// <summary>
    /// 插入单个实体
    /// </summary>
    /// <param name="entity">实体</param>
    /// <param name="saveChanges">是否立即提交（事务中设为 false）</param>
    public virtual T Insert(T entity, bool saveChanges = true)
    {
        if (string.IsNullOrEmpty(entity.Code))
            entity.Code = Guid.NewGuid().ToString("N");
        return _repository.Insert(entity, saveChanges);
    }

    /// <summary>
    /// 更新单个实体
    /// </summary>
    /// <param name="entity">实体</param>
    /// <param name="saveChanges">是否立即提交（事务中设为 false）</param>
    /// <param name="updateFields">指定更新的字段（null=全部）</param>
    public virtual T Update(T entity, bool saveChanges = true, string[]? updateFields = null)
    {
        return updateFields == null
            ? _repository.Update(entity, saveChanges)
            : _repository.Update(entity, saveChanges, updateFields);
    }

    /// <summary>
    /// 删除单个实体
    /// </summary>
    /// <param name="id">物理主键</param>
    /// <param name="saveChanges">是否立即提交（事务中设为 false）</param>
    public virtual void Delete(int id, bool saveChanges = true)
        => _repository.Delete(id, saveChanges);

    /// <summary>
    /// 批量删除
    /// </summary>
    /// <param name="ids">物理主键集合</param>
    /// <param name="saveChanges">是否立即提交</param>
    public virtual void DeleteBatch(IEnumerable<int> ids, bool saveChanges = true)
        => _repository.DeleteBatch(ids, saveChanges);

    /// <summary>
    /// 条件删除
    /// </summary>
    public virtual void DeleteWhere(Expression<Func<T, bool>> predicate, bool saveChanges = true)
        => _repository.DeleteWhere(predicate, saveChanges);

    // ==================== 批量操作（含事务） ====================

    /// <summary>
    /// 批量插入（事务保护，统一提交）
    /// </summary>
    public virtual List<T> InsertBatch(IEnumerable<T> entities)
    {
        var list = entities.ToList();
        foreach (var entity in list)
        {
            if (string.IsNullOrEmpty(entity.Code))
                entity.Code = Guid.NewGuid().ToString("N");
        }

        _repository.ExecuteInTransaction(() =>
        {
            foreach (var entity in list)
                _repository.Insert(entity, false);  // 事务中不立即提交
        });  // 事务退出时统一提交

        return list;
    }

    /// <summary>
    /// 批量更新（事务保护，统一提交）
    /// </summary>
    public virtual List<T> UpdateBatch(IEnumerable<T> entities)
    {
        var list = entities.ToList();
        _repository.ExecuteInTransaction(() =>
        {
            foreach (var entity in list)
                _repository.Update(entity, false);
        });
        return list;
    }

    /// <summary>
    /// 批量删除（事务保护，统一提交）
    /// </summary>
    public virtual int DeleteBatchTransaction(IEnumerable<int> ids)
    {
        var count = 0;
        _repository.ExecuteInTransaction(() =>
        {
            foreach (var id in ids)
            {
                _repository.Delete(id, false);
                count++;
            }
        });
        return count;
    }

    // ==================== 带审计的写入（Controller 层便捷方法） ====================

    /// <summary>插入并填充审计字段</summary>
    public virtual T InsertWithAudit(T entity, string userId, string userName, bool saveChanges = true)
    {
        FillCreateAudit(entity, userId, userName);
        return Insert(entity, saveChanges);
    }

    /// <summary>更新并填充审计字段</summary>
    public virtual T UpdateWithAudit(T entity, string userId, string userName, bool saveChanges = true, string[]? updateFields = null)
    {
        FillUpdateAudit(entity, userId, userName);
        return Update(entity, saveChanges, updateFields);
    }

    // ==================== 私有方法 ====================

    private void FillCreateAudit(T entity, string userId, string userName)
    {
        entity.CreateTime = DateTime.UtcNow;
        entity.UpdateTime = DateTime.UtcNow;
        entity.CreateBy = userId;
        entity.UpdateBy = userName;
    }

    private void FillUpdateAudit(T entity, string userId, string userName)
    {
        entity.UpdateTime = DateTime.UtcNow;
        entity.UpdateBy = userName;
    }
}
```

### 2.3 ExcelExporter — Excel 导出服务

> 对标参考架构的 `ExcelController.GetExcelInfo`。
> 基于 GridConfig 的列定义（XSFlag=true）动态生成 Excel。

```csharp
namespace YZH.Core.Services;

using NPOI.SS.UserModel;
using NPOI.XSSF.UserModel;

/// <summary>
/// Excel 导出服务
/// 基于 GridConfig 配置动态生成 Excel 文件
/// </summary>
public class ExcelExporter
{
    private readonly GridConfigLoader _configLoader;

    public ExcelExporter(GridConfigLoader configLoader)
    {
        _configLoader = configLoader;
    }

    /// <summary>
    /// 导出 Excel（基于 GridConfig 的列定义）</summary>
    public byte[] Export<T>(IEnumerable<T> data, string configName) where T : BaseEntity
    {
        var config = _configLoader.GetConfig(configName);
        var columns = config.Columns
            .Where(c => c.XSFlag)
            .OrderBy(c => c.SXH)
            .ToList();

        IWorkbook workbook = new XSSFWorkbook();
        var sheet = workbook.CreateSheet(config.Title);
        var rowIndex = 0;

        // 标题行
        if (!string.IsNullOrEmpty(config.Title))
        {
            var titleRow = sheet.CreateRow(rowIndex++);
            var titleCell = titleRow.CreateCell(0);
            titleCell.SetCellValue(config.Title);
            var titleStyle = CreateTitleStyle(workbook);
            titleCell.CellStyle = titleStyle;
            sheet.AddMergedRegion(new CellRangeAddress(0, 0, 0, columns.Count - 1));
        }

        // 表头行
        var headerRow = sheet.CreateRow(rowIndex++);
        var headerStyle = CreateHeaderStyle(workbook);
        for (int i = 0; i < columns.Count; i++)
        {
            var cell = headerRow.CreateCell(i);
            cell.SetCellValue(columns[i].DesName);
            cell.CellStyle = headerStyle;
        }

        // 数据行
        var dataStyle = CreateDataStyle(workbook);
        foreach (var item in data)
        {
            var dataRow = sheet.CreateRow(rowIndex++);
            for (int i = 0; i < columns.Count; i++)
            {
                var cell = dataRow.CreateCell(i);
                cell.CellStyle = dataStyle;
                var prop = typeof(T).GetProperty(columns[i].FieldName,
                    System.Reflection.BindingFlags.IgnoreCase | 
                    System.Reflection.BindingFlags.Public | 
                    System.Reflection.BindingFlags.Instance);
                var value = prop?.GetValue(item);
                SetCellValue(cell, value, columns[i]);
            }
        }

        // 自动列宽
        for (int i = 0; i < columns.Count; i++)
            sheet.AutoSizeColumn(i);

        using var ms = new MemoryStream();
        workbook.Write(ms);
        return ms.ToArray();
    }

    private void SetCellValue(ICell cell, object? value, DefineColumn column)
    {
        if (value == null) return;

        switch (column.Type)
        {
            case ControlType.DatePicker:
            case ControlType.DateTimePicker:
                if (value is DateTime dt)
                    cell.SetCellValue(dt.ToString(column.Format ?? "yyyy-MM-dd HH:mm:ss"));
                break;
            case ControlType.Decimal:
                if (decimal.TryParse(value.ToString(), out var dec))
                    cell.SetCellValue((double)dec);
                break;
            case ControlType.CheckBox:
                cell.SetCellValue(value.ToString() == "True" || value.ToString() == "1" ? "是" : "否");
                break;
            default:
                cell.SetCellValue(value.ToString());
                break;
        }
    }

    private ICellStyle CreateTitleStyle(IWorkbook wb)
    {
        var style = wb.CreateCellStyle();
        var font = wb.CreateFont();
        font.FontHeightInPoints = 16;
        font.IsBold = true;
        style.SetFont(font);
        style.Alignment = HorizontalAlignment.Center;
        style.VerticalAlignment = VerticalAlignment.Center;
        return style;
    }

    private ICellStyle CreateHeaderStyle(IWorkbook wb)
    {
        var style = wb.CreateCellStyle();
        var font = wb.CreateFont();
        font.FontHeightInPoints = 12;
        font.IsBold = true;
        style.SetFont(font);
        style.Alignment = HorizontalAlignment.Center;
        style.FillForegroundColor = IndexedColors.Grey25Percent.Index;
        style.FillPattern = FillPattern.SolidForeground;
        style.BorderTop = BorderStyle.Thin;
        style.BorderBottom = BorderStyle.Thin;
        style.BorderLeft = BorderStyle.Thin;
        style.BorderRight = BorderStyle.Thin;
        return style;
    }

    private ICellStyle CreateDataStyle(IWorkbook wb)
    {
        var style = wb.CreateCellStyle();
        style.BorderTop = BorderStyle.Thin;
        style.BorderBottom = BorderStyle.Thin;
        style.BorderLeft = BorderStyle.Thin;
        style.BorderRight = BorderStyle.Thin;
        return style;
    }
}
```

### 2.4 ExcelImporter — Excel 导入服务

```csharp
namespace YZH.Core.Services;

using NPOI.SS.UserModel;
using NPOI.XSSF.UserModel;

/// <summary>
/// Excel 导入服务
/// 读取 Excel 文件，映射为实体列表（基于 GridConfig 列映射）
/// </summary>
public class ExcelImporter
{
    private readonly GridConfigLoader _configLoader;

    public ExcelImporter(GridConfigLoader configLoader)
    {
        _configLoader = configLoader;
    }

    /// <summary>
    /// 读取 Excel 并映射为实体列表</summary>
    public List<ImportItem<T>> Read<T>(Stream excelStream, string configName) where T : BaseEntity, new()
    {
        var config = _configLoader.GetConfig(configName);
        var columns = config.Columns
            .Where(c => c.BCFlag)
            .OrderBy(c => c.SXH)
            .ToList();

        var result = new List<ImportItem<T>>();
        
        var workbook = new XSSFWorkbook(excelStream);
        var sheet = workbook.GetSheetAt(0);
        
        // 跳过标题行和表头行（从第3行开始读取数据）
        var startRow = config.Title.IsNullOrEmpty() ? 2 : 3;
        
        for (int rowIndex = startRow; rowIndex <= sheet.LastRowNum; rowIndex++)
        {
            var row = sheet.GetRow(rowIndex);
            if (row == null) continue;

            var entity = new T();
            var hasValue = false;

            for (int colIndex = 0; colIndex < columns.Count; colIndex++)
            {
                var cell = row.GetCell(colIndex);
                var cellValue = GetCellValue(cell);
                if (!string.IsNullOrEmpty(cellValue)) hasValue = true;

                var prop = typeof(T).GetProperty(columns[colIndex].FieldName,
                    System.Reflection.BindingFlags.IgnoreCase | 
                    System.Reflection.BindingFlags.Public | 
                    System.Reflection.BindingFlags.Instance);
                
                if (prop != null)
                {
                    try
                    {
                        var converted = Convert.ChangeType(cellValue, prop.PropertyType);
                        prop.SetValue(entity, converted);
                    }
                    catch { /* 转换失败保持默认值 */ }
                }
            }

            if (hasValue)
                result.Add(new ImportItem<T>
                {
                    Entity = entity,
                    RowIndex = rowIndex,
                    ImportAction = DetermineImportAction(entity)
                });
        }
        return result;
    }

    private string? GetCellValue(ICell? cell)
    {
        if (cell == null) return null;
        return cell.CellType switch
        {
            CellType.Numeric => DateUtil.IsCellDateFormatted(cell)
                ? cell.DateCellValue.ToString("yyyy-MM-dd")
                : cell.NumericCellValue.ToString(),
            CellType.String => cell.StringCellValue?.Trim(),
            CellType.Boolean => cell.BooleanCellValue.ToString(),
            _ => null
        };
    }

    /// <summary>
    /// 判断是新增还是更新（基于 code 字段）</summary>
    private ImportAction DetermineImportAction<T>(T entity)
    {
        // 子类可重写：基于 code 查询数据库判断
        return ImportAction.Insert;
    }
}

/// <summary>导入项（含实体+元数据）</summary>
public class ImportItem<T> where T : BaseEntity
{
    public T Entity { get; set; } = null!;
    public int RowIndex { get; set; }
    public ImportAction ImportAction { get; set; }
    public string? ErrorMessage { get; set; }
}

public enum ImportAction { Insert, Update, Skip }
```

### 2.5 GridConfigLoader — 配置加载器

```csharp
namespace YZH.Core.Services;

/// <summary>
/// GridConfig 配置加载器
/// 从 JSON 文件加载，支持内存缓存
/// </summary>
public class GridConfigLoader
{
    private readonly IMemoryCache _cache;
    private readonly string _configDirectory;

    public GridConfigLoader(IMemoryCache cache, IWebHostEnvironment env)
    {
        _cache = cache;
        _configDirectory = Path.Combine(env.ContentRootPath, "GridConfigs");
    }

    /// <summary>
    /// 获取配置（优先缓存）</summary>
    public GridConfig GetConfig(string configName)
    {
        var cacheKey = $"GridConfig_{configName}";
        
        return _cache.GetOrCreate(cacheKey, entry =>
        {
            entry.SlidingExpiration = TimeSpan.FromMinutes(30);
            return LoadFromFile(configName);
        })!;
    }

    /// <summary>
    /// 根据类型名获取配置</summary>
    public GridConfig GetConfig<T>()
    {
        var typeName = typeof(T).Name;
        return GetConfig(typeName);
    }

    /// <summary>
    /// 强制刷新缓存</summary>
    public void Invalidate(string configName)
    {
        _cache.Remove($"GridConfig_{configName}");
    }

    /// <summary>
    /// 从文件加载配置</summary>
    private GridConfig LoadFromFile(string configName)
    {
        var filePath = Path.Combine(_configDirectory, $"{configName}.json");
        if (!File.Exists(filePath))
            throw new FileNotFoundException($"GridConfig not found: {filePath}");
        
        var json = File.ReadAllText(filePath);
        return JsonSerializer.Deserialize<GridConfig>(json, new JsonSerializerOptions
        {
            PropertyNameCaseInsensitive = true
        })!;
    }

    /// <summary>
    /// 保存/更新配置（供配置页面使用）</summary>
    public void SaveConfig(GridConfig config)
    {
        var filePath = Path.Combine(_configDirectory, $"{config.ConfigName}.json");
        var json = JsonSerializer.Serialize(config, new JsonSerializerOptions { WriteIndented = true });
        File.WriteAllText(filePath, json);
        Invalidate(config.ConfigName);
    }
}
```

### 2.6 DictService — 字典数据服务

```csharp
namespace YZH.Core.Services;

/// <summary>
/// 字典数据服务
/// 为前端下拉框、选择器等提供数据源
/// </summary>
public class DictService
{
    private readonly BaseDbContext _context;

    public DictService(BaseDbContext context)
    {
        _context = context;
    }

    /// <summary>根据字典名称获取字典项列表</summary>
    public virtual List<DictItem> GetDictItems(string dictName)
    {
        // 从数据字典表查询
        return _context.Set<Sys_Dictionary>()
            .Where(d => d.Code == dictName)
            .Select(d => new DictItem
            {
                Value = d.Value ?? "",
                Label = d.Name ?? ""
            })
            .ToList();
    }

    /// <summary>根据类型编码获取字典项（支持多级字典）</summary>
    public virtual List<DictItem> GetDictByCategory(string categoryCode)
    {
        return _context.Set<Sys_Dictionary>()
            .Where(d => d.CategoryCode == categoryCode && d.Enable == 1)
            .OrderBy(d => d.Sort)
            .Select(d => new DictItem
            {
                Value = d.Value ?? "",
                Label = d.Name ?? "",
                Tag = d.Tag
            })
            .ToList();
    }

    /// <summary>获取通用状态字典（Enable / Status 等）</summary>
    public virtual List<DictItem> GetCommonDict(string dictType)
    {
        return dictType.ToLower() switch
        {
            "enable" => new List<DictItem>
            {
                new() { Value = "1", Label = "启用" },
                new() { Value = "0", Label = "禁用" }
            },
            "status" => new List<DictItem>
            {
                new() { Value = "1", Label = "正常" },
                new() { Value = "0", Label = "停用" }
            },
            _ => new List<DictItem>()
        };
    }
}

public class DictItem
{
    public string Value { get; set; } = string.Empty;
    public string Label { get; set; } = string.Empty;
    public string? Tag { get; set; }
    public bool Disabled { get; set; }
}
```

### 2.7 EntityHelper — 实体工具类

```csharp
namespace YZH.Core.Services;

/// <summary>
/// 实体工具类
/// 提供实体元数据查询、反射操作
/// </summary>
public static class EntityHelper
{
    /// <summary>获取实体对应数据库表名</summary>
    public static string GetTableName<T>()
    {
        var type = typeof(T);
        var attr = type.GetCustomAttribute<TableAttribute>();
        return attr?.Name ?? type.Name;
    }

    /// <summary>获取实体所有可写字段名</summary>
    public static string[] GetWritableFields<T>()
    {
        return typeof(T).GetProperties(BindingFlags.Public | BindingFlags.Instance)
            .Where(p => p.CanWrite && p.Name != "Id")
            .Select(p => p.Name)
            .ToArray();
    }

    /// <summary>根据 GridConfig 获取可保存字段（BCFlag=true）</summary>
    public static string[] GetSaveableFields(GridConfig config)
    {
        return config.Columns
            .Where(c => c.BCFlag)
            .Select(c => c.FieldName)
            .ToArray();
    }

    /// <summary>获取字段的显示名称</summary>
    public static string GetFieldDisplayName(string fieldName, GridConfig config)
    {
        var col = config.Columns.FirstOrDefault(c =>
            c.FieldName.Equals(fieldName, StringComparison.OrdinalIgnoreCase));
        return col?.DesName ?? fieldName;
    }

    /// <summary>复制实体属性（排除审计字段）</summary>
    public static void CopyProperties<TSource, TDest>(TSource source, TDest dest, params string[] excludeFields)
        where TSource : BaseEntity
        where TDest : BaseEntity
    {
        var properties = typeof(TSource).GetProperties(BindingFlags.Public | BindingFlags.Instance)
            .Where(p => p.CanRead && p.CanWrite);

        foreach (var prop in properties)
        {
            if (excludeFields.Contains(prop.Name, StringComparer.OrdinalIgnoreCase))
                continue;

            var value = prop.GetValue(source);
            var destProp = typeof(TDest).GetProperty(prop.Name);
            destProp?.SetValue(dest, value);
        }
    }
}
```

### 2.8 WorkUnit — 事务工作单元（回调模式）

> 对标 Vol 框架的 `DbContextBeginTransaction(Func<WebResponseContent> action)`。
> **核心理念**：事务边界由回调函数界定，回调内所有 `saveChanges: false` 的操作统一提交。

```csharp
namespace YZH.Core.Services;

/// <summary>
/// 事务工作单元 — 回调模式
/// 
/// 使用方式：
///   workUnit.Execute(() => {
///       entityRepo.Insert(entity1, false);  // 不立即提交
///       entityRepo.Insert(entity2, false);  // 不立即提交
///       entityRepo.Delete(id, false);       // 不立即提交
///   });  // 退出时统一 Commit + SaveChanges
/// </summary>
public class WorkUnit : IDisposable
{
    private readonly BaseDbContext _context;
    private IDbContextTransaction? _transaction;
    private bool _nesting;  // 嵌套事务标记（已有事务时不再开启新事务）

    public WorkUnit(BaseDbContext context)
    {
        _context = context;
        _nesting = context.Database.CurrentTransaction != null;
    }

    /// <summary>
    /// 在事务中执行操作（回调模式）
    /// 回调内所有 saveChanges:false 的操作在退出时统一提交
    /// 
    /// 如果当前已有事务（嵌套调用），则直接执行回调（共享上层事务）
    /// </summary>
    public void Execute(Action action)
    {
        if (_nesting)
        {
            action();  // 嵌套：直接执行，共享上层事务
            return;
        }

        using var transaction = _context.Database.BeginTransaction();
        try
        {
            action();  // 执行业务操作（所有方法 saveChanges=false）
            _context.SaveChanges();  // 统一保存
            transaction.Commit();   // 提交事务
        }
        catch
        {
            transaction.Rollback();
            throw;
        }
    }

    /// <summary>
    /// 在事务中执行操作（带返回值）
    /// </summary>
    public TResult Execute<TResult>(Func<TResult> func)
    {
        if (_nesting)
        {
            return func();
        }

        using var transaction = _context.Database.BeginTransaction();
        try
        {
            var result = func();
            _context.SaveChanges();
            transaction.Commit();
            return result;
        }
        catch
        {
            transaction.Rollback();
            throw;
        }
    }

    /// <summary>
    /// 异步事务回调
    /// </summary>
    public async Task ExecuteAsync(Func<Task> action)
    {
        if (_nesting)
        {
            await action();
            return;
        }

        await using var transaction = await _context.Database.BeginTransactionAsync();
        try
        {
            await action();
            await _context.SaveChangesAsync();
            await transaction.CommitAsync();
        }
        catch
        {
            await transaction.RollbackAsync();
            throw;
        }
    }

    /// <summary>异步事务回调（带返回值）</summary>
    public async Task<TResult> ExecuteAsync<TResult>(Func<Task<TResult>> func)
    {
        if (_nesting)
        {
            return await func();
        }

        await using var transaction = await _context.Database.BeginTransactionAsync();
        try
        {
            var result = await func();
            await _context.SaveChangesAsync();
            await transaction.CommitAsync();
            return result;
        }
        catch
        {
            await transaction.RollbackAsync();
            throw;
        }
    }

    public void Dispose()
    {
        // 只有非嵌套时才释放事务资源
    }
}
```

### 2.9 SqlBaseService — SQL 拼接轻量查询

> Dapper + 原始 SQL 拼接，用于过滤、分页、排序等查询场景。
> 比 LINQ 表达式树更直观、更灵活。

```csharp
namespace YZH.Core.Services;

using Dapper;
using System.Data;

/// <summary>
/// SQL 拼接轻量查询服务
/// 采用 Dapper + 原始 SQL，处理过滤、分页、排序等场景
/// 
/// 使用示例：
///   var sql = sqlBase.BuildQuery("sys_user", request.Conditions, "create_time DESC");
///   var (items, total) = sqlBase.GetPage<UserDto>(sql, request.Page, request.PageSize);
/// </summary>
public class SqlBaseService
{
    private readonly IDbConnection _connection;

    public SqlBaseService(IDbConnection connection)
    {
        _connection = connection;
    }

    // ==================== SQL 构建 ====================

    /// <summary>构建带条件的分页 SQL</summary>
    public SqlBuilder BuildQuery(string tableName, SearchCondition[]? conditions, string? orderBy = null)
    {
        var sql = new SqlBuilder();
        sql.Append($"SELECT * FROM {tableName}");
        sql.AppendWhere(conditions);
        if (!string.IsNullOrEmpty(orderBy))
            sql.Append($" ORDER BY {orderBy}");
        return sql;
    }

    /// <summary>构建 Count SQL</summary>
    public SqlBuilder BuildCount(string tableName, SearchCondition[]? conditions)
    {
        var sql = new SqlBuilder();
        sql.Append($"SELECT COUNT(*) FROM {tableName}");
        sql.AppendWhere(conditions);
        return sql;
    }

    // ==================== 查询执行 ====================

    /// <summary>分页查询</summary>
    public virtual (List<T> items, int total) GetPage<T>(SqlBuilder querySql, int page, int pageSize)
    {
        var offset = (page - 1) * pageSize;
        var items = _connection.Query<T>(
            $"{querySql.SQL} LIMIT @Offset @PageSize",
            new { Offset = offset, PageSize = pageSize, querySql.Parameters
        }).ToList();

        var total = _connection.ExecuteScalar<int>(
            BuildCountSql(querySql),
            querySql.Parameters);

        return (items, total);
    }

    /// <summary>查询列表（不分页）</summary>
    public virtual List<T> GetList<T>(SqlBuilder querySql)
    {
        return _connection.Query<T>(querySql.SQL, querySql.Parameters).ToList();
    }

    /// <summary>查询单个</summary>
    public virtual T? GetFirst<T>(SqlBuilder querySql)
    {
        return _connection.QueryFirstOrDefault<T>(querySql.SQL, querySql.Parameters);
    }

    /// <summary>执行非查询（INSERT/UPDATE/DELETE）</summary>
    public virtual int Execute(string sql, object? parameters = null)
    {
        return _connection.Execute(sql, parameters);
    }

    // ==================== 私有方法 ====================

    private static string BuildCountSql(SqlBuilder querySql)
    {
        // 替换 SELECT * 为 SELECT COUNT(*)
        var sql = querySql.SQL;
        var selectIndex = sql.IndexOf("SELECT ", StringComparison.OrdinalIgnoreCase);
        var fromIndex = sql.IndexOf(" FROM ", StringComparison.OrdinalIgnoreCase);
        if (selectIndex >= 0 && fromIndex > selectIndex)
        {
            sql = sql.Substring(0, selectIndex) + "SELECT COUNT(*)" + sql.Substring(fromIndex);
        }
        // 移除 ORDER BY（如果有）
        var orderIndex = sql.LastIndexOf(" ORDER BY ", StringComparison.OrdinalIgnoreCase);
        if (orderIndex > 0)
        {
            sql = sql.Substring(0, orderIndex);
        }
        return sql;
    }
}

/// <summary>SQL 构建器（参数化查询，防注入）</summary>
public class SqlBuilder
{
    private readonly StringBuilder _sql = new();
    private readonly DynamicParameters _parameters = new();
    private int _paramIndex = 0;

    public string SQL => _sql.ToString();
    public object Parameters => _parameters;

    public SqlBuilder Append(string sql)
    {
        _sql.Append(' ').Append(sql);
        return this;
    }

    /// <summary>根据条件动态拼接 WHERE 子句</summary>
    public SqlBuilder AppendWhere(SearchCondition[]? conditions)
    {
        if (conditions == null || conditions.Length == 0) return this;

        var validConditions = conditions
            .Where(c => !string.IsNullOrEmpty(c.Field) && c.Value != null)
            .ToList();

        if (!validConditions.Any()) return this;

        _sql.Append(" WHERE ");
        for (int i = 0; i < validConditions.Count; i++)
        {
            var condition = validConditions[i];
            var paramName = $"p_{_paramIndex++}";

            if (i > 0) _sql.Append(" AND ");

            var op = condition.Operator.ToLower() switch
            {
                "eq" => "=",
                "neq" => "<>",
                "gt" => ">",
                "gte" => ">=",
                "lt" => "<",
                "lte" => "<=",
                "like" => "LIKE",
                _ => "="
            };

            if (op == "LIKE")
            {
                _sql.Append($"@{paramName}");
                _parameters.Add(paramName, $"%{condition.Value}%");
            }
            else
            {
                _sql.Append($"{condition.Field} {op} @{paramName}");
                _parameters.Add(paramName, condition.Value);
            }
        }

        return this;
    }

    public override string ToString() => SQL;
}
```

## 三、PageBaseController<T> — 单页面控制器基类

### 3.1 设计思路

基于基础设施服务层，通过 **组合** 而非继承实现单页面控制器。
基类本身也只是一个薄的编排层，把请求委托给基础设施服务。

```csharp
namespace YZH.Core.Web.Controllers;

[ApiController]
[Route("api/[controller]")]
public abstract class PageBaseController<T> : ControllerBase where T : BaseEntity
{
    // === 基础设施服务（组合引用）===
    protected readonly EntityService<T> EntityService;
    protected readonly ExcelExporter Exporter;
    protected readonly ExcelImporter Importer;
    protected readonly GridConfigLoader ConfigLoader;
    protected readonly WorkUnit WorkUnit;

    // === 页面配置 ===>
    protected GridConfig Config { get; }

    protected PageBaseController(
        EntityService<T> entityService,
        ExcelExporter exporter,
        ExcelImporter importer,
        GridConfigLoader configLoader,
        WorkUnit workUnit)
    {
        EntityService = entityService;
        Exporter = exporter;
        Importer = importer;
        ConfigLoader = configLoader;
        WorkUnit = workUnit;
        Config = LoadConfig();
    }

    // ============================================================
    // 一、配置与初始化
    // ============================================================

    /// <summary>加载 GridConfig（默认从 JSON 文件）</summary>
    protected virtual GridConfig LoadConfig()
    {
        return ConfigLoader.GetConfig<T>();
    }

    /// <summary>获取配置（前端调用）</summary>
    [HttpGet("config")]
    public virtual ActionResult<ApiResponse<GridConfig>> GetConfig()
    {
        OnConfigLoading(Config);
        return Ok(ApiResponse<GridConfig>.Ok(Config));
    }

    /// <summary>配置加载时的钩子</summary>
    protected virtual void OnConfigLoading(GridConfig config) { }

    // ============================================================
    // 二、查询（含分页）
    // ============================================================

    [HttpPost("page")]
    public virtual ActionResult<ApiResponse<PagedResult<T>>> GetPage(
        [FromBody] PageRequest request)
    {
        var ctx = CreateContext(request.Conditions);
        OnQuerying(ctx);

        var (items, total) = EntityService.GetPage(new PagerOptions
        {
            Page = request.Page,
            PageSize = request.PageSize,
            SortBy = request.SortField,
            SortDirection = request.SortOrder,
            Filters = ConvertConditions(request.Conditions)
        });

        var result = new PagedResult<T>(items, total, request.Page, request.PageSize);
        OnQueried(ctx, result);

        return Ok(ApiResponse<PagedResult<T>>.Ok(result));
    }

    protected virtual void OnQuerying(PageContext<T> ctx) { }
    protected virtual void OnQueried(PageContext<T> ctx, PagedResult<T> result) { }

    // ============================================================
    // 三、新增
    // ============================================================

    [HttpPost("add")]
    public virtual ActionResult<ApiResponse<T>> Add([FromBody] T entity)
    {
        var ctx = CreateSaveContext(entity, OperType.Add);

        var validateResult = ValidateEntity(entity, Config);
        if (!validateResult.Success)
            return BadRequest(ApiResponse<T>.Fail(validateResult.Message));

        OnAdding(ctx);
        if (ctx.Cancel)
            return BadRequest(ApiResponse<T>.Fail(ctx.ErrorMessage ?? "操作已取消"));

        var result = EntityService.Insert(entity, ctx.UserId, ctx.UserName);
        ctx.Entity = result;
        OnAdded(ctx);

        return Ok(ApiResponse<T>.Ok(result, "创建成功"));
    }

    protected virtual void OnAdding(SaveContext<T> ctx) { }
    protected virtual void OnAdded(SaveContext<T> ctx) { }

    // ============================================================
    // 四、修改
    // ============================================================

    [HttpPost("update")]
    public virtual ActionResult<ApiResponse<T>> Update([FromBody] T entity)
    {
        var ctx = CreateSaveContext(entity, OperType.Update);

        var validateResult = ValidateEntity(entity, Config);
        if (!validateResult.Success)
            return BadRequest(ApiResponse<T>.Fail(validateResult.Message));

        OnUpdating(ctx);
        if (ctx.Cancel)
            return BadRequest(ApiResponse<T>.Fail(ctx.ErrorMessage ?? "操作已取消"));

        var saveableFields = EntityHelper.GetSaveableFields(Config);
        var result = saveableFields.Length > 0
            ? EntityService.Update(entity, ctx.UserId, ctx.UserName, saveableFields)
            : EntityService.Update(entity, ctx.UserId, ctx.UserName);

        ctx.Entity = result;
        OnUpdated(ctx);

        return Ok(ApiResponse<T>.Ok(result, "更新成功"));
    }

    protected virtual void OnUpdating(SaveContext<T> ctx) { }
    protected virtual void OnUpdated(SaveContext<T> ctx) { }

    // ============================================================
    // 五、删除
    // ============================================================

    [HttpPost("delete")]
    public virtual ActionResult<ApiResponse> Delete([FromBody] string[] ids)
    {
        var ctx = CreateSaveContext(null, OperType.Delete);

        OnDeleting(ctx);
        if (ctx.Cancel)
            return BadRequest(ApiResponse.Fail(ctx.ErrorMessage ?? "操作已取消"));

        var count = EntityService.DeleteBatchTransaction(ids);

        OnDeleted(ctx);
        return Ok(ApiResponse.Ok($"已删除 {count} 条记录"));
    }

    protected virtual void OnDeleting(SaveContext<T> ctx) { }
    protected virtual void OnDeleted(SaveContext<T> ctx) { }

    // ============================================================
    // 六、导出
    // ============================================================

    [HttpPost("export")]
    public virtual IActionResult Export([FromBody] SearchCondition[]? conditions)
    {
        var predicate = EntityService.BuildPredicate(conditions);
        var items = EntityService.GetList(predicate);
        var bytes = Exporter.Export(items, Config.ConfigName);

        return File(bytes,
            "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
            $"{Config.Title}_{DateTime.Now:yyyyMMdd_HHmmss}.xlsx");
    }

    // ============================================================
    // 七、导入
    // ============================================================

    [HttpPost("import")]
    public virtual ActionResult<ApiResponse<ImportResult>> Import(IFormFile file)
    {
        using var stream = file.OpenReadStream();
        var importItems = Importer.Read<T>(stream, Config.ConfigName);

        var result = new ImportResult { TotalRows = importItems.Count };

        // 事务回调模式：所有操作 saveChanges=false，退出回调时统一提交
        WorkUnit.Execute(() =>
        {
            foreach (var item in importItems)
            {
                var existing = FindByCode(item.Entity.Code);
                if (existing != null)
                {
                    // 更新：保留原 Id，Code 不变
                    item.Entity.Id = existing.Id;
                    EntityService.InsertWithAudit(item.Entity, "system", "导入", saveChanges: false);
                    result.Updated++;
                }
                else
                {
                    // 新增：自动生成 Code
                    EntityService.InsertWithAudit(item.Entity, "system", "导入", saveChanges: false);
                    result.Inserted++;
                }
            }  // 回调退出时统一 Commit + SaveChanges
        });

        return Ok(ApiResponse<ImportResult>.Ok(result,
            $"导入完成：新增 {result.Inserted} 条，更新 {result.Updated} 条"));
    }

    /// <summary>根据业务 code 查找实体（子类重写）</summary>
    protected virtual T? FindByCode(string code) => null;

    // ============================================================
    // 八、字典数据源
    // ============================================================

    [HttpGet("dict/{dictName}")]
    public virtual ActionResult<ApiResponse<List<DictItem>>> GetDict(string dictName)
    {
        var dict = GetDictItems(dictName);
        return Ok(ApiResponse<List<DictItem>>.Ok(dict));
    }

    protected virtual List<DictItem> GetDictItems(string dictName) => new();

    // ============================================================
    // 九、辅助方法
    // ============================================================

    protected ValidationResult ValidateEntity(T entity, GridConfig config)
    {
        foreach (var col in config.Columns.Where(c => !c.YXK && c.BCFlag))
        {
            var prop = typeof(T).GetProperty(col.FieldName,
                System.Reflection.BindingFlags.IgnoreCase |
                System.Reflection.BindingFlags.Public |
                System.Reflection.BindingFlags.Instance);
            var value = prop?.GetValue(entity);
            if (value == null || (value is string s && string.IsNullOrWhiteSpace(s)))
                return ValidationResult.Fail($"{col.DesName} 不能为空");
        }
        return ValidationResult.Ok();
    }

    private PageContext<T> CreateContext(SearchCondition[]? conditions) => new()
    {
        Config = Config,
        Conditions = conditions ?? Array.Empty<SearchCondition>(),
        HttpContext = HttpContext
    };

    private SaveContext<T> CreateSaveContext(T? entity, OperType operType) => new()
    {
        Config = Config,
        Entity = entity!,
        OperType = operType,
        HttpContext = HttpContext
    };

    private List<FilterItem> ConvertConditions(SearchCondition[]? conditions)
    {
        return conditions?.Select(c => new FilterItem
        {
            Field = c.Field,
            Operator = c.Operator,
            Value = c.Value
        }).ToList() ?? new List<FilterItem>();
    }
}
```

## 六、总结

### 6.1 核心设计理念

```
基础设施（无状态服务）
       ↓ DI 注入
通用 Controller 基类（组合基础设施）
       ↓ 继承 + 重写少量方法
业务 Controller（极简）
       ↓ HTTP
前端 YzhListPage 基类组件
       ↓ Props 传入 config + hooks
业务页面（3个文件：index.vue + config.ts + api.ts）
```

### 6.2 关键决策

| 问题 | 决策 | 原因 |
|------|------|------|
| 实体操作放在哪？ | `EntityService<T>` 而非 Repository | Repository 管数据访问，Service 管业务编排 |
| Controller 如何获取基础能力？ | DI 组合而非继承 | 灵活替换、便于单元测试 |
| 导入导出逻辑放哪？ | 独立服务（Exporter / Importer） | 可被任何 Controller / 后台任务复用 |
| 事务如何控制？ | `WorkUnit` 回调模式 | `Execute(Action)` 回调内所有 `saveChanges:false` 操作统一提交，结构紧凑 |
| 配置加载放哪？ | `GridConfigLoader` | 支持热更新、缓存 |
| 数据查询怎么做？ | Dapper + SQL 拼接（`SqlBaseService`） | 比 LINQ 表达式树更直观，适合动态过滤、分页、排序 |
| 主键策略？ | `Id`（int 自增）物理主键 + `Code`（GUID）业务键 | 物理主键优化存储，业务键用于导入匹配/跨系统交互 |
