| 项 | 数量 |
|---|---:|
| 9001 全部条款 | 78 |
| 其中父条款（无原文，仅分组） | 18 |
| **叶子条款（有原文、要生成属性）** | **60（60/60 原文齐）** |

四标准叶子条款：9001 = 60、24001 = 35、45001 = 43、42061 = 70，合计 218。**第一轮只做 9001 的 60 条。**
