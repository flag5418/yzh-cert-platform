
`FillStatus` 六态定义：

```text
filled        至少一行关键字段有实际值
partial       有实际数据，但关键字段不全或只填少量行
blank         某条记录实例存在，但该实例字段为空
template_only 只有模板/表头/字段名，没有业务实例
unreadable    文本/表格无法辨认
absent        没有这份文档
```

## 3. 本次发现的两个问题

### 3.1 不是提示词问题，是输入截断

第一次跑 `QR-017` 时，只给了前 20 段正文，模型判 `partial`。  
改成完整 905 段后，判 `filled`。

**结论：** `DocFact` 的准确性依赖输入覆盖。P3 的 `RenderDocHits()` 必须：
- 给完整记录表，或明确标注 `Coverage=抽样`；
- 不能只给前 20 行却让模型判断整份记录；
- 对超长记录，先按 sheet/段落块采样，并在 `SampleRows` 标 `RowRef`。

### 3.2 `blank` 与 `template_only` 必须固定

第一次跑：
- `PR-027`、`QR-027` 判 `blank`；
- `QR-020` 判 `template_only`。

同一类“空白表单”出现两种结果。  
**修正：** 明确“只有模板/表头/字段名，没有业务实例 = `template_only`”；“有记录实例但字段为空 = `blank`”。重跑后 5/5 一致。
