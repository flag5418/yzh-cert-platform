## 四、两条采集路线

### 4.1 路线 A：按条款

**适用文档**：

- 质量手册（章节/条款框架）；
- 方针、目标、领导作用；
- 组织环境、相关方需求期望；
- 内审、管理评审；
- 报告结论、体系级汇总。

**输入**：`标准 + 条款号`（可再带 `企业`、`报告版本`）。

**输出**：条款级事实 / 判定依据 / 文件引用。

**现有入口**：

```text
GET /api/Auditor/EnterpriseDoc/extraction/by-clause?standardCode=&clauseNumber=&onlyDone=
```

**不适用**：程序、作业指导书、记录、设备台账、供应商清单。它们不是「一条条款一段」，硬按条款跑会重复、漏项、输出膨胀。

### 4.2 路线 B：按章节 + 部门

**适用文档**：

- 程序文件；
- 作业指导书 / 操作规程；
- 记录 / 表单；
- 设备台账；
- 供应商清单；
- 文件清单 / 封面（文件控制单独走 `document_control`）。

**输入**：`标准 + 章节（如 8 / 8.5）+ 部门（如 生产部）+ 文档类型`。

**输出**：该部门的「过程—指导—记录—证据指针」包：

```json
{
  "FileCode": "...",
  "FileName": "17生产和服务提供控制程序.doc",
  "DocType": "程序文件",
  "ExtractionMode": "过程画像",
  "OwnerDept": "生产部",
  "DeptNames": ["生产部", "品质部", "技术部"],
  "ClauseNumbers": "",
  "MatchedBy": "mode_fallback",
  "HasExtraction": true
}
```

**新入口**：

```text
POST /api/Auditor/EnterpriseDoc/collect
{
  "EnterpriseCode": "7f9c7fa37cbf4c14aa1f4bffdc30ae51",
  "StandardCode": "c9d3e1f5-2a68-4b7c-8e04-5a1b7f3d9c62",
  "Chapter": "8",
  "DeptNames": ["生产部"],
  "DocTypes": ["程序文件", "作业指导书", "记录表单"],
  "MaxDocs": 100
}
```

只读：不建队列、不调用 LLM、不改文档状态。

代码落点：

- `EnterpriseDocService.CollectAsync`：匹配、回读 `ContentJson`、部门合并、`MatchedBy`；
- `EnterpriseDocController.Collect` + `CollectRequest`：`POST collect`；
- 辅助方法：`ReadClauseNumbers` / `ReadExtractionDeptNames` / `ModeMatchesChapter` / `ClauseInChapter`。

### 4.3 文档类型 → 路线选择

| 文档类型 | 路线 | 提取模式 | 输出深度 |
|---|---|---|---|
| 质量手册 | A | `ClauseFull` / 章节框架 | 章节/条款 |
| 方针、目标、领导作用 | A | `PolicyProfile` | 近原文 |
| 组织环境 / 相关方 | A | `ContextList` | 条款级事实 |
| 内审 / 管理评审 | A | `Audit` | 近原文发现/结论 |
| 程序文件 | B | `ProcessProfile` / `ReportProjection` | 摘要 + 3–6 关键控制 |
| 作业指导书 | B | `WorkInstructionCitation` | 3–8 步骤 + 记录 |
| 记录 / 表单 | B | `RecordProfile` | 字段 + 2–3 样例 |
| 设备台账 | B | `RecordProfile` | 7.1.3 + 设备管理部 |
| 供应商清单 | B | 待定（8.4 evidence） | 8.4 + 采购部 |
| 文件清单 / 封面 | 文件控制 | `DocumentControl` | 元数据 + 目录 |
| 财务 / 考勤等无关 | 跳过 | `None` | 0 秒，不调 LLM |

### 4.4 为什么这样分

- **报告的分量不在程序/指导全文**：真实报告对 17 只显式引用 2 条（7.5.3、Q8.1），8.5.1–8.7 的证据来自生产计划、作业文件、检验记录；
- **记录才是证据层**：需要日期、批次、型号、实测值、人员、结论；
- **方针/领导/审核是近原文层**：不能改写成摘要；
- **手册是框架层**：用于定位，不用于证据；
- **索引是导航层**：只给文件号、版本、保存部门/期限。

所以「所有文档 × 所有条款 × 所有标准」既慢又不准；正确做法是先画像，再选路线，再按章节/条款 + 部门收窄。
