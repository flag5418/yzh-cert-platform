## 3. 当前已知的边界与未决项

1. **文档提示词太重**：Id10 约 10KB，字段字典按格式展开；不同咨询公司/企业格式差异大，需要压成“文档分类 + 核心作用 + 关键字段 + 填写状态 + 样本 + 覆盖”。
2. **条款提示词证据依赖不足**：`EvidenceContract` 仍是 `EvidenceName[]` 平铺，没有 `Dependencies/CrossChecks`，也没有把 `4.2.5` 作为 `evidence_rule` 接入。
3. **空白模板不能判缺失**：应输出 `template_only`，只写“模板存在、抽样为空”，不补 ERP、不编造抽样。
4. **NC 不作为核心**：不从文档反推 NC，报告 NC 只作验证样本。
5. **报告不是提取源**：报告数据只作对账列，不能回填企业文档事实。
