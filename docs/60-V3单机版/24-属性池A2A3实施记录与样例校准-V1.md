## 二、提示词改了什么（相对原来那份兜底）

| 改动 | 原因 |
|---|---|
| 补 `EvidenceForm` / `EvidenceFamily` / `Role` 三条判据 | 属性池 8→11，提示词不同步 ⇒ 模型静默不产新属性（这是此前"属性对不上"的根因） |
| 删 `DocCheckMode` 判据 | 该属性不在池内，留着会让模型输出池外字段 |
| 新增「三属性一致约束」 | f1↔cite、f2↔sample、角色与族的大致对应；不一致必须说明理由，不许两头填满凑一致 |
| 新增「不适用给空值」硬约束 | 挂不上的属性给空串/空数组是合法输出，⛔ 不许硬编填满 |
| `Role` 判据明确写「按功能判、不按章号判」+ 跨标准同功能同角色 | 你确认过的结论：章号与功能错位 |

提示词正文特征：只写**判据**，字段清单全部由 `{{attr_pool}}` 实时渲染（属性池增删改自动跟上，不用再改正文）。

## 三、三条样例（跨 3 个功能角色，用来校准口径）

### 样例 1 · 8.4.1 总则（外部提供的过程、产品和服务）

| 属性 | 值 |
|---|---|
| `ClauseIntent` | 控制外部提供的过程、产品和服务，使其符合组织与顾客的要求 |
| `Obligation` | `shall` |
| `Applicability` | `general`（原文无"适用时"，有 a/b/c 三种情形，属场景枚举而非适用条件） |
| `ApplicabilityCondition` | 空（同上） |
| `Process` | `["purchase"]` |
| `Severity` | `critical` |
| `EvidenceForm` | `sample` |
| `EvidenceFamily` | `f1f2`（"确定**并实施**…准则" ⇒ 建立+执行） |
| `Role` | `r5` 运行 |

`Artifacts`（提示词正文，摘录）：

> 只输出 JSON 数组…元素含 Kind（artifact_type 码）、Name、Purpose。去采购与外包类文件里找：供方评价准则与合格供方名录（list）、供方评价与再评价记录（record）、采购订单与采购合同（record）、外包协议（procedure）、进货检验或验证记录（record）。认关键字段：供方名称、评价日期、评价结论、批准人、采购物料与数量、验证或验收结果。

`EvidenceChain`（取证剧本，摘录）：

> …先调取合格供方名录与评价准则，核对评价项是否覆盖供应能力、资质与绩效监视；再抽 3 份本期采购或外包记录，逐份追到对应的进货验证或外包验收记录；最后访谈采购负责人，确认再评价的触发条件、不合格供方的处置方式。

### 样例 2 · 6.1 应对风险和机遇的措施

| 属性 | 值 |
|---|---|
| `ClauseIntent` | 策划应对风险和机遇的措施，并确定如何在体系中实施与评价其有效性 |
| `Obligation` | `shall` |
| `Applicability` / `ApplicabilityCondition` | `general` / 空 |
| `Process` | `["management"]` |
| `Severity` | `major` |
| `EvidenceForm` | `cite` |
| `EvidenceFamily` | `f1f2`（"策划…措施" + "整合并实施" + "评价有效性"） |
| `Role` | `r3` 策划 |

`Artifacts` 关键物：风险与机遇识别评价表、措施清单/措施计划、措施实施与有效性评价记录、相关程序文件。
`EvidenceChain` 三步：查风险与机遇清单是否覆盖 4.1 因素与 4.2 相关方要求 → 抽 2–3 项措施追到实施记录与有效性评价 → 访谈管理者代表确认如何整合进过程。

### 样例 3 · 9.2 内部审核

| 属性 | 值 |
|---|---|
| `ClauseIntent` | 按策划的时间间隔实施内部审核，评价体系是否符合要求并得到有效实施和保持 |
| `Obligation` | `shall` |
| `Applicability` / `ApplicabilityCondition` | `general` / 空 |
| `Process` | `["management"]` |
| `Severity` | `critical`（内审失效 = 体系自我纠错失效） |
| `EvidenceForm` | `sample` |
| `EvidenceFamily` | `f1f2`（"策划、制定、实施和保持审核方案"） |
| `Role` | `r6` 绩效 |

`Artifacts` 关键物：内审程序、年度审核方案与实施计划、内审检查表、内审报告、不符合报告与整改记录、内审员资格/任命文件。
`EvidenceChain` 三步：查年度方案（频次/方法/职责/准则是否覆盖全条款全部门）→ 抽 1 次完整内审看检查表、报告、不符合是否闭环 → 核对内审员是否审了自己部门，访谈负责人确认跟踪方式。
