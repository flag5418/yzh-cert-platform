## 一、四标准骨架对照（先章后款）

> 结论：国家制定标准的严格逻辑得到语料证实——9001/24001/45001 章条同构且环节一一对应；42061 是独立血统（旧 HLS 结构），但其**附录 B 提供了与 9001 的官方对照**，跨标准映射有权威依据（国标对比规律三）。

### 3.2 关键发现

1. **文档信号三层齐备、互相印证**：①文件名 = 条款标题同义改写（第一信号，覆盖 90%+）；②封面编号 KSY-QMS-P-xx 与报告引用编号（P-14-01/P-15-02/P-21-01）直接对上记录；③手册"目录与标准条款对应表 + 每节末'相关/引用文件'"是条款→程序的第二映射。
2. **编号与条款号无严格映射**：程序编号按章节顺序分块（4→6/7→8→9/10）但被 6/9/10 章程序穿插，8 章块内顺序亦非单调。**不能靠编号猜条款，必须靠文件名 + 手册引用 + 目的段**。
3. **"文档→条款"方向需语义兜底**：程序 21 标题"放行"但目的段写"监视测量"、程序 12 目的段通篇"服务"（制造企业模板残留）——**单靠文件名会误判，须读目的段/手册正文确认语义**。
4. 报告引用与归档目录的三处 gap：检验规范类三阶文件（《原材料检查指导书》《成品通用检验标准书》等）与《钉制机设备操作流程》不在归档目录；程序名与文件名不一致（审核员按内容意译）；《品质异常处理单》vs《不合格品处理单》近似对应。
5. 手册对第 8 章逐条款完整覆盖（含 8.3 不适用声明），**手册每节末尾"相关/引用文件"是可机器提取的条款→文档映射源**。

### 3.3 对照结论

**条款→文档方向可自助完成**（三层信号够）；**文档→条款方向须目的段/手册正文兜底**；三阶文件层信号最弱（检验规范、操作规程类最易散佚，需现场补证）。这直接决定对照主数据的建立顺序：文件名批量对上 → 手册引用文件小节机器提取 → 目的段语义确认兜底。
