# 企业文档与审核报告的映射实证 V1

> 目的：在讨论模型之前，先用真实报告把"企业文档 → 报告句子"的对应关系摸清楚，回答三个问题：
> ① 报告里的字到底从哪来 ② 哪些是搬运、哪些是加工 ③ 哪些必须模型、哪些纯规则就够。
> 样本：3 份正式审核记录（1 份 80 页多部门 QES 一体化 + 2 份单部门）。全部有文本层，可精确统计。

---

## 一、样本与口径

| 实例 | 规模 | 结构 | 用途 |
|---|---|---|---|
| A 公司检查清单及审核记录 | 80 页，6 个部门，记录列 49,522 字，843 句 | 三栏：过程要求 / 检查清单 / 审核记录 | 主力样本（多部门、含外包、含证书抽查） |
| 二阶段-行政部 AC 组 | 5 页，50 句 | 同上 | 验证"程序引用 + 风险表搬运" |
| 二阶段-财务部 AC 组 | 3 页，41 句 | 同上 | 验证"职责条文为主" |

统计口径：按"记录"栏切句（。；为界），按字符统计占比，避免短句多、长句少造成的偏差。

---

## 二、报告文字的构成（A 公司 843 句 / 49,522 字）

> **口径修正（2026-11-10 补测，见 06 号文档）**：下表"搬运 42.6%"是**按句子长度推断**的口径（长句视为搬运）。用三套"企业资料 + 对应报告"配对样本做逐字比对后证实：报告里真正照抄原文的比例只有 **3–11%**，那 42.6% 实际是**改写后的长句**（事实全部保留，句式由审核员重写）。结论方向不变（事实来自文档），但研发上必须按"抽事实点 + 填模板"做，不能按"复制原文段"做。

| 句子类型 | 句数 | 字符 | 字符占比 | 平均句长 | 典型形态 |
|---|---:|---:|---:|---:|---|
| 搬运（原文照抄） | 212 | 20,122 | **42.6%** | 93 字 | 证件字段、合同条款、职责条文、风险清单 |
| 短说明（其他） | 401 | 11,552 | 24.5% | 28 字 | "关键过程：计量配料""特种设备：无" |
| 引用（《》+概括） | 94 | 9,661 | **20.5%** | 95 字 | "查见《X 程序》（编号），规定……" |
| 结论 | 93 | 5,183 | 11.0% | 52 字 | "经查……基本符合要求" |
| 抽样明细（编号行） | 168 行 | 5,619 | 11.3% | 33 字 | "1、××，低压电工作业，2023-05-22 至 2029-05-21" |

**结论一：报告里 63% 的字是"引用 + 搬运"，只有 11% 是判断结论。**

也就是说，审核员写报告的主要工作量是**把企业文档里的内容搬进正确的位置**，不是"想判断"。这与你之前的判断一致，但有量化：搬运占 42.6%，比引用还多。

**结论二：真正被"点名"最多的不是程序文件，而是各种表/清单。**

105 处《》书名号引用，按文件名类型分布：

| 文件名类型 | 次数 | 说明 |
|---|---:|---|
| 表 / 清单 / 台账 / 一览表 | **41** | 记录表单是证据本体，被点名最多 |
| 其他（协议、报告类） | 15 | — |
| 程序文件 | 13 | 每次带长段概括（约 95 字） |
| 记录（培训、检验等） | 11 | — |
| 合同 | 10 | 多为整段搬运 |
| 管理手册 | 8 | 多为条文搬运 |
| 报告（内审、管评） | 6 | — |
| 制度 / 规定 / 规范 | 1 | 极少 |

**结论三：抽查只占 11% 的字，但集中在"编号行"，是最适合模板化的部分。**

168 条编号行，形态高度固定：`序号、姓名/编号、岗位/项目、日期或有效期、发证/检验机构`。这部分恰恰是审核员最费时间的地方（要从一堆记录里逐条抄字段），自动化性价比最高。

**结论四：报告体量按部门差异极大。**

| 部门 | 句数 | 字数 | 特征 |
|---|---:|---:|---|
| 生产部及现场、实验室 | 429 | 26,556 | 最大，现场 + 环境因素 + 危险源 |
| 领导层 | 152 | 7,537 | 证件、工艺流程、内外部因素 |
| 综合部 | 123 | 7,435 | 培训、文件控制 |
| 销售部 | 74 | 4,300 | 职责条文 + 目标 |
| 采购部 | 64 | 3,599 | 供方评价 + 合同 |
| 财务部（另一实例） | 41 句 | — | 几乎全是职责条文 |

**一个部门可达 2.6 万字** → 生成时必须按条款组分段，不可能一次喂完。

## 三、四类转化：原文长什么样，要抽什么

### 类型 A：搬运（42.6%）——原文照抄，几乎不改写

**证件类**（A 公司 P47）：

> 公司地址为租赁，查见《租赁合同》：甲方…乙方…租用期限：20 年（自 2022 年 4 月 1 日起至 2042 年 3 月 31 日止）。双方对租金、责任等进行了约定，双方已盖章。
> 《不动产权证》：达国用(2006)第 04508 号；土地使用权人…；用途：工业用地；使用权面积 12053.6000 ㎡；终止日期：2053 年 2 月 18 日。

**职责条文**（A 公司 P62，销售部）：

> a）负责预拌混凝土、预拌砂浆的市场开发、业务洽谈及客户维护工作…
> b）负责客户需求识别与评审，组织开展合同评审工作…
> c）负责产品交付、现场服务及客户反馈收集…
> d）负责销售合同的签订、执行及台账管理…
> e）负责市场信息收集与分析…
> f）负责识别销售过程中的环境因素、危险源…

**这就是你说的"质量手册绝大部分原文引用"**：职责是按 a)–f) 逐条搬的，一个字没改。

**需要抽什么**：证件字段（证号、权利人、用途、面积、期限、发证机关、日期）、条文段落（按 a)b)c) 切分）、签署状态（是否盖章签字）。

**加工度**：L0（复制）。规则可做，关键是"定位到哪一章/哪一页"。

### 类型 B：引用 + 概括（20.5%）——文件名 + 编号 + 一句话说它规定了什么

（行政部 AC 组 P1）

> 查见《危险源辨识、风险评价和控制程序》（XXKJ-CX-03），行政部具体负责组织公司的危险源辨识与风险评价工作，采用 LEC 法进行评价。
> 查见《环境因素的识别与评价控制程序》（XXKJ-CX-02），行政部负责环境因素的汇总、登记、评定并判别其影响程度。

**注意**：这一句平均 95 字，不是"简单提一句"。它是"文件名 + 编号 + 该程序规定的核心动作 + 该部门在其中的角色"四件套。

**需要抽什么**：文件元数据（名称、编号、版本、日期、编制/审批）+ 该程序"适用范围/职责/核心流程"三段里的一句。

**加工度**：L2（压缩概括）。这是唯一必须模型的环节。

### 类型 C：抽样明细（11.3%）——编号行

（A 公司 P31）

> 经与现场负责人沟通，组织现场配置有电工、装载机司机、搅拌司机、实验员、检验员、安全员等，抽查如下：
> 1、××，低压电工作业，2023-05-22 至 2029-05-21，××市应急管理局。
> 2、××，装载机操作，2025 年 2 月 7 日，××市工程机械安全协会。

**需要抽什么**：人员/设备编号、资质或参数、有效期、发证机构。

**加工度**：L1（字段罗列）。有固定字段就能纯规则拼，不需要模型。

### 类型 D：结论（11.0%）——判断句

> 经查，基本符合要求。
> 控制措施基本适宜，基本符合要求。
> 以上经行政部进行执行并确认风险及机遇应对措施结果评价，均有效。

**结论句可选词汇极为有限**：基本符合 / 符合 / 基本适宜 / 有效 / 未发现 / 待确认。这是一个**封闭词表**，不需要模型自由发挥。

## 四、按文档类型：报告里到底怎么写

| 文档类型 | 报告里的写法 | 转化 | 要抽的字段 | 加工度 | 能否纯规则 |
|---|---|---|:--:|:--:|
| 手册-方针/目标 | 引用 + 目标数值列举 | 搬运 | 章节定位、数值 | L0 | 是 |
| 手册-部门职责 | a)b)c) 逐条照抄 | 搬运 | 职责段落 | L0 | 是 |
| 手册-工艺流程 | "关键过程 / 特殊过程 / 外包过程"三行 | 结构改写 | 流程图 + 术语 | L1 | 半（需识别术语） |
| 程序文件 | 查见《X 程序》（编号），规定…… | 引用 + 概括 | 元数据 + 核心职责句 | **L2** | 否 |
| 作业指导书 | 同上，更短，有时只提名称 | 引用 | 元数据 | L1–L2 | 半 |
| 记录-台账/清单 | "抽查 N 份，如下：1、… 2、…" | 抽样 | 明细字段 | L1 | 是 |
| 记录-合同 | 名称 + 双方 + 标的 + 数量 + 期限 + 签署 | 搬运 | 合同字段清单 | L0 | 是 |
| 记录-培训/检验 | 抽 N 份，时间/项目/结果/人员 | 抽样 | 明细字段 | L1 | 是 |
| 证书/证照 | 证号 + 权利人 + 用途 + 期限 + 发证机关 | 搬运 | 证书字段 | L0 | 是 |
| 内审/管评报告 | 结论 + 不符合项 + 整改闭环 | 引用 + 概括 | 结论段 + NC 清单 | L2 | 半 |
| 现场观察/访谈 | "现场查见……""询问负责人，表示……" | 人工 | 无（审核员录入） | L3 | 否 |

**汇总：L0 + L1（复制与字段罗列）覆盖 63% + 11% ≈ 74%；L2（压缩概括）约 20%；L3（判断）11%。**

**这就是全文最重要的一个数字：约 74% 的报告内容可以用规则完成，只有约 20% 真正需要模型，11% 必须由人给。**

## 五、真正难的不是"抽"，是"选"和"归位"

三个难点，按难度排序：

**难点 1：选哪几份证据（最需要经验）**

同一条款往往有多份文档同时可用。例如 8.4 采购，A 公司有 3 份供方评价 + 2 份合同 + 外包说明，报告里只写了 2 份合同 + 3 家供方。**选哪几份、抽几个样本，是审核员的抽样判断**，不是文档能告诉你的。

→ 必须由规则给默认（如"同一类记录抽 3 份，覆盖不同供方/不同月份"）+ 人工调整。

**难点 2：归位到条款与部门**

一份《培训记录表》同时服务 7.2（能力）和 7.3（意识）；一份《环境因素识别表》同时服务 6.1.2 和 8.1。**同一份文档要挂多个条款、多个部门**，而且挂错不报错，只表现为"这个条款没证据"或"写出来的话不像这个部门的事"。

→ 靠"记录类型 → 条款"映射表，一次性由专家确认，之后固定。

**难点 3：把长段落压成一句话**

程序文件动辄 5 页，报告里只写一句"规定了……"。压缩必须"只保留职责与核心动作，删掉流程细节"，否则写出来像抄书。

→ 这是唯一必须模型的环节（L2）。

## 六、对模型评估的影响：把模型的使用面压到 20%

| 环节 | 谁做 | 理由 |
|---|---|---|
| 文档分类（手册/程序/指导书/记录） | 规则优先，模型兜底 | 目录结构 + 文件名 + 首屏特征已足够 |
| 文档 → 条款归位 | **模型**（语义匹配） | 文件名认不出，必须读内容判断 |
| 字段抽取（证号/期限/签署/明细行） | 规则优先 | 字段有固定词与固定位置，规则命中率高于模型 |
| 长段落 → 一句概括 | **模型**（唯一刚需） | 压缩是语义工作 |
| 抽样选择 | 规则 + 人 | 抽样策略是判断，模型不该定 |
| 结论词 | 人 | 责任归属 |
| 句式拼装 | 模板 | 顺序固定，不需要模型 |

**结论：模型只做两件事——文档归位、段落概括。** 其余全部规则 + 模板。这比"让模型读所有文档生成所有内容"的做法，成本和不可控性都低一个量级。

## 附：三条可直接写进代码的规则

1. **结论词用封闭词表**：基本符合 / 符合 / 基本适宜 / 有效 / 未发现 / 待确认 / 不适用。超出词表的不许出现。
2. **编号行是抽查的唯一载体**：报告里凡"抽 N 份"，必须紧跟 N 条编号行，条数必须等于声明的样本数。声明 3 份却列 4 条，直接判为不一致。
3. **引用句四件套齐全才算合格**：文件名 +（编号）+ 该文件规定的核心动作 + 该部门在其中的角色。缺任一件，句子退回重写，不许输出。

## 一句话

**报告不是"写"出来的，是"搬 + 引 + 抽 + 断"拼出来的；其中 74% 靠规则，20% 靠模型概括，11% 靠人。**
