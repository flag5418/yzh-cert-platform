# 74-条款证据契约的文档事实边界与证据包输出-V1

> 依据用户 2026-11-14 三条裁决：
> 1. 空白模板可能只是特定格式，真实数据可能在 ERP 或其他系统；文档侧只能按文档事实写“有这个格式、抽样为空”，剩余交审核员判断，**提示词不得制造假象、不得编造数据**。
> 2. NC 很难从文档反推；NC 怎么开是审核员精心设计的，可能避重就轻；**NC 不作为核心目标，可以忽略**。
> 3. 核心是“读懂条款、抓得准、按文档分类把证据整理好”，**不是找到一个对应文档，把原文丢给审核员继续整理分析**。

---

## 1. 三条边界

### 1.1 文档事实边界

只说文件夹里能看见的：

- 有没有这份文档；
- 是不是模板；
- 抽样行/字段填没填；
- 有哪些表头字段；
- 实际填了哪些行、哪些列；
- 覆盖到什么范围（能看见的才写）。

不说：

- “企业没有这份记录”；
- “企业没做”；
- “符合/不符合”；
- “实际数据应该在 ERP 里”；
- 任何补出来的批次、日期、数量、人员。

### 1.2 NC 边界

- 不从文档推 NC；
- 不判断 NC 应该开给谁；
- 报告里的 NC 只作为验证样本，不作为提取目标；
- `4.2.5`、`7.4.1` 这类“记录控制/供方监视”的 NC，不进入核心链路。

### 1.3 输出边界

不把原文 paragraphs 整段丢给审核员。按条款输出“证据包”：

- 证据角色（程序/清单/记录/报告/包）；
- 文档编码与名称；
- 关键字段；
- 实际抽样行（只放真实存在的）；
- 填写状态；
- 覆盖范围；
- 需审核员核实什么；
- 可能在哪找（ERP、现场、访谈、原始检验记录），只做提示，不做事实。

---

## 2. 三层分离

| 层 | 回答什么 | 产出 | 禁止 |
|---|---|---|---|
| 条款层 | 这条要求需要什么证据 | `EvidenceContract` | 不写企业有没有、不写符合性 |
| 文档层 | 企业文档里实际有什么 | `DocumentFact` | 不补数据、不判 NC、不判缺失 |
| 审核层 | 能不能判、怎么判、还缺什么 | `EvidencePackage + AuditorHandoff` | 不替代审核员结论 |

**关键：`EvidenceContract` 的 `JudgementRules` 不再给提取阶段用。** 它应该改名为 `AuditorRules` 或标 `ForAuditor=true`。提取阶段只负责“把事实整理好”，不负责“判”。

---

## 3. `DocumentFact` 字段

```json
{
  "DocName": "生产过程自检记录",
  "DocCode": "XASL-PR-027",
  "DocClass": "record",
  "EvidenceRole": "production_record",
  "TemplatePresent": true,
  "FillStatus": "blank",
  "KeyFields": [
    "产品名称","产品代号","产品规格","生产批号","原材料批号","投产数量",
    "工序名称","检测点","标准值","上限值","下限值","检具编号"
  ],
  "SampleRows": [],
  "RowCount": 43,
  "ColumnCount": 29,
  "Coverage": "unknown",
  "Source": "folder",
  "Note": "模板存在，抽样为空；实际数据可能在 ERP/其他系统，需审核员核实"
}
```

约束：

- `FillStatus` 只能是 `filled / partial / blank / absent / unreadable`。
- `blank` 的含义是“格式存在、抽样为空”，**不是缺失**。
- `SampleRows` 只放真实存在的行；没有就空数组。
- `Coverage` 在空白时只能是 `unknown`，不能猜“全批次”。
- `Note` 只能写观察，不能写结论。

---

## 4. 匹配状态修正

| 状态 | 含义 | 是否可用于提取结论 |
|---|---|---|
| `exact` | 文档有，字段齐，样本有 | 是 |
| `partial` | 文档有，字段/样本部分有 | 是 |
| `template_only` | 只有模板，抽样为空 | 是（只表达“格式存在”） |
| `absent` | 文件夹里没有这份文档 | 是 |
| `not_applicable` | 条款/条件不适用 | 是 |
| `unreadable` | 文件损坏/无法解析 | 是 |
| `report_only` | 文件夹没数据，报告里有 | **否**，只作对账观察 |

**`template_only` 替代之前的“空白=缺失”。** 这样既说出事实，又不冤枉企业。

## 5. 证据包输出

每条条款输出一个包，不给原文：

```json
{
  "Clause": "7.5.1",
  "ClauseIntent": "对生产和服务提供过程进行策划、实施、监视和控制，以确保产品符合规范。",
  "EvidenceExpectation": [
    {"Role":"production_record","Name":"生产记录","ExpectedFields":["产品名称","规格型号","生产批号","数量","过程参数结果","产品特性结果","操作人员","日期"]},
    {"Role":"release_record","Name":"产品放行记录","ExpectedFields":["产品名称","批号","数量","放行人","日期"]}
  ],
  "DocumentFacts": [
    {"DocName":"生产指令单","DocCode":"XASL-PR-025","FillStatus":"blank","SampleRows":[]},
    {"DocName":"生产过程自检记录","DocCode":"XASL-PR-027","FillStatus":"blank","SampleRows":[],"RowCount":43,"ColumnCount":29},
    {"DocName":"随工单","DocCode":"XASL-PR-028","FillStatus":"blank","SampleRows":[]}
  ],
  "EvidenceReadiness": "needs_verification",
  "AuditorHandoff": {
    "WhatToVerify": [
      "2026-06-23 / 2026-05-15 / 2026-07-02 三个批次的生产记录是否在 ERP 或原始生产记录中",
      "产品放行记录/放行人员身份是否有实际记录",
      "交付后活动（如有）是否有记录"
    ],
    "PossibleExternalSources": ["ERP","生产现场","原始生产记录","访谈"],
    "OpenQuestions": ["文件夹只有空白模板，不能据此判断企业未生产或未记录"]
  }
}
```

`EvidenceReadiness` 只给三档：

- `ready`：证据包基本齐，审核员可直接用；
- `partial`：有部分证据，需补看；
- `needs_verification`：模板/空白/缺项多，需审核员到现场或系统核实。

## 7. 对提示词的硬约束

### 7.1 文档提示词（V2.2）

- `Records` 必须带 `FillStatus`；
- `SampleRows` 只能来自实际文档，空就空；
- 新增 `Warnings: template_only / sample_empty / external_source_possible`；
- 删除/降级 `report_only`（报告不是提取源）；
- 禁止在 `Warnings` 写“企业未做/缺失/不符合”；
- `Note` 统一写“模板存在，抽样为空；实际数据可能在 ERP/其他系统，需审核员核实”。

### 7.2 条款提示词

- `EvidenceContract` 输出 `EvidenceItems[]`，每项带 `Role / Name / ExpectedFields / Required / Condition`；
- `JudgementRules` 改为 `AuditorRules` 或 `ForAuditor=true`；
- 禁止 `ReportUse` 驱动提取；
- 增加 `FactBoundary`：“只定义期望证据，不判断企业有没有”。

### 7.3 匹配层

- 输入：条款 `EvidenceItems` + 文档 `DocumentFacts`；
- 输出：`Match`（`exact/partial/template_only/absent/not_applicable/unreadable`）+ `AuditorHandoff`；
- 不输出 `NC`、`C5`、`missing`；
- `report_only` 只在对账报告里出现，不进入生产结论。

---

## 8. 结论

- 空白模板的正确状态是 `template_only`，不是 `missing`；
- 报告数据只能做验证样本，不能回填文档事实；
- NC 不作为核心，不从文档反推；
- 核心产物是“按条款组织的证据包 + 审核员待核实清单”，不是原文；
- 下一步：把 V2.2 文档提示词加 `FillStatus/template_only`，把条款提示词改成 `EvidenceItems[]` + `AuditorRules`，再用 `7.5.1/7.4.1/8.3.2/7.6` 重跑。
