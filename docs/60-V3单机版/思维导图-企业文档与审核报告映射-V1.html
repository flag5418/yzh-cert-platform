企业文档 → 审核报告：映射关系

实证样本：3 份正式审核记录（1 份 80 页 QES 一体化、6 个部门、49,522 字、843 句）
搬运 42.6%
引用+概括 20.5%
抽查 11.3%
结论 11.0%
短说明 14.6%
原文照抄 文件名+一句话概括 编号行明细 判断句
报告文字从哪来
报告不是"写"出来的，是搬 + 引 + 抽 + 断 拼出来的
规则可做 74% ｜ 模型概括 20% ｜ 人判断 11%
① 四类转化
加工度决定谁来做
L0 复制 / L1 抽样 / L2 概括 / L3 判断
L0 搬运 42.6%｜证件字段、合同条款、职责 a)–f) 逐条照抄
L1 抽样 11.3%｜"1、××，低压电工作业，2023-05-22 至 2029-05-21"
L2 引用+概括 20.5%｜文件名 +（编号）+ 规定的核心动作 + 本部门角色
L3 结论 11.0%｜基本符合 / 基本适宜 / 有效 / 待确认（封闭词表）
② 文档类型 → 写法
7 类，写法各不相同
手册最长，程序最难压缩
手册·职责 a)b)c) 逐条搬运 → L0
手册·工艺 关键过程 / 特殊过程 / 外包过程 三行 → L1
程序文件 查见《X 程序》（编号），规定…… → L2
指导书 引用更短，有时只提名称 → L1–L2
台账/清单 抽 N 份，列明细 → L1
合同 名称 + 双方 + 标的 + 期限 + 签署 → L0
证书 证号 + 权利人 + 用途 + 期限 + 发证机关 → L0
③ 三个难点
难在选与归位，不在抽
抽错位置不报错，只表现为没证据
选哪几份 同条款多份可用，报告只写 2–3 份 → 抽样策略，规则默认+人调
归位到条款×部门 一份培训记录同时服务 7.2 与 7.3 → 映射表一次确认后固定
长段压成一句 5 页程序 → 一句"规定了……" → 唯一必须模型的环节
④ 模型边界
只做两件事
归位 + 概括；其余全部规则与模板
交给模型 文档→条款归位（语义匹配）；长段落→一句概括
不让模型做 字段抽取（规则命中率更高）、抽样选择、结论词、句式顺序
必须人做 结论确认、现场观察与访谈、NC 事实描述
⑤ 可直接写进代码
三条硬规则
违反即判不合格
结论封闭词表 基本符合 / 符合 / 基本适宜 / 有效 / 未发现 / 待确认 / 不适用
抽样条数必须对齐 声明抽 3 份就必须 3 条编号行，多一条少一条即不一致
引用句四件套 文件名 + 编号 + 核心动作 + 部门角色，缺一退回重写
⑥ 下一步
先实证，后评估模型
不做模型也能验证 74% 的部分
1. 基线表：文档类型 → 句子形态 → 字段（7 类）
2. 取 1 家企业 5 个条款，手工还原"文档 → 报告句"
3. 与真实报告逐句比对，出差异清单
4. 只对 L2 环节验证模型必要性（占比 <25% 时模型只做概括）
关键数字：报告正文 63% 是搬运与引用，11% 是判断；引用最多的是"表/清单/台账"（105 处中 41 处），程序文件仅 13 处但每处平均 95 字。
结论：自动化主战场是"把已有内容搬到正确位置"，不是"生成判断"。
