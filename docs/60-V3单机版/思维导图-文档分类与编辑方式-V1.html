只有 31–45% 进报告

③ 五个编辑动作
覆盖全部报告文字
前四个能程序化，第五个必须人
① 点名复述 9–20%｜文件名 + 编号 + "明确了……"一句
② 字段罗列 证号/期限/双方/面积，纯规则
③ 抽看明细 1–2%｜"抽 N 份：1、… 2、…"，事实密度最高
④ 改写成句 69–79%｜事实全保留，句式重写（必须模型）
⑤ 判断结论 7–10%｜符合/有效/适宜/未发现（人确认，词表封闭）
④ 加工度修正
L0≈0，重心在 L1+L2
旧口径"搬运 42.6%"实为改写长句
L0 复制 ≈0%｜报告里没有大段原文
L1 事实抽取 全部句子的事实来源｜规则 + 解析器
L2 模板复述 69–79%｜模板为主，模型兜底
L3 判断 7–10%｜人
⑤ 对系统的三个结论
省钱与成败都在这里
按文档重要度分级，而非全量跑
不做相似段复制：做"抽事实 + 填模板"
不做全量全条款：手册精读、程序只取元数据+一句、三阶几乎不读、记录只读被引用那几份 → 调用量降一个数量级
模板两维：文档类型 × 条款类型（手册写"规定了…"，记录写"抽看了…结论为…"）
⑥ 下一步
先规则，后模型
用三套样本做回归测试更省
1. 12 类句式模板（每类 2–3 变体），覆盖 69–79% 描述句
2. 6 类记录字段清单（证书/合同/培训/校准/评审/内审）
3. 规则 + 模板回归，目标 ≥60% 字符可拼出
4. 差额才交模型，事实冻结不许改
⑦ 事实层 / 风格层解耦
换机构不重做事实层
风格差异未实测，属推断
事实层（不变） 属性池 / 文档分类 / 字段抽取 / 明细
风格层（每机构一套） 句式模板 + 标题层级 + 结论词表 + 报告结构（CNCA 19 项 vs ACM 四列表）
注意 三份样本同属 ACM 一家，机构间风格差异尚无实测
