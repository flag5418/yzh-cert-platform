# 9001 第 8 章「运行」条款深读卡（V1）

> 语料：GB/T 19001-2016 原文（OCR 有残损，情态词判据取可辨识字句）；实证：科斯亚-ACM二阶段（主锚）、双尼-ACM二阶段（补锚）。

## 第 8 章章核心

第 8 章围绕**「把顾客要求转化为合格产品和服务交付出去」**展开，是 PDCA 中 **D（实施）** 的主体章。8.1 总纲（策划+控制，接住第 6 章的风险措施与质量目标）；8.2 接单（识别/评审顾客要求=输入侧）；8.4 供方（把不做的过程外包并管住）；8.5 过程实施（受控条件下生产/服务，含标识、防护、更改）；8.6 放行（验证完成才交付，是输出闸门）；8.7 不合格输出（闸门拦下的东西怎么处置）。8.3 设计开发是"组织自己定义产品"时的特殊路径，来料/来图加工型企业常声明不适用（科斯亚即如此）。上下游承接：上游 4.4（过程识别）、6.1（风险措施→8.1b"实施第 6 章所确定的措施"）、7.1/7.2（资源与人员→8.5 受控条件）；下游 9.1（监视测量验证 8 章结果）、9.2（内审查 8 章实施）、10.2（不合格→纠正措施，接 8.7）。

### 8.1 运行的策划和控制
- 章核心归属：本章"过程落地总纲"，规定运行层面策划什么、控制什么、留什么证据。
- PDCA：上游 4.4 过程识别 + 6.1 风险措施 + 6.2 目标 → 本条产出策划输出；下游 8.2–8.7 全部按此执行，9.1.3 d)"策划是否得到有效实施"回头评它。
- 章节分类：执行 D。
- 证据来源分型：**文档原生为主**。判据："组织应通过以下措施对所需的过程进行策划、实施和控制"（应策划）、"确定并保持、保留成文信息，以 1) 确信过程已经按策划进行"（应保留）→ 策划文件/记录可查可抽；变更控制部分需**现场访谈**。
- 本条款回答：产品实现的路线图是否被策划过、且能证实按策划走了？
- 检查点 ×6：
  1. 实现过程是否被策划成流程？看手册/过程清单/工艺流程图；抽流程图；访谈负责人；判定=流程覆盖接单到交付。
  2. 过程准则（产品接收准则）是否建立？看检验标准/抽样计划；判定=有接收准则。
  3. 策划是否对应了 6.1 风险措施？看风险应对计划；判定=运行措施与风险表对应。
  4. 是否策划并保留了运行记录？抽生产记录/检验记录清单；判定=记录可支撑"按策划进行"。
  5. 外包过程是否识别并受控？看过程清单/8.4 文件；判定=外包已纳入 8.4。
  6. 策划变更是否评审？看变更记录；判定=无变更或有评审痕迹。
- 写法：批级套路——"策划了 XX 流程 + 制定了 XX 准则文件 + 策划了 XX 记录 + 外包/特殊过程有无 + 策划变更有无"。句式槽位：`公司依据产品的实现要求策划、明确了产品实现流程`＋`策划了相应的生产和检验记录，如：…等`＋`暂无策划变更`。
- 实证锚点（科斯亚 P24，逐字）："Q8.1 公司依据产品的实现要求策划、明确了产品实现流程。1、产品生产流程：吻合器（含电动）用吻合钉加工工艺流程：领料一制钉一检测一包装一入库 … 7、外包过程：无。"（双尼 P35 补锚：销售流程 8 步＋"2026 年暂无策划变更"）

### 8.2.1 顾客沟通
- 章核心归属：8.2 负责接单输入侧，本条管"与顾客的通道"。
- PDCA：上游 4.2 相关方需求；下游 8.2.2/8.2.3 用沟通结果形成要求；9.1.2 顾客满意回收反馈闭环。
- 章节分类：执行 D。
- 证据来源分型：**文档原生＋现场**。判据："与顾客沟通的内容应包括"（应包括，五项 a–e）——沟通渠道/制度可查（文档），沟通实况（电话答疑等）需**现场观察**。
- 本条款回答：顾客找得到你吗、你知道他在说什么吗（含投诉/财产/应急）？
- 检查点 ×5：①沟通渠道是否规定并涵盖 a–e 五项？看程序文件；②问询/订单/更改是否有专人处理？抽订单台账；③顾客投诉是否入渠道？看投诉记录（→10.2）；④顾客财产沟通异常机制？看 8.5.3 接口；⑤重大时应急措施是否预先定？看应急规定；现场看沟通实况。判定基准=五项各有着落，至少三项有证据。
- 写法：批级——"沟通方式列举＋投诉处理＋财产接口＋应急条款"。槽位：`业务人员通过签订合同/订单、顾客拜访、电话及邮件等形式与顾客沟通，明确顾客对产品规格、材质、数量、价格、交货期、包装及标识等的要求`（科斯亚 P30）。
- 实证锚点：科斯亚 P30 上句逐字；双尼 P36 补锚："组织明确了与顾客的沟通方式，如：电话沟通、上门拜访、邮件沟通、微信沟通等"＋现场"见现场销售人员：邓**与客户进行电话沟通…现场观察，该员工用语礼貌，知识熟练"。

### 8.2.2 产品和服务要求的确定
- 章核心归属：8.2 输入侧"要求定下来"。
- PDCA：上游 8.2.1 沟通结果＋4.2 法律法规；下游 8.2.3 评审对象、8.5 生产依据（图纸/技术标准）。
- 章节分类：执行 D。
- 证据来源分型：**文档原生**。判据："组织应确保：a) 产品和服务的要求得到规定，包括 1) 适用的法律法规要求"（应确保…得到规定）→ 规定动作落在合同/图纸/技术文件，可查。
- 本条款回答：顾客要求的 + 法规的 + 自己认为必要的，都规定齐了吗？能满足所声明的要求吗？
- 检查点 ×5：①顾客要求（规格/数量/交付）是否成文？抽合同；②法规要求是否识别？看法规清单引用；③组织附加要求是否明确？看技术文件；④要求与能力匹配性（能声明满足）？访谈+看 8.2.3 评审；⑤顾客图纸/标准是否转化为内部文件？看转化文件（科斯亚：KSY-QMS-WI-12/13）。
- 写法：批级——"合同明确了 X 项要求＋法规符合＋图纸转化"。
- 实证锚点（科斯亚 P30，逐字）："查顾客提供的图纸、技术标准已转化为公司作业文件（KSY-QMS-WI-12、WI-13）并传递至生产部、品质部执行"。双尼补锚：合同"明确了产品的质量要求，执行的技术标准、交付时间及地点、包装要求、违约责任等，经双方确认后签字盖章"（P36）。

### 8.2.3 产品和服务要求的评审
- 章核心归属：8.2 输入侧"承诺前先过秤"。
- PDCA：上游 8.2.2 规定的要求；下游 8.1 生产计划、8.5 交付；评审结果记录供 9.1 抽查。
- 章节分类：执行 D。
- 证据来源分型：**采样分析为主**。判据："在承诺向顾客提供产品和服务之前，组织应对如下各项要求进行评审"（应评审）＋"8.2.3.2 适用时，组织应保留与下列方面有关的成文信息：a) 评审结果"（应保留）→ 有评审记录可抽样。
- 本条款回答：接单之前，公司有没有资格、有能力接下这单？分歧解决了吗？
- 检查点 ×6：①承诺前是否评审（时间序：评审早于签订）？抽评审表比对日期；②评审是否覆盖 a–e 五类要求？看评审内容项；③不一致订单是否已解决？抽变更单；④顾客无成文要求时是否确认？看确认记录；⑤评审结论是否有能力判断？看结论用语；⑥评审记录是否保留？抽样判定。
- 写法：批级——"抽见合同评审记录 N 份：客户/产品/日期＋评审内容摘要＋结论＋评审人"。槽位（逐字样板，科斯亚 P30）：`抽见合同评审记录（KSY-QMS-P-14-01）：1）顾客：常州摇旗精密磨具有限公司，产品：皮缝钉，评审日期：2026.3.16 … 评审结论均为"公司完全可以完成该项目，可以签订此合同"，评审人：潘明海、黄勇、胥加娟、曲天骄`。
- 实证锚点：科斯亚 P30 上句逐字；双尼补锚（P36）：合同评审"先由购销部、财务部等评审，最终总经理审批通过可签定合同…评审结论：同意"。

### 8.2.4 产品和服务要求的更改
- 章核心归属：8.2 输入侧"要求变了别丢".
- PDCA：上游 8.2.3 评审；下游 8.5.6/8.3.6 更改控制、相关部门执行。
- 章节分类：执行 D。
- 证据来源分型：**采样分析**。判据："组织应确保相关的成文信息得到修改，并确保相关人员知道已更改的要求"（应确保…修改）→ 更改后的文件与传递记录可抽样；无更改期以访谈补证。
- 本条款回答：要求改了之后，文件跟着改了吗、干活的知道吗？
- 检查点 ×4：①更改是否触发文件修改？比对改前改后版本；②是否重新评审？抽评审记录；③相关人员是否知晓？看传递/培训/签收记录；④本期间有无更改？访谈确认。判定=改了且传到了。
- 写法：批级——"本次审核期间未见合同变更情况，如有变更，双方协商后重新评审确认"（此句即常见槽位）。
- 实证锚点（科斯亚 P30，逐字）："顾客要求的变更由销售部重新组织评审并传递至相关部门。…本次审核期间未见合同变更情况，如有变更，双方协商后重新评审确认。"（双尼补锚 P36："暂无合同要求的变更，如有，按策划的要求实施"）

### 8.3.1 总则（含 8.3.2–8.3.6）
- 章核心归属：本章"自己定义产品"的路径，本组条款管设计开发全生命周期。
- PDCA：上游 8.2 确定的要求＝设计输入来源；下游 8.5 按设计输出生产、8.6 按接收准则放行。
- 章节分类：执行 D。
- 证据来源分型：**文档原生**（若适用）。判据："组织应建立、实施和保持适当的设计和开发过程"（应建立）；8.3.3/8.3.4/8.3.5/8.3.6 各"应保留…成文信息"→ 输入/输出/评审验证确认记录可查。
- 本条款回答：产品是组织自己设计的吗？是→设计过程管住了吗；否→为什么不适用、理由成立吗？
- 检查点 ×6：①是否适用？看手册范围声明；②不适用理由是否成立且不影响能力责任？看范围声明论证；③（适用时）策划是否含阶段/评审/验证/确认/职责？看计划；④输入是否充分、矛盾已解决？抽输入清单；⑤输出是否含接收准则？看输出文件；⑥更改是否受控有记录？抽更改单。
- 写法：不适用时批级套路="产品均按顾客提供的图纸…进行生产制造，不涉及设计开发活动，故 8.3 不适用＋不影响能力责任"；适用时按 8.3.2→8.3.6 逐项举证。
- 实证锚点（科斯亚 P12，逐字）："公司产品均按顾客提供的图纸、技术规范或样品进行生产制造，不涉及产品和服务的设计和开发活动，故GB/T19001-2016 标准中8.3 条款不适用。该条款不适用不影响本公司提供满足顾客要求和适用法律法规要求的产品的能力或责任。"——**本案例 8.3 全组无运行实证锚点，判据仅标准原文＋不适用声明**。

### 8.4.1 外部提供的过程、产品和服务的控制（总则）
- 章核心归属：本章"借力必管"，8.4 负责把外购/外包纳入体系控制。
- PDCA：上游 8.1 c) 确定所需货源、4.4 过程识别（外包过程）；下游 8.5.1 生产使用来料、9.1.3 f) 评价外部供方绩效。
- 章节分类：执行 D。
- 证据来源分型：**文档原生＋采样分析**。判据："确定并实施对外部供方的评价、选择、绩效监视以及再评价的准则"（应确定并实施）＋"对于这些活动和由评价引发的任何必要的措施，组织应保留成文信息"（应保留）→ 准则文件＋评价记录可抽样。
- 本条款回答：外供的东西控制在手里吗？供方是怎么选出来、怎么持续评价的？
- 检查点 ×6：①三种外供情形是否识别（构成部分/代表交付/外包过程）？看过程清单；②评价选择再评价准则是否成文？看程序文件；③合格供方清单是否在用？抽清单；④抽查供方评审表（资质/能力/质量/服务/交货）；⑤评价引发的措施有无？看淘汰/整改记录；⑥无外包过程时是否有识别结论？看声明。
- 写法：批级——"见《合格供应商清单》＋抽见《供应商评审表》：供方/产品/评价内容/结论/批准人"。槽位（科斯亚 P30 逐字）：`查原材料、包材等的供应商评审表，抽见"江阴市金祺达金属制品有限公司，韦恩堡金属有限公司，浙江名科塑业股份有限公司"等评审内容包括供方资质（符合）、供货能力（基本满足）…总经理潘明海批准"同意将该供应商列为我公司合格供应商"（2026.6.10）`。
- 实证锚点：科斯亚 P30 上句逐字；同页问题锚点："组织未能提供纸箱供应商森木包装厂的供应商评审表"（OFI 素材）。双尼补锚 P38："Q8.4 组织编制了《采购控制程序》，保证所采购的物资符合法律法规和顾客的需求"。

### 8.4.2 控制类型和程度
- 章核心归属：8.4"管到什么份上"。
- PDCA：上游 8.4.1 准则；下游 8.5.1 来料检验执行、9.1 供方绩效数据。
- 章节分类：执行 D。
- 证据来源分型：**采样分析**。判据："组织应确保外部提供的过程…不会对组织稳定地向顾客交付合格产品和服务的能力产生不利影响…d) 确定必要的验证或其他活动，以确保外部提供的过程、产品和服务满足要求"（应确保…确定）→ 验证活动（进料检验等）记录可抽样。
- 本条款回答：不同供方/不同物料，控制深浅是否分级、验证是否真的做了？
- 检查点 ×5：①控制类型是否按风险分级（A 类材/包材）？看分级规定；②外部过程是否仍处体系控制内？看程序覆盖；③进厂验证是否实施？抽来料检验记录（科斯亚 KSY-QMS-P-21-01）；④验证判定与放行是否闭环？比对入库单；⑤验证不通过是否走 8.7？看处置单。
- 写法：批级——"控制类型＋验证活动＋抽记录：日期/供应商/项目/实测/判定/检验员"。
- 实证锚点（科斯亚 P30，逐字）："采购产品每批次入库前由品质部实施进料检验（见KSY-QMS-P-21-01），合格后办理入库。"（双尼补锚：供方直接供货、随货检测报告/合格证验收，P36–37）

### 8.4.3 提供给外部供方的信息
- 章核心归属：8.4"把话说清楚再下单"。
- PDCA：上游 8.2.2 规定的要求；下游供方按信息交付、8.4.2 验证对表。
- 章节分类：执行 D。
- 证据来源分型：**文档原生＋采样**。判据："组织应确保在与外部供方沟通之前所确定的要求是充分和适宜的。组织应与外部供方沟通以下要求"（应确保…应沟通）→ 采购订单/合同/技术协议可抽样；互动实况现场访谈。
- 本条款回答：下单前，要求（含批准、能力、验证安排）传达全了吗？
