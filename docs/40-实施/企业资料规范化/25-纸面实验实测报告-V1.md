## 八、★ 意外发现（4 条，都不是设计问题，是现状问题）

### 8.1 ★★★ 模板行本身就是一份「完整答卷」

`YZH-STD-ENT` 模板行里的 167 份文档，**不是空白模板**，而是**河北雄安尚龙医疗科技的完整成品集**（含真实人名、日期、示例数据）。

这意味着平台**已经拥有一套可复用的完整答案**。生产的**最短路径**是：

```
模板复用（167 份）→ 替换企业标识（1,253 处确定性锚点）→ 补 ≤5 处生成内容 → 交付
```

而**不是** `README` §一 描述的：

```
企业上传散乱资料 → 识别 → 提取 → 匹配 → 填充 → 交付
```

⇒ **`05` 册的命题（散乱资料 → 标准文档）可能被过度设计了。** 见 §十 Q-4。

### 8.2 ⚠️ 模板含上一家企业的**示例数据**（合规风险）

| 文件 | 示例数据 |
|------|---------|
| `XASL-QR-008 外来文件登记表` | 接收人/保管人 = **董晶晶**，获取日期 = 2026.02.05，160 处 |
| `XASL-OR-001 培训签到及有效性评价表` | 培训人员 = **尚月永/王倩/董晶晶/尚月兴**，45 处 |
| `XASL-QR-010 质量记录清单` | 生效日期 = 2026.02.05，190 处 |

**新企业套用时若不清空 → 直接继承上一家企业的姓名与日期。** 这在认证审核中是**实质性风险**（记录造假嫌疑）。

⇒ 必须有一条**「示例数据清空/重置」规则**。见 §十 Q-5。

## 十、待裁决（3 条，**全部是新增**）

### Q-4 ★★★ 一期是否改走「模板复用 + 标识替换」？

| 选项 | 含义 | 代价 |
|------|------|------|
| **A（推荐）** | 一期：**模板复用 + 1,253 处标识替换 + ≤5 处生成**；企业文件提取（⑤）**整期延后** | 需**重写 `README` §一 的命题**；`05` 册前半（01/03/04/06/08/09）大量内容降级为二期 |
| **B** | 维持原命题（散乱资料 → 匹配 → 填充），模板复用只作为 fallback | 实测显示这条路上**没有真实数据可验证**（§8.4），风险最高 |
| **C** | 双轨并行 | 单人开发 + 10/15 死线，**不可行** |

**实测依据**：§三（98.6% 确定性）+ §六（0.1% 生成）+ §8.4（提取链路零真实数据）。

**为什么这是最要紧的一条**：它决定 `05` 册**一半以上的内容**是"现在做"还是"二期做"。

### Q-5 ★★ 模板示例数据如何清空？

| 选项 | 含义 |
|------|------|
| **A（推荐）** | 锚点上打 `SampleData=true` 标记 → 填充前**整行清空**（适用于清单类表格） |
| **B** | 新企业复制模板时，**按行清空「非表头且含示例值」的行** |
| **C** | 只清人名/日期，保留法规清单等通用内容 |

**实测依据**：§8.2（160 + 45 + 190 处示例数据）。

### Q-6 一期是否保留 `Confidence` 字段？
