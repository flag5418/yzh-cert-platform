### 2.2 第二轮：UI 精修（10 处）

#### A. 样式层 —— **类名用了，全仓没有 CSS 定义**（4 处，肉眼可见）

| 文件 | 未定义类名 | 症状 |
|---|---|---|
| `AnchorRuleTab.vue` | `tag` / `tag.w` / `tag.d` / `tag.b` / `tag.s` / `tiny` | 卡片右上角 4 个状态（孤儿 / 未配 / 必填 / 已配）**渲染成裸文字**，无底色无边框 |
| `ContractTab.vue` | `tag i` | AI 分析状态（尚未分析 / 分析中 / 已完成 / 分析失败）**渲染成裸文字**，与同行「模型：…」分不开 |
| `PromptPanel.vue` | `bind-option` / `bind-option__name` / `bind-option__meta` | 下拉项三段文字挤在一起，长名称不省略号截断（把版本数挤出可视区） |
| `PromptPanel.vue` | `bind-hint--warn` | 「系统里还没有任何提示词 —— 请改用『新建提示词』」这句**关键引导**与普通提示同色 |

> **判据方法（已沉淀，可全仓复用）**：node 脚本取 `<style` 之前为模板、之后为样式块，
> 把 `class="…"` 拆词后与样式块里 `.类名` 集合做差集。**20 行脚本，全仓可查。**

⇒ 全部换成项目标准 `YzhStatusBadge`（顺带满足 S08），`bind-*` 补齐样式。

#### B. 交互层（4 处）

| # | 缺陷 | 修法 |
|---|---|---|
| U1 | 「必填项」是 **32×18px 手搓 `<div>` 开关**：不可键盘聚焦、无 `role`/`aria-checked`、与 EP 视觉不一致 | 换 `el-switch`（保留乐观更新 + 失败回滚 + 单行 loading） |
| U2 | 筛选 chip（`.filters .f`）与锚点卡片（`.ac`）是 `<div @click>` ⇒ **Tab 够不着** | chip 换 `<button type="button">` + `:aria-pressed`；卡片加 `role="button"` `tabindex="0"` `@keydown.enter/space` + `:focus-visible` 描边 |
| U3 | `index.vue` 的「清除筛选」是 `<span @click>` ⇒ 同样够不着 | 换 `<button type="button">` |
| U4 | `PromptPanel.onMaterialSelect` **写入目标靠「最后一个获得焦点的输入框」猜** | 见下 |

**U4 展开（这是本次最值得说的一处）**：
「新建提示词」对话框里**也有一个素材区**，而它旁边还有「编码 / 名称」两个输入框 ——
用户在「名称」里点了光标、再点一个素材 chip，token 就被插进了**名称**里。
且原实现走 `el.value = x` + `dispatchEvent(new Event('input'))`，**绕过 Vue 响应式**
（一旦绑定方式从 `v-model` 换成别的，这段会静默失效）。
⇒ 改为「**写入目标由调用点显式给定**」(`onMaterialSelect(val, 'edit' | 'create')`)，
并且**只改状态**、`nextTick` 后把光标按新状态摆回去。

#### C. 逻辑 / 性能层（2 处）

| # | 缺陷 | 修法 |
|---|---|---|
| U5 | **`SourceSpec` 一行被解析 4 次**：`stats` 一遍、`filtered` 一遍、模板里 `isUnconfigured(a)` 与 `sourceSummary(a)` 每卡每渲染各一遍 ⇒ N 个锚点每次渲染解析 **4N 次 JSON**；且「什么是未配」有 **3 份各写各的实现** | 抽 `components/anchorStats.ts` 纯函数：一行只解析一次，判据只有一份 |
| U6 | `AnchorSidePanel.kindOptions()` 是**函数**，在 `v-for` 里逐行调用 ⇒ 每次渲染重建数组 | 改 `computed` |

**另清理死代码 4 项**：
- `AnchorSidePanel.insertText`（`defineExpose` 后**无人调用**）+ `lastFocusedInput` + `onInputFocus`
  + **10 处 `@focus="onInputFocus"`**（⚠️ 只删函数不删模板绑定 ⇒ 运行期 `undefined is not a function`）
- `AnchorRuleTab.tableRef`（声明了但模板从未 `ref="tableRef"` ⇒ `refresh()` 里那句是永久 no-op）

而 `sourceSpec.ts` 的注释明确写着「解析失败 ⇒ 界面提示『原值无法解析，保存将覆盖』」。
⇒ 半截 JSON 时用户只看到「未配置来源」，随手加一个来源一保存，**原值就被覆盖没了**。
