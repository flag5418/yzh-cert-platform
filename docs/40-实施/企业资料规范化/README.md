## ★ 一句话定位

> **企业散乱原始资料 → 画像 → 模板锚点 → 填写规则 → 规范化执行引擎 → 标准目录下的标准文档。**

这是一条**完整流水线**，跨「后台端(定义侧) + 专家端(执行侧)」两个平台，且含 Shared 共享层，**不是单个模块**。

## 一、体系边界（为何拆成这套册）

| 侧 | 平台 | 代码落点 | 职责 |
|----|------|---------|------|
| **定义侧** | 后台端 `cert-admin` | `DocTemplateAnchor`、`SourceResolver`、`FillParamDef/Value`、`AiFillInvoker` | 模板上传/锚点扫描、填写规则、全局参数、技能/Prompt |
| **执行侧** | 专家端 `cert-auditor` | `DocumentFillOrchestrator`、`DocFillValue/Action/Log`、`WordFillWriter/ExcelFillWriter` | 7 步编排、取值、AI 提炼、单元格/整表写入 |
| **共享层** | `CertPlatform.Shared` | 实体 `DocFillLog/DocAiSuggestion`、Office 写入器 | 两端共用基础 |

> ⚠️ **双端交叉处理**：能力归属不按平台硬切，Shared 单列；交叉通过 README 双向引用表达，不重复放文档。
