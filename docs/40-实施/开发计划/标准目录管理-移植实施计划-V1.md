|-------------------|---------------------------|

| `_db.Set<T>().Add(entity); await _db.SaveChangesAsync()` | `_db.InsertAsync(entity)` |
| `_db.Set<T>().Update(entity); await _db.SaveChangesAsync()` | `_db.UpdateAsync(entity)` |
| `_db.Set<T>().Remove(entity); await _db.SaveChangesAsync()` | `_db.DeleteByCodeAsync<T>(code)` |
| `await _db.Set<T>().ToListAsync()` | `_db.GetListAsync<T>(predicate)` |
| `_db.Database.GetDbConnection().CreateCommand()` | `_db.SqlQueryAsync<T>(sql, parameters)` |
| `_db.Database.ExecuteSqlRaw(sql)` | `_db.SqlExecuteAsync(sql, parameters)` |

## 八、移植关键注意事项

### 8.1 OSS 接口化（重要）

新项目已抽象出 `IObjectStorage` 接口，支持 MinIO / 阿里 OSS 可插拔切换：

| 组件 | 路径 | 状态 |
|------|------|:----:|
| `IObjectStorage` 接口 | `YZH.Core.Stand/Interfaces/IObjectStorage.cs` | ✅ 已完成 |
| `MinioObjectStorage` 实现 | `YZH.Core.DataBase/Infra/MinioObjectStorage.cs` | ✅ 已完成 |
| `AliyunOssStorage` 骨架 | `YZH.Core.DataBase/Infra/AliyunOssStorage.cs` | ✅ 骨架已完成 |

**移植红线：**

| 禁止 ❌ | 必须 ✅ |
|--------|--------|
| 直接使用 `IMinioClient` | 通过 `IObjectStorage` 接口操作 |
| 引用 `Minio.DataModel.Args` | 使用 `_storage.UploadAsync/DownloadAsync/DeleteAsync` |
| 老项目的 `FileStorageService` | 已通过 `MinioObjectStorage` 实现 |
| 老项目的 `FolderFileManager` | 逻辑合并入 `StandardDirectoryService` |

**老项目 ExportAsZip 必须改写：**

老项目 ExportAsZip 直接调用 Minio SDK（`GetObjectArgs`、`StatObjectArgs`），移植后必须改为：
```csharp
// 老项目（直接调 MinIO）
var getArgs = new GetObjectArgs().WithBucket(bucketName).WithObject(objectName);
await _minioClient.GetObjectAsync(getArgs);

// 新项目（通过接口）
var (stream, contentType) = await _storage.DownloadAsync(objectName);
```

**老项目 SourceExistsAsync 必须改写：**
```csharp
// 老项目（直接调 MinIO）
var statArgs = new StatObjectArgs().WithBucket(bucketName).WithObject(objectName);
await _minioClient.StatObjectAsync(statArgs);

// 新项目（通过接口）
var exists = await _storage.ExistsAsync(objectName);
```

### 8.2 ORM 差异

| 注意事项 | Vol (EF Core) | YZH (IDbOrm/SqlSugar) |
|---------|---------------|----------------------|
| 全局查询过滤器 | 自动过滤 IsDeleted | **手动在 SQL 中加** |
| 实体跟踪 | 默认跟踪 | 无跟踪，需显式 Update |
| 事务 | `Db.Ado.BeginTran()` | `_db.BeginTran()` 或 `DbUseTran` |
| 原生 SQL | `FromSqlRaw` | `_db.SqlQueryAsync<T>()` |
| 分页 | `Skip().Take()` | `_db.GetPageAsync<T>()` |

### 8.3 路由差异

| 老项目 | 新项目 |
|--------|--------|
| `api/standard-directory/*` | `api/Workflow/StandardDirectory/*` |
| `api/DirectoryTemplate/*` | `api/Foundation/DirectoryTemplate/*` |
| `api/Queue/*` | `api/System/QueueMonitor/*` |

### 8.4 返回格式差异

| 老项目 | 新项目 |
|--------|--------|
| `JsonNormal(result)` | `Ok(new { code = 200, data = result })` |
| `new WebResponseContent().OK(msg, data)` | `Ok(new { code = 200, msg, data })` |
| `new WebResponseContent().Error(msg)` | `Ok(new { code = 400, msg })` 或 `BadRequest(...)` |
