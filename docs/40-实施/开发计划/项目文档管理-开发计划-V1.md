## 一、需求概述

在新架构中实现"标准目录管理"页面（TreeTable 模式），管理认证机构的标准文件目录结构（配置→文件夹→文件），支持文件上传/下载/转换，引入队列和 MinIO 作为 YZH 核心能力。

### 页面形态

```
┌──────────────────────────────────────────────────────────┐
│ 左树：机构→标准→阶段（三级）          右表：文件夹/文件    │
│ ┌──────────────────┐  ┌────────────────────────────────┐ │
│ │ ☒ 河北尚龙        │  │ 4 记录文件                      │ │
│ │   ├─ ISO 9001    │  │   ├─ 4.1 内审记录               │ │
│ │   │  ├─ S1 一阶段 │  │   │  └─ 内审计划.docx [已上传]  │ │
│ │   │  └─ S2 二阶段 │  │   └─ 4.2 管理评审               │ │
│ │   └─ ISO 13485   │  │       └─ 管理评审报告.xlsx [待上传]│ │
│ └──────────────────┘  └────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

### 核心功能

| 功能 | 说明 |
|------|------|
| 左树三级 | 机构 → 标准 → 阶段 |
| 右表文件夹/文件 | 展示当前阶段的文件夹树+文件列表 |
| 文件上传 | 拖拽/点击上传到 MinIO，入队转换 |
| 文件下载 | 从 MinIO 流式下载 |
| 文件转换 | Word→PDF 队列异步转换 |
| 队列监控 | 实时进度、取消、重试 |
| 资源锁定 | 上传/转换中锁定文件，防止并发 |

#### P0-2：IObjectStorage 接口

**文件**：`src/yzh-core/YZH.Core.Stand/Interfaces/IObjectStorage.cs`

```csharp
namespace YZH.Core.Stand.Interfaces;

/// <summary>
/// 通用对象存储抽象（YZH 核心能力）
/// <para>实现可插拔：MinIO / 阿里 OSS / 本地文件系统</para>
/// <para>配置驱动：appsettings.json → Storage:Provider</para>
/// </summary>
public interface IObjectStorage
{
    Task UploadAsync(string objectName, Stream stream, long size, string contentType = "application/octet-stream", CancellationToken ct = default);
    Task<(Stream Stream, string ContentType)> DownloadAsync(string objectName, CancellationToken ct = default);
    Task DeleteAsync(string objectName, CancellationToken ct = default);
    Task RenameAsync(string oldObjectName, string newObjectName, CancellationToken ct = default);
    Task<List<string>> ListObjectsAsync(string prefix, CancellationToken ct = default);
    Task DeletePrefixAsync(string prefix, CancellationToken ct = default);
    Task<bool> ExistsAsync(string objectName, CancellationToken ct = default);
}
```

#### P0-5：Storage 注册扩展

**文件**：`src/yzh-core/YZH.Core.Web/Extensions/StorageServiceExtensions.cs`

```csharp
public static class StorageServiceExtensions
{
    public static IServiceCollection AddYzhStorage(this IServiceCollection services, IConfiguration config)
    {
        var provider = config["Storage:Provider"] ?? "minio";
        switch (provider)
        {
            case "aliyun-oss":
                services.AddScoped<IObjectStorage, AliyunOssStorage>();
                break;
            default: // "minio"
                services.AddSingleton<IMinioClient>(sp => { ... });
                services.AddScoped<IObjectStorage, MinioObjectStorage>();
                break;
        }
        return services;
    }
}
```

CREATE TABLE IF NOT EXISTS yzh_queue (
    Id BIGINT NOT NULL AUTO_INCREMENT,
    Code VARCHAR(36) NOT NULL,
    QueueCode VARCHAR(64) NOT NULL,
    QueueType VARCHAR(30) NOT NULL,
    QueueName VARCHAR(200) NOT NULL,
    ScopeKey VARCHAR(200) NULL,
    SourceType VARCHAR(30) NULL,
    SourceId VARCHAR(64) NULL,
    Status VARCHAR(20) NOT NULL DEFAULT 'pending',
    TotalCount INT NOT NULL DEFAULT 0,
    PendingCount INT NOT NULL DEFAULT 0,
    ProcessingCount INT NOT NULL DEFAULT 0,
    CompletedCount INT NOT NULL DEFAULT 0,
    FailedCount INT NOT NULL DEFAULT 0,
    CancelledCount INT NOT NULL DEFAULT 0,
    Progress INT NOT NULL DEFAULT 0,
    StartTime DATETIME NULL,
    EndTime DATETIME NULL,
    OrgCode VARCHAR(50) NULL,
    CreateTime DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (Id),
    UNIQUE KEY uk_code (Code),
    UNIQUE KEY uk_queue_code (QueueCode),
    KEY idx_status (Status),
    KEY idx_scope_key (ScopeKey)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

## 九、风险点

| 风险 | 影响 | 缓解 |
|------|------|------|
| QueueManager 1110 行迁移复杂 | P0 阶段耗时 | 逐方法迁移，先跑通 file_convert 单一场景 |
| OfficeConvertService 依赖 LibreOffice | 运行环境 | Docker 部署时安装 LibreOffice |
| 旧项目 SignalR 推送 | 实时通知 | 新架构可先用轮询，后续加 SignalR |
| MinIO Bucket 策略 | 存储隔离 | 统一用 `cert-platform` Bucket，路径前缀隔离 |
