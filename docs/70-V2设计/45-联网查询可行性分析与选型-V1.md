## 零、结论摘要（先看这 6 条）

| #   | 结论                                                                                            | 影响                 |
| --- | ----------------------------------------------------------------------------------------------- | -------------------- |
| 1   | **官方站点后端直连全部不可行**（72% 返回 412/521 WAF，其余改 SPA 或加验证码）                   | 自动爬取方案**排除** |
| 2   | **企业照面信息不该"联网获取"，应从营业执照 AI 提取**（执照是必交材料）                          | 主流成本 ≈ **0**     |
| 3   | 联网查企业照面的真实单价是 **0.05~0.3 元/次**，不是 1~2 元；"1~2 元/企业"= 把所有接口都调了一遍 | 只买 1 个接口即可    |
| 4   | 缓存复用（`cert_public_skill_result` 唯一键 + TTL）使成本 = **每企业 1 次**，非每查询 1 次      | 100 企业 ≈ 5~30 元   |
| 5   | **人员类全部暂缓**（无官方 API、付费通道均需"本人授权"，属敏感个人信息）                        | 人员类只留 `manual`  |
| 6   | 建议最终形态：**`api` 仅 1 个（工商照面）+ 其余全 `manual`**                                    | 见 §四               |

## 一、可行性实测：官方站点直连结果

> 测试方式：`curl --noproxy '*'` 直连目标接口，绕过本地代理。日期 2026-10-30。

| 站点                         | 用途                 | 实测结果             | 判定                         |
| ---------------------------- | -------------------- | -------------------- | ---------------------------- |
| `cx.mem.gov.cn`              | 应急管理特种作业证   | **412**              | 瑞数 WAF，不可用             |
| `zwfw.mem.gov.cn`            | 应急管理政务服务     | **412**              | 瑞数 WAF，不可用             |
| `www.gsxt.gov.cn`            | 国家企业信用信息公示 | **521**              | WAF，不可用                  |
| `www.creditchina.gov.cn`     | 信用中国             | **412**              | WAF，不可用                  |
| `zxgk.court.gov.cn`          | 全国法院被执行人     | **200 + 图形验证码** | 需人工过验证码               |
| `jzsc.mohurd.gov.cn`         | 住建四库一平台       | **200（已改 SPA）**  | 旧 API 返回首页 HTML，不可用 |
| `cnse.e-cqs.cn/info-pub/pub` | 认证认可信息公示     | **302**              | 跳转登录，不可用             |

**结论**：政府公开站点普遍部署 **瑞数 WAF / 图形验证码 / 登录鉴权**，`AccessMode=api` 的自动抓取路线**整体排除**。
→ 这些源只能以 **`manual`**（审核员人工访问 + 回填）或 **`web`**（存网址 + 人工查）形式提供。

## 二、可用数据源全景

### 2.1 企业类（可自动化）

| 数据                      | 代表服务商                               | 单价（市场价）    | 我方是否需要   |
| ------------------------- | ---------------------------------------- | ----------------- | -------------- |
| **工商照面信息**（33 项） | 数脉 API（阿里云市场）、凭安征信、亿企查 | **￥0.05~0.3/次** | ★ 仅作**核验** |
| 行政处罚 / 经营异常       | 企查查 410 系列、天眼查、启信慧眼        | ￥0.2~0.5/次      | 按条款需要     |
| 失信 / 被执行             | 同上                                     | ￥0.2~0.5/次      | 按条款需要     |
| 国抽不合格                | 无官方 API                               | —                 | `manual`       |

> 阿里云市场同类商品：数脉 API 标 **￥0.05/次**（含免费试用）；企查查开放平台 1000 元/5000 次 = **￥0.2/次**（免费试用 20 次）；你查看的凭安商品页 **￥2 为套餐起价**，非单价。

### 2.2 人员类（暂缓）

| 数据                           | 通道                       | 障碍                                             |
| ------------------------------ | -------------------------- | ------------------------------------------------ |
| 特种作业证（应急/住建）        | 官方                       | WAF / SPA，无开放 API                            |
| 职称证书                       | 各省人社                   | 无统一开放渠道                                   |
| 行业协会证（混凝土、工程机械） | 无                         | 无任何 API，只能 `manual`                        |
| 姓名+身份证核验                | 羽山数据 / 天远 / valuemap | **需"本人授权"**，身份证属《个保法》敏感个人信息 |

## 三、成本分析

### 3.1 两种模式的成本量级

| 模式                 | 做法                                    | 单企业成本                     |
| -------------------- | --------------------------------------- | ------------------------------ |
| ❌ **聚合套餐**      | 买"企业全维度"，自动跑 20+ 接口         | **1~2 元**（用户观察到的价格） |
| ✅ **单接口 + 缓存** | 只买工商照面，每企业只调 1 次，永久缓存 | **0.05~0.3 元**                |

### 3.2 成本分层（按价值付钱，不按接口付钱）

| 层     | 做什么                   | 手段                                      | 单企业成本                     |
| ------ | ------------------------ | ----------------------------------------- | ------------------------------ |
| **L1** | 拿照面信息               | 营业执照 → LLM 提取（复用 F4 文档条款化） | **≈ 0**                        |
| **L2** | 核验照面                 | 联网调 1 次工商照面接口                   | 0.05~0.3 元｜**每企业仅 1 次** |
| **L3** | 风险类（处罚/诉讼/抽查） | 仅条款要求时按需查，或人工录入            | 按需，多数企业为 0             |
| **L4** | 人工兜底                 | 审核员在官方站点手查后填                  | **0**                          |

### 3.3 100 家企业核算

| 方案                 | 计算         | 总成本    |
| -------------------- | ------------ | --------- |
| 聚合套餐             | 100 × 1.5 元 | 150 元    |
| 单接口 + 缓存        | 100 × 0.1 元 | **10 元** |
| 纯 L1 + L4（不联网） | 100 × 0      | **0 元**  |

> **核心洞察**：营业执照是认证**必交材料**，照面 9 项字段（名称/信用代码/类型/住所/法人/注册资本/成立日期/期限/经营范围）**全部可从执照提取**。联网的唯一增量价值是"**核验真实性**"，不是"获取"。

### 4.1 Skill 清单（精简后）

| `Code`            | 名称         | `Category` | `AccessMode` | 备注                       |
| ----------------- | ------------ | ---------- | ------------ | -------------------------- |
| `GS_REGISTER`     | 工商照面信息 | 工商       | **api**      | 唯一付费项；单接口，非聚合 |
| `GS_PENALTY`      | 行政处罚     | 工商       | manual       | 审核员手查回填             |
| `GS_ABNORMAL`     | 经营异常     | 工商       | manual       | 同上                       |
| `GS_DISHONEST`    | 失信被执行   | 司法       | manual       | 同上                       |
| `SAMR_SPOT_CHECK` | 国家监督抽查 | 质量       | manual       | 国抽不合格可触发法定任务   |
| `PERSON_CERT`     | 人员证书核验 | 质量       | manual       | 统一格式回填（§2.3）       |

### 4.2 表字段补充（在 26 号基础上）

| 表                         | 建议新增                                                   | 理由                                         |
| -------------------------- | ---------------------------------------------------------- | -------------------------------------------- |
| `cert_public_skill`        | `SubjectType`（`enterprise`/`person`）                     | 支持企业/人员两类主体                        |
|                            | `AuthType` / `CredentialKey`                               | 区分免费/需授权；密钥指向 `cert_sys_config`  |
|                            | `CostCent`（每次调用成本，分）                             | 成本可核算                                   |
| `cert_public_skill_result` | `SubjectType` / `SubjectName` / `SubjectIdNo`（加密+脱敏） | 人员类主体标识                               |
|                            | `CostCent` / `AuthProofCode`                               | 记账 + 授权凭证留痕                          |
|                            | 唯一键调整为 `(SkillCode, QueryKey)`                       | 人员查询 `EnterpriseCode` 可空，原唯一键失效 |

### 4.3 后端抽象

新增 `IPublicQueryProvider`：`ApiProvider`（HTTP 调外部接口）+ `ManualProvider`（人工录入）。⛔ 不把非普适逻辑塞进基类。

### 4.4 红线从三条扩为四条（26 号 §五）

原三条（只查公开数据 / 结果只作线索 / 必须留痕）**追加**：

> **④ 涉及个人信息的查询必须留存授权凭证**（`AuthProofCode`），身份证号**加密存储 + 页面脱敏**。
