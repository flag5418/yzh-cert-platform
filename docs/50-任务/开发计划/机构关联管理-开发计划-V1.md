## 一、需求概述

开发两个 **TreeTable（左树右表）** 页面，管理认证机构与其他实体的多对多关联关系：

| 页面 | 左树 | 右表 | 关联字段 |
|------|------|------|---------|
| 机构-标准关联 | 认证机构 | 所有有效 ISO 标准 | `OrgCode + StandardCode` |
| 机构-阶段关联 | 认证机构 | 所有有效认证阶段 | `OrgCode + StageCode` |

### 交互模式：勾选分配（非传统 CRUD）

```
┌──────────────────────────────────────────────────────────┐
│  左树：认证机构            右表：ISO 标准（全量）          │
│  ┌────────────────┐        ┌────────────────────────────┐ │
│  │ ☒ 河北尚龙      │   ←→   │ ☒  ISO 9001:2015  质量管理  │ │
│  │   ○ 某某机构    │        │ ☐  ISO 14001:2015 环境管理  │ │
│  │   ○ 某某机构    │        │ ☒  ISO 13485:2016 医疗器械  │ │
│  └────────────────┘        └────────────────────────────┘ │
│                           ↑ 勾选 = 立即保存                │
│                           ↑ 取消 = 立即删除                │
└──────────────────────────────────────────────────────────┘
```

**核心规则**：
1. 左树选中一个机构 → 右表加载**所有有效标准/阶段**
2. 已关联的标准/阶段自动勾选（checkbox = checked）
3. 用户勾选 → 立即调用 add API 创建关联记录
4. 用户取消勾选 → 立即调用 delete API 删除关联记录
5. **无弹窗操作**，所有交互通过 checkbox 完成
6. 未选中机构时，右表为空（提示"请先选择机构"）

## 三、设计决策

### 3.1 左树：认证机构

两个页面共享同一套左树数据源：

| 属性 | 值 |
|------|-----|
| 数据源 | `cert_certification_body` |
| TreeConfig.NameField | `Name` |
| TreeConfig.CodeField | `Code` |
| TreeConfig.ParentCodeField | `ParentCode` |
| TreeConfig.MaxLevel | 1（扁平，所有机构为根节点） |
| TreeConfig.AllowEdit | `false`（机构管理由认证机构页面负责） |
| TreeConfig.AllowDelete | `false` |
| TreeConfig.NoSelectionBehavior | `empty`（未选中时右表为空） |

### 3.2 右表：全量标准/阶段 + Checkbox

**与传统 TreeTable 的区别**：

| 特性 | 传统 TreeTable | 本需求 |
|------|---------------|--------|
| 数据源 | 当前实体的 filter 结果 | 关联实体的全量数据（cert_iso_standard / cert_phase_definition） |
| 选中行 | 单行编辑/删除 | Checkbox 多选，勾选即关联 |
| 操作按钮 | 编辑、删除、新增弹窗 | 无操作列，checkbox 替代一切 |
| 数据过滤 | 按当前实体字段过滤 | 全量显示（仅 IsValid=1） |

**机构-标准关联**：
| 显示列 | 来源表 | 说明 |
|--------|--------|------|
| ☒ (checkbox) | cert_org_standard | 已关联则 checked |
| StandardCode | cert_iso_standard | 标准编号 |
| StandardName | cert_iso_standard | 标准名称 |
| VersionYear | cert_iso_standard | 版本年份 |
| Category | cert_iso_standard | 分类 |

**机构-阶段关联**：
| 显示列 | 来源表 | 说明 |
|--------|--------|------|
| ☒ (checkbox) | cert_org_stage | 已关联则 checked |
| PhaseCode | cert_phase_definition | 阶段编号 |
| PhaseName | cert_phase_definition | 阶段名称 |
| SortOrder | cert_phase_definition | 排序号 |

### 3.3 命名修正

DB 列名 `standard_code` / `phase_code` 已存在，不修改。Entity 保持现有 Property 名（`StdCode` / `StageCode`），通过 `[SugarColumn(ColumnName)]` 映射。

### P2：后端 Controller

#### 设计思路

本需求与传统 TreeTable 不同：右表不是当前实体的 filter 结果，而是**关联实体的全量数据**。

**方案**：不使用 `TreeTableControllerBase`，改为**独立 Controller**，自行实现：
- 左树：复用 `EntityService<CertificationBody>` 获取机构列表
- 右表：直接查 `cert_iso_standard`（或 `cert_phase_definition`）全量
- 关联：查 `cert_org_standard`（或 `cert_org_stage`）获取已关联编码列表
- 勾选/取消：直接操作关联表

#### P2-1：CertOrgStandardController

**文件**：`src/certplatform-api/CertPlatform.Admin/Controllers/Foundation/CertOrgStandardController.cs`

```csharp
[ApiController]
[Route("api/Foundation/[controller]")]
public class CertOrgStandardController : ControllerBase
{
    // GET  /api/Foundation/CertOrgStandard/tree/root
    //      → 返回所有有效机构（左树）

    // GET  /api/Foundation/CertOrgStandard/list?orgCode=xxx
    //      → 返回所有有效标准 + 标记哪些已关联该机构

    // POST /api/Foundation/CertOrgStandard/save
    //      Body: { OrgCode, StandardCode, Linked: true/false }
    //      → Linked=true: 创建关联；Linked=false: 删除关联

    // POST /api/Foundation/CertOrgStandard/batch-save
    //      Body: { OrgCode, Items: [{ StandardCode, Linked }] }
    //      → 批量保存（全量勾选场景）
}
```

**API 详细设计**：

| 方法 | 路由 | 说明 |
|------|------|------|
| GET | `/tree/root` | 左树：所有有效机构 |
| GET | `/list?orgCode=xxx` | 右表：全量标准 + checked 状态 |
| POST | `/save` | 单条：创建/删除关联 |
| POST | `/batch-save` | 批量：全量保存勾选结果 |

**`/list` 响应格式**：
```json
{
  "data": [
    { "Code": "xxx", "StandardCode": "ISO 9001:2015", "StandardName": "质量管理体系", "VersionYear": 2015, "Linked": true },
    { "Code": "yyy", "StandardCode": "ISO 14001:2015", "StandardName": "环境管理体系", "VersionYear": 2015, "Linked": false }
  ]
}
```

**`/save` 请求格式**：
```json
{ "OrgCode": "CB001-CODE", "StandardCode": "ISO 9001:2015", "Linked": true }
```

import { yzhApi } from '@yzh-core'

export const certOrgStandardApi = {
  /** 左树：所有有效机构 */
  treeRoot: () => yzhApi.get('/api/Foundation/CertOrgStandard/tree/root'),
  /** 右表：全量标准 + checked 状态 */
  list: (orgCode: string) => yzhApi.get(`/api/Foundation/CertOrgStandard/list?orgCode=${orgCode}`),
  /** 单条保存：勾选/取消 */
  save: (data: { OrgCode: string; StandardCode: string; Linked: boolean }) =>

  /** 批量保存 */
  batchSave: (data: { OrgCode: string; Items: { StandardCode: string; Linked: boolean }[] }) =>
    yzhApi.post('/api/Foundation/CertOrgStandard/batch-save', data),
}

### P6：前端页面

#### P6-1：机构-标准关联页面

**文件**：`src/certplatform-web/cert/cert-admin/src/pages/foundation/cert-org-standard/index.vue`

**布局**：
```
┌─────────────────────────────────────────────────┐
│ YzhTreeTableLayout                                     │
│ ┌──────────┐ ┌─────────────────────────────────┐ │
│ │ 左树      │ │ 右表                             │ │
│ │ 认证机构  │ │ ☒ ISO 9001:2015  质量管理  2015 │ │
│ │           │ │ ☐ ISO 14001:2015 环境管理  2015 │ │
│ │           │ │ ☒ ISO 13485:2016 医疗器械  2016 │ │
│ └──────────┘ └─────────────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

**核心逻辑**：
1. `onMounted` → 加载左树（机构列表）
2. 点击机构节点 → 调用 `list(orgCode)` → 返回全量标准 + `Linked` 状态
3. 右表用 `el-table` + `el-table-column type="selection"` 渲染 checkbox
4. 表格加载后，遍历数据将 `Linked=true` 的行 `toggleRowSelection`
5. 用户勾选/取消 → 调用 `save({ OrgCode, StandardCode, Linked: true/false })`
6. 操作列：无（checkbox 即全部交互）

**关键组件**：
- `el-tree`：左树
- `el-table` + `el-table-column type="selection"`：右表 checkbox
- 无 `YzhForm`、无弹窗
