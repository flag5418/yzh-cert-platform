## 一、问题现状

### 1.1 四层命名风格混乱

| 层级 | 当前风格 | 问题 |
|------|----------|------|
| **DB** | 混合（snake_case + PascalCase 混用） | 同一张表内两种风格并存 |
| **C#** | 混合（EF Core `[Table]`+`[Column]` vs SqlSugar `[SugarTable]`+`[SugarColumn]`） | 双 ORM 框架 |
| **JSON** | PascalCase | 与 DB 不一致 |
| **TS** | PascalCase + 语义偏移（加前缀/改名） | 与 C# 不一致 |

### 1.2 逐表问题清单

| 表名 | DB 风格 | C# ORM | TS 问题 | 评分 |
|------|---------|--------|---------|------|
| `cert_cert_stage` | PascalCase ✅ | SqlSugar ✅ | 一致 ✅ | **A** |
| `cert_iso_clause` | PascalCase ✅ | SqlSugar ✅ | 一致 ✅ | **A** |
| `cert_sys_config` | PascalCase ✅ | SqlSugar ✅ | — | **A** |
| `cert_iso_standard` | snake_case ❌ | SqlSugar ✅ | 一致 ✅ | **B** |
| `cert_phase_definition` | 混合 ❌ | EF Core ❌ | 一致 ✅ | **B** |
| `cert_certification_body` | snake_case ❌ | EF Core ❌ | `Name`→`OrgName` ❌ | **C** |
| `audit_task` | snake_case ❌ | EF Core ❌ | `TaskNumber`→`TaskNo` ❌ | **C** |
| `cert_enterprise` | 混合 ❌ | EF Core ❌ | `Code`→`EntCode` ❌ | **C** |

### 1.3 TS 语义偏移清单

| C# 属性 | TS 字段 | 问题类型 |
|---------|---------|----------|
| `Name` | `OrgName` | 加前缀 |
| `ShortName` | `OrgShortName` | 加前缀 |
| `Status` | `OrgStatus` | 加前缀 |
| `TaskNumber` | `TaskNo` | 改名 |
| `PlannedDate` | `AuditDate` | 语义不同 |
| `Code` | `EntCode` | 加前缀 |
| `OrgCode` | `OrgId` | 语义完全不同 |
| `CreateTime` | `CreateDate` | 改名 |

## 二、统一方案：全链路 PascalCase

### 2.1 风格决策

| 层级 | 目标风格 | 理由 |
|------|----------|------|
| **DB** | PascalCase | 与 C# 一致，零映射成本；新表已用此风格（`cert_cert_stage`） |
| **C#** | PascalCase（天然） | SqlSugar 默认 PascalCase |
| **JSON** | PascalCase | 已是此风格 |
| **TS** | PascalCase | 与 C# 1:1 对应 |

### 2.2 为什么选 PascalCase 而不是 snake_case

| 对比项 | PascalCase | snake_case |
|--------|-----------|------------|
| C# 天然匹配 | ✅ 零映射 | ❌ 每个字段都要 `[SugarColumn]` |
| JSON 天然匹配 | ✅ | ❌ 需要转换 |
| TS 天然匹配 | ✅ | ❌ 需要转换 |
| MySQL 惯例 | ⚠️ 非标准 | ✅ 标准 |
| 新表已用风格 | ✅ `cert_cert_stage` | — |
| 工作量 | **小**（改旧表列名） | **大**（所有层都要加映射） |

### 2.3 最终一致性目标

```
DB 列名 PascalCase
  ↕  零映射（列名==属性名）
C# 属性 PascalCase
  ↕  EntityConfig FieldName = C# 属性名
JSON 配置 PascalCase
  ↕  TS 接口字段 = C# 属性名
TS 接口 PascalCase
```
