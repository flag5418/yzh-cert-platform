> **范围**：`sys_config` 模块完整实现 + 29 张 `cert_*` 表的审计字段诊断与实体映射修复
> **依据**：BaseEntity 权威定义 + 数据库实测 29 张表结构 + ISoftDelete/IIsValid 接口

## 〇、TL;DR

| 问题 | 严重度 | 影响 |
|------|:------:|------|
| BaseEntity.Id 是 `string (Guid)` 占位符，子类必须 `new long Id` 覆盖为物理主键 | 🔴 | 未覆盖的实体主键类型错误，查询/写入失败 |
| BaseEntity 只有 `CreateBy/UpdateBy/DeleteBy`，现有实体错误声明了独立 `Creator/Modifier/Deleter` 属性 | 🔴 | 架构驱动失效，字段冗余 |
| 数据库审计字段实际是齐全的，之前的"缺失"判断有误 | 🟡 | 实体映射应忠实反映 DB 结构，接口只控制行为 |
| `cert_phase_definition` 使用不同命名约定（create_time/create_by/...）| 🟡 | 需特殊映射处理 |

## 一、架构原则（铁律）

### 1.1 Id 与 Code 的设计

| 字段 | C# 类型 | DB 类型 | 用途 |
|------|---------|---------|------|
| `Id` | 基类 `string`（占位符）/ 子类 `long` | bigint 自增 | 仅作物理主键、排序，**不参与业务关联** |
| `Code` | `string` | varchar(36) GUID | **业务唯一标识**，所有关联/查询/更新/删除 |

```csharp
// ✅ 正确：子类覆盖 Id 为物理主键
[SugarTable("cert_iso_standard")]
public class ISOStandard : BaseEntity
{
    [SugarColumn(ColumnName = "Id", IsPrimaryKey = true, IsIdentity = true)]
    public new long Id { get; set; }  // ← 覆盖基类 string Id

    [SugarColumn(ColumnName = "Code")]
    public new string Code { get; set; } = string.Empty;
}
```

### 1.2 BaseEntity 标准审计字段（唯一权威定义）

> **来源**：`src/yzh-core/YZH.Core.Stand/Models/Entity/BaseEntity.cs`

| FS# | C# 属性 | 基类类型 | DB 列名变体（全部映射到此属性） |
|-----|---------|----------|-------------------------------|
| F01 | `Id` | `string` (占位符) | 子类 `new long Id` → `Id` 列 |
| F02 | `Code` | `string` | `code` / `Code` |
| F03 | `CreateTime` | `DateTime` | `create_date` / `CreateDate` / `create_time` |
| F04 | `CreateBy` | `string?` | `creator` / `create_by` / `CreateBy` |
| F05 | `UpdateTime` | `DateTime?` | `modify_date` / `ModifyDate` / `update_date` / `update_time` |
| F06 | `UpdateBy` | `string?` | `modifier` / `update_by` / `UpdateBy` |
| F07 | `DeleteTime` | `DateTime?` | `delete_time` / `DeleteTime` |
| F08 | `DeleteBy` | `string?` | `deleter` / `delete_by` / `DeleteBy` |
| F09 | `IsDeleted` | `bool` | `is_deleted`（部分表有） |
| F10 | `IsValid` | `int` | `enable` / `is_valid` |
| F11 | `Sort` | `int`（需子类加） | `sort` / `Sort` / `sort_order` |
| F12 | `Remark` | `string?`（需子类加） | `remark` / `Remark` |

> ⚠️ **关键约束**：所有基类属性标记 `[SugarColumn(IsIgnore = true)]`，子类必须用 `new` + `[SugarColumn(ColumnName="xxx")]` 显式覆盖。
>
> ⚠️ **禁止行为**：不要声明独立的 `Creator`/`Modifier`/`Deleter` 属性。数据库中的 `creator`、`modifier`、`deleter` 列统一映射到 BaseEntity 的 `CreateBy`、`UpdateBy`、`DeleteBy`。

### 1.3 接口驱动行为（控制框架，不控制映射）

| 接口/特性 | 定义 | 行为 |
|-----------|------|------|
| `ISoftDelete` | `bool IsDeleted { get; set; }` | 查询自动过滤 `IsDeleted=true`；删除时设标记而非物理删除 |
| `IIsValid` | `int IsValid { get; set; }` | 查询自动过滤 `IsValid=1`；提供 `toggle-valid` 端点 |
| `[YZHDeleteStrategy(Soft)]` | 类特性 | 默认删除行为 = 软删除 |
| `[YZHDeleteStrategy(Hard)]` | 类特性 | 强制物理删除 |

**映射 vs 接口的分离原则**：
- 实体映射 = 忠实反映数据库结构（有什么列就映射什么列）
- 接口 = 控制框架运行时行为（不过滤、不 toggle）

## 三、统一实体映射模板

> **核心原则**：所有表使用 BaseEntity 的统一属性（CreateBy/UpdateBy/DeleteBy），不创建独立的 Creator/Modifier/Deleter 属性。

### 3.1 通用审计字段映射代码

```csharp
// ── 所有 cert_* 实体的标准审计字段覆盖 ──

/// <summary>物理主键（bigint 自增）</summary>
[SugarColumn(ColumnName = "Id", IsPrimaryKey = true, IsIdentity = true)]
public new long Id { get; set; }

/// <summary>业务编码（GUID）</summary>
[SugarColumn(ColumnName = "Code")]
public new string Code { get; set; } = string.Empty;

// ── 根据表实际列名选择正确的 ColumnName ──

/// <summary>创建人（映射到 creator 或 create_by）</summary>
[SugarColumn(ColumnName = "creator")]  // 或 "create_by" / "CreateBy"
public new string? CreateBy { get; set; }

/// <summary>创建时间</summary>
[SugarColumn(ColumnName = "create_date")]  // 或 "CreateDate" / "create_time"
public new DateTime CreateTime { get; set; } = DateTime.UtcNow;

/// <summary>更新人（映射到 modifier 或 update_by）</summary>
[SugarColumn(ColumnName = "modifier")]  // 或 "update_by" / "UpdateBy"
public new string? UpdateBy { get; set; }

/// <summary>更新时间</summary>
[SugarColumn(ColumnName = "modify_date")]  // 或 "ModifyDate" / "update_time"
public new DateTime? UpdateTime { get; set; }

/// <summary>删除人（映射到 deleter 或 delete_by）</summary>
[SugarColumn(ColumnName = "deleter")]  // 或 "delete_by" / "DeleteBy"
public new string? DeleteBy { get; set; }

/// <summary>删除时间</summary>
[SugarColumn(ColumnName = "delete_time")]  // 或 "DeleteTime"
public new DateTime? DeleteTime { get; set; }

/// <summary>软删除标记（仅部分表有 is_deleted 列）</summary>
[SugarColumn(ColumnName = "is_deleted")]  // 或 [SugarColumn(IsIgnore = true)]
public new bool IsDeleted { get; set; }

/// <summary>有效标志（映射到 enable 或 is_valid）</summary>
[SugarColumn(ColumnName = "enable")]  // 或 "is_valid"
public new int IsValid { get; set; } = 1;

/// <summary>排序号（如存在）</summary>
[SugarColumn(ColumnName = "Sort")]  // 或 "sort" / "sort_order"
public new int Sort { get; set; }

/// <summary>备注（如存在）</summary>
[SugarColumn(ColumnName = "Remark")]  // 或 "remark"
public new string? Remark { get; set; }
```

### 3.2 选择 ColumnName 的规则

| 表特征 | CreateBy ColumnName | UpdateBy ColumnName | DeleteBy ColumnName |
|--------|--------------------|--------------------|--------------------|
| 同时有 creator + create_by | `create_by`（优先） | `update_by`（优先） | `delete_by`（优先） |
| 只有 creator | `creator` | `modifier` | `deleter` |
| 只有 create_by | `create_by` | `update_by` | `delete_by` |
| 无此类列 | `[SugarColumn(IsIgnore = true)]` | `[SugarColumn(IsIgnore = true)]` | `[SugarColumn(IsIgnore = true)]` |

### 5.3 后端 Controller

```csharp
// 文件：src/certplatform-api/CertPlatform.Admin/Controllers/System/ConfigController.cs

using Microsoft.AspNetCore.Mvc;
using YZH.Core.Api.Controllers;
using YZH.Core.Api.Services;
using YZH.Core.Stand.Models;
using CertPlatform.Shared.Entities.Sys;

namespace CertPlatform.Admin.Controllers.System;

[ApiController]
[Route("api/System/[controller]")]
public class ConfigController : YzhControllerBase<SysConfig>
{
    public ConfigController(EntityService<SysConfig> entityService, IUserContext userContext)
        : base(entityService, userContext)
    {
    }

    /// <summary>
    /// 新增前校验：config_key 唯一性
    /// </summary>
    protected override async Task<(bool ok, string? msg)> OnBeforeAdd(SysConfig entity)
    {
        if (string.IsNullOrEmpty(entity.ConfigKey))
            return (false, "参数键不能为空");
        var exists = await Entity.ExistsAsync(c => c.ConfigKey == entity.ConfigKey);
        if (exists.Data)
            return (false, $"参数键 {entity.ConfigKey} 已存在");
        return (true, null);
    }

    /// <summary>
    /// 修改前校验
    /// </summary>
    protected override async Task<(bool ok, string? msg)> OnBeforeUpdate(SysConfig entity)
    {
        if (string.IsNullOrEmpty(entity.ConfigKey))
            return (false, "参数键不能为空");
        var exists = await Entity.ExistsAsync(c => c.ConfigKey == entity.ConfigKey && c.Code != entity.Code);
        if (exists.Data)
            return (false, $"参数键 {entity.ConfigKey} 已存在");
        return (true, null);
    }
}
```
