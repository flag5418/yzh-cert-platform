# 迁移工作台 — 旧代码迁移入口

> **状态**：活跃维护 | **更新**：2026-09-12

## 这个目录解决什么问题

旧 Vol 架构（`src/old/server/`）已完成大部分后台管理逻辑，新架构（`src/yzh-core/` +
`src/certplatform-api/`）正在逐步重写。**大量历史接口在新框架下已失效甚至不存在。**

迁移时的核心诉求：**给 AI 一份地图，让它能按图索骥找到旧代码，并知道新架构该怎么写。**

### 建议阅读顺序

```
第一次接触迁移        →  README（本文） → 01-迁移总表 → 02-历史项目地图
拿到一个模块要开工    →  02-历史项目地图 §八 检索索引 → §九 阅读顺序

```
