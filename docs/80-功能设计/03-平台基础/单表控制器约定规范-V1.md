# 单表控制器约定规范-V1

## 概述

本文档定义单表控制器的完整约定规范。基于 **Convention over Configuration（约定优于配置）** 原则，前端可通过约定自动匹配后端接口，无需为每个单表业务编写重复代码。

## 一、命名约定

### 1.1 实体类
```
命名规则：{业务名称}
示例：Sys_User, ISOStandard, CertApplication
```

### 1.2 控制器
```
命名规则：{业务名称}Controller
示例：SysUserController, ISOStandardController

注意：去除下划线，使用 PascalCase
```

### 1.3 路由前缀
```
规则：api/{ControllerName（不含Controller后缀）}
示例：
  - SysUserController → api/sysuser
  - ISOStandardController → api/isostandard
```

## 二、API 接口约定

### 2.1 核心 CRUD 接口

| 功能 | HTTP 方法 | URL 路径 | 控制器方法名 | 说明 |
|------|-----------|----------|--------------|------|
| 分页查询 | POST | `api/{name}/page` | GetPage | 返回分页数据 |
| 获取详情 | GET | `api/{name}/{id}` | GetById | 根据 ID 查询 |
| 根据编码查询 | GET | `api/{name}/by-code/{code}` | GetByCode | 根据 Code 查询 |
| 新增 | POST | `api/{name}/add` | Add | 创建新记录 |
| 修改 | POST | `api/{name}/update` | Update | 更新记录 |
| 单个删除 | POST | `api/{name}/delete` | Delete | 传递 ID 字符串 |
| 批量删除 | POST | `api/{name}/delete-batch` | DeleteBatch | 传递 ID 数组 |

### 2.2 配置与字典接口

| 功能 | HTTP 方法 | URL 路径 | 控制器方法名 |
|------|-----------|----------|--------------|
| 获取配置 | GET | `api/{name}/config` | GetConfig |
| 获取单个字典 | GET | `api/{name}/dict/{dictCode}` | GetDict |
| 获取多个字典 | POST | `api/{name}/dicts` | GetDicts |
| 获取字典编码列表 | GET | `api/{name}/dict-codes` | GetDictCodes |
| 刷新字典缓存 | POST | `api/{name}/dict-refresh/{dictCode}` | RefreshDict |

### 2.3 缓存管理接口

| 功能 | HTTP 方法 | URL 路径 | 控制器方法名 |
|------|-----------|----------|--------------|
| 清除实体缓存 | POST | `api/{name}/cache-clear` | ClearCache |
| 获取缓存信息 | GET | `api/{name}/cache-info` | GetCacheInfo |

### 2.4 自定义行操作接口

| 功能 | HTTP 方法 | URL 路径 | 控制器方法名 |
|------|-----------|----------|--------------|
| 执行自定义操作 | POST | `api/{name}/action/{methodName}` | ExecuteAction |

### 2.5 导入导出接口（待实现）

| 导出 | POST | `api/{name}/export` | Export |

## 三、响应格式约定

所有接口返回统一格式：

```json
{
  "success": true,      // 是否成功
  "code": 200,          // 状态码（200 成功，400 业务错误，500 系统错误）
  "message": "操作成功", // 提示信息
  "data": { ... }       // 业务数据
}
```

### 分页响应示例

```json
{
  "success": true,
  "code": 200,
  "message": "查询成功",
  "data": {
    "items": [ ... ],
    "total": 100,
    "page": 1,
    "pageSize": 20
  }
}
```

## 四、前端配套结构

### 4.1 通用 API 客户端

```typescript
// 前端根据约定拼接 URL
class SingleTableApi<T> {
  constructor(protected controllerName: string) {}
  
  // POST api/{name}/page
  getPage(params: PageRequest) {
    return http.post(`api/${this.controllerName}/page`, params)
  }
  
  // POST api/{name}/add
  add(data: T) {
    return http.post(`api/${this.controllerName}/add`, data)
  }
  
  // POST api/{name}/update
  update(data: T) {
    return http.post(`api/${this.controllerName}/update`, data)
  }
  
  // POST api/{name}/delete
  delete(id: string) {
    return http.post(`api/${this.controllerName}/delete`, id)
  }
  
  // POST api/{name}/delete-batch
  deleteBatch(ids: string[]) {
    return http.post(`api/${this.controllerName}/delete-batch`, ids)
  }
  
  // GET api/{name}/config
  getConfig() {
    return http.get(`api/${this.controllerName}/config`)
  }
  
  // GET api/{name}/dict/{code}
  getDict(dictCode: string) {
    return http.get(`api/${this.controllerName}/dict/${dictCode}`)
  }
  
  // POST api/{name}/action/{methodName}
  executeAction(methodName: string, data: T) {
    return http.post(`api/${this.controllerName}/action/${methodName}`, data)
  }
}
```

### 4.2 通用页面组件

前端只需配置 `GridConfig`，即可通过通用组件渲染页面：

```vue
<template>
  <YzhSingleTable
    :controller-name="'sysuser'"
    :title="'用户管理'"
  />
</template>
```

通用组件内部流程：
1. 加载 `GET api/sysuser/config` 获取 GridConfig
2. 加载所需字典数据 `GET api/sysuser/dict/{code}`
3. 渲染表格和搜索表单
4. 调用 `POST api/sysuser/page` 获取数据
5. 操作按钮根据配置绑定对应的 API

## 五、GridConfig JSON 命名约定

```
文件路径：GridConfigs/{EntityName}.json
文件名：与实体类名一致

示例：
  - Sys_User 实体 → GridConfigs/SysUser.json
  - ISOStandard 实体 → GridConfigs/ISOStandard.json
```

## 六、字典注册约定

### 6.1 字典编码命名

```
规则：{字段名}Dict 或 {业务含义}
示例：StatusDict, GenderDict, CertTypeDict
```

### 6.2 字典注册方式

```csharp
protected override void OnRegisterDicts()
{
    DictService.Register(ControllerName, "StatusDict", () => new List<DictItem>
    {
        new() { DictValue = "1", DictLabel = "启用" },
        new() { DictValue = "0", DictLabel = "禁用" }
    });
    
    // 绑定数据库字典表
    DictService.Register(ControllerName, "GenderDict", () => 
        _db.SysDictionaries.Where(d => d.Category == "gender")
            .Select(d => new DictItem { DictValue = d.Value, DictLabel = d.Label })
            .ToList());
}
```

## 七、自定义行操作约定

### 7.1 按钮配置

在 GridConfig 中配置 CustomButtons：

```json
{
  "rowButtons": {
    "edit": true,
    "delete": true,
    "view": true,
    "customButtons": {
      "启用": "Enable",
      "禁用": "Disable",
      "重置密码": "ResetPassword"
    }
  }
}
```

### 7.2 控制器实现

```csharp
// Controller 中实现对应方法（必须是 public，参数为实体类型）
public ActionResult<ApiResponse> Enable(SysUser entity)
{
    entity.Enable = 1;
    var result = EntityService.Update(entity, UserContext.UserId, UserContext.UserName);
    return result.Success ? Ok(ApiResponse.Ok("已启用")) : BadRequest(ApiResponse.Fail(result.Message));
}

public ActionResult<ApiResponse> Disable(SysUser entity)
{
    entity.Enable = 0;
    var result = EntityService.Update(entity, UserContext.UserId, UserContext.UserName);
    return result.Success ? Ok(ApiResponse.Ok("已禁用")) : BadRequest(ApiResponse.Fail(result.Message));
}

public ActionResult<ApiResponse> ResetPassword(SysUser entity)
{
    entity.Password = _passwordHelper.AesEncrypt("123456");
    var result = EntityService.Update(entity, UserContext.UserId, UserContext.UserName);
    return result.Success ? Ok(ApiResponse.Ok("密码已重置为123456")) : BadRequest(ApiResponse.Fail(result.Message));
}
```

## 九、生命周期钩子约定

Controller 可覆盖以下钩子实现自定义逻辑：

| 钩子方法 | 调用时机 | 用途 |
|----------|----------|------|
| OnRegisterDicts | 构造函数后 | 注册字典数据源 |
| OnConfigLoading | 加载配置时 | 动态修改配置 |
| OnQuerying | 查询前 | 修改/取消查询 |
| OnBuildingQuery | 构建查询条件 | 添加自定义过滤 |
| OnQueried | 查询后 | 数据翻译/格式化 |
| OnDetailLoaded | 详情加载后 | 详情数据加工 |
| OnBeforeAdding | 新增前 | 数据校验/填充 |
| OnAfterAdded | 新增后（事务内） | 关联操作 |
| OnBeforeUpdating | 更新前 | 数据校验 |
| OnAfterUpdated | 更新后（事务内） | 关联操作 |
| OnBeforeDeleting | 删除前 | 关联检查 |
| OnAfterDeleted | 删除后（事务内） | 清理操作 |
| OnAfterCommitted | 提交后（事务外） | 清缓存/发通知 |
| OnRegisterActions | 注册自定义操作 | 扩展允许的操作 |
| OnCustomValidate | 自定义校验 | 业务规则校验 |
