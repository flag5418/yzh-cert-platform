# 后端基类能力设计规范 V1

> 本文档定义了认证平台后端**基础设施层**的完整基类设计。
> 所有 Controller、服务、队列、后台任务等**统一遵循此规范**。
> 本规范独立于"单页面架构"，单页面能力基于此规范构建。

---

## 一、架构总览

### 1.1 设计参考

| 参考源 | 借鉴内容 |
|--------|----------|
| `YZH.WPF.Core.ViewModel.BaseMainModel` | 列表操作模式（Add/Edit/Del/Refresh/Export） |
| `YZH.WPF.Core.ViewModel.BaseEditModel` | 编辑操作模式（AuditAdd/AuditEdit/SaveCheck） |
| `YZH.Web.Core.BaseEntityController` | 统一 ApiResult 返回 + 异常处理 |
| `YZH.Web.Core.WorkFlowController` | 多实体混合事务（`UseTransaction` 回调模式） |
| `YZH.Web.Core.GlobalExceptionMiddleware` | 全局异常兜底 + 日志记录 |
| Vol 框架 `RepositoryBase` | 数据访问基础能力 |

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **结果封装** | 所有写操作返回 `IOperationResult`，包含 Success/Message/Data |
| **全局容错** | 异常在基类统一捕获和记录，业务代码无需 try-catch |
| **事务通用** | WorkUnit 不限定单一泛型，支持多实体混合操作 |
| **审计日志** | 所有数据库写操作自动记录操作人、时间、操作类型 |
| **无状态优先** | 基础设施服务无状态，可注入任何上层组件 |

### 1.3 关键数据模型约定

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | `int` | 物理主键（AUTO_INCREMENT） |
| `Code` | `string` | 业务唯一键（GUID `ToString("N")`） |

## 二、操作结果封装

### 2.1 IOperationResult

> 对标参考架构的 `ApiOk`/`ApiErr`，但更结构化。
> 每个实体操作的返回值，包含成功标志、消息、数据。

```csharp
namespace YZH.Core.Stand.Models;

/// <summary>
/// 操作结果基接口
/// 所有写操作（Insert/Update/Delete）的标准返回值
/// </summary>
public interface IOperationResult
{
    bool Success { get; }
    string Message { get; }
    Exception? Exception { get; }
}

/// <summary>
/// 操作结果（带数据）
/// </summary>
public interface IOperationResult<out T> : IOperationResult
{
    T? Data { get; }
}

/// <summary>
/// 操作结果实现
/// </summary>
public class OperationResult : IOperationResult
{
    public bool Success { get; protected set; }
    public string Message { get; protected set; } = string.Empty;
    public Exception? Exception { get; protected set; }

    public static OperationResult Ok(string message = "操作成功")
        => new() { Success = true, Message = message };

    public static OperationResult Fail(string message, Exception? ex = null)
        => new() { Success = false, Message = message, Exception = ex };
}

/// <summary>
/// 操作结果实现（带数据）
/// </summary>
public class OperationResult<T> : IOperationResult<T>
{
    public bool Success { get; protected set; }
    public string Message { get; protected set; } = string.Empty
    public Exception? Exception { get; protected set; }
    public T? Data { get; protected set; }

    public static OperationResult<T> Ok(T data, string message = "操作成功")
        => new() { Success = true, Message = message, Data = data };

    public static OperationResult<T> Fail(string message, Exception? ex = null)
        => new() { Success = false, Message = message, Exception = ex };
}

/// <summary>
/// 批量操作结果
/// </summary>
public class BatchOperationResult : IOperationResult
{
    public bool Success { get; protected set; }
    public string Message { get; protected set; } = string.Empty;
    public Exception? Exception { get; protected set; }
    public int SuccessCount { get; protected set; }
    public int FailCount { get; protected set; }
    public List<(string Code, string Error)> Failures { get; protected set; } = new();

    public static BatchOperationResult Ok(int successCount, string message = "批量操作成功")
        => new() { Success = true, SuccessCount = successCount, Message = message };

    public static BatchOperationResult Partial(int successCount, int failCount, List<(string, string)> failures)
        => new() { Success = false, SuccessCount = successCount, FailCount = failCount, Failures = failures, Message: $"成功 {successCount} 条，失败 {failCount} 条" };

    public static BatchOperationResult Fail(string message, Exception? ex = null)
        => new() { Success: false, Message = message, Exception = ex };
}
```

## 三、EntityService<T> — 通用实体操作服务

### 3.1 设计目标

> 对标参考架构的 `BaseEntityController` + `IDbOrm`。
> **核心差异**：每个写操作返回 `IOperationResult`，异常由基类统一捕获和记录。

```csharp
namespace YZH.Core.Services;

/// <summary>
/// 通用实体操作服务（无 Controller 依赖）
/// 提供标准 CRUD、批量操作、分页查询等原子操作
/// 任何上层组件（Controller / 队列 / 导入导出）都可组合引用
/// 
/// 设计要点：
/// - 所有写操作返回 IOperationResult（基类统一捕获异常、记录日志）
/// - 业务查找以 Code（GUID）为主键
/// - 审计字段自动填充（CreateBy/UpdateBy/CreateTime/UpdateTime）
/// - 所有写操作支持 saveChanges 参数，事务中设为 false
/// </summary>
public class EntityService<T> where T : BaseEntity
{
    private readonly IRepository<T> _repository;
    private readonly IAuditLogger _auditLogger;

    public EntityService(IRepository<T> repository, IAuditLogger auditLogger)
    {
        _repository = repository;
        _auditLogger = auditLogger;
    }

    // ==================== 原子查询操作 ====================

    /// <summary>根据物理主键 Id 获取实体</summary>
    public virtual T? GetById(int id) => _repository.GetById(id);

    /// <summary>根据业务 Code 获取实体（主要查找方式）</summary>
    public virtual T? GetByCode(string code) => _repository.GetByCode(code);

    /// <summary>获取单个实体</summary>
    public virtual T? GetOne(Expression<Func<T, bool>> predicate)
        => _repository.GetOne(predicate);

    /// <summary>获取列表</summary>
    public virtual List<T> GetList(Expression<Func<T, bool>>? predicate = null)
        => _repository.GetList(predicate);

    /// <summary>分页查询</summary>
    public virtual (List<T> items, int total) GetPage(PagerOptions options)
        => _repository.GetPage(options);

    /// <summary>统计数量</summary>
    public virtual int Count(Expression<Func<T, bool>>? predicate = null)
        => _repository.Count(predicate);

    /// <summary>判断是否存在</summary>
    public virtual bool Exists(Expression<Func<T, bool>> predicate)
        => _repository.Exists(predicate);

    /// <summary>根据 Code 判断是否存在</summary>
    public virtual bool ExistsByCode(string code)
        => _repository.Exists(x => x.Code == code);

    // ==================== 原子写操作（返回 IOperationResult） ====================

    /// <summary>
    /// 插入单个实体（自动填充 Code 和审计字段）
    /// 异常由基类统一捕获和记录，返回 IOperationResult
    /// </summary>
    /// <param name="entity">实体</param>
    /// <param name="userId">操作人 ID</param>
    /// <param name="userName">操作人名称</param>
    /// <param name="saveChanges">是否立即提交（事务中设为 false）</param>
    public virtual IOperationResult<T> Insert(
        T entity, 
        string userId, 
        string userName, 
        bool saveChanges = true)
    {
        try
        {
            // 自动填充 Code
            if (string.IsNullOrEmpty(entity.Code))
                entity.Code = Guid.NewGuid().ToString("N");

            // 填充审计字段
            FillCreateAudit(entity, userId, userName);

            // 执行插入
            var result = _repository.Insert(entity, saveChanges);

            // 记录审计日志
            _auditLogger.LogInsert(entity, userId, userName);

            return OperationResult<T>.Ok(result);
        }
        catch (Exception ex)
        {
            // 记录异常日志
            _auditLogger.LogException(ex, "Insert", entity, userId);
            return OperationResult<T>.Fail(GetFriendlyError(ex, "新增"), ex);
        }
    }

    /// <summary>
    /// 更新单个实体
    /// </summary>
    public virtual IOperationResult<T> Update(
        T entity, 
        string userId, 
        string userName, 
        bool saveChanges = true, 
        string[]? updateFields = null)
    {
        try
        {
            FillUpdateAudit(entity, userId, userName);

            var result = updateFields == null
                ? _repository.Update(entity, saveChanges)
                : _repository.Update(entity, saveChanges, updateFields);

            _auditLogger.LogUpdate(entity, userId, userName);

            return OperationResult<T>.Ok(result);
        }
        catch (Exception ex)
        {
            _auditLogger.LogException(ex, "Update", entity, userId);
            return OperationResult<T>.Fail(GetFriendlyError(ex, "修改"), ex);
        }
    }

    /// <summary>
    /// 删除单个实体
    /// </summary>
    public virtual IOperationResult Delete(int id, string userId, string userName, bool saveChanges = true)
    {
        try
        {
            var entity = _repository.GetById(id);
            if (entity == null)
                return OperationResult.Fail("记录不存在或已被删除");

            _repository.Delete(id, saveChanges);

            _auditLogger.LogDelete(entity, userId, userName);

            return OperationResult.Ok("删除成功");
        }
        catch (Exception ex)
        {
            _auditLogger.LogException(ex, "Delete", null, userId);
            return OperationResult.Fail(GetFriendlyError(ex, "删除"), ex);
        }
    }

    /// <summary>
    /// 根据 Code 删除（业务键删除）
    /// </summary>
    public virtual IOperationResult DeleteByCode(string code, string userId, string userName, bool saveChanges = true)
    {
        try
        {
            var entity = GetByCode(code);
            if (entity == null)
                return OperationResult.Fail("记录不存在或已被删除");

            _repository.Delete(entity.Id, saveChanges);

            _auditLogger.LogDelete(entity, userId, userName);

            return OperationResult.Ok("删除成功");
        }
        catch (Exception ex)
        {
            _auditLogger.LogException(ex, "DeleteByCode", null, userId);
            return OperationResult.Fail(GetFriendlyError(ex, "删除"), ex);
        }
    }

    // ==================== 批量操作（事务保护） ====================

    /// <summary>
    /// 批量插入（事务保护，统一提交）
    /// </summary>
    public virtual IOperationResult<List<T>> InsertBatch(
        IEnumerable<T> entities, 
        string userId, 
        string userName)
    {
        var list = entities.ToList();
        foreach (var entity in list)
        {
            if (string.IsNullOrEmpty(entity.Code))
                entity.Code = Guid.NewGuid().ToString("N");
            FillCreateAudit(entity, userId, userName);
        }

        try
        {
            _repository.ExecuteInTransaction(() =>
            {
                foreach (var entity in list)
                    _repository.Insert(entity, false);
            });

            _auditLogger.LogBatchInsert(list, userId, userName);
            return OperationResult<List<T>>.Ok(list);
        }
        catch (Exception ex)
        {
            _auditLogger.LogException(ex, "InsertBatch", null, userId);
            return OperationResult<List<T>>.Fail(GetFriendlyError(ex, "批量新增"), ex);
        }
    }

    /// <summary>
    /// 批量更新（事务保护，统一提交）
    /// </summary>
    public virtual IOperationResult<List<T>> UpdateBatch(
        IEnumerable<T> entities, 
        string userId, 
        string userName)
    {
        var list = entities.ToList();
        try
        {
            _repository.ExecuteInTransaction(() =>
            {
                foreach (var entity in list)
                {
                    FillUpdateAudit(entity, userId, userName);
                    _repository.Update(entity, false);
                }
            });

            _auditLogger.LogBatchUpdate(list, userId, userName);
            return OperationResult<List<T>>.Ok(list);
        }
        catch (Exception ex)
        {
            _auditLogger.LogException(ex, "UpdateBatch", null, userId);
            return OperationResult<List<T>>.Fail(GetFriendlyError(ex, "批量修改"), ex);
        }
    }

    /// <summary>
    /// 批量删除（事务保护，统一提交）
    /// </summary>
    public virtual IOperationResult DeleteBatch(
        IEnumerable<int> ids, 
        string userId, 
        string userName)
    {
        var idList = ids.ToList();
        try
        {
            _repository.ExecuteInTransaction(() =>
            {
                foreach (var id in idList)
                    _repository.Delete(id, false);
            });

            _auditLogger.LogBatchDelete(idList, userId, userName);
            return OperationResult.Ok($"已删除 {idList.Count} 条记录");
        }
        catch (Exception ex)
        {
            _auditLogger.LogException(ex, "DeleteBatch", null, userId);
            return OperationResult.Fail(GetFriendlyError(ex, "批量删除"), ex);
        }
    }

    // ==================== 私有方法 ====================

    private void FillCreateAudit(T entity, string userId, string userName)
    {
        entity.CreateTime = DateTime.UtcNow;
        entity.UpdateTime = DateTime.UtcNow;
        entity.CreateBy = userId;
        entity.UpdateBy = userName;
    }

    private void FillUpdateAudit(T entity, string userId, string userName)
    {
        entity.UpdateTime = DateTime.UtcNow;
        entity.UpdateBy = userName;
    }

    /// <summary>
    /// 将异常转换为用户友好的错误消息
    /// 基类统一处理，业务代码无需关心
    /// </summary>
    private string GetFriendlyError(Exception ex, string operationName)
    {
        // 唯一约束冲突
        if (ex.Message?.Contains("Duplicate") == true || ex.Message?.Contains("UNIQUE") == true)
            return $"{operationName}失败：数据已存在（唯一约束冲突）";

        // 外键约束
        if (ex.Message?.Contains("foreign key") == true || ex.Message?.Contains("FOREIGN KEY") == true)
            return $"{operationName}失败：数据被其他业务引用，无法操作";

        // 连接超时
        if (ex is MySqlConnector.MySqlException mysqlEx && mysqlEx.Number == 1042)
            return $"{operationName}失败：数据库连接超时，请稍后重试";

        return $"{operationName}失败：{ex.Message}";
    }
}
```

## 四、WorkUnit — 事务工作单元

### 4.1 设计目标

> 对标参考架构的 `_orm.UseTransaction(db => {...}, out txErr)`。
> **核心能力**：事务内可执行**任意多实体类型**的混合操作（不只是单一泛型 T）。

```csharp
namespace YZH.Core.Services;

/// <summary>
/// 事务工作单元 — 通用回调模式
/// 
/// 核心能力：
/// 1. 支持多实体类型混合操作（如同时更新 User + UserRole + Menu）
/// 2. 回调内所有 saveChanges:false 的操作统一提交
/// 3. 嵌套事务支持（已有事务时共享上层事务）
/// 4. 统一异常处理和日志记录
/// 5. 返回 IOperationResult（操作是否成功由基类判断）
/// 
/// 使用示例：
///   workUnit.Execute(() => {
///       userService.Insert(user, userId, userName, saveChanges: false);
///       roleService.InsertRole(userId, roleId, userName, saveChanges: false);
///       auditService.Log("UserCreated", user.Code);
///   });  // 退出时统一 Commit + SaveChanges
/// </summary>
public class WorkUnit : IDisposable
{
    private readonly BaseDbContext _context;
    private IDbContextTransaction? _transaction;
    private bool _nesting;
    private bool _completed;

    public WorkUnit(BaseDbContext context)
    {
        _context = context;
        _nesting = context.Database.CurrentTransaction != null;
    }

    /// <summary>
    /// 在事务中执行操作（回调模式）
    /// 回调内所有 saveChanges:false 的操作在退出时统一提交
    /// 
    /// 如果当前已有事务（嵌套调用），则直接执行回调（共享上层事务）
    /// </summary>
    public IOperationResult Execute(Action action)
    {
        if (_nesting)
        {
            try
            {
                action();
                return OperationResult.Ok();
            }
            catch (Exception ex)
            {
                return OperationResult.Fail($"事务操作失败：{ex.Message}", ex);
            }
        }

        using var transaction = _context.Database.BeginTransaction();
        try
        {
            action();                   // 执行业务操作（所有方法 saveChanges=false）
            _context.SaveChanges();      // 统一保存
            transaction.Commit();       // 提交事务
            _completed = true;
            return OperationResult.Ok();
        }
        catch (Exception ex)
        {
            try { transaction.Rollback(); }
            catch (Exception rollbackEx)
            {
                return OperationResult.Fail($"事务回滚失败：{rollbackEx.Message}", rollbackEx);
            }
            return OperationResult.Fail($"事务操作失败：{ex.Message}", ex);
        }
    }

    /// <summary>
    /// 在事务中执行操作（带返回值）
    /// </summary>
    public IOperationResult<TResult> Execute<TResult>(Func<TResult> func)
    {
        if (_nesting)
        {
            try
            {
                var result = func();
                return OperationResult<TResult>.Ok(result);
            }
            catch (Exception ex)
            {
                return OperationResult<TResult>.Fail($"事务操作失败：{ex.Message}", ex);
            }
        }

        using var transaction = _context.Database.BeginTransaction();
        try
        {
            var result = func();
            _context.SaveChanges();
            transaction.Commit();
            _completed = true;
            return OperationResult<TResult>.Ok(result);
        }
        catch (Exception ex)
        {
            try { transaction.Rollback(); }
            catch (Exception rollbackEx)
            {
                return OperationResult<TResult>.Fail($"事务回滚失败：{rollbackEx.Message}", rollbackEx);
            }
            return OperationResult<TResult>.Fail($"事务操作失败：{ex.Message}", ex);
        }
    }

    /// <summary>
    /// 异步事务回调
    /// </summary>
    public async Task<IOperationResult> ExecuteAsync(Func<Task> action)
    {
        if (_nesting)
        {
            try
            {
                await action();
                return OperationResult.Ok();
            }
            catch (Exception ex)
            {
                return OperationResult.Fail($"事务操作失败：{ex.Message}", ex);
            }
        }

        await using var transaction = await _context.Database.BeginTransactionAsync();
        try
        {
            await action();
            await _context.SaveChangesAsync();
            await transaction.CommitAsync();
            _completed = true;
            return OperationResult.Ok();
        }
        catch (Exception ex)
        {
            try { await transaction.RollbackAsync(); }
            catch { /* 回滚失败不掩盖原始异常 */ }
            return OperationResult.Fail($"事务操作失败：{ex.Message}", ex);
        }
    }

    /// <summary>
    /// 异步事务回调（带返回值）
    /// </summary>
    public async Task<IOperationResult<TResult>> ExecuteAsync<TResult>(Func<Task<TResult>> func)
    {
        if (_nesting)
        {
            try
            {
                var result = await func();
                return OperationResult<TResult>.Ok(result);
            }
            catch (Exception ex)
            {
                return OperationResult<TResult>.Fail($"事务操作失败：{ex.Message}", ex);
            }
        }

        await using var transaction = await _context.Database.BeginTransactionAsync();
        try
        {
            var result = await func();
            await _context.SaveChangesAsync();
            await transaction.CommitAsync();
            _completed = true;
            return OperationResult<TResult>.Ok(result);
        }
        catch (Exception ex)
        {
            try { await transaction.RollbackAsync(); }
            catch { /* 回滚失败不掩盖原始异常 */ }
            return OperationResult<TResult>.Fail($"事务操作失败：{ex.Message}", ex);
        }
    }

    public void Dispose()
    {
        // 非嵌套时在 Dispose 中处理未完成的事务
        if (!_nesting && !_completed && _transaction != null)
        {
            try { _transaction.Rollback(); } catch { /* 忽略 */ }
        }
        _transaction?.Dispose();
    }
}
```

## 五、IUserContext — 用户上下文与 IP 获取

### 5.1 设计目标

> 对标 Vol 框架的 `HttpContextExtension.GetUserIp()`（参见 `YZH.Core/Extensions/RequestExtension.cs`）。
> 统一获取当前请求的 **客户端 IP 地址**、用户信息，供审计日志、权限校验等使用。

### 5.2 IP 获取逻辑

```
优先级: X-Real-IP (Nginx) > X-Forwarded-For (多级代理) > RemoteIpAddress
```

| 来源 | 说明 |
|------|------|
| `X-Real-IP` | Nginx/反向代理设置的客户端真实 IP |
| `X-Forwarded-For` | 多级代理场景，取第一个逗号分隔的 IP |
| `RemoteIpAddress` | 直接连接 IP（`::1` 自动转为 `127.0.0.1`） |
| 兜底 | 获取失败时返回 `0.0.0.0` |

### 5.3 接口定义

```csharp
namespace YZH.Core.Stand.Models;

/// <summary>
/// 用户上下文接口 - 提供当前请求的用户信息、IP 地址
/// </summary>
public interface IUserContext
{
    string UserId { get; }
    string UserName { get; }
    string? UserTrueName { get; }
    string ClientIp { get; }        // ← 核心: 客户端 IP 地址
    string? UserAgent { get; }
    bool IsAuthenticated { get; }
    IEnumerable<string> GetRoleIds();
    RequestContext GetRequestContext();  // ← 获取完整上下文用于审计
}

/// <summary>请求上下文信息（用于审计日志）</summary>
public class RequestContext
{
    public string UserId { get; set; } = string.Empty;
    public string UserName { get; set; } = string.Empty;
    public string ClientIp { get; set; } = string.Empty;
    public string? UserAgent { get; set; }
    public string RequestPath { get; set; } = string.Empty;
public string RequestMethod { get; set; } = string.Empty;
    public DateTime Timestamp { get; set; } = DateTime.UtcNow;
}
```

### 5.4 实现

```csharp
namespace YZH.Core.Api.Services;

/// <summary>
/// 用户上下文实现 — 基于 IHttpContextAccessor
/// IP 获取逻辑对标 Vol 框架的 HttpContextExtension.GetUserIp()
/// </summary>
public class UserContext : IUserContext
{
    private readonly IHttpContextAccessor _httpContextAccessor;
    private readonly HttpContext? _httpContext;

    public UserContext(IHttpContextAccessor httpContextAccessor)
    {
        _httpContextAccessor = httpContextAccessor;
        _httpContext = httpContextAccessor.HttpContext;
    }

    public string UserId => _httpContext?.User?.FindFirst(ClaimTypes.NameIdentifier)?.Value ?? "0";
    public string UserName => _httpContext?.User?.FindFirst(ClaimTypes.Name)?.Value ?? "anonymous";
    public string? UserTrueName => _httpContext?.User?.FindFirst("UserTrueName")?.Value
        ?? _httpContext?.User?.FindFirst(ClaimTypes.GivenName)?.Value;

    /// <summary>
    /// 获取客户端 IP 地址 - 优先级: X-Real-IP > X-Forwarded-For > RemoteIpAddress
    /// </summary>
    public string ClientIp
    {
        get
        {
            if (_httpContext == null) return "0.0.0.0";
            try
            {
                var remoteIpAddress = _httpContext.Connection?.RemoteIpAddress?.ToString() ?? "0.0.0.0";

                if (_httpContext.Request.Headers.TryGetValue("X-Real-IP", out var realIp))
                {
                    var ip = realIp.ToString();
                    if (!string.IsNullOrEmpty(ip) && ip != remoteIpAddress) return ip;
                }

                if (_httpContext.Request.Headers.TryGetValue("X-Forwarded-For", out var forwardedFor))
                {
                    var forwarded = forwardedFor.ToString();
                    if (!string.IsNullOrEmpty(forwarded))
                    {
                        var ip = forwarded.Split(',', StringSplitOptions.TrimEntries)[0];
                        if (!string.IsNullOrEmpty(ip)) return ip;
                    }
                }

                return remoteIpAddress == "::1" ? "127.0.0.1" : remoteIpAddress;
            }
            catch { return "0.0.0.0"; }
        }
    }

    public string? UserAgent => _httpContext?.Request?.Headers["User-Agent"].ToString();
    public bool IsAuthenticated => _httpContext?.User?.Identity?.IsAuthenticated ?? false;

    public IEnumerable<string> GetRoleIds()
        => _httpContext?.User?.FindAll(ClaimTypes.Role)?.Select(c => c.Value) ?? Enumerable.Empty<string>();

    public RequestContext GetRequestContext() => new()
    {
        UserId = UserId,
        UserName = UserName,
        ClientIp = ClientIp,
        UserAgent = UserAgent,
        RequestPath = _httpContext?.Request?.Path.Value ?? "",
        RequestMethod = _httpContext?.Request?.Method ?? "",
        Timestamp = DateTime.UtcNow
    };
}
```

## 六、IAuditLogger — 审计日志服务

### 6.1 设计目标

> 对标参考架构的 `LogHelper.Error(ex)` / `LogHelper.Info(msg)`。
> 所有数据库操作自动记录操作人、时间、操作类型、客户端 IP。
> 
> **与 Vol 架构的区别**：审计日志接受 `RequestContext`（来自 `IUserContext.GetRequestContext()`），
> 而非单独的 userId/userName。这样审计日志可以同时记录 IP 地址、User-Agent、请求路径等完整上下文信息。

```csharp
namespace YZH.Core.Api.Services;

/// <summary>
/// 审计日志服务接口 - 使用 RequestContext 传递完整上下文（含 IP、UserAgent 等）
/// </summary>
public interface IAuditLogger
{
    void LogInsert<T>(T entity, RequestContext context) where T : BaseEntity;
    void LogUpdate<T>(T entity, RequestContext context) where T : BaseEntity;
    void LogDelete<T>(T entity, RequestContext context) where T : BaseEntity;
    void LogBatchInsert<T>(List<T> entities, RequestContext context) where T : BaseEntity;
    void LogBatchUpdate<T>(List<T> entities, RequestContext context) where T : BaseEntity;
    void LogBatchDelete<T>(List<int> ids, RequestContext context) where T : BaseEntity;
    void LogException(Exception ex, string operationType, object? entity, RequestContext context);
    void LogOperation(string operationType, string description, RequestContext context);
}

/// <summary>
/// 审计日志实现 - 文件日志 + 控制台（带颜色区分级别）
/// </summary>
public class AuditLogger : IAuditLogger
{
    private readonly IWebHostEnvironment _environment;

    public AuditLogger(IWebHostEnvironment environment)
    {
        _environment = environment;
    }

    public void LogInsert<T>(T entity, RequestContext context) where T : BaseEntity
        => Log("INSERT", $"{context.UserName}({context.ClientIp}) 新增 {typeof(T).Name} Id={entity.Id}", context);

    public void LogUpdate<T>(T entity, RequestContext context) where T : BaseEntity
        => Log("UPDATE", $"{context.UserName}({context.ClientIp}) 更新 {typeof(T).Name} Id={entity.Id}", context);

    public void LogDelete<T>(T entity, RequestContext context) where T : BaseEntity
        => Log("DELETE", $"{context.UserName}({context.ClientIp}) 删除 {typeof(T).Name} Id={entity.Id}", context);

    public void LogBatchInsert<T>(List<T> entities, RequestContext context) where T : BaseEntity
        => Log("BATCH_INSERT", $"{context.UserName}({context.ClientIp}) 批量新增 {entities.Count} 条 {typeof(T).Name}", context);

    public void LogBatchUpdate<T>(List<T> entities, RequestContext context) where T : BaseEntity
        => Log("BATCH_UPDATE", $"{context.UserName}({context.ClientIp}) 批量更新 {entities.Count} 条 {typeof(T).Name}", context);

    public void LogBatchDelete<T>(List<int> ids, RequestContext context) where T : BaseEntity
        => Log("BATCH_DELETE", $"{context.UserName}({context.ClientIp}) 批量删除 {ids.Count} 条 {typeof(T).Name}", context);

    public void LogException(Exception ex, string operationType, object? entity, RequestContext context)
    {
        var entityInfo = entity != null ? $"Entity={entity.GetType().Name}" : "Entity=null";
        Log("ERROR", $"{operationType} 异常: {ex.Message}, {entityInfo}, User={context.UserName}({context.ClientIp})", context);
    }

    public void LogOperation(string operationType, string description, RequestContext context)
        => Log(operationType, $"{context.UserName}({context.ClientIp}) {description}", context);

    private void Log(string level, string message, RequestContext context)
    {
        var logEntry = $"[{DateTime.UtcNow:yyyy-MM-dd HH:mm:ss.fff}] [{level}] [User={context.UserName}({context.ClientIp})] {message}";

        // 控制台日志（带颜色）
        try
        {
            var originalColor = Console.ForegroundColor;
            Console.ForegroundColor = level switch
            {
                "ERROR" => ConsoleColor.Red,
                "DELETE" => ConsoleColor.Yellow,
                "INSERT" => ConsoleColor.Green,
                "UPDATE" => ConsoleColor.Cyan,
                _ => ConsoleColor.Gray
            };
            Console.WriteLine(logEntry);
            Console.ForegroundColor = originalColor;
        }
        catch { /* 忽略日志写入失败 */ }

        // 文件日志
        try
        {
            var logDir = Path.Combine(_environment.ContentRootPath, "Logs", "Audit");
            Directory.CreateDirectory(logDir);
            var logFile = Path.Combine(logDir, $"{DateTime.UtcNow:yyyy-MM-dd}.log");
            File.AppendAllText(logFile, logEntry + Environment.NewLine);
        }
        catch { /* 日志写入失败不影响主流程 */ }
    }
}
```

## 八、PageBaseController<T> — 单页面控制器基类

### 8.1 设计目标

> 基于 `EntityService<T>` + `WorkUnit` + `ApiResponse` 构建的单页面控制器。
> 通过 **组合** 而非继承实现。
> 对标参考架构的 `BaseMainModel<T>` + `BaseEditModel<T>` 前后端联动。

```csharp
namespace YZH.Core.Web.Controllers;

/// <summary>
/// 单页面控制器基类
/// 提供标准 CRUD、分页、导入导出能力
/// 所有操作返回统一 ApiResponse，异常由基类统一处理
/// </summary>
[ApiController]
[Route("api/[controller]")]
public abstract class PageBaseController<T> : ControllerBase where T : BaseEntity
{
    // === 基础设施服务（组合引用）===
    protected readonly EntityService<T> EntityService;
    protected readonly WorkUnit WorkUnit;
    protected readonly IAuditLogger AuditLogger;
    protected readonly GridConfigLoader ConfigLoader;
    protected readonly ExcelExporter Exporter;
    protected readonly ExcelImporter Importer;

    // === 页面配置 ===
    protected GridConfig Config { get; }

    protected PageBaseController(
        EntityService<T> entityService,
        WorkUnit workUnit,
        IAuditLogger auditLogger,
        GridConfigLoader configLoader,
        ExcelExporter exporter,
        ExcelImporter importer)
    {
        EntityService = entityService;
        WorkUnit = workUnit;
        AuditLogger = auditLogger;
        ConfigLoader = configLoader;
        Exporter = exporter;
        Importer = importer;
        Config = LoadConfig();
    }

    // ============================================================
    // 一、配置与初始化
    // ============================================================

    /// <summary>加载 GridConfig（默认从 JSON 文件）</summary>
    protected virtual GridConfig LoadConfig() => ConfigLoader.GetConfig<T>();

    /// <summary>获取配置（前端调用）</summary>
    [HttpGet("config")]
    public virtual ActionResult<ApiResponse<GridConfig>> GetConfig()
    {
        OnConfigLoading(Config);
        return Ok(ApiResponse<GridConfig>.Ok(Config));
    }

    protected virtual void OnConfigLoading(GridConfig config) { }

    // ============================================================
    // 二、查询（含分页）
    // ============================================================

    [HttpPost("page")]
    public virtual ActionResult<ApiResponse<PagedResult<T>>> GetPage(
        [FromBody] PageRequest request)
    {
        var ctx = CreateContext(request.Conditions);
        OnQuerying(ctx);

        var (items, total) = EntityService.GetPage(new PagerOptions
        {
            Page = request.Page,
            PageSize = request.PageSize,
            SortBy = request.SortField,
            SortDirection = request.SortOrder,
            Filters = ConvertConditions(request.Conditions)
        });

        var result = new PagedResult<T>(items, total, request.Page, request.PageSize);
        OnQueried(ctx, result);

        return Ok(ApiResponse<PagedResult<T>>.Ok(result));
    }

    protected virtual void OnQuerying(PageContext<T>) { });
    protected virtual void OnQueried(PageContext<T> ctx, PagedResult<T> result) { }

    // ============================================================
    // 三、新增（基类统一异常处理和结果封装）
    // ============================================================

    [HttpPost("add")]
    public virtual ActionResult<ApiResponse<T>> Add([FromBody] T entity)
    {
        var ctx = CreateSaveContext(entity, OperType.Add);

        // 校验
        var validateResult = ValidateEntity(entity, Config);
        if (!validateResult.Success)
            return BadRequest(ApiResponse<T>.Fail(validateResult.Message));

        OnAdding(ctx);
        if (ctx.Cancel)
            return BadRequest(ApiResponse<T>.Fail(ctx.ErrorMessage ?? "操作已取消"));

        // 插入（EntityService 返回 IOperationResult，基类统一处理）
        var result = EntityService.Insert(entity, ctx.UserId, ctx.UserName);

        if (!result.Success)
            return BadRequest(ApiResponse<T>.Fail(result.Message));

        ctx.Entity = ((IOperationResult<T>)result).Data!;
        OnAdded(ctx);

        return Ok(ApiResponse<T>.Ok(ctx.Entity, "创建成功"));
    }

    protected virtual void OnAdding(SaveContext<T>) { }) { }
    protected virtual void OnAdded(SaveContext<T> ctx) { }

    // ============================================================
    // 四、修改
    // ============================================================

    [HttpPost("update")]
    public virtual ActionResult<ApiResponse<T>> Update([FromBody] T entity)
    {
        var ctx = CreateSaveContext(entity, OperType.Update);

        var validateResult = ValidateEntity(entity, Config);
        if (!validateResult.Success)
            return BadRequest(ApiResponse<T>.Fail(validateResult.Message));

        OnUpdating(ctx);
        if (ctx.Cancel)
            return BadRequest(ApiResponse<T>.Fail(ctx.ErrorMessage ?? "操作已取消"));

        var saveableFields = EntityHelper.GetSaveableFields(Config);
        var result = saveableFields.Length > 0
            ? EntityService.Update(entity, ctx.UserId, ctx.UserName, updateFields: saveableFields)
            : EntityService.Update(entity, ctx.UserId, ctx.UserName);

        if (!result.Success)
            return BadRequest(ApiResponse<T>.Fail(result.Message));

        ctx.Entity = ((IOperationResult<T>)result).Data!;
        OnUpdated(ctx);

        return Ok(ApiResponse<T>.Ok(ctx.Entity, "更新成功"));
    }

    protected virtual void OnUpdating(SaveContext<T> ctx) { }
    protected virtual void OnUpdated(SaveContext<T> ctx) { }

    // ============================================================
    // 五、删除
    // ============================================================

    [HttpPost("delete")]
    public virtual ActionResult<ApiResponse> Delete([FromBody] int[] ids)
    {
        var ctx = CreateSaveContext(default(T)!, OperType.Delete);

        OnDeleting(ctx);
        if (ctx.Cancel)
            return BadRequest(ApiResponse.Fail(ctx.ErrorMessage ?? "操作已取消"));

        var result = EntityService.DeleteBatch(ids, ctx.UserId, ctx.UserName);

        OnDeleted(ctx);

        return result.Success
            ? Ok(ApiResponse.Ok(result.Message))
            : BadRequest(ApiResponse.Fail(result.Message));
    }

    protected virtual void OnDeleting(SaveContext<T> ctx) { }
    protected virtual void OnDeleted(SaveContext<T> ctx) { }

    // ============================================================
    // 六、批量混合操作示例（WorkUnit 多实体事务）
    // ============================================================

    /// <summary>
    /// 示例：同时更新 User + 新建 AuditLog（多实体类型事务）
    /// </summary>
    [HttpPost("batch-update-with-log")]
    public virtual ActionResult<ApiResponse> BatchUpdateWithLog(
        [FromBody] UserUpdateRequest request)
    {
        var userId = User.GetUserId();
        var userName = User.GetUserName();

        // WorkUnit.Execute 返回 IOperationResult（基类统一处理异常和日志）
        var result = WorkUnit.Execute(() =>
        {
            foreach (var id in request.Ids)
            {
                var entity = EntityService.GetById(id);
                if (entity == null) continue;

                // 更新实体（不提交）
                EntityService.Update(entity, userId, userName, saveChanges: false);
            }

            // 可以在此处调用其他 EntityService 进行多实体操作
            // auditService.LogOperation("BatchUpdate", $"更新了 {request.Ids.Count} 条", userId, saveChanges: false);
        });

        return result.Success
            ? Ok(ApiResponse.Ok("批量更新成功"))
            : StatusCode(500, ApiResponse.Fail(result.Message));
    }

    // ============================================================
    // 七、导出 / 导入
    // ============================================================

    [HttpPost("export")]
    public virtual IActionResult Export([FromBody] SearchCondition[]? conditions)
    {
        var items = BuildFilteredList(conditions);
        var bytes = Exporter.Export(items, Config.ConfigName);
        return File(bytes,
            "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
            $"{Config.Title}_{DateTime.Now:yyyyMMdd_HHmmss}.xlsx");
    }

    [HttpPost("import")]
    public virtual ActionResult<ApiResponse<ImportResult>> Import(IFormFile file)
    {
        using var stream = file.OpenReadStream();
        var importItems = Importer.Read<T>(stream, Config.ConfigName);
        var result = new ImportResult { TotalRows = importItems.Count };

        var txResult = WorkUnit.Execute(() =>
        {
            foreach (var item in importItems)
            {
                var existing = FindByCode(item.Entity.Code);
                if (existing != null)
                {
                    item.Entity.Id = existing.Id;
                    EntityService.InsertWithAudit(item.Entity, "system", "导入", saveChanges: false);
                    result.Updated++;
                }
                else
                {
                    EntityService.InsertWithAudit(item.Entity, "system", "导入", saveChanges: false);
                    result.Inserted++;
                }
            }
        });

        if (!txResult.Success)
            return BadRequest(ApiResponse<ImportResult>.Fail(txResult.Message));

        return Ok(ApiResponse<ImportResult>.Ok(result,
            $"导入完成：新增 {result.Inserted} 条，更新 {result.Updated} 条"));
    }

    protected virtual T? FindByCode(string code) => null;

    // ============================================================
    // 八、辅助方法
    // ============================================================

    protected ValidationResult ValidateEntity(T entity, GridConfig config)
    {
        foreach (var col in config.Columns.Where(c => !c.YXK && c.BCFlag))
        {
            var prop = typeof(T).GetProperty(col.FieldName,
                System.Reflection.BindingFlags.IgnoreCase |
                System.Reflection.BindingFlags.Public |
                System.Reflection.BindingFlags.Instance);
            var value = prop?.GetValue(entity);
            if (value == null || (value is string s && string.IsNullOrWhiteSpace(s)))
                return ValidationResult.Fail($"{col.DesName} 不能为空");
        }
        return ValidationResult.Ok();
    }

    protected virtual List<T> BuildFilteredList(SearchCondition[]? conditions)
    {
        // 默认返回全部
        return EntityService.GetList();
    }

    private PageContext<T> CreateContext(SearchCondition[]? conditions) => new()
    {
        Config = Config,
        Conditions = conditions ?? Array.Empty<SearchCondition>(),
        HttpContext = HttpContext
    };

    private SaveContext<T> CreateSaveContext(T entity, OperType operType) => new()
    {
        Config = Config,
        Entity = entity,
        OperType = operType,
        HttpContext = HttpContext
    };

    private List<FilterItem> ConvertConditions(SearchCondition[]? conditions)
    {
        return conditions?.Select(c => new FilterItem
        {
            Field = c.Field,
            Operator = c.Operator,
            Value = c.Value
        }).ToList() ?? new List<FilterItem>();
    }
}
```

## 十一、与参考架构的对应关系

### 11.1 分层对应

| 参考架构 | 本规范实现 | 说明 |
|----------|-----------|------|
| `BaseMainModel<T>` (前端 VM) | `PageBaseController<T>` | 列表+编辑的统一 |
| `BaseEditModel<T>.Insert()` | `EntityService<T>.Insert()` | 返回 IOperationResult |
| `IDbOrm().Insert/Update/Delete` | `IRepository<T>` | 数据访问 |
| `_orm.UseTransaction(db => {...})` | `WorkUnit.Execute(() => {...})` | 多实体混合事务 |
| `LogHelper.Error(ex)` | `IAuditLogger.LogException()` | 审计日志 |
| `ApiOk` / `ApiErr` | `ApiResponse.Ok()` / `.Fail()` | 统一返回格式 |
| `GlobalExceptionMiddleware` | `EntityService` 内 try-catch | 异常兜底 |

### 11.2 关键改进（对比参考架构）

| 方面 | 参考架构 | 本规范 |
|------|----------|--------|
| 异常处理 | 各 Controller 手动 try-catch | 基类统一捕获 + 日志 |
| 事务泛型 | 单实体类型为主 | 任意多实体混合操作 |
| 操作返回 | bool / 直接返回值 | `IOperationResult`（含成功标志+消息+异常） |
| 日志记录 | 手动调用 `LogHelper.Error` | 自动记录在 `IAuditLogger` |
| 审计填充 | 手动设置 CreateBy 等 | 基类自动填充 |

## 十二、总结

### 12.1 设计层次

```
┌─────────────────────────────────────────────────────────────┐
│            单页面 Controller（继承 PageBaseController）        │
│  组合引用: EntityService + WorkUnit + AuditLogger + UserContext│
├─────────────────────────────────────────────────────────────┤
│             基础能力层（本文档定义）                            │
│  EntityService<T> / WorkUnit / IAuditLogger / IUserContext  │
│  ApiResponse / IOperationResult / GridConfigLoader          │
├─────────────────────────────────────────────────────────────┤
│             数据访问层                                        │
│  IRepository<T> / BaseRepository<T> / BaseDbContext         │
└─────────────────────────────────────────────────────────────┘
```

### 12.2 核心理念

1. **基类统一容错**：所有异常在 `EntityService` / `WorkUnit` 基类统一捕获和记录
2. **结果封装明确**：每个操作返回 `IOperationResult`，包含 Success/Message/Exception/Data
3. **事务通用灵活**：`WorkUnit` 不绑定泛型，支持多实体混合操作
4. **审计自动化**：所有写操作自动记录操作人、IP 地址、时间、类型到日志（通过 `RequestContext`）
5. **用户上下文统一**：`IUserContext` 统一获取 IP（X-Real-IP > X-Forwarded-For > RemoteIpAddress）、用户信息
6. **前后端对齐**：`ApiResponse` 统一格式，前端通过 `success` 字段判断结果
