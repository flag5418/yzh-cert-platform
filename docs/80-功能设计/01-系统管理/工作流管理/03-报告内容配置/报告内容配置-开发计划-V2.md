> **日期**：2026-08-16
> **版本**：V2 | **状态**：待审核
> **前置文档**：
> - 数据库设计：`docs/20-架构决策/数据库表设计-V2.md` §3.2 A-12 / 域 D

## 一、设计依据

### 1.1 ISO 标准约束（摘要）

| 约束 | 标准依据 | 设计决策 |
|------|---------|---------|
| 报告必须含审核目标/范围/准则/发现/结论 | ISO 17021-1 §9.4.6 | 通过报告章节列表定义，章节对应标准要求的内容要素 |
| 不同标准/阶段有不同报告模板 | 行业实践 | 模板表关联 standard_code + phase_code |
| 报告章节可配置 | 设计理念 | 章节列表 CRUD + 排序 |
| 配置与执行分离 | 设计理念 | 章节内容生成由工作流承载，配置页只维护章节结构 |

> 完整标准约束详见：`YZH-知识库/03-边界与约束/ISO体系认证NC与报告标准约束-V1.md`

### 1.2 关键设计决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 模板 + 章节两层结构 | 模板定义"报告框架"（如 ISO9001一审报告），章节定义"框架内的各部分"（如审核概况、审核发现、审核结论） |
| 2 | 章节只维护结构（名称+排序+启用） | 章节内容由工作流引擎在审核完成时填充，配置页不操作内容 |
| 3 | 章节可选关联条款 | 报告章节可对应某个 ISO 条款（如"审核发现"对应不符合项相关的条款），但不强制 |
| 4 | section_config JSON 保留但不用 | 模板表的 section_config 列保留，当前章节通过独立的 rpt_report_section 表维护，更灵活 |
| 5 | 工作流配置由引擎回写 | `workflow_config` 列已存在于 rpt_report_section，当前前端不操作 |

## 二、页面布局

### 2.1 整体布局

```
┌──────────────────────────────────────────────────────────────┐
│  报告内容配置                                                │
├──────────┬───────────────────────────────────────────────────┤
│          │  [当前: CB-001 / ISO9001 / 一阶段]                  │
│ 树形     ├───────────────────────────────────────────────────┤
│ 导航     │  ┌─ 报告模板 ─────────────────────────────────┐      │
│          │  │ 模板名称              | 默认 | 操作        │      │
│ 机构     │  │ ISO9001第一阶段审核报告 | 是  | 章节|编辑|删│      │
│ ├─标准   │  │ ISO9001第二阶段审核报告 | 否  | 章节|编辑|删│      │
│ │ ├─阶段 │  └──────────────────────────────────────────┘      │
│ │        │  [新建模板]                                        │
│          │                                                    │
│          │  ┌─ 报告章节 — ISO9001一审 ───────────────────┐      │
│          │  │ 章节名称     | 英文     | 排序 | 启用 | 操作 │      │
│          │  │ 审核概况     | Overview | 1    | 是   | 编辑│      │
│          │  │ 审核范围     | Scope    | 2    | 是   | 编辑│      │
│          │  │ 审核发现     | Findings | 3    | 是   | 编辑│      │
│          │  │ 审核结论     | Conclus. | 4    | 是   | 编辑│      │
│          │  └──────────────────────────────────────────┘      │
│          │  [新建章节]                                        │
└──────────┴───────────────────────────────────────────────────┘
```

**左侧树**：机构 → 标准 → 阶段（三级，懒加载，与 NC 配置页面一致）
**右侧上区**：选中阶段后显示该 org+standard+phase 下的报告模板列表
**右侧下区**：选中模板后显示该模板下的章节列表

### 2.2 两个区域的关系

```
选中阶段节点
  → 右侧上区加载模板列表
    → 选中某模板（点击"章节"按钮）
      → 右侧下区加载该模板的章节列表
```

## 三、模板编辑弹窗

### 3.1 弹窗设计

```
┌─ 新建报告模板 ────────────────────────────────┐
│                                                │
│  模板名称*: [ISO9001第一阶段审核报告         ] │
│                                                │
│  是否默认: [否 ▼]                              │
│  备注:     [                               ]  │
│                                                │
│         [取消]  [保存]                         │
└────────────────────────────────────────────────┘
```

### 3.2 字段对照

| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| templateName | el-input | 是 | 模板名称 |
| isDefault | el-switch | 否 | 是否默认模板 |
| remark | el-input textarea | 否 | 备注 |

### 3.3 隐含自动带入字段

| 字段 | 来源 |
|------|------|
| orgCode | 树形导航选中的机构节点 |
| standardCode | 树形导航选中的标准节点 |
| phaseCode | 树形导航选中的阶段节点 |
| cbCode | 认证机构编码（与 orgCode 同源或从机构信息获取） |
| code | 后端自动生成（UUID） |

### 3.4 表中保留但当前不操作的字段

| 字段 | 原因 |
|------|------|
| templateFilePath | 后期 MinIO 模板文件上传时操作 |
| sectionConfig | 当前通过独立的章节表维护，不操作 JSON |

| 字段 | 原因 |

## 十、与 NC 配置模块的关系

```
                    cert_iso_clause（ISO 条款表）
                    │
                    ├──→ cert_validation_rule.clause_code
                    │    （NC 检查项 — 审核中发现不符合）
                    │
                    └──→ rpt_report_section.clause_code（可选）
                         （报告章节 — 审核完成后组装报告）

两个模块共用：
- 左侧树形导航（机构→标准→阶段）
- ISO 条款表（NC 强制关联，报告章节可选关联）
- 工作流引擎（NC 判定逻辑 / 报告内容生成，后期开发）
```

### 两个模块的对比

| 维度 | NC 检查项配置 | 报告内容配置 |
|------|-------------|-------------|
| 主表 | `cert_validation_rule` | `cert_report_template` + `rpt_report_section` |
| 左侧树 | 机构→标准→阶段（相同） | 机构→标准→阶段（相同） |
| 右侧布局 | 单列表 | 模板列表 + 章节列表（上下两区） |
| 弹窗字段 | 5 字段（名称+英文+条款+启用+备注） | 模板 3 字段 / 章节 5 字段 |
| 条款关联 | **强制**（必选） | 可选（后期扩展） |
| 执行逻辑 | 工作流 DAG（引擎回写 ruleJson） | 工作流 DAG（引擎回写 workflowConfig） |
| 严重度 | 引擎决定 | 不适用 |
