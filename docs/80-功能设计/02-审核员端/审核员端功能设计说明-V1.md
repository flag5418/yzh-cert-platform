# 体系认证审核员端（Auditor）功能设计说明 V1.0（待评审）

> 版本：V1.0（评审稿）
> 定位：基于多轮业务讨论与行业调研（BSI / SGS / Intertek / TÜV / LQMS / Odoo ISO Audit 等基线）整理的功能设计基线，供整体评估后进入页面级细化与开发。

---

## 1. 文档说明

### 1.1 目的
明确审核员端（以下简称"auditor 端"）的核心业务模型、功能模块、模块内核心功能与页面布局建议，作为后续 L2 页面结构、L3 交互设计、L4 技术选型的评审基线。

### 1.2 范围
- 本设计覆盖：审核员端 Web（PC 优先，后续可扩展移动端）。
- 企业用户端（企业登录后交流、传资料）在本文档中仅定义与审核员端的交互边界（账号管理、消息、资料回传），不展开独立设计。
- 后台管理系统（机构侧：标准配置、阶段模板、套餐配置、审核员管理等）不属于本端范围，仅说明配置来源。

### 1.3 技术栈基线（简）
Vue 3 + TypeScript + Naive UI；Vite 端口 9991；axios / pinia / vue-router。与后台管理端（Element Plus）为独立系统。

## 2. 业务模型基线

### 2.1 角色与关系

```
审核员（注册制）──绑定──> 认证机构(CB)
  │                          │
  │               机构决定可选标准集（ISO 9001/14001/45001...）
  │
  ├─ 企业档案（审核员私有，多个；企业代码仅在审核员维度内唯一）
  ├─ 企业用户（审核员为企业创建的登录账号，企业侧与审核员交流/传资料）
  ├─ 当前执行企业（同一时间聚焦一个企业做认证）
  └─ 个人账户（任务次数：免费额度 + 充值额度）

企业 ──绑定──> 标准
  └─ 阶段（多个并存，但同一时间最多一个"进行中"）
       ├─ 阶段资料（资料库，任何阶段均可维护）
       ├─ NC 检查任务（多个，异步队列执行）
       └─ 报告任务（多个，异步队列执行）
```

### 2.2 核心业务规则

| 规则 | 说明 |
|---|---|
| 审核员注册制 | 一个审核员只能注册绑定一个认证机构，机构决定可用标准集 |
| 企业私有 | 同一企业在不同审核员端是两个独立企业记录，企业代码审核员维度内唯一 |
| 单活跃阶段 | 一个企业同一时刻最多一个"进行中"阶段，不能同时进行多个阶段的认证 |
| 阶段多并存 | 阶段记录可多个并存（历史归档 + 当前进行中 + 补建阶段），审核员可随时建立任意阶段用于补录资料 |
| 归档冻结任务 | 阶段归档 = 本阶段体系认证完成，禁止再发起任务；资料仍可查看与补充（资源库属性） |
| 资料库属性 | auditor 端同时是企业的体系认证资源库：资料上传/替换/查看不依赖阶段活跃状态 |
| 异步任务 | NC 检查、文件上传、报告生成均走后台队列，提交即返回任务ID，结果异步到达 |
| 按次计费 | 每次 NC 检查任务计 1 次、每次报告生成计 1 次；免费额度（注册赠 10 次）优先消耗 |
| 结果需人工复核 | 队列自动结果不可直接对外，必须经审核员复核/修订后方可生效 |

### 2.3 阶段状态机

```
待开始 → 进行中 → 已归档
  │         │
  │         └── 可发起 NC检查 / 报告任务
  └── 可补建、可进入进行中（同一时间仅一个进行中）
已归档：任务冻结、资料可查可补、不可回退到进行中
```

### 2.4 任务状态机（异步队列）

```
已提交(排队中) → 执行中 → 成功 → 【待复核】→ 已确认/已签发
                  │
                  └→ 失败 → 失败原因 → 一键重试（不重复扣次）
                              └→ 可转人工排查（人工处理入口）
```

- 提交即返回：点击发起任务只创建任务记录，立即返回任务 ID，不阻塞等待结果
- 成功后的"待复核"是强制环节：自动结果需审核员人工确认/修订后才生效
- 失败可重试；重试免费，防用户损失

### 2.5 计费模型

| 项目 | 规则 |
|---|---|
| 计费单位 | 1 次 NC 检查任务 = 1 次；1 次报告生成 = 1 次 |
| 免费额度 | 注册赠送 10 次（独立计，优先消耗） |
| 充值套餐 | 由机构/平台配置下发（示例：100元=12次、200元=25次），前端不硬编码 |
| 剩余次数 | 免费剩余 + 充值剩余 |
| 扣次时机（建议） | 任务提交时扣减；失败自动退回；重试不重复扣 |
| 拦截 | 剩余次数为 0 时发起任务被拦截并引导充值；≤3 次时弱提醒 |

### 2.6 消息与通知模型

| 通知类型 | 触发点 | 渠道 |
|---|---|---|
| 任务通知 | 队列完成/失败/待复核 | 站内消息（系统通知 Tab）+ 微信推送（未来） |
| 会话消息 | 审核员 ↔ 企业用户交流 | 站内会话 Tab |
| 资料通知 | 企业上传资料待确认 | 站内消息 |
| 账户通知 | 余额不足/充值到账/扣次 | 站内消息 |
| 逾期提醒 | NC 整改逾期、资料未齐 | 站内消息 + 未来微信推送 |

## 4. 核心模块功能设计

### 4.1 登录 / 注册

| 功能 | 说明 |
|---|---|
| 账号密码登录 | 手机号/账号 + 密码 |
| 注册 | 选择认证机构（下拉，机构列表来自平台）→ 填写审核员信息 → 绑定微信（扫码）→ 赠送 10 次任务 |
| 微信绑定 | 登录后个人中心可绑定/解绑；未来微信推送、微信登录 |
| 记住登录 / 找回密码 | 基础能力 |

**页面建议**：居中卡片式登录；注册分两步（Step1 机构与账号信息 → Step2 微信绑定引导，可跳过）。

### 4.2 工作台（首页）

| 功能 | 说明 |
|---|---|
| 当前执行企业卡片 | 企业名、标准、当前阶段、阶段进度（资料齐全度/N C 完成数）、待办数、最近消息 |
| 待办聚合表 | 排队中任务、失败待重试、待复核任务、NC 整改逾期、资料待确认，一键跳转 |
| 企业列表 | 其他企业（可切换当前企业、新建企业、查看归档） |
| 剩余次数提示 | 顶部展示，≤3 弱提醒，=0 拦截并引导充值 |

**页面建议**：

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：Logo | 当前企业名(可切换) | 剩余次数 | 消息铃铛 | 头像 │
├──────────┬───────────────────────────────────────────────────┤
│ 左侧菜单  │ 工作台                                            │
│ ● 工作台  │ ┌─────────────────────────────────────────────┐  │
│   消息中心 │ │ 当前执行企业卡片                              │  │
│   企业管理 │ │ [企业名] [ISO 9001] [阶段: 初次认证·进行中]  │  │
│   资源管理 │ │ 资料 12/15 | NC 2/3 | 报告 0/1 | 待办 3     │  │
│   NC检查   │ └─────────────────────────────────────────────┘  │
│   报告     │ ┌─────────────────────────────────────────────┐  │
│   个人中心 │ │ 待办聚合                                     │  │
│           │ │ [排队中] [失败重试] [待复核] [NC逾期] [资料待确认] │
│           │ └─────────────────────────────────────────────┘  │
│           │ 其他企业列表（切换当前/新建/归档筛选）             │
└──────────┴───────────────────────────────────────────────────┘
```

### 4.3 企业管理

| 功能 | 说明 |
|---|---|
| 企业列表 | 状态筛选（进行中/已归档/全部）、搜索、排序（最近活跃） |
| 新建企业 | 选择机构下适用标准 → 填写企业基础信息（自动生成企业代码）→ 创建首个阶段 |
| 切换当前企业 | 手动设置"当前执行企业"，默认最近活跃 |
| 归档查看 | 已归档企业进入只读详情 |

### 4.4 企业详情（次级左栏导航）

进入企业后页面内出现次级导航：

```
┌──────────┬────────────────────────────────────────────┐
│ 一级菜单  │ 企业详情                                    │
│ ...      │ 次级左栏：                                   │
│          │  ● 阶段列表（进行中置顶）                    │
│          │  ● 企业用户                                  │
│          │  ● 归档记录                                  │
│          │  ───────────────────────────                │
│          │ 内容区：                                     │
│          │  阶段卡片/列表 + 新建阶段 + 基本信息          │
└──────────┴────────────────────────────────────────────┘
```

| 功能 | 说明 |
|---|---|
| 企业基本信息 | 企业名、统一社会信用代码、绑定标准、企业代码、创建时间 |
| 阶段列表 | 进行中阶段置顶高亮；历史阶段时间线；已归档标记；新建阶段按钮 |
| 企业用户管理 | 创建企业用户账号（用户名/初始密码）、重置密码、启用/禁用、登录记录 |
| 归档记录 | 历史阶段只读视图 + 各阶段变更时间线 |

### 4.5 阶段管理（阶段详情）

阶段详情是业务核心承载页，内部四个 Tab：

```
┌──────────────────────────────────────────────────────┐
│ 阶段详情：ISO9001·初次认证 · 进行中                    │
│ [资料库] [NC检查] [报告] [标准目录]                    │
└──────────────────────────────────────────────────────┘
```

#### 4.5.1 资料库（资源管理在阶段内的落地）

| 功能 | 说明 |
|---|---|
| 资料列表 | 按目录/条款分组展示，含版本号、上传人（审核员/企业）、状态（待确认/已归档） |
| 上传/替换 | 上传新文件、替换旧文件（生成新版本，旧版本可回溯） |
| 待确认区 | 企业上传的资料先入待确认，审核员确认后归档 |
| 下载/预览 | 在线预览（PDF/图片/Office）、下载 |
| 关联条款 | 资料可关联到标准条款/检查项 |
| 变更记录 | 每次上传/替换/删除留痕（时间线） |

#### 4.5.2 NC 检查

| 功能 | 说明 |
|---|---|
| NC 任务列表 | 本阶段下 NC 检查任务，含异步状态徽标（排队/执行/成功/失败/待复核） |
| 发起 NC 检查 | 选择检查范围/资料集 → 提交队列（扣 1 次） |
| NC 任务详情 | 见 4.7 |

#### 4.5.3 报告

| 功能 | 说明 |
|---|---|
| 报告任务列表 | 本阶段下报告任务，含异步状态徽标 |
| 发起报告生成 | 提交队列（扣 1 次） |
| 报告编辑 | 见 4.8 |

#### 4.5.4 标准目录

| 功能 | 说明 |
|---|---|
| 目录导出 | 一键导出该标准+该阶段下的资料清单（Excel/PDF/Word），发放给企业填写 |
| 清单勾稽 | 清单项与阶段资料库挂钩：已提交版本、缺项一目了然 |
| 回传关联 | 企业按清单回传的资料自动关联清单项 |

### 4.6 资源管理（独立入口）

| 功能 | 说明 |
|---|---|
| 全局检索 | 任意企业/任意阶段资料，按企业、阶段、文件名、条款、标签搜索 |
| 资料详情 | 版本历史、关联任务/条款、操作日志 |
| 任务内直达 | 从 NC/报告任务详情一键跳转到对应企业资料库，并定位到当前任务引用文件 |
| 批量操作 | 批量下载、批量归档 |

### 4.7 NC 检查（任务详情与复核）

**任务详情页分两个区：**

```
┌──────────────────────────────────────────────────────┐
│ NC任务详情：ISO9001·初次认证·自动检查结果·待复核       │
│ ┌────────────────────────────────────────────────┐  │
│ │ 自动结果区（队列产出，只读）                     │  │
│ │ 检查项1: 条款4.1 符合 ✓（证据: 文件A 第3页）      │  │
│ │ 检查项2: 条款7.5 不符合 ✗ → 建议NC               │  │
│ │ 来源标注：基于文件A/B自动检查，file_hash=...     │  │
│ └────────────────────────────────────────────────┘  │
│ ┌────────────────────────────────────────────────┐  │
│ │ 人工复核区（审核员编辑）                         │  │
│ │ [确认] [修正] [增删NC] [调整严重度] [补充证据]    │  │
│ │ 修订留痕：原值→新值、操作人、时间                │  │
│ └────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

| 功能 | 说明 |
|---|---|
| 自动结果复核 | 逐条确认/修正 AI 判定；修正后保留原始自动结果（可对照） |
| NC 管理 | 分级：严重(Major)/一般(Minor)/观察项/改进机会；条款号、客观证据（图文附件）、状态 |
| 整改闭环 | 开 NC → 企业整改 → 提交证据 → 验证关闭；逾期升级提醒 |
| 修订留痕 | 每次人工修订记录操作人、时间、原值→新值 |
| 一键跳转资源库 | 查看 NC 引用的源文件，可替换资料后重新检查 |

### 4.8 报告（编辑与签发）

| 功能 | 说明 |
|---|---|
| 报告生成 | 提交队列自动生成草稿（扣 1 次） |
| 章节编辑 | 章节级审阅/修改；条款逐条结论编辑；AI 生成内容可覆盖 |
| 数据来源面板 | 每段内容标注数据来源（文件/检查项/NC），可信度展示 |
| 人工复核 | 草稿 → 确认/修订 → 签发；签发后锁定只读 |
| 导出 | PDF/Word 导出；签发版带电子签名（未来） |
| 修订留痕 | 同 NC，记录每次修改 |

### 4.9 消息中心

```
┌──────────────────────────────────────────────────────┐
│ 消息中心                                              │
│ [会话] [系统通知]                                     │
│ 会话：按企业分组的聊天列表 → 聊天窗口                  │
│ 系统通知：任务完成/失败/待复核/资料待确认/余额/逾期    │
└──────────────────────────────────────────────────────┘
```

| 功能 | 说明 |

## 7. 附：行业调研基线（来源摘要）

调研对象：BSI Connect、SGS Audit Performance Manager / iAudit、Intertek iEnable、Intact Platform（TÜV 等底层）、LQMS、Certify Plus、Odoo BB ISO Audit、SHALINK/REYX CAB AuditPro、CNCA 认监委规则。

核心结论：
- 审核员端聚焦"执行与记录"（任务、清单、取证、NC、报告草稿），机构端聚焦"管理与治理"（派组、评审、决定、证书、上报）
- 全生命周期状态机：受理 → 报价 → 合同 → 策划 → 文件评审(Stage1) → 现场审核(Stage2) → 发现 → 报告 → 评审 → 决定 → 发证 → 监督/再认证
- NC 行业标准：Major/Minor/观察项/改进机会四级；CAPA 闭环（纠正 → 根因分析 → 措施计划 → 实施 → 证据 → 验证关闭）；逾期升级
- 报告双轨复核：审核员草稿 → 组长确认 → 技术评审（四眼/六眼）→ 认证决定；末次会议结论需企业确认
- 资料管理：资料清单模板导出（Document Request List / Pre-audit Evidence Collection）、版本控制、证据按条款关联、企业门户自助提交
- 通知多渠道：站内/邮件/短信/微信/App 推送；触发点=新排程、结果提交、报告生成、NC 逾期、证书到期
- 异步形态：移动端离线采集、联网同步；多角色并行录入后台聚合
