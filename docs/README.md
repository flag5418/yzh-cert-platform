### 边界判定

| 疑问 | 规则 |
|------|------|
| 这条内容归框架还是项目？ | 问"**换个项目还成立吗**"——成立归 `10-YZH架构/`，不成立归 `20-体系认证/` |
| 这份是计划还是报告？ | 待实施/进行中 → `50-任务/`；完成报告/测试/验收 → `40-实施/`；被取代 → `90-归档/旧版本/` |
| 这份文档过期了吗？ | 本项目旧版本 → `90-归档/旧版本/`；旧系统知识（长期有效）→ `90-归档/历史项目/` |

## 四、维护约定

1. **新增文档**：先判断归属层，再放入对应目录，并在该层 `README.md` 登记。
2. **文档命名**：强制 `-V1` 后缀（见 [`00-工程体系/文档生命周期管理规范-V1.md`](./00-工程体系/文档生命周期管理规范-V1.md)）。
3. **废弃文档**：**不删除**，移入 `90-归档/` 对应子目录。
4. **状态标记**：`生效` / `编写中` / `设计稿` / `已废弃`。
