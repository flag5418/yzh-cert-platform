## 五、维护约定

1. **新增文档**：先判断归属层，再放入对应目录，并在该层 `README.md` 登记。
2. **文档命名**：强制 `-V1` 后缀（见 [`00-工程体系/文档生命周期管理规范-V1.md`](./00-工程体系/文档生命周期管理规范-V1.md)）。
3. **废弃文档**：**不删除**，移入 `90-归档/` 对应子目录。
4. **状态标记**：`生效` / `编写中` / `设计稿` / `已废弃`。
5. **归档层不参与日常检索**，也不被活跃文档作为权威依据引用。
