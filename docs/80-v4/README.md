## 二、阅读顺序

**只想知道为什么重启** → 读 `01` 的"一页结论"和"四个条款实测"两节。

**要开始干** → 读 `10` 的 §零（五条结论）、§八（9 条缺口）、§九（6 条验收）。
`10` 是"逐章吃透"的第一刀（第 4/5 章），有实测数字、有目标句；`08` 的 §零/§六 与 `09` 的 §三/§七 是它的上游依据。

**要理解为什么这样切** → 读 `08` 的 §零（结论）、§六（四个缺陷的修法），再读 `09` 的 §三（六个连接键）、§七（P0–P3 分期）。
`02` 的 §二（产品形态）、§三（EvidenceItem）、§五（召回）仍是产品形态的权威描述。

**要给专家看** → 只拿 `02` 的 §2.2（一张取证卡长什么样）。
