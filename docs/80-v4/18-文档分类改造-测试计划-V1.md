## 二、快速通道：Admin「试跑」（不落库、不入队，最快看结果）

**入口**：管理员端 `http://127.0.0.1:9990` → 菜单「文档提取规则」(`business/doc-extract-rule`) → 打开 `doc_profile` 提示词 → 页面内「试跑」上传文档。

> 试跑链路与线上同源（同一 `IFileConvertCore` 转换内核；画像按 6 占位符渲染）。

### T1 · 画像指纹输出（正样本）

- **步骤**：选提示词 `doc_profile`，上传 **S1 质量手册**，试跑。
- **预期**：返回 JSON 含
  - `"ClassSource": "fingerprint"`
  - `"Fingerprints": [ ... ]`（至少命中 `manual.clause_mapping` / `manual.policy_objective` 之一）
  - `"DocType": "manual"`、`"ExtractionMode": "manual_chapter"`
  - `Reason` 文本里**回引命中了哪个指纹 Key**
- **判读**：`Fingerprints` 非空 + `Reason` 能对上指纹 Key ⇒ 过。

### T2 · 判不出 ⇒ unclassified（零兜底）

- **步骤**：上传 **S6**（文件名带「程序」但正文是财务制度），试跑 `doc_profile`。
- **预期**：`"DocType": "unclassified"`、`"ExtractionMode": "unclassified"`、`Confidence: 0`；**不得**因为是「程序」就判 `procedure`。
- **判读**：出现 `unclassified` 且没有把文件名当依据 ⇒ 过（§8 第 2 条）。

### T3 · 整链续跑（画像 → 按类型提取）

- **步骤**：上传 **S5 管理评审记录.doc**，选 `doc_profile` 试跑。
- **预期**：返回体含 `ProfileOutput`（画像 JSON）+ 已自动续跑 `doc_extract_audit` 的提取结果；画像 `ExtractionMode="audit_profile"`。
- **判读**：`Note` 写明「画像判定 ExtractionMode=audit_profile，已自动续跑 doc_extract_audit」⇒ 过。

## 四、数据库核对（可选，直接看落库）

```bash
# 4.1 画像带证据（Fingerprints / ClassSource / ExtractionMode）
docker exec -e MYSQL_PWD=CHANGE_ME yzh-mysql mysql -uroot --default-character-set=utf8mb4 -N -B yzh_cert_platform -e "
SELECT FileName,
       JSON_UNQUOTE(JSON_EXTRACT(DocProfileJson,'\$.DocType'))        AS DocType,
       JSON_UNQUOTE(JSON_EXTRACT(DocProfileJson,'\$.ExtractionMode')) AS Mode,
       JSON_UNQUOTE(JSON_EXTRACT(DocProfileJson,'\$.ClassSource'))    AS ClassSource,
       JSON_EXTRACT(DocProfileJson,'\$.Fingerprints')                 AS Fp
FROM cert_enterprise_doc
WHERE IsDeleted=0 AND DocProfileJson IS NOT NULL ORDER BY UpdateTime DESC LIMIT 20;"

# 4.2 提取产物含 Sections
docker exec -e MYSQL_PWD=CHANGE_ME yzh-mysql mysql -uroot --default-character-set=utf8mb4 -N -B yzh_cert_platform -e "
SELECT e.FileName,
       JSON_LENGTH(JSON_EXTRACT(x.ContentJson,'\$.ModeOutput.Sections')) AS SecCount,
       JSON_EXTRACT(x.ContentJson,'\$.ModeOutput.Sections')             AS Sections
FROM cert_document_extraction x
JOIN cert_enterprise_doc e ON e.Code = x.FileCode
WHERE x.IsDeleted=0 ORDER BY x.ExtractedAt DESC LIMIT 10;"
```

**预期**：
- 4.1：`ClassSource` 一律 = `fingerprint`；`Fp` 非空；判不出的样本 `Mode=unclassified`。
- 4.2：样本 `SecCount` ≥1（S5 应为 **2**）。
