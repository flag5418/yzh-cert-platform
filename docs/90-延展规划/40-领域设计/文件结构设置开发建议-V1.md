**理由**：
- 符合 YZH V3.0 架构规范

**实施方案**：
```javascript
// Enterprise.vue - 重构为 YzhCrudTable 模式
<template>
  <YzhCrudTable
    ref="crudTable"
    :schema="schema"
    :options="viewOptions"
    :lifecycles="lifecycles"
    page-key="Enterprise"
    :incremental-update="true"
    :search-mode="'fixed'"
  >
    <template #gridHeader>
      <el-alert
        title="企业管理：维护所有申请认证的企业信息"
        type="info"
        :closable="false"
        show-icon
      />
    </template>
  </YzhCrudTable>
</template>

<script setup lang="ts">
import { ref, markRaw } from 'vue'
import { YzhCrudTable } from '@/yzh/index'
import viewOptions from './options.js'

const crudTable = ref()

const schema = Object.freeze({
  keyField: 'Code',
  keyType: 'string',
  defaultSortField: 'CreateDate',
  defaultSortOrder: 'desc',
  controllerName: 'Enterprise',
  tableName: 'ent_enterprise',
  statusTagColors: { Status: 'enterprise_status' },
})

const lifecycles = markRaw({
  onAddSaveBefore(main: any) {
    if (!main.CreditCode) {
      main.CreditCode = ''  // 可在此添加自动生成逻辑
    }
    return true
  },
})
</script>
```

### 建议 3：实现文件上传 API

**API 设计**：
```
POST   /api/enterprise-file/upload       # 上传文件
GET    /api/enterprise-file/{fileCode}   # 下载文件
DELETE /api/enterprise-file/{fileCode}   # 删除文件
POST   /api/enterprise-file/{fileCode}/version  # 上传新版本

```

**实现要点**：
1. 使用 MinIO 存储文件
2. 计算文件 SHA256 哈希
3. 上传时自动创建版本号
4. 支持断点续传（大文件）

## 四、技术要点

### 4.1 文件夹树查询

使用 MySQL 递归 CTE：
```sql
WITH RECURSIVE folder_tree AS (
    -- 根节点
    SELECT Id, Code, EnterpriseCode, ParentCode, FolderName, 
           1 AS Level, CAST(Code AS CHAR(2000)) AS Path
    FROM ent_enterprise_document
    WHERE ParentCode IS NULL AND EnterpriseCode = @enterpriseCode
    
    UNION ALL
    
    -- 子节点
    SELECT d.Id, d.Code, d.EnterpriseCode, d.ParentCode, d.FolderName,
           ft.Level + 1, CONCAT(ft.Path, '/', d.Code)
    FROM ent_enterprise_document d
    INNER JOIN folder_tree ft ON d.ParentCode = ft.Code
    WHERE d.EnterpriseCode = @enterpriseCode
)
SELECT * FROM folder_tree ORDER BY Path;
```

### 4.2 文件上传流程

```
1. 前端选择文件
   ↓
2. 计算文件 SHA256（前端或使用 spark-md5）
   ↓
3. 检查文件是否已存在（基于哈希去重）
   ↓
4. 上传到 MinIO
   ↓
5. 创建 EnterpriseFile 记录
   ↓
6. 创建 FileVersion 记录
   ↓
7. 返回文件信息
```

### 4.3 文件下载流程

```
1. 验证用户权限
   ↓
2. 从 MinIO 获取文件流
   ↓
3. 返回文件（或重定向到 MinIO 预签名 URL）
```
