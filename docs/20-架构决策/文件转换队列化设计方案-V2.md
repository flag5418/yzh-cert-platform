### 4.1 完整流程

```

                                                │ 1. 激活文件记录            │

                                                              │
              ┌───────────────────────────────────────────────┴───────────────┐

              │  ┌─────────────────────────────────────────────────────────┐  │

              │                                                               │
    ┌─────────┼─────────┬─────────┬─────────┬─────────┐                       │
    │Worker 1 │Worker 2 │Worker 3 │Worker 4 │Worker 5 │                       │
    │LibreOffice│LibreOffice│LibreOffice│LibreOffice│LibreOffice│             │
    └────┬────┘└────┬───┘└────┬───┘└────┬───┘└────┬───┘                       │

```
GET  /api/standard-directory/convert/progress?taskId=xxx
     → 返回批次转换进度

GET  /api/standard-directory/convert/queue-status
     → 返回全局队列状态（管理员用）

POST /api/standard-directory/convert/cancel?taskId=xxx
     → 取消指定批次，强制终止正在处理的任务

POST /api/standard-directory/convert/retry?taskId=xxx
     → 重试失败的转换任务
```

GET  /api/sys-config/list?category=convert_queue

PUT  /api/sys-config/update-batch
     → 批量更新参数（body: [{configKey, configValue}, ...]）

GET  /api/sys-config/value/{configKey}
     → 获取单个参数值

### 6.3 站内消息 API

```
GET  /api/message/list?page=1&pageSize=20&unreadOnly=true
     → 获取消息列表

     → 标记已读

## 九、关键设计决策

### 9.1 为什么不引入 Redis 队列？

| 因素 | 分析 |
|------|------|
| 当前部署 | 单机 Docker，进程内 SemaphoreSlim 足够 |
| 用户规模 | 几十个审核员，5 并发够用 |
| 复杂度 | 不引入新中间件 |
| 迁移路径 | 后续多机部署时可平滑迁移到 Redis Stream |

### 9.2 为什么用 cert_sys_config 而非 appsettings.json？

| 因素 | 分析 |
|------|------|
| 动态调整 | 不重启后端即可修改参数 |
| 管理界面 | 有 UI 页面，运维人员可操作 |
| 审计 | 参数变更可记录修改人/时间 |
| 多实例 | 多机部署时配置统一（后续可加 Redis 缓存） |

### 9.3 强制终止的实现

```csharp
// 取消任务时
public async Task CancelTaskAsync(string taskId)
{
    // 1. 获取该批次正在处理的任务
    var processingJobs = await _db.Set<ConvertJob>()
        .Where(j => j.TaskId == taskId && j.Status == "processing")
        .ToListAsync();
    
    // 2. 取消 CancellationToken（触发 LibreOffice 进程超时）
    foreach (var job in processingJobs)
    {
        if (_runningTokens.TryGetValue(job.Id, out var cts))
        {
            cts.Cancel(); // 触发 Docker 容器内 LibreOffice 进程终止
        }
    }
    
    // 3. 更新待处理任务为 cancelled
    await _db.Set<ConvertJob>()
        .Where(j => j.TaskId == taskId && j.Status == "pending")
        .ExecuteUpdateAsync(s => s.SetProperty(j => j.Status, "cancelled"));
    
    // 4. 推送取消通知
    await _hubContext.Clients
        .Group($"convert_{taskId}")
        .SendAsync("ReceiveHomePageMessage", new { 
            value = "convert_cancelled", 
            taskId 
        });
}
```
