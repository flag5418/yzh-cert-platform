## 二、边界判定

### 2.1 与框架层的边界

| 判定问题 | 归 `10-YZH架构/` | 归本层 |
|----------|------------------|--------|
| 换个项目还成立吗？ | 成立（`Sys_*` / `yzh_*`） | 不成立（`cert_` / `ent_` / `wf_`） |
| 表的定义位置 | 框架初始化 SQL | 项目 SQL |
| 例 | `Sys_User`、`Sys_Role`、`Sys_Menu`、`yzh_queue` | `cert_standard`、`ent_enterprise`、`wf_skill` |

> **模糊时的补充规则**：按**表的定义位置**判归属，两边各加一行指针，避免"都以为对方写了"。

### 2.2 与项目规则层的边界

| | `30-项目规则/` | 本层 |
|---|---|---|
| 性质 | 强制遵守的**规范** | 描述性的**设计** |
| 例 | "命名必须 PascalCase" | "标准目录模块包含哪几张表、几个页面" |
