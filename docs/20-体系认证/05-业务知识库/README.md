## 定位

存放**业务领域知识**——行业标准、认证规则、术语、业务约束。

与 [`30-项目规则/知识库/`](../../30-项目规则/知识库) 的分工：

| | 本层（业务知识） | `30-项目规则/知识库/`（技术知识） |
|---|---|---|
| 内容 | ISO 标准、NC 规则、报告规范、认证流程 | 代码模板、踩坑记录、架构约束 |
| 读者 | 产品、业务、AI 生成业务逻辑时 | 开发者、AI 写代码时 |
| 变化 | 随行业标准与业务规则 | 随技术栈与框架 |

## 使用提示

生成**业务逻辑代码**（如 NC 判定、报告章节生成）前，**必须先读本层**，
避免凭通用知识臆造行业规则。
