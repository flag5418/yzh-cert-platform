## 二、右侧信息是**固定**的（打开就有，不用去点）

只要打开一份标准文档，右侧就是：

1. **文档属性**（自动带出，可改）
   - **分组**（语义分析带出）
   - **文档作用**（语义分析带出）
   - **是否可替换**（仅固定文档：标准自带 / 企业提供）
2. **全局填写规则** —— ⛔ **没有 ai 节点就整块不显示**；有 ai 节点才出现，带「自动分析」按钮，**每段可单独保存**
3. **锚点规则**（另一个 Tab）

---

## 三、类型是**自动判定**的

| 文件 | 判定 | 能不能改 |
|---|---|---|
| 图片 / PDF（anydoc 解析不了） | **固定文档** | ⛔ **锁定，按钮点不动** |
| 其余（doc / docx / xls / xlsx…） | **可编辑文档** | ✅ 可改成固定文档 |

切到固定文档时，锚点和 ai 规则会被清掉（固定文档不生成内容）。

---

## 四、锚点规则：列表 → 点开就是设置页

- 锚点按 **字段 / 表格** 两组
- 点一个锚点 ⇒ 右侧换成它的设置页，**两个明显分区**：
  - **数据区域** —— 数据源（5 类）+ 参数 + 是否关联文档 + AI 提示词
  - **操作区域** —— 操作方式（2 类）+ 落空策略 + 位置（扫描器带出）
- 底部 **保存**（自动保存）
- 顶部两个按钮：**自动填充** / **预览**
  - **自动填充**：一键给字段和表格填入值 ⇒ **可修改、可清空**
  - **预览**：切到「填充后预览」画面

### 数据源 5 类（你给的）

| 数据源 | 要不要参数 | 说明 |
|---|---|---|
| **全局参数** | 选一个字段 | 零 LLM |
| **AI 自动生成** | 可空 | 按本段语义生成 |
| **AI 字段** | 可空 | 按提示词生成字段值 |
| **AI 表格** | 可空 | 生成整张表 |
| **AI 提示词** | — | 纯提示词驱动 |

### 操作 2 类（底层）

**单元格更新**（替换单元格 / 文本 token）｜**表格更新**（按行列填充表格区域）

---

## 五、状态三态（只显示一个徽标，⛔ 不弹提醒、不拦保存）

| 状态 | 判据 |
|---|---|
| **已设置** | 固定文档 ⇒ 信息自动生成，**默认就是已设置**；可编辑文档 ⇒ 锚点全配 **且**（有 ai 节点时）全局填写规则存在 |
| **正在设置** | 信息不全（如：有 ai 节点但没有全局填写规则） |
| **未设置** | 什么都没动 |

> ⛔ **不强求**「必须有全局填写规则才能保存」。

---

## 六、怎么点（4 分钟）

1. 左树点 **`营业执照（扫描件）.pdf`** ⇒ 类型被**锁成固定文档**（按钮点不动），右侧自动跳到「全局规则」
2. 左树点 **`内审计划表.doc`** ⇒ 可编辑；右侧「锚点规则」点 `{{ENT_NAME}}` ⇒ 进设置页看**数据区域 / 操作区域**
3. 点右上 **自动填充** ⇒ 中栏自动切到「填充后预览」，字段和表格都填上了值
4. 点 **全局规则** Tab ⇒ 看分组 / 作用（自动带出、可改）+ 全局填写规则
5. 左树点 **`相关方需求和期望一览表.xls`**（未设置）⇒ 中栏提示「先『上传空白模板』」

## 八、本轮修正：注释收敛（1 条）

> 你的原话：**「没必要导出充斥着注释……可以在一个标签页顶部用一个 `!` 点击来显示帮助信息……
> 应该适当的收敛，毕竟是专业系统，我们需要的简洁，整齐，严谨」**

| # | 改动 | 落在哪 |
|:--:|---|---|
| 1 | **删掉顶部整条说明条** | 页面最上方（原来占 2 段、约 2000 字符） |
| 2 | **帮助收进 Tab 行右侧的圆形「!」** —— 点开是浮层，按当前 Tab 给条目（锚点 5 条 / 全局 2 条）；**再点收起、点浮层外也收起、切 Tab 自动收起** | 右侧 Tab 行最右 |
| 3 | **页面内解释性小字全部收敛**：`class="tip"` 0 处、`class="hint"` 0 处、`※` 0 处 | 全页 |
| 4 | **★ 打开文档默认落「全局规则」Tab**（原为「锚点规则」） | `selectDoc()` / 初始状态 |

**⛔ 保留的是「事实」与「选项语义」，删掉的是「教用户怎么操作」：**

- ✅ 保留：状态徽标、`3 未配`、`共 N 个锚点`、`（扫描器带出）`、数据源卡片下的一句话（5 类怎么区分）、
  未配齐时的**一条**警示条「锚点未配齐 ⇒ 不能自动填充 / 预览」
- ⛔ 删除：「这个锚点的值从哪来」「值怎么落到文档里」「打开文档时自动带出，可修改」这类整句说明

> ★ 顺带修掉一个真 bug：`id="btnUpTpl"` 原来出现 **2 次**（预览头 + 「还没模板」分支），
> 属 id 冲突 ⇒ 现在**只留预览头一个统一入口**，分支里只留一行提示。
>
> ★ 第 4 条的道理（用户口径）：**全局规则**（分组 / 文档作用）由**原始文件**语义分析带出，
> **第一次打开就有**；而**锚点规则**要等**空白模板**上传后才能扫 ⇒ 没有理由先落在锚点 Tab。
