★ V6 本轮改动：全文规则改上下结构

问题：上一版把「素材区（左）」与「提示词编辑区（右）」左右分栏。 第 3 栏总共只有 610px —— 素材区固定 210px 后，编辑区只剩 约 380px， 写提示词的地方反而最窄（提示词是长句，最需要宽度）。

做法：改上下结构 ——

区 内容 高度
上 · 素材区 三行，每组一行：⚓ 锚点 / ▤ 全局参数 / ✎ 填写方法； 每行左侧是组名 + 条数，右侧是 chip 列表（横向滚动） 固定 ~104px
下 · 编辑区 提示词 textarea（flex:1 占满剩余高度）+ 下方「已引用」清单 占满剩余（≥150px）

三个好处： ① 编辑区宽度从 ~380px 提到 610px（一行能写更多字）； ② 素材区高度固定 ⇒ 条目增减不会让编辑区上下跳动； ③ 上下顺序 = 使用顺序（先选素材，再写提示词）。

★ 素材区用「横向滚动」而不是「换行」： 换行会让高度随条目数变化（锚点 5 个 vs 12 个 = 高度差一倍）， 而上下结构里素材区一变高，编辑区就被挤。

事实与操作

这个功能是干嘛的、为什么这么设计、注意事项		 收进「!」浮层（看一次就够，需要时再点开）

上一轮（V4）三处改动

⑤ 菜单九宫格：第 3 栏只有 610px 宽 —— 横向 5 项 = 550px 已经贴边， 再加功能就挤爆；纵向省宽但吃高度，把内容区压小。九宫格（2 列）宽高都省， 且 4~6 项都能一眼看全。常用项永不被遮挡。右上角可切横向 / 纵向对比。

⑥ 类型并入「识别与类型」（第一级菜单）：语义分析任何文档都必须做； 而类型只是点一下卡片，不值得单独占一页。合并后菜单 5 → 4 项： 识别与类型 · 锚点设置 · 全文规则 · 测试验证。 页面内是「先分析 → 再确认类型」的两步引导。

⑦ 全文规则重构 = 素材书签 + 光标插入：即使没有任何 AI 填入项， 它也能阐述「这份文档怎么筛选企业的材料」「哪些单元格怎么写」。 编辑器左侧是三组可点击的书签： ① 锚点（本模板扫出的全部锚点）② 企业参数（全局参数 + 企业字段） ③ 填写方法（日期 / 金额 / 序号等写法约定片段）。 点一下 ⇒ 插入到光标处 ⇒ 拼出一份完整的填写方法。

⚠️ 待你裁决（D8）：插入的是引擎原文 token {{ENT_NAME}}（引擎零改动，推荐）还是可读标记 [ENT_NAME]（更好读，但引擎要加一层解析）。 原型按原文 token 做，并在下方列出「已引用」清单辅助阅读。

① 一级菜单位置修正

上一版把 5 个功能按钮横跨整个页面顶部（压在第 1/2/3 栏之上），错。 现在移进 第 3 栏顶部，它成了「这一栏的菜单」，与第 3 栏的内容是同一层级的关系。 顶行只留「当前文档是谁 + 全局未保存提醒」。

★ 原型里给了两种菜单形态可切换（右上角）： 横向（顶部一排，省纵向空间）／纵向（左侧竖排，更像「菜单」，且状态徽标读起来更顺）。 我倾向纵向——因为它能让「已设置 / 未设置」一眼扫完，横向两行式反而要来回看。**请你定（D6）。**

② 保存 ≠ 完成：文档三态

状态 判据
未设置规则 无 cert_standard_doc_contract 行
正在设置 有契约行，但必需项没全过（保存过 ≠ 完成）
已完成设置 有契约行，且必需项全过

必需项（决定状态）：

  • 通用：① AI 语义分析完成（标签 + 作用）　② 文档类型已确认
  • editable 追加：③ 锚点已扫描且无未配来源
  • fixed 追加：③ 标签非空　④ 作用非空　（⛔ 不要求指纹 —— 否则 PDF 会永远完不成）

建议项（不影响状态，只给黄点提示）：全文规则已挂接、填写规则与说明非空。

③ ★ 状态是「算出来的」，不是「存出来的」

cert_standard_doc_contract.Status 这一列已经存在（默认 draft）， 但我建议不要拿它存完成度。理由：完成度会被别处改掉 —— 删锚点、换空白模板、解绑提示词，都会让文档从「已完成」退回「正在设置」， 而没有任何人负责回退那一列 ⇒ 状态必然漂移，然后「左树筛选」和「实际能不能跑」就对不上了。

✅ 正确做法：完成度实时算。所需原子字段全都有了 （docCategory / analyzeStatus / anchorCount / noSrcCount / fillPromptCode / hasContract）， 后端在 directory-tree 的 Extra 里下发 setupStatus + missingItems， 前端只展示。口径唯一在后端、不落库、永不漂移、零额外查询。

④ 固定底部保存条 + 未保存提醒

  • 第 3 栏底部常驻保存条：左侧「完成度 3/4 · 缺 XX」+ 未保存标记，右侧 [保存]。任何时候都能点。
  • 切换文档或切换功能时若有未保存改动 ⇒ 弹确认（保存并切换 / 丢弃 / 取消），⛔ 不静默丢弃。
  • 左树节点打橙点表示「有未保存改动」；顶行显示「⚠ N 份文档有未保存改动」，点击可跳转。

怎么点

  1. 左树点 陪审人员.doc → 第 3 栏顶部是功能菜单，底部是保存条
  2. 点「语义分析」→ 点「开始分析」→ 在「文档作用」里改几个字然后点空白处（触发失焦）→ 看底部保存条出现「● 未保存」
  3. 此时直接点左树的 风险管理报告.doc → 弹未保存确认
  4. 选「保存并切换」→ 回左树看：该文档变成正在设置（因为锚点还没配），不是「已完成」
  5. 点「锚点设置」→ 模拟上传扫描 → 把唯一的「未配来源」锚点配掉 → 看底部完成度变成 4/4、状态变已完成设置
  6. 切到「测试验证」→ 发布按钮才可点
