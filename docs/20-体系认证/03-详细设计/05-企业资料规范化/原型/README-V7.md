## 二、C1~C6 到底是什么

| # | 条件 | 性质 |
|:--:|---|---|
| **C1** | 可编辑但**没有空白模板**（锚点只能从模板扫出） | 必需项 |
| **C2** | 标「标准自带」但**标准域没有这份文件** | 必需项 |
| **C3** | 标「企业提供」但**没有匹配依据** | 必需项 |
| **C4** | 有 **ai 锚点**但没有**全局填写规则** | 必需项 |
| **C5** | 有锚点**未配数据源** | 必需项 |
| **C6** | `fixed` 却有锚点 | **只是矛盾提示**（⛔ 不影响状态） |

> ★ **性质**：C1~C6 **不是闸门，是状态推导的输入**。
> 程序 ⛔ 不阻止保存任何组合，只如实算「现在是几态」+ 说出矛盾。

**三条设计原则**（49-V4 §一）：判断权归维护人员（P1）｜程序不阻断只如实推导（P2'）｜建议 ≠ 事实，人工确认后才算（P3）。

## 三、怎么点出效果（4 分钟）

1. **C1** —— 点左树 `陪审人员.doc` → 「识别与类型」→ 底部保存条显示 `缺 1 项：C1`
2. **可替换性** —— 点左树 `营业执照（扫描件）.pdf` → 往下拉，第 ③ 块「可替换性」两张卡片
   → 点「标准自带」→ 保存条从 `C3` 变成 `C2`（因为标准域里没这份文件）
3. **★ 一进来就是「已完成」** —— 点左树 `附录三 程序文件清单.docx` → 状态直接是**已完成设置**（标准自带 + 标准域有文件 ⇒ 无缺项）
4. **产物三分支** —— 中栏蓝色那条：`最终产物：企业上传的原件 / 空白模板填完的结果 / 标准域那一份`
5. **回链** —— 点任意字段旁的 **ⓘ** → 看到「配置项 / 落库列 / 后台页面 / 当前值」+「去后台看」
6. **不阻断** —— 随便怎么配、随便保存，⛔ 不会弹「不允许」
