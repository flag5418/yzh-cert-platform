## 分组方式

按**业务模块**分组（而非按角色），理由：同一模块常跨多个角色端，按模块分组可避免重复。

## 阅读提示

- 每份文档**不代表当前实现状态**——实现状态以
  [`10-YZH架构/12-框架能力清单-V1.md`](../../10-YZH架构/12-框架能力清单-V1.md) 与代码为准。
- 文档版本号（`-V2` / `-V3` / `-V4`）表示**文档自身的迭代**，不是模块版本。
- 同名多版本并存时，**取最高版本**；旧版本应移入 `90-归档/旧版本/`。
