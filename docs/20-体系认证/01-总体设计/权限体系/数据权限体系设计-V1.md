## 〇、设计理念

### 0.1 核心原则

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         数据权限设计原则                                │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  1. YZH.Core 不动                       → 框架保持通用性               │
│  2. 项目层扩展                          → 所有业务逻辑在 CertPlatform  │
│  3. 按需加载                            → 查询时才加载特定信息         │
│  4. 链式调用                            → 与 SqlSugar 原生 API 兼容    │
│  5. 角色隔离                            → 不同角色加载不同信息         │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          架构分层                                        │
```

## 一、用户上下文扩展

### 1.1 CertUserContext 设计

**继承关系**：
```
UserContext（YZH.Core）
    └── CertUserContext（CertPlatform.Shared）
```

**设计原则**：
- 不预加载任何业务信息
- 所有业务字段默认为 `null`
- 通过扩展方法按需加载

```csharp
// 文件位置：CertPlatform.Shared/Models/CertUserContext.cs
namespace CertPlatform.Shared.Models
{
    /// <summary>
    /// 认证平台用户上下文（继承 YZH 框架 UserContext）
    /// 不预加载任何业务信息，按需扩展
    /// </summary>
    public class CertUserContext : UserContext
    {
        // ===== 企业用户信息（按需加载）=====
        public string? EnterpriseCode { get; set; }
        public string? EnterpriseName { get; set; }
        
        // ===== 审核员信息（按需加载）=====
        public string? TeamCode { get; set; }
        public string? AuditorCode { get; set; }
        public string? ProfessionalField { get; set; }
        
        // ===== 虚拟机构信息（按需加载）=====
        public string? VirtualOrgCode { get; set; }
        
        // ===== 维护人员信息（按需加载）=====
        public List<string>? MaintainScope { get; set; }
        
        // ===== 机构树信息（按需加载）=====
        public List<string>? OrgCodes { get; set; }
        
        // ===== 判断方法（用于数据权限注入）=====
        
        /// <summary>
        /// 是否为企业用户
        /// </summary>
        public bool IsEnterpriseUser() 
            => RoleIds.Any(r => r == RoleIds.EntAdmin || r == RoleIds.EntUser);
        
        /// <summary>
        /// 是否为审核员
        /// </summary>
        public bool IsAuditor() 
            => RoleIds.Any(r => r == RoleIds.Auditor || r == RoleIds.TeamLead);
        
        /// <summary>
        /// 是否为维护人员
        /// </summary>
        public bool IsMaintainer() 
            => RoleIds.Any(r => r == RoleIds.ConfigMaintainer);
        
        /// <summary>
        /// 是否为机构管理员
        /// </summary>
        public bool IsOrgAdmin() 
            => RoleIds.Contains(RoleIds.OrgAdmin);
    }
}
```

### 1.3 扩展方法实现

```csharp
// 文件位置：CertPlatform.Shared/Services/CertUserContextService.cs
namespace CertPlatform.Shared.Services
 {
    public class CertUserContextService : ICertUserContextLoader
    {
        private readonly SqlSugarClient _db;
        
        public CertUserContextService(SqlSugarClient db)
        {
            _db = db;
        }
        
        /// <summary>
        /// 加载企业用户信息（按需）
        /// </summary>
        public async Task<CertUserContext> LoadEnterpriseInfoAsync(CertUserContext context)
        {
            // 判断是否为企业角色
            if (!context.IsEnterpriseUser())
                return context;
            
            // 查询 attach_ent_admin 表
            var entAdmin = await _db.Queryable<AttachEntAdmin>()
                .Where(a => a.Code == context.Code)
                .FirstAsync();
            
            if (entAdmin != null)
            {
                context.EnterpriseCode = entAdmin.EnterpriseCode;
                context.EnterpriseName = entAdmin.EnterpriseName;
            }
            
            return context;
        }
        
        /// <summary>
        /// 加载审核员信息（按需）
        /// </summary>
        public async Task<CertUserContext> LoadAuditorInfoAsync(CertUserContext context)
        {
            // 判断是否为审核员角色
            if (!context.IsAuditor())
                return context;
            
            // 查询 attach_auditor 表
            var auditor = await _db.Queryable<AttachAuditor>()
                .Where(a => a.Code == context.Code)
                .FirstAsync();
            
            if (auditor != null)
            {
                context.TeamCode = auditor.TeamCode;
                context.AuditorCode = auditor.AuditorCode;
                context.ProfessionalField = auditor.ProfessionalField;
            }
            
            return context;
        }
        
        /// <summary>
        /// 加载维护人员信息（按需）
        /// </summary>
        public async Task<CertUserContext> LoadMaintainerInfoAsync(CertUserContext context)
        {
            // 判断是否为维护角色
            if (!context.IsMaintainer())
                return context;
            
            // 查询 sys_maintainer_scope 表
            var scopes = await _db.Queryable<SysMaintainerScope>()
                .Where(s => s.UserCode == context.Code)
                .Select(s => s.ScopeCode)
                .ToListAsync();
            
            context.MaintainScope = scopes;
            return context;
        }
        
        /// <summary>
        /// 加载机构树信息（按需）
        /// </summary>
        public async Task<CertUserContext> LoadOrgTreeInfoAsync(CertUserContext context)
        {
            // 使用 CTE 递归查询所有子机构
            var childOrgs = await _db.Ado.SqlQuery<string>(@$"
                WITH RECURSIVE org_tree AS (
                    SELECT code FROM sys_organization WHERE code = @OrgCode
                    UNION ALL
                    SELECT o.code FROM sys_organization o
                    INNER JOIN org_tree t ON o.parent_code = t.code
                )
                SELECT code FROM org_tree
            ", new { OrgCode = context.OrgCode });
            
            context.OrgCodes = childOrgs.ToList();
            return context;
        }
        
        /// <summary>
        /// 加载虚拟机构信息（按需）
        /// </summary>
        public async Task<CertUserContext> LoadVirtualOrgInfoAsync(CertUserContext context)
        {
            // 判断是否为虚拟机构角色
            if (!context.RoleIds.Any(r => r == RoleIds.OrgAdmin))
                return context;
            
            // 查询 attach_auditor_org 表
            var auditorOrg = await _db.Queryable<AttachAuditorOrg>()
                .Where(a => a.Code == context.OrgCode)
                .FirstAsync();
            
            if (auditorOrg != null)
            {
                context.VirtualOrgCode = auditorOrg.VirtualOrgCode;
            }
            
            return context;
        }
    }
}
```

## 二、SqlSugar 查询扩展

### 2.1 设计原则

```
┌─────────────────────────────────────────────────────────────────────────┐
│                       SqlSugar 查询扩展设计原则                          │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  1. 静态扩展方法                        → 不修改 SqlSugar 源码          │
│  2. 链式调用                            → 与 SqlSugar 原生 API 兼容     │
│  3. 实体特定                            → 每个实体有独立的扩展方法      │
│  4. 条件注入                            → 根据 CertUserContext 注入条件 │
│  5. 无副作用                            → 不修改原始查询对象            │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2.2 扩展方法实现

```csharp
// 文件位置：CertPlatform.Shared/Extensions/DataScopeExtensions.cs
namespace CertPlatform.Shared.Extensions
 {
    /// <summary>
    /// SqlSugar 数据权限查询扩展（项目层，不修改 YZH.Core）
    /// </summary>
    public static class DataScopeExtensions
    {
        // ==================== AuditTask 数据权限 ====================
        
        /// <summary>
        /// 为 AuditTask 查询注入数据权限条件
        /// </summary>
        public static ISugarQueryable<AuditTask> ForAuditTask(
            this ISugarQueryable<AuditTask> query, 
            CertUserContext user)
        {
            // 审核员：只能看自己被分配的任务
            if (user.IsAuditor())
            {
                return query.Where(t => t.AuditorCode == user.AuditorCode);
            }
            
            // 审核组长：看本组全部任务
            if (user.RoleIds.Contains(RoleIds.TeamLead) && !string.IsNullOrEmpty(user.TeamCode))
            {
                return query.Where(t => t.TeamCode == user.TeamCode);
            }
            
            // 机构管理员：看本机构及子机构全部任务
            if (user.IsOrgAdmin() && user.OrgCodes != null)
            {
                return query.Where(t => user.OrgCodes.Contains(t.OrgCode));
            }
            
            return query;
        }
        
        // ==================== Enterprise 数据权限 ====================
        
        /// <summary>
        /// 为 Enterprise 查询注入数据权限条件
        /// </summary>
        public static ISugarQueryable<Enterprise> ForEnterprise(
            this ISugarQueryable<Enterprise> query, 
            CertUserContext user)
        {
            // 企业用户：只能看本企业数据
            if (user.IsEnterpriseUser() && !string.IsNullOrEmpty(user.EnterpriseCode))
            {
                return query.Where(e => e.Code == user.EnterpriseCode);
            }
            
            // 机构管理员：看本机构及子机构企业
            if (user.IsOrgAdmin() && user.OrgCodes != null)
            {
                return query.Where(e => user.OrgCodes.Contains(e.OrgCode));
            }
            
            return query;
        }
        
        // ==================== ISOStandard 数据权限 ====================
        
        /// <summary>
        /// 为 ISOStandard 查询注入数据权限条件
        /// </summary>
        public static ISugarQueryable<ISOStandard> ForISOStandard(
            this ISugarQueryable<ISOStandard> query, 
            CertUserContext user)
        {
            // 维护人员：只能看自己维护范围内的标准
            if (user.IsMaintainer() && user.MaintainScope != null)
            {
                return query.Where(s => user.MaintainScope.Contains(s.Category));
            }
            
            return query;
        }
        
        // ==================== CertMessage 数据权限 ====================
        
        /// <summary>
        /// 为 CertMessage 查询注入数据权限条件
        /// </summary>
        public static ISugarQueryable<CertMessage> ForCertMessage(
            this ISugarQueryable<CertMessage> query, 
            CertUserContext user)
        {
            // 所有用户只能看自己的消息
            return query.Where(m => m.UserId == user.UserId);
        }
        
        // ==================== 通用扩展（支持泛型）====================
        
        /// <summary>
        /// 通用数据权限注入（通过 [DataScope] 特性驱动）
        /// </summary>
        public static ISugarQueryable<T> WithDataScope<T>(
            this ISugarQueryable<T> query, 
            CertUserContext user) where T : class
        {
            var dataScopeAttr = typeof(T).GetCustomAttributes(typeof(DataScopeAttribute), false)
                .Cast<DataScopeAttribute>()
                .FirstOrDefault();
            
            if (dataScopeAttr == null)
                return query;
            
            return dataScopeAttr.ScopeType switch
            {
                DataScopeType.Self => query.Where($"{dataScopeAttr.FilterField} = @UserCode", 
                    new { UserCode = user.Code }),
                
                DataScopeType.OrgOnly => query.Where($"{dataScopeAttr.FilterField} = @OrgCode", 
                    new { OrgCode = user.OrgCode }),
                
                DataScopeType.OrgChildren => query.Where($"{dataScopeAttr.FilterField} IN (@OrgCodes)", 
                    new { OrgCodes = user.OrgCodes ?? new List<string> { user.OrgCode } }),
                
                DataScopeType.Enterprise => query.Where($"{dataScopeAttr.FilterField} = @EnterpriseCode", 
                    new { EnterpriseCode = user.EnterpriseCode }),
                
                DataScopeType.Custom => ApplyCustomScope<T>(query, user, dataScopeAttr),
                
                _ => query
            };
        }
        
        /// <summary>
        /// 应用自定义范围（查询 sys_data_permission_scope 表）
        /// </summary>
        private static ISugarQueryable<T> ApplyCustomScope<T>(
            ISugarQueryable<T> query, 
            CertUserContext user, 
            DataScopeAttribute attr)
        {
            // 查询该用户的自定义权限范围
            var scopeCodes = user.MaintainScope ?? new List<string>();
            
            if (scopeCodes.Count == 0)
                return query.Where("1=0");  // 无权限，返回空
            
            return query.Where($"{attr.FilterField} IN (@ScopeCodes)", 
                new { ScopeCodes = scopeCodes });
        }
    }
}
```

### 2.3 数据权限特性定义

```csharp
// 文件位置：CertPlatform.Shared/Annotations/DataScopeAttribute.cs
namespace CertPlatform.Shared.Annotations
{
    /// <summary>
    /// 数据权限作用域特性
    /// 标记在实体类上，指定数据过滤规则
    /// </summary>
    [AttributeUsage(AttributeTargets.Class, AllowMultiple = false, Inherited = false)]
    public class DataScopeAttribute : Attribute
    {
        /// <summary>
        /// 数据权限类型
        /// </summary>
        public DataScopeType ScopeType { get; set; }
        
        /// <summary>
        /// 过滤字段名（数据库列名）
        /// 如：org_code、auditor_code、enterprise_code
        /// </summary>
        public string FilterField { get; set; }
        
        /// <summary>
        /// 是否包含子机构数据（仅 OrgScope 类型有效）
        /// </summary>
        public bool IncludeChildren { get; set; } = false;
        
        public DataScopeAttribute(DataScopeType scopeType, string filterField)
        {
            ScopeType = scopeType;
            FilterField = filterField;
        }
    }
    
    /// <summary>
    /// 数据权限类型
    /// </summary>
    public enum DataScopeType
    {
        /// <summary>全局可见（无过滤）</summary>
        All = 0,
        
        /// <summary>仅本人可见</summary>
        Self = 1,
        
        /// <summary>本机构及子机构可见</summary>
        OrgChildren = 2,
        
        /// <summary>本机构可见（不含子机构）</summary>
        OrgOnly = 3,
        
        /// <summary>指定范围可见（通过 sys_data_permission_scope 表配置）</summary>
        Custom = 4,
        
        /// <summary>本企业可见</summary>
        Enterprise = 5
    }
}
```

## 三、使用示例

### 3.1 审核员查询任务

```csharp
// 文件位置：CertPlatform.Admin/Services/AuditTaskService.cs
namespace CertPlatform.Admin.Services
 {
    public class AuditTaskService
    {
        private readonly SqlSugarClient _db;
        private readonly CertUserContext _userContext;
        private readonly ICertUserContextLoader _loader;
        
        public async Task<List<AuditTask>> GetMyTasksAsync()
        {
            // ★ 按需加载审核员信息
            var enrichedUser = await _loader.LoadAuditorInfoAsync(_userContext);
            
            // ★ 链式调用：注入数据权限
            var tasks = await _db.Queryable<AuditTask>()
                .ForAuditTask(enrichedUser)
                .Where(t => t.DeleteTime == null)
                .OrderByDescending(t => t.CreateDate)
                .ToListAsync();
            
            return tasks;
        }
    }
}
```

## 五、数据库表结构

### 5.1 数据权限范围表

```sql
-- 自定义数据权限范围表
CREATE TABLE sys_data_permission_scope (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_code       VARCHAR(36) NOT NULL COMMENT '用户Code',
    scope_type      VARCHAR(20) NOT NULL COMMENT '标准/条款/阶段/企业等',
    scope_code      VARCHAR(50) NOT NULL COMMENT '范围编码',
    create_date     DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE INDEX uk_scope (user_code, scope_type, scope_code)
) COMMENT '自定义数据权限范围表';
```

## 六、与用户权限统一接口的关系

### 6.1 两套机制的分工

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      数据权限 vs 用户权限接口                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  DataScopeExtensions（数据权限体系）                                     │
│  ─────────────────────────────────────────────────────────────          │
│  ▪ 用途：后端查询时过滤数据行                                            │
│  ▪ 场景：业务 Service 查询列表数据                                      │
│  ▪ 方式：SqlSugar 链式调用 `.ForAuditTask(user)`                        │
│  ▪ 示例：审核员查询任务时，自动添加 WHERE auditor_code = 'xxx'          │
│                                                                         │
│  UserPermissionService（用户权限统一接口）                               │
│  ─────────────────────────────────────────────────────────────          │
│  ▪ 用途：前端获取可选数据范围                                            │
│  ▪ 场景：下拉选择框、树形选择器                                         │
│  ▪ 方式：REST API 调用 `/api/UserPermission/accessible-xxx`             │
│  ▪ 示例：维护人员选择标准时，只返回其维护范围内的标准                    │
│                                                                         │
│  ★ 两者互补，不重复                                                    │
│     - 后端查询列表 → 使用 DataScopeExtensions                           │
│     - 前端下拉选择 → 使用 UserPermissionService                         │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 6.2 使用场景对比

| 场景 | 使用机制 | 说明 |
|------|---------|------|
| 审核员查看任务列表 | DataScopeExtensions | 后端查询时自动过滤 |
| 前端选择审核员（下拉框） | UserPermissionService | 返回可选审核员列表 |
| 机构管理员查看企业列表 | DataScopeExtensions | 后端查询时自动过滤 |
| 前端选择企业（下拉框） | UserPermissionService | 返回可选企业列表 |
| 维护人员编辑配置 | DataScopeExtensions | 后端查询时自动过滤 |
| 前端选择标准（下拉框） | UserPermissionService | 返回可选标准列表 |

## 七、设计亮点

| 亮点 | 说明 |
|------|------|
| **YZH 不动** | 框架保持通用，可复用于其他项目 |
| **按需加载** | 查询时才加载特定信息，避免无用查询 |
| **链式调用** | 与 SqlSugar 原生 API 无缝集成 |
| **角色隔离** | 不同角色加载不同信息，互不干扰 |
| **类型安全** | 使用强类型 `CertUserContext`，编译期检查 |
| **易于测试** | 每个扩展方法可独立单元测试 |
