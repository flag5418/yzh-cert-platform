## 一、设计基础

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **对齐 V3.0 企业中心模型** | 企业（Enterprise）是一级核心实体，所有数据围绕企业组织 |
| **配置层与业务层分离** | 管理员维护的模板/规则（配置层）与审核员操作产生的数据（业务层）分属不同数据域 |
| **行业标准术语** | 所有表名、字段名、界面标签使用认证行业标准术语（附录A），不做自创缩写 |
| **证据数据只追加** | 文件/照片/录音等证据每条新版本新建记录，不覆盖旧记录 |
| **过程数据留痕** | NC / 检查项 / 整改等有状态机的数据，每次变更记录变更日志 |
| **提取-校验双链路** | AI 数据提取链路和校验规则链路是系统两条核心数据流，表结构需完整支撑 |
| **一个机构一个机构定制** | Phase 1 按单个认证机构配置，但表结构预留多机构扩展（机构级隔离） |

### 1.2 术语约定

本文档严格使用以下行业标准术语（完整术语表见附录A）：

| 术语 | 英文 | 说明 |
|------|------|------|
| 认证机构 | Certification Body (CB) | 执行认证并颁发证书的组织 |
| 审核员 / 审核组长 | Auditor / Lead Auditor | 执行审核任务的人员 |
| 企业 | Enterprise / Auditee | 受审核方，一级核心实体 |
| 阶段 | Phase | 认证生命周期节点：初审S1 → 初审S2 → 一监 → 二监 → 再认证 |
| 不符合项 | Nonconformity (NC) | 未满足标准要求的审核发现 |
| 条款 | Clause | ISO 标准的层次化要求项 |
| 审核任务 | Audit Task | 一个阶段内的一次审核执行 |
| 整改 | Rectification | 企业针对 NC 的纠正及纠正措施 |

## 二、五大数据域总览

```
域 A：认证体系配置    （管理员维护，认证机构级，极少变动）
域 B：企业档案        （审核员+企业共同维护，企业级）
域 C：审核执行        （审核员操作，任务级）
域 D：报告生成        （报告任务级）
域 E：系统基础        （Vol 框架内置 + 补充）
```

## 三、域 A：认证体系配置（13 张表）

| A-01 | CertificationBody | 认证机构 | 认证机构注册信息 | — |
| A-02 | ISOStandard | ISO 标准 | 机构已分析清楚、能实施的标准 | → A-01 |
| A-03 | ISOClause | 标准条款 | 标准的树形条款结构（如 7.1 → 7.1.1 → 7.1.2） | → A-02 |

| A-12 | ReportTemplate | 报告模板 | 机构×标准×阶段的报告模板文件 | → A-01, A-02, A-04 |

| B-01 | Enterprise | 企业 | 受审核方核心信息 | — |
| B-02 | EnterpriseUser | 企业用户 | 企业方的登录账号 | → B-01 |
| B-03 | EnterprisePhase | 企业阶段 | 企业当前所处的认证阶段 | → B-01, A-04, A-02 |

## 附录A：行业标准术语对照

| 术语 | 英文 | 定义 |
|------|------|------|
| 认证机构 | Certification Body (CB) | 经 CNAS 认可、有权颁发管理体系证书的机构 |
| 审核员 | Auditor | 受认证机构派遣执行审核任务的人员 |
| 审核组长 | Lead Auditor | 管理审核组、审批 NC 和报告的高级审核员 |
| 企业 / 受审核方 | Enterprise / Auditee | 申请认证的组织 |
| 审核任务 | Audit Task | 一个阶段内的一次审核执行 |
| 不符合项 | Nonconformity (NC) | 未满足标准要求的审核发现 |
| 严重不符合 | Major NC | 影响体系有效运行的重大偏离 |
| 轻微不符合 | Minor NC | 个别的、非系统性的偏离 |
| 观察项 | Observation | 尚未构成 NC 但存在潜在风险 |
| 纠正 | Correction | 消除已发现的不符合（治标） |
| 纠正措施 | Corrective Action | 消除不符合的原因，防止再发生（治本） |
| 审核发现 | Audit Finding | 审核过程中记录的观察结果 |
| 审核准则 | Audit Criteria | 审核的依据（标准条款+法规+内部文件） |
| 审核范围 | Audit Scope | 审核覆盖的产品/过程/场所 |
| 认证范围 | Certification Scope | 证书上写的业务范围 |
| 条款 | Clause | ISO 标准的层次化要求项（如 7.1） |
| 审核人天 | Audit Days | 审核所需工作天数 |
| 审核方案 | Audit Programme | 一个认证周期内的审核安排（Phase 2） |
| 证书 | Certificate | 认证机构颁发的正式证明文件（Phase 2） |
| 阶段 | Phase | 认证生命周期节点：初审S1→初审S2→一监→二监→再认证 |
