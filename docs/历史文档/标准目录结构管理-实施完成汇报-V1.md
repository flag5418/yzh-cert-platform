## 数据库表结构

```sql
-- cert_standard_directory_config (标准目录配置表)
Id, Code, DirectoryCode, StandardCode, PhaseCode, RootFolderName, Status, ...

-- cert_standard_directory_folder (标准目录文件夹表)
Id, Code, FolderCode, DirectoryCode, ParentCode, FolderName, Depth, SortOrder, ...

Id, Code, FileCode, FolderCode, DirectoryCode, FileName, FileType, IsRequired, ...
```

## 编码规则

| 类型 | 格式 | 示例 |
|------|------|------|
| 目录编码 | `SDC-{StandardCode}\|{PhaseCode}` | `SDC-ISO9001\|PH01` |
| 文件夹编码 | `FD-{DirectoryCode}\|L{Level}\|S{Seq}` | `FD-SDC-ISO9001\|PH01\|L01\|S001` |
| 文件编码 | `FL-{FolderCode}\|{FileNameHash}\|v{Version}` | `FL-FD-SDC-ISO9001\|PH01\|L01\|S001\|B7A3F2\|v1` |

---

## MinIO 存储路径

```
/{StandardCode}/{PhaseCode}/{CbCode}/{FolderCode}/{FileName}-{Hash}-{Version}/{FileName}

示例：
/ISO9001/PH01/CB001/FD-SDC-ISO9001|PH01|L01|S001/营业执照正本-B7A3F2-v1/营业执照正本.pdf
```

## API 端点

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/standard-directory/configs` | 获取配置列表 |
| POST | `/api/standard-directory/configs` | 创建配置 |
| PUT | `/api/standard-directory/configs/{code}` | 更新配置 |
| DELETE | `/api/standard-directory/configs/{code}` | 删除配置 |
| GET | `/api/standard-directory/configs/{code}/folders` | 获取文件夹树 |
| POST | `/api/standard-directory/configs/{code}/folders` | 创建文件夹 |
| GET | `/api/standard-directory/folders/{code}/files` | 获取文件列表 |
| POST | `/api/standard-directory/folders/{code}/upload` | 上传文件 |
