## 一、开发前检查清单

### 1.1 确认页面类型

| 类型 | 组件 | 适用场景 |

| A: 单表 CRUD | `YzhCrudTable` | 无关联的独立表（如认证阶段定义） |

## 二、后端开发步骤

### Step 1: 创建 C# 实体

**文件位置**: `VOL.Entity/CertPlatform/{模块}/Xxx.cs`

```csharp
using System.ComponentModel.DataAnnotations;
using System.ComponentModel.DataAnnotations.Schema;
using VOL.Entity.CertPlatform;  // YZHBaseEntity 所在命名空间

namespace VOL.Entity.CertPlatform.{模块}
{
    [Entity(TableCnName = "中文名", TableName = "数据库表名", DBServer = "VOLContext")]
    [Table("数据库表名")]
    public class Xxx : YZHBaseEntity  // ⚠️ 必须继承 YZHBaseEntity
    {
        // ===== 主键 =====
        // YZHBaseEntity 已有 Id (long, 自增) 和 Code (string, GUID)
        
        // ===== 业务字段 =====
        [Required]
        [StringLength(200)]
        [Editable(true)]  // Vol 要求：标记为可编辑列
        public string Name { get; set; }
        
        // ===== 排序字段（如果需要） =====
        [Editable(true)]
        public int Sort { get; set; } = 0;
        
        // ===== 注意：不要在基类添加 Sort 属性！ =====
        // YZHBaseEntity 已移除 Sort，各子类按需添加
    }
}
```

**⚠️ 踩坑记录**：
- YZHBaseEntity 的 `Sort` 属性已移除 `[NotMapped]`，如果表有 `sort` 列，子类需自己声明
- 所有 `string` 字段默认非空，不需要额外 `[Required]`
- `[Editable(true)]` 必须，否则保存时报"没有配置好 Model 为编辑列"

**文件位置**: `VOL.Builder/Services/CertPlatform/XxxService.cs`

```csharp
// 如果只是标准 CRUD，无需创建 Service
// Vol 的 ServiceBase<TEntity, TRepository> 已提供 GetPageData/Add/Update/Del/Export
```

### Step 3: 创建 Controller

**主类文件**: `VOL.WebApi/Controllers/CertPlatform/XxxController.cs`
**Partial 类**: `VOL.WebApi/Controllers/CertPlatform/Partial/XxxController.cs`

```csharp
// 主类（代码生成器生成，不要手动修改）
[Route("api/Xxx")]  // ⚠️ 路由名必须与前端 schema.controllerName 一致
[PermissionTable(Name = "Xxx")]
public partial class XxxController : ApiBaseController<IXxxService>
{
    public XxxController(IXxxService service) : base(service) { }
}

// Partial 类（自定义方法写在这里）
namespace VOL.WebApi.Controllers.CertPlatform
{
    public partial class XxxController
    {
        // 自定义接口写在这里...
    }
}
```

**⚠️ 关键点**:
- `[Route("api/Xxx")]` — 前端调用 `/api/Xxx/GetPageData`
- 继承 `ApiBaseController<IXxxService>` — 获得 Vol 的基础能力
- Partial 类用于扩展，不修改主类

## 三、前端开发步骤

### Step 4: 创建 options.js

**文件位置**: `src/views/cert/{模块}/Xxx/options.js`

```javascript
export default function () {
  const table = {
    name: "Xxx",                    // 实体名（与后端一致）
    cnName: "中文名",                // 页面标题
    url: "/Xxx/",                   // API 前缀（注意末尾 /）
    sortName: "CreateDate",          // 默认排序字段
    key: "Id",                      // 主键字段
    footer: "Foots",
    pagination: { pageSize: 20, pageSizes: [10, 20, 50, 100] },
  };

  // 编辑表单默认值
  const editFormFields = {
    Name: "",
    Status: "active",
    // ...
  };

  // 搜索条件默认值
  const searchFormFields = {
    keyword: "",
    Status: "",
  };

  return {
    table,
    key: table.key,
    tableName: table.name,
    tableCNName: table.cnName,
    newTabEdit: false,
    editFormFields,
    searchFormFields,

    // ===== 列定义 =====
    columns: [
      { field: 'Id', title: 'ID', width: 70, hidden: true },           // hidden=true 不显示
      { field: 'Name', title: '名称', width: 200, sortable: true },
      { field: 'Status', title: '状态', width: 100, 
        dataKey: 'org_status' },                                  // dataKey=字典编号
    ],

    // ===== 编辑表单 =====
    editFormOptions: [
      [
        { field: 'Name', title: '名称', type: 'input', required: true },
        { field: 'Status', title: '状态', type: 'select', dataKey: 'org_status' },
      ],
    ],

    // ===== 搜索表单 =====
    searchFormOptions: [
      [
        { field: 'keyword', title: '关键词', type: 'input' },
        { field: 'Status', title: '状态', type: 'select', dataKey: 'org_status' },
      ],
    ],
  };
}
```

**⚠️ 字典使用规范**:
- `dataKey`: 对应 `Sys_DictionaryList.Dic_No` 的值
- 前端会自动调用 `/api/Sys_Dictionary/GetVueDictionary` 加载字典
- 表格列和编辑表单都会自动翻译显示

### Step 5: 创建 Vue 页面

```vue
    // 新增前的自定义逻辑...
```

### 4.2 前端测试

- [ ] 页面能打开，无控制台错误
- [ ] 表格数据显示正确
- [ ] 分页功能正常
- [ ] 新增弹窗打开正常
- [ ] 编辑功能正常

- [ ] 字典值显示中文（不是原始值）
- [ ] 搜索功能正常

### 4.3 常见问题排查

| 问题现象 | 可能原因 | 解决方案 |
|----------|----------|----------|
| `/api/undefined/GetPageData` | schema 缺少 controllerName | 添加 `controllerName: 'Xxx'` |
| `Unknown column 'c.Sort'` | YZHBaseEntity.Sort 冲突 | 子类自己声明 Sort 或移除基类 Sort |
| 字典显示原始值 | dataKey 未配置或字典不存在 | 检查 Sys_DictionaryList 是否有对应数据 |
| 404 "未找到请求地址" | yzh-page-config 无配置 | 插入配置记录或修改 http.js |
| 删除无反应 | 接口路径错误（Remove vs Del） | 改用 `/api/Xxx/Del` |

## 五、文件组织规范

### 5.1 后端文件结构

```
VOL.Entity/CertPlatform/
├── Cert/                 # 认证相关实体
│   ├── CertificationBody.cs
│   └── ISOStandard.cs
├── Audit/                # 审核相关实体

└── YZHBaseEntity.cs     # 基类（不要随意修改！）

VOL.Builder/Services/CertPlatform/
├── Partial/              # Service 扩展（业务代码写这里）
└── ...

VOL.WebApi/Controllers/CertPlatform/
├── XxxController.cs            # 主类（路由+构造函数）
└── Partial/
    └── XxxController.cs       # 扩展（自定义接口）
```


## 六、决策参考

当遇到以下情况时，请参考本文档或讨论：

1. **新建页面时** → 按 Section 二的步骤执行
2. **选择组件模式时** → 参考 Section 5.2 的选择指南
3. **删除功能报错时** → 确认用的是 Del 不是 Remove
4. **字典不翻译时** → 检查 dataKey 和 Sys_DictionaryList 数据
5. **想了解 Vol 内部机制时** → 参考《YZH 与 Vol 边界定义》文档
