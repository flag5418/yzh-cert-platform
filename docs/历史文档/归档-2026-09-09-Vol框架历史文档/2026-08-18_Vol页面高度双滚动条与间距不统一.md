# Vol 页面高度双滚动条与间距不统一

> 日期：2026-08-18
> 严重度：★★★（影响所有页面）
> 状态：已修复

## 现象

1. 打开任意页面（如 ISOClause、NCConfig、SysConfig 等），需要滚动才能查看完整内容
2. 各页面 padding 不统一：有 `20px`、`16px 24px`、`8px` 等多种
3. 页面高度计算依赖硬编码 `calc(100vh - 140px)` 或 `calc(100vh - 96px)`

## 根因分析

### Vol 布局链路

```
#vol-container (flex, height:100%)
  └── .vol-content (flex:1, height:0)
       └── .vol-container (flex:1, flex-direction:column, height:100%)
            ├── .vol-header (61px 固定)
            ├── .vol-path (34px tabs)
            └── .vol-main (flex:1, height:0, overflow:auto)  ← 第1层滚动条
                 └── el-scrollbar (height:100%)
                      └── .el-scrollbar__wrap (height:100%, overflow:auto)  ← 第2层滚动条
                           └── .el-scrollbar__view  ← ❌ 无 height:100%
                                └── 页面组件根元素
```

### 三个核心问题

| # | 问题 | 根因 |
|---|------|------|
| 1 | **双滚动条** | `.vol-main` 有 `overflow:auto`，`el-scrollbar__wrap` 也有 `overflow:auto`，两层都滚动 |
| 2 | **页面无法用 height:100% 撑满** | `.el-scrollbar__view` 默认无 `height:100%`，页面组件无法用 `height:100%` 填满视口 |
| 3 | **间距不统一** | 各页面各自设置 padding（20px / 16px 24px / 8px），没有统一规范 |

### Vol 原生页面的 workaround

- `Sys_Menu`：用 `position:absolute; width:100%; height:100%` 绕过 scrollbar
- `ViewGrid`：用 `height: calc(100vh - 96px); padding: 8px` 硬编码
- 自定义页面：用 `height: calc(100vh - 140px)` 硬编码（多算了 44px 给 CertPageHeader）

## 修复方案

### 1. 底层修正（`index.less`）

```less
.vol-main {
  overflow: hidden; /* 改为 hidden，由 el-scrollbar 统一处理滚动 */
  flex: 1;
  height: 0;

  .el-scrollbar__view {
    height: 100%;           /* 关键：让页面组件可以用 height:100% 撑满 */
    min-height: auto !important;
  }
}
```

### 2. ViewGrid 修正（`ViewGrid.less`）

```less
.layout-container-padding {
  height: 100%;  /* 原来是 calc(100vh - 96px)，改为 100% */
  padding: 8px;
}
```

### 3. 页面统一规范

所有体系认证页面根容器遵循：
```css
.xxx-page {
  height: 100%;           /* 撑满视口（依赖 .el-scrollbar__view 的 height:100%） */
  padding: 16px;          /* 上下左右统一 16px */
  box-sizing: border-box;
  overflow: auto;         /* 简单页面：自身处理滚动 */
  /* 或：display:flex; flex-direction:column; overflow:hidden;（需要内部 flex 分区时） */
}
```

有 `CertPageHeader` + 内容区的页面：
```css
.xxx-page {
  height: 100%;
  display: flex;
  flex-direction: column;
  overflow: hidden;
  box-sizing: border-box;
}
.xxx-page .page-body {
  flex: 1;
  min-height: 0;          /* flex 子元素必须 min-height:0 才能 shrink */
  padding: 16px;
  box-sizing: border-box;
}
```

## 教训

1. **不要在业务页面用 `calc(100vh - Npx)` 硬编码高度** —— 顶部导航高度会变化（不同主题 tabs 高度不同），硬编码迟早出问题
2. **检查 flex 链路中的 height 约束** —— flex 布局中每个层级都需要明确高度约束，缺少一层就会导致子元素高度为 0 或溢出
3. **避免双滚动条** —— `.vol-main` 的 `overflow:auto` + `el-scrollbar` 的 `overflow:auto` 会导致双滚动条，应统一由一层处理
4. **间距从底层统一** —— 不要在业务页面各自设置 padding，应在布局层或通过 CSS 变量统一

## 后续规范

新建页面时，根容器必须遵循以下模板：

```vue
<template>
  <div class="xxx-page">
    <CertPageHeader title="页面标题" :icon="IconXxx" />
    <div class="page-body">
      <!-- 内容 -->
    </div>
  </div>
</template>

<style scoped>
.xxx-page {
  height: 100%;
  display: flex;
  flex-direction: column;
  overflow: hidden;
  box-sizing: border-box;
}
.page-body {
  flex: 1;
  min-height: 0;
  padding: 16px;
  box-sizing: border-box;
}
</style>
```
