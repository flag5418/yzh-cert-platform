# 标准目录结构管理 - 详细设计文档

**版本**：V3.0 | **日期**：2026-08-08 | **状态**：最终稿

---

## 一、核心目标

建立标准目录结构管理体系，支持：
1. 管理员定义标准目录模板（机构无关）
2. 审核员选择机构+标准+阶段后自动实例化目录
3. 文件上传/拖拽上传按规则编码存储

## 二、编码规则

### 2.1 编码格式定义

```
┌─────────────────────────────────────────────────────────────────────┐
│  标准目录编码 (DirectoryCode)                                         │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 格式：SDC-{StandardCode}|{PhaseCode}                         │   │
│  │ 示例：SDC-ISO9001|PH01, SDC-ISO13485|PH02                    │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  文件夹编码 (FolderCode)                                             │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 格式：FD-{DirectoryCode}|L{Level}|S{Sequence}                │   │
│  │ 示例：FD-SDC-ISO9001|PH01|L01|S001                           │   │
│  │       FD-SDC-ISO9001|PH01|L01|S002                           │   │
│  │       FD-SDC-ISO9001|PH01|L02|S001                           │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  文件编码 (FileCode)                                                 │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 格式：FL-{FolderCode}|{FileNameHash}|v{Version}              │   │
│  │ 示例：FL-FD-SDC-ISO9001|PH01|L01|S001|B7A3F2|v1              │   │
│  │       FL-FD-SDC-ISO9001|PH01|L01|S001|B7A3F2|v2              │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  版本编码 (VersionCode)                                              │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │ 格式：VR-{FileCode}|{VersionNumber}                          │   │
│  │ 示例：VR-FL-FD-SDC-ISO9001|PH01|L01|S001|B7A3F2|v1|001       │   │
│  │       VR-FL-FD-SDC-ISO9001|PH01|L01|S001|B7A3F2|v1|002       │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.2 编码优势

| 特点 | 说明 |
|------|------|
| **唯一性** | 每段编码全球唯一，无冲突 |
| **可读性** | 使用 `|` 分割，一眼看清结构 |
| **可追溯** | 从编码可直接追溯所属标准、阶段、层级 |
| **稳定性** | 名称、顺序可调整，编码不变 |
| **易解析** | 代码中直接 `Split('|')` 即可解析 |

## 三、数据库设计

### 3.1 标准目录配置表

```sql
-- ============================================================
-- 标准目录配置表 (cert_standard_directory_config)
-- 作用：定义标准目录结构（机构无关）
-- ============================================================

CREATE TABLE cert_standard_directory_config (
    Id bigint NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    
    -- 编码字段
    Code varchar(36) NOT NULL COMMENT '全局唯一编码（GUID）',
    DirectoryCode varchar(100) NOT NULL COMMENT '目录编码（SDC-{标准}|{阶段}）',
    
    -- 关联字段
    StandardCode varchar(50) NOT NULL COMMENT '标准编码',
    PhaseCode varchar(50) NOT NULL COMMENT '阶段编码',
    
    -- 目录配置
    RootFolderName varchar(200) DEFAULT NULL COMMENT '根文件夹名称',
    
    -- 状态
    Status enum('draft','active','archived') DEFAULT 'draft',
    Enable tinyint(1) DEFAULT 1,
    
    -- 审计字段
    CreateID int DEFAULT NULL,
    Creator varchar(50) DEFAULT NULL,
    CreateDate datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
    ModifyID int DEFAULT NULL,
    Modifier varchar(50) DEFAULT NULL,
    ModifyDate datetime DEFAULT NULL,
    DeleteID int DEFAULT NULL,
    Deleter varchar(50) DEFAULT NULL,
    DeleteTime datetime DEFAULT NULL,
    Status_field varchar(50) DEFAULT 'active',
    Enable_field tinyint DEFAULT 1,
    Sort int DEFAULT 0,
    Remark text COMMENT '备注',
    
    PRIMARY KEY (Id),
    UNIQUE KEY uk_code (Code),
    UNIQUE KEY uk_directory_code (DirectoryCode),
    UNIQUE KEY uk_standard_phase (StandardCode, PhaseCode),
    KEY idx_standard_code (StandardCode),
    KEY idx_phase_code (PhaseCode),
    KEY idx_status (Status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='标准目录配置表';
```

## 五、编码生成服务

```csharp
public class CodeGeneratorService : ICodeGeneratorService
{
    // 标准目录编码：SDC-{StandardCode}|{PhaseCode}
    public string GenerateDirectoryCode(string standardCode, string phaseCode)
    {
        var cleanStandard = standardCode.Replace(":", "").Replace("-", "");
        var cleanPhase = phaseCode.Replace(":", "").Replace("-", "");
        return $"SDC-{cleanStandard}|{cleanPhase}";
    }

    // 文件夹编码：FD-{DirectoryCode}|L{Level}|S{Sequence}
    public string GenerateFolderCode(string directoryCode, int level, int sequence)
    {
        return $"FD-{directoryCode}|L{level:D2}|S{sequence:D3}";
    }

    // 文件编码：FL-{FolderCode}|{FileNameHash}|v{Version}
    public string GenerateFileCode(string folderCode, string fileName, int version)
    {
        var hash = ComputeFileNameHash(fileName);
        return $"FL-{folderCode}|{hash}|v{version}";
    }

    // 版本编码：VR-{FileCode}|{VersionNumber}
    public string GenerateVersionCode(string fileCode, int versionNumber)
    {
        return $"VR-{fileCode}|{versionNumber:D3}";
    }

    // MinIO 存储路径：/{StandardCode}/{PhaseCode}/{CbCode}/{FolderCode}/{FileName}-{Hash}-{Version}/{FileName}
    public string GenerateStoragePath(string standardCode, string phaseCode, 
                                       string cbCode, string folderCode, 
                                       string fileName, string fileHash, int version)
    {
        var cleanStandard = standardCode.Replace(":", "").Replace("-", "");
        var cleanPhase = phaseCode.Replace(":", "").Replace("-", "");
        var cleanCb = cbCode.Replace(":", "").Replace("-", "");
        var cleanFolder = folderCode.Replace("|", "-");
        var versionDir = $"{fileName}-{fileHash}-v{version}";
        
        return $"/{cleanStandard}/{cleanPhase}/{cleanCb}/{cleanFolder}/{versionDir}/{fileName}";
    }

    private string ComputeFileNameHash(string fileName)
    {
        var bytes = Encoding.UTF8.GetBytes(fileName);
        var hash = MD5.HashData(bytes);
        return Convert.ToBase64String(hash).Substring(0, 6).Replace('/', 'X');
    }
}
```

## 六、文件上传流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                     文件上传流程                                      │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. 前端选择文件或拖拽文件夹                                          │
│     └─ 获取：文件流、文件名、所在文件夹编码                            │
│                                                                     │
│  2. 后端计算文件哈希                                                  │
│     └─ Hash = MD5(文件流)                                            │
│                                                                     │
│  3. 后端生成存储路径和文件编码                                         │
│     ├─ 查询文件夹信息：StandardCode, PhaseCode, CbCode               │
│     ├─ 生成路径：/ISO9001/PH01/CB001/FD-...|L01|S001/               │
│     │                         营业执照正本-B7A3F2-v1/营业执照正本.pdf │
│     └─ 生成 FileCode：FL-FD-SDC-ISO9001|PH01|L01|S001|B7A3F2|v1     │
│                                                                     │
│  4. 上传到 MinIO                                                     │
│     └─ PutObject(bucket, path, stream)                               │
│                                                                     │
│  5. 保存文件记录到数据库                                              │
│     ├─ FileCode = FL-FD-SDC-ISO9001|PH01|L01|S001|B7A3F2|v1        │
│     ├─ StoragePath = /ISO9001/PH01/CB001/FD-.../.../营业执照正本.pdf│
│     └─ FileHash = B7A3F2                                            │
│                                                                     │
│  6. 返回文件信息给前端                                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 十、关键决策记录

| 决策点 | 方案 | 理由 |
|--------|------|------|
| 标准目录配置是否关联机构 | 否 | 标准目录是通用模板，机构无关 |
| 编码分隔符 | `\|` | 可读性强，易解析，不易与文件名冲突 |
| 文件夹编码层级表达 | `L01\|S001` | 清晰表达层级和序号 |
| MinIO 路径结构 | 标准/阶段/机构/文件夹/文件 | 便于按目录快速定位文件 |
| 文件名处理 | 哈希+版本目录 | 防止重名，便于版本管理 |
