# 体系认证平台 - 前端架构重设计 V1

> **版本**：V1.0 | **日期**：2026-09-04 | **状态**：待评审 | **作者**：AI 编码助手
>
> **目标**：彻底废弃 vol.web 框架（view-grid、VolProvider、ViewGrid 等），按"自研 Yzh 组件 + Element Plus"的新架构全面重写。
>
> **背景**：经过大半年的演进，vol 框架的历史包袱（命名空间冲突、props 黑盒、类型推断缺失、样式难以深度控制、与业务耦合严重）已成为业务增长的阻力。本方案定义"彻底重写 + 试点验证 + 渐进迁移"的三阶段实施路径。

---

## 一、目标与原则

### 1.1 目标
1. **彻底脱离 vol 框架**：不再依赖 view-grid、VolProvider、OrderByExpression 等任何 vol 特有概念
2. **自研 YzhTable/YzhForm**：基于 Element Plus 自研表/单组件，业务开发者只通过 Schema/Props 描述业务，不接触底层
3. **统一前后端协议**：RESTful + 统一响应包装 + OpenAPI 生成 TS 类型
4. **可跨项目复用**：yzh 组件库可在后台管理端、审核员端、企业端共用

### 1.2 设计原则
| 原则 | 含义 |
|---|---|
| **Schema 驱动** | 页面 = 数据 + 行为 + 样式配置，不写模板逻辑 |
| **类型先行** | 全部使用 TS + 泛型，IDE 自动补全 |
| **单一职责** | YzhTable 只管表格，YzhForm 只管表单，业务侧通过插槽扩展 |
| **零隐式行为** | 不做"魔法"——所有行为必须可观察、可覆盖、可测试 |
| **对齐 Element Plus 主题** | 视觉规范基于 Element Plus 设计令牌（深色/浅色/紧凑三套） |

## 四、核心组件设计

### 4.1 YzhTable（替代 view-grid）

**核心理念**：业务侧只描述"显示什么字段、字段如何格式化"，不关心"分页/排序/选择/筛选"等通用能力。

```ts
// 1. 定义列
const columns: YzhTableColumn[] = [
  { prop: 'userName', label: '用户名', width: 120, sortable: true },
  { prop: 'userTrueName', label: '真实姓名', width: 120 },
  { prop: 'enable', label: '状态', width: 80, formatter: (v) => v === 1 ? '启用' : '禁用' },
  { prop: 'createDate', label: '创建时间', width: 180, formatter: (v) => dayjs(v).format('YYYY-MM-DD HH:mm') },
  { prop: 'actions', label: '操作', width: 180, slot: 'actions' }
]

// 2. 数据源（必须返回标准 Page）
const dataLoader: YzhTableDataLoader<SysUser> = async (params) => {
  const res = await getUserPage(params)
  return { rows: res.data.rows, total: res.data.total }
}

// 3. 使用
<YzhTable
  :columns="columns"
  :data-loader="dataLoader"
  :search-fields="searchFields"
  selectable
  @selection-change="onSelection"
>
  <template #actions="{ row }">
    <el-button text type="primary" @click="onEdit(row)">编辑</el-button>
    <el-button text type="danger" @click="onDelete(row)">删除</el-button>
  </template>
</YzhTable>
```

**核心 Props**：
- `columns: YzhTableColumn[]` 列定义
- `dataLoader: (params) => Promise<Page<T>>` 数据加载器
- `searchFields?: SearchField[]` 搜索栏字段（与 YzhSearchBar 联动）
- `selectable?: boolean` 多选
- `defaultSort?: { prop, order }` 默认排序
- `pageSize?: number` 默认 20
- `stripe / border / height` Element Plus 表格原生属性透传

**内置能力（自动）**：
- 加载/空/错误三种状态
- 排序（点击表头 → 回传 dataLoader）
- 分页（page/rows → 回传 dataLoader）
- 多选（内置 selectedRows 状态）
- 工具栏（刷新、列设置、密度切换）
- 行 Hover / 高亮

### 4.4 YzhApiClient

```ts
// 基础客户端
const client = new YzhApiClient({
  baseURL: import.meta.env.VITE_API_BASE,
  getToken: () => localStorage.getItem('token'),
  onUnauthorized: () => router.push('/login')
})

// 自动类型化请求
const users = await client.get<Page<SysUser>>('/api/Sys_User/getPageData', { params: { page: 1, rows: 20 } })
```

**统一响应包装**（建议后端采用）：
```ts
interface ApiResponse<T> {
  code: number       // 0=成功，其他=失败
  message: string    // 提示信息
  data: T
  timestamp: number
  traceId: string    // 链路追踪
}
```

**向后兼容策略**：vol 的 `{ status, msg, rows, total }` 暂保留，YzhApiClient 通过 `legacy: true` 标志自动适配。

## 五、权限与状态

### 5.1 状态管理（Pinia）

```ts
// stores/auth.ts
export const useAuthStore = defineStore('auth', () => {
  const token = ref<string>(localStorage.getItem('token') || '')
  const user = ref<UserInfo | null>(null)
  const roles = ref<string[]>([])
  const permissions = ref<string[]>([])

  const isAuthenticated = computed(() => !!token.value)
  const hasPermission = (code: string) => permissions.value.includes(code)

  return { token, user, roles, permissions, isAuthenticated, hasPermission }
})
```

### 5.2 权限指令

```vue
<el-button v-permission="'Sys_User.Add'">新增</el-button>
```

### 5.3 路由守卫

```ts
router.beforeEach((to, from, next) => {
  const auth = useAuthStore()
  if (to.meta.requiresAuth && !auth.isAuthenticated) {
    return next({ path: '/login', query: { redirect: to.fullPath } })
  }
  if (to.meta.permission && !auth.hasPermission(to.meta.permission)) {
    ElMessage.error('无访问权限')
    return next(false)
  }
  next()
})
```

| Sys_Dictionary | ✅ | 同上 |
| 体系认证业务 | ✅ | CertPlatform 22 个 Controller |

### 6.2 协议约定
- **请求**：`POST /api/{Module}/{Action}` + JSON Body
- **响应**（vol 默认）：
  ```json
  { "status": 0, "msg": null, "total": 100, "rows": [...], "data": null }
  ```
  - `status === 0` 成功
  - `status !== 0` 失败
- **新架构兼容**：YzhApiClient 已实现对 vol 响应格式的适配

### 6.3 后端需补强的接口（V1 不强制）
- 统一响应包装（迁移期使用 legacy 适配器）
- 批量操作（批量删除/启用/禁用）
- OpenAPI 文档生成（用于前端 codegen）
- 文件分片上传

## 附录 A：YzhTable MVP Props 清单

```ts
interface YzhTableProps<T = any> {
  columns: YzhTableColumn<T>[]
  dataLoader: (params: PageParams) => Promise<Page<T>>
  searchFields?: SearchField[]
  selectable?: boolean
  showPagination?: boolean          // 默认 true
  pageSize?: number                 // 默认 20
  defaultSort?: { prop: string; order: 'asc' | 'desc' }
  height?: string | number
  rowKey?: string                   // 默认 'id'
  emptyText?: string
  toolbar?: boolean | { refresh?: boolean; columnSetting?: boolean; density?: boolean }
}

interface YzhTableColumn<T = any> {
  prop: keyof T | string
  label: string
  width?: number | string
  minWidth?: number | string
  fixed?: 'left' | 'right'
  sortable?: boolean | 'custom'
  align?: 'left' | 'center' | 'right'
  formatter?: (value: any, row: T, index: number) => any
  slot?: string                     // 自定义插槽名
  hidden?: boolean
  className?: string
}

interface Page<T> {
  rows: T[]
  total: number
}

interface PageParams {
  page: number
  rows: number
  sort?: string
  order?: 'asc' | 'desc'
  [key: string]: any                // 搜索条件
}
```
