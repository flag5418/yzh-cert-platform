# 树形结构设计（V1）— 统一虚拟树 + 左树右表

> **版本**：V1.0 | **日期**：2026-09-07 | **状态**：设计中
>
> 本文档定义：前端树形结构的统一虚拟模型、工具函数、基类设计、懒加载约定、后端接口规范。
> **本文件为树形结构架构的唯一权威表述**；后续树形相关编码必须对齐本文。

---

## 一、核心理念

```
┌─────────────────────────────────────────────────────────────────────┐
│                      树形结构核心理念                                 │
├─────────────────────────────────────────────────────────────────────┤
│  1. Code 统一关联   → 去掉 id，所有节点关联统一用 code/parentCode    │
│  2. 虚拟标准结构    → TreeNode 统一模型，任意实体可映射              │
│  3. 纯函数工具集    → TreeUtils 无副作用，可独立测试                 │
│  4. 增量更新        → 增删改只更新局部，不刷新整树                   │
│  5. 懒加载标准化    → 固定接口方法名，前端动态传参                   │
│  6. 复杂树手动构造  → 基类方法 virtual，支持多表组合树               │
└─────────────────────────────────────────────────────────────────────┘
```

## 二、统一 TreeNode 虚拟结构

### 2.1 结构设计

```typescript
/**
 * 前端标准树节点（虚拟结构）
 * 
 * ★ 核心原则：去掉 id 字段，所有关联统一用 code
 * 
 * 无论后端 T 实体字段如何，一律映射到此结构
 * 类比 WPF 的 DefinitionNode
 */
export interface TreeNode {
  // ═══════════════════════════════════════════════════════════════
  //  核心标识字段（Code 体系，无 id）
  // ═══════════════════════════════════════════════════════════════
  
  /** 业务编码（唯一标识，关联查询用） */
  code: string
  
  /** 显示名称 */
  name: string
  
  /** 父节点编码（根节点为空字符串或 null） */
  parentCode: string | null

  // ═══════════════════════════════════════════════════════════════
  //  层级/结构（前端计算）
  // ═══════════════════════════════════════════════════════════════
  
  /** 层级深度（0=根，前端计算） */
  level: number
  
  /** 是否叶子节点（前端计算或后端返回） */
  isLeaf: boolean

  // ═══════════════════════════════════════════════════════════════
  //  UI 状态
  // ═══════════════════════════════════════════════════════════════
  
  /** 是否展开 */
  isExpanded: boolean
  
  /** 懒加载加载中 */
  isLoading: boolean
  
  /** 子节点是否已加载（懒加载用） */
  loaded: boolean
  
  /** 禁止交互 */
  disabled: boolean
  
  /** 勾选状态 */
  checked: boolean
  
  /** 半选状态（子节点部分勾选时） */
  indeterminate: boolean
  
  /** 选中高亮状态 */
  selected: boolean

  // ═══════════════════════════════════════════════════════════════
  //  节点类型（不同层次不同类型，动态显示）
  // ═══════════════════════════════════════════════════════════════
  
  /** 
   * 节点类型
   * - 同构树：如组织机构 root/company/dept/team
   * - 异构树：如 机构+标准+阶段 混合
   * - 点击时根据类型展示不同信息/操作
   */
  nodeType: string
  
  /** 节点图标 */
  icon?: string
  
  /** 节点颜色 */
  color?: string
  
  /** 徽标/角标（如数量） */
  badge?: number | string

  // ═══════════════════════════════════════════════════════════════
  //  懒加载配置
  // ═══════════════════════════════════════════════════════════════
  
  /**
   * 懒加载配置
   * - null = 非懒加载节点（子节点已内嵌在 children 中）
   * - 对象 = 需要懒加载，配置接口信息
   * 
   * ★ 接口方法名固定为：getChildren
   * ★ 参数固定为：{ parentCode: string, nodeType: string, level: number }
   * ★ 返回格式固定为：TreeNode[]
   */
  lazyLoadConfig?: {
    /** 是否启用懒加载 */
    enabled: true
    /** 子节点类型（用于接口判断返回什么类型） */
    childNodeType: string
    /** 是否已加载过（避免重复请求） */
    loaded?: boolean
  } | null

  // ═══════════════════════════════════════════════════════════════
  //  子节点
  // ═══════════════════════════════════════════════════════════════
  
  /** 子节点集合 */
  children: TreeNode[]

  // ═══════════════════════════════════════════════════════════════
  //  原始数据引用
  // ═══════════════════════════════════════════════════════════════
  
  /** 原始 T 实体完整数据（保留引用，提交修改时使用） */
  raw: any
}
```

### 2.2 去掉 id 的理由

| 原有设计 | 修正设计 | 理由 |
|---------|---------|------|
| `id` + `parentId` | `code` + `parentCode` | 所有业务表统一以 code 关联 |
| 数字/Guid 主键 | 业务编码主键 | 业务语义清晰，跨系统可识别 |
| 需要额外映射 | 直接对应 | 前端无需维护 id↔code 映射表 |

### 2.3 节点示例

```typescript
// 组织机构节点
{
  code: 'D001',
  name: '技术部',
  parentCode: 'C001',  // 父节点是公司 C001
  level: 2,
  isLeaf: false,
  isExpanded: true,
  nodeType: 'department',
  icon: 'User',
  children: [
    { code: 'T001', name: '前端组', parentCode: 'D001', level: 3, isLeaf: true, nodeType: 'team', children: [], raw: {...} },
    { code: 'T002', name: '后端组', parentCode: 'D001', level: 3, isLeaf: true, nodeType: 'team', children: [], raw: {...} }
  ],
  raw: { deptCode: 'D001', deptName: '技术部', parentCode: 'C001', ... }
}

// 懒加载节点（未展开）
{
  code: 'ORG001',
  name: '某认证机构',
  parentCode: null,
  level: 0,
  isLeaf: false,
  isExpanded: false,
  isLoading: false,
  loaded: false,
  nodeType: 'org',
  lazyLoadConfig: { enabled: true, childNodeType: 'standard' },
  children: [],  // 未加载
  raw: {...}
}
```

## 三、树配置 TreeConfig

```typescript
/**
 * 树结构字段映射配置
 * 
 * 将后端 T 实体字段映射到 TreeNode 标准字段

export interface TreeConfig {
  // ═══════════════════════════════════════════════════════════════
  //  字段映射（必填）
  // ═══════════════════════════════════════════════════════════════
  
  /** 业务编码字段 → TreeNode.code */
  codeField: string
  
  /** 显示名称字段 → TreeNode.name */
  nameField: string
  
  /** 父节点编码字段 → TreeNode.parentCode */
  parentCodeField: string

  // ═══════════════════════════════════════════════════════════════
  //  字段映射（可选）
  // ═══════════════════════════════════════════════════════════════
  
  /** 节点类型字段 → TreeNode.nodeType */
  typeField?: string
  
  /** 图标字段 → TreeNode.icon */
  iconField?: string
  
  /** 是否叶子字段 → TreeNode.isLeaf */
  leafField?: string
  
  /** 排序字段 */
  sortField?: string

  // ═══════════════════════════════════════════════════════════════
  //  行为配置
  // ═══════════════════════════════════════════════════════════════
  
  /** 根节点父编码值（加载根节点条件） */
  rootParentCode: string | null  // 如 null, '', 'root'
  
  /** 是否懒加载 */
  lazy: boolean
  
  /** 是否严格模式（勾选不联动父子） */
  checkStrictly: boolean
  
  /** 是否只能选择叶子节点 */
  onlyLeafSelectable: boolean
  
  /** 是否允许删除含子节点的父节点 */
  allowDeleteWithChildren: boolean
  
  /** 是否默认展开所有节点 */
  defaultExpandAll: boolean
  
  /** 最大层级深度（0=不限） */
  maxLevel: number
}
```

## 四、TreeUtils 纯函数工具集

### 4.1 设计原则

- **纯函数**：无副作用，输入确定则输出确定
- **不可变**：不修改输入参数，返回新数据
- **可测试**：每个函数可独立单元测试
- **通用性**：不依赖特定框架

### 4.2 构造类函数

```typescript
/**
 * 树工具函数集合
 */
export const TreeUtils = {
  // ─────────────────────────────────────────────────────────────
  //  构造
  // ─────────────────────────────────────────────────────────────
  
  /**
   * 核心：List → Tree（扁平集合转标准树结构）
   * 
   * 类比 WPF 的 CreateNodes<T>()
   * 
   * @param items 扁平实体列表
   * @param config 字段映射配置
   * @param options 构造选项
   * @returns 树节点数组
   * 
   * @example
   * const items = [
   *   { deptCode: 'C001', deptName: '总公司', parentCode: null },
   *   { deptCode: 'D001', deptName: '技术部', parentCode: 'C001' },
   *   { deptCode: 'T001', deptName: '前端组', parentCode: 'D001' }
   * ]
   * const tree = TreeUtils.buildTree(items, {
   *   codeField: 'deptCode',
   *   nameField: 'deptName',
   *   parentCodeField: 'parentCode',
   *   rootParentCode: null
   * })
   */
  buildTree<T>(
    items: T[],
    config: TreeConfig,
    options?: {
      /** 从某个节点开始构建子树（仅返回该节点及以下） */
      startFromCode?: string
      /** 最大层级限制 */
      maxLevel?: number
      /** 当前层级（内部递归用） */
      currentLevel?: number
    }
  ): TreeNode[],
  
  /**
   * 将单个实体转为 TreeNode
   */
  entityToNode<T>(entity: T, config: TreeConfig, level: number): TreeNode,
  
  /**
   * TreeNode 转回实体（用于提交修改）
   */
  nodeToEntity<T>(node: TreeNode, config: TreeConfig): Partial<T>,
  
  /**
   * 扁平化：Tree → List
   */
  flattenTree(nodes: TreeNode[]): TreeNode[],
  
  // ─────────────────────────────────────────────────────────────
  //  遍历/查询
  // ─────────────────────────────────────────────────────────────
  
  /**
   * 递归：获取所有子孙节点（扁平列表，不包含自身）
   * 类比 WPF 的 GetChildren()
   */
  getDescendants(node: TreeNode): TreeNode[],
  
  /**
   * 递归：获取所有子孙节点（包含自身）
   */
  getDescendantsWithSelf(node: TreeNode): TreeNode[],
  
  /**
   * 向上：获取所有祖先节点（从根到父节点路径）
   */
  getAncestors(node: TreeNode, rootNodes: TreeNode[]): TreeNode[],
  
  /**
   * 获取从根到当前节点的完整路径 code[]
   */
  getPath(rootNodes: TreeNode[], node: TreeNode): string[],
  
  /**
   * 获取从根到当前节点的完整路径 name[]
   */
  getPathNames(rootNodes: TreeNode[], node: TreeNode): string[],
  
  /**
   * 按 code 查找节点（深度优先）
   */
  findNode(rootNodes: TreeNode[], code: string): TreeNode | null,
  
  /**
   * 按条件查找节点
   */
  findNodeBy(rootNodes: TreeNode[], predicate: (node: TreeNode) => boolean): TreeNode | null,
  
  /**
   * 按条件查找所有匹配节点
   */
  findNodesBy(rootNodes: TreeNode[], predicate: (node: TreeNode) => boolean): TreeNode[],
  
  /**
   * 获取父节点
   */
  getParent(rootNodes: TreeNode[], node: TreeNode): TreeNode | null,
  
  // ─────────────────────────────────────────────────────────────
  //  勾选/选择
  // ─────────────────────────────────────────────────────────────
  
  /**
   * 级联设置子节点勾选
   * 类比 WPF 的 CheckFlag setter
   */
  setChildrenChecked(node: TreeNode, checked: boolean): void,
  
  /**
   * 向上更新父节点勾选状态（计算 indeterminate）
   */
  updateParentChecked(node: TreeNode, rootNodes: TreeNode[]): void,
  
  /**
   * 获取所有勾选节点（递归）
   */
  getCheckedNodes(rootNodes: TreeNode[]): TreeNode[],
  
  /**
   * 获取所有勾选节点的 code[]
   */
  getCheckedCodes(rootNodes: TreeNode[]): string[],
  
  /**
   * 框选：选中某节点及其所有子孙
   */
  checkNodeWithDescendants(node: TreeNode, checked: boolean): void,
  
  /**
   * 设置整棵树勾选
   */
  setAllChecked(rootNodes: TreeNode[], checked: boolean): void,
  
  // ─────────────────────────────────────────────────────────────
  //  增删改（增量更新，修改原数据）
  // ─────────────────────────────────────────────────────────────

   * 自动挂到父节点 children 下
   * 类比 WPF 的 Add()
   */

    rootNodes: TreeNode[],
    parentNode: TreeNode | null,
    newNode: TreeNode

   * 增量：删除节点从树
   * 返回是否成功
   * 类比 WPF 的 Remove()
   */
  removeNode(rootNodes: TreeNode[], node: TreeNode): boolean,
  
  /**
   * 增量：更新节点显示名称

   */
  updateNodeName(node: TreeNode, newName: string): void,
  
  /**
   * 增量：更新节点数据
   */
  updateNode(node: TreeNode, updates: Partial<TreeNode>): void,
  
  /**
   * 替换节点（修改后刷新）
   */
  replaceNode(rootNodes: TreeNode[], oldCode: string, newNode: TreeNode): boolean,
  
  /**
   * 移动节点到新父节点下
   */
  moveNode(rootNodes: TreeNode[], node: TreeNode, newParentNode: TreeNode | null): boolean,
  
  // ─────────────────────────────────────────────────────────────
  //  过滤/筛选/搜索
  // ─────────────────────────────────────────────────────────────
  
  /**
   * 按节点类型过滤
   */
  filterByType(rootNodes: TreeNode[], nodeType: string): TreeNode[],
  
  /**
   * 搜索：返回匹配节点列表（支持模糊匹配）
   */
  search(rootNodes: TreeNode[], keyword: string): TreeNode[],
  
  /**
   * 搜索：返回匹配节点及其所有祖先（用于高亮+展开）
   */
  searchWithAncestors(rootNodes: TreeNode[], keyword: string): TreeNode[],
  
  /**
   * 过滤树（保留满足条件的节点及其祖先）
   */
  filterTree(rootNodes: TreeNode[], predicate: (node: TreeNode) => boolean): TreeNode[],
  
  // ─────────────────────────────────────────────────────────────
  //  统计
  // ─────────────────────────────────────────────────────────────
  
  /**
   * 获取子节点数量（递归，不包含自身）
   */
  getChildrenCount(node: TreeNode): number,
  
  /**
   * 获取树的深度
   */
  getDepth(rootNodes: TreeNode[]): number,
  
  /**
   * 获取节点总数
   */
  getTotalCount(rootNodes: TreeNode[]): number,
  
  // ─────────────────────────────────────────────────────────────
  //  展开/折叠
  // ─────────────────────────────────────────────────────────────
  
  /**
   * 展开所有节点
   */
  expandAll(rootNodes: TreeNode[]): void,
  
  /**
   * 折叠所有节点
   */
  collapseAll(rootNodes: TreeNode[]): void,
  
  /**
   * 展开到指定层级
   */
  expandToLevel(rootNodes: TreeNode[], level: number): void,
  
  /**
   * 展开到指定节点（展开其所有祖先）
   */
  expandToNode(rootNodes: TreeNode[], node: TreeNode): void,
  
  // ─────────────────────────────────────────────────────────────
  //  验证
  // ─────────────────────────────────────────────────────────────
  
  /**
   * 验证树结构完整性
   * - 无循环引用
   * - 所有节点 parentCode 可找到（根节点除外）
   */
  validate(rootNodes: TreeNode[]): { valid: boolean; errors: string[] },
  
  /**
   * 检测循环引用
   */
  hasCircle(rootNodes: TreeNode[]): boolean,
}
```

### 4.3 buildTree 算法说明

```
输入: items = [
  { code: 'A', name: '节点A', parentCode: null },
  { code: 'A1', name: '节点A1', parentCode: 'A' },
  { code: 'A2', name: '节点A2', parentCode: 'A' },
  { code: 'A11', name: '节点A11', parentCode: 'A1' },
  { code: 'B', name: '节点B', parentCode: null }
]

算法: O(n) 两次遍历
  1. 第一次遍历：所有节点放入 map<code, TreeNode>
  2. 第二次遍历：根据 parentCode 挂载到父节点 children

输出: [
  { code: 'A', name: '节点A', children: [
    { code: 'A1', name: '节点A1', children: [
      { code: 'A11', name: '节点A11', children: [] }
    ]},
    { code: 'A2', name: '节点A2', children: [] }
  ]},
  { code: 'B', name: '节点B', children: [] }
]
```

## 五、节点类型系统

### 5.1 NodeTypeConfig

```typescript
/**
 * 节点类型定义
 * 
 * 不同类型节点：
 * - 显示不同图标
 * - 点击时右侧展示不同信息
 * - 可用操作不同
 * - 可包含的子节点类型不同
 */
export interface NodeTypeConfig {
  /** 类型标识 */
  type: string
  
  /** 显示名称 */
  label: string
  
  /** 图标 */
  icon: string
  
  /** 允许的操作 */
  allowedActions: TreeNodeAction[]
  
  /** 允许的子节点类型（空=不允许子节点） */
  allowedChildTypes: string[]
  
  /** 是否可作为关联目标（右侧表格查询条件） */
  isRelatable: boolean
  
  /** 是否只能作为根节点 */
  onlyRoot: boolean
  
  /** 是否只能作为叶子节点 */
  onlyLeaf: boolean
  
  /** 最大子节点数（0=不限） */
  maxChildren: number
  
  /** 节点说明 */
  description?: string
}

/** 节点操作类型 */
export type TreeNodeAction = 'add' | 'edit' | 'delete' | 'select' | 'check' | 'move' | 'export'
```

## 六、懒加载标准化约定

### 6.1 前端约定

```typescript
/**
 * 懒加载接口标准
 * 
 * ★ 固定方法名：getChildren
 * ★ 固定请求参数格式
 * ★ 固定响应格式
 */

// 请求参数（POST body）
interface GetChildrenRequest {
  /** 父节点编码（必填） */
  parentCode: string
  /** 父节点类型（可选，用于异构树判断） */
  parentNodeType: string
  /** 层级（可选） */
  level: number
  /** 子节点期望类型（可选） */
  childNodeType?: string
  /** 附加过滤条件（可选） */
  filters?: Record<string, any>
}

// 响应格式
interface GetChildrenResponse {
  code: 200
  message: string
  data: {
    /** 子节点列表（扁平结构，前端自动组装） */
    items: any[]
    /** 是否有更多（分页加载场景） */
    hasMore?: boolean
  }
}
```

### 6.3 前端懒加载流程

```
用户点击展开节点
    │
    ▼
检查 node.lazyLoadConfig
    │
    ├── null / enabled=false → 直接展开（子节点已在 children 中）
    │
    └── enabled=true → 检查 loaded
                          │
                          ├── true → 直接展开
                          │
                          └── false → 发起请求
                                        │
                                        ▼
                              POST /api/{Controller}/getChildren
                              body: {
                                parentCode: node.code,
                                parentNodeType: node.nodeType,
                                level: node.level + 1,
                                childNodeType: node.lazyLoadConfig.childNodeType
                              }
                                        │
                                        ▼
                              响应 → TreeUtils.entityToNode → 挂载到 children
                                        │
                                        ▼
                              node.loaded = true
                              node.isExpanded = true
```

## 七、TreeTableLogic<T, V> 基类

### 7.1 设计说明

```typescript
/**
 * 左树右表 Logic 基类
 * 
 * T = 树实体类型（如 Sys_Dept）
 * V = 表格实体类型（如 Sys_User）
 * 
 * ★ 复杂树构造方法为 virtual，允许子类手动构造
 */
export abstract class TreeTableLogic<T extends Record<string, any>, V extends Record<string, any>> {
  
  // ═══════════════════════════════════════════════════════════════
  //  树状态
  // ═══════════════════════════════════════════════════════════════
  
  /** 树配置 */
  abstract treeConfig: TreeConfig
  
  /** 表格与树的关联配置 */
  abstract relation: { relateField: string }
  
  /** 树数据 */
  treeData = ref<TreeNode[]>([])
  
  /** 树加载状态 */
  treeLoading = ref(false)
  
  // ═══════════════════════════════════════════════════════════════
  //  选中状态
  // ═══════════════════════════════════════════════════════════════
  
  /** 当前点击节点 */
  selectedNode = ref<TreeNode | null>(null)
  
  /** 勾选节点集合 */
  checkedNodes = ref<TreeNode[]>([])
  
  // ═══════════════════════════════════════════════════════════════
  //  表格状态（继承自 CrudPageLogic）
  // ═══════════════════════════════════════════════════════════════
  
  /** 表格数据 */
  rows = ref<V[]>([])
  
  /** 加载状态 */
  loading = ref(false)
  
  /** 分页 */
  pagination = reactive({ page: 1, pageSize: 20, total: 0 })
  
  /** 搜索参数 */
  searchParams = reactive<Record<string, any>>({})
  
  /** 控制器名称 */
  abstract controllerName: string
  
  // ═══════════════════════════════════════════════════════════════
  //  抽象方法（子类必须实现）
  // ═══════════════════════════════════════════════════════════════
  
  /**
   * 加载树数据
   * @param parentCode 父节点编码（懒加载时传入）
   */
  abstract loadTree(parentCode?: string | null): Promise<T[]>
  
  /**
   * 实体 → TreeNode 映射
   */
  abstract entityToTreeNode(entity: T, level: number): TreeNode
  
  /**
   * TreeNode → 实体（用于提交）
   */
  abstract treeNodeToEntity(node: TreeNode): Partial<T>
  
  // ═══════════════════════════════════════════════════════════════
  //  Virtual 方法（子类可覆盖，用于复杂树构造）
  // ═══════════════════════════════════════════════════════════════
  
  /**
   * ★ Virtual：构造树形结构
   * 
   * 默认实现：调用 TreeUtils.buildTree() 自动构造
   * 
   * 子类可覆盖此方法实现：
   * - 多表组合树（如 机构+标准+阶段）
   * - 异构树（不同层级不同类型）
   * - 自定义过滤/排序逻辑
   */
  protected buildTreeFromItems(items: T[]): TreeNode[] {
    return TreeUtils.buildTree(items, this.treeConfig)
  }
  
  /**
   * ★ Virtual：自定义节点转换
   * 
   * 默认实现：调用 entityToTreeNode()
   * 
   * 子类可覆盖实现：
   * - 根据实体字段动态设置 nodeType
   * - 根据条件设置 lazyLoadConfig
   * - 根据权限设置 disabled
   */
  protected convertEntityToNode(entity: T, level: number): TreeNode {
    return this.entityToTreeNode(entity, level)
  }
  
  /**
   * ★ Virtual：加载后的数据处理
   * 
   * 子类可覆盖实现：
   * - 自动展开某些节点
   * - 自动选中某个节点
   * - 根据权限过滤节点
   */
  protected onTreeLoaded(treeData: TreeNode[]): void {
    if (this.treeConfig.defaultExpandAll) {
      TreeUtils.expandAll(treeData)
    }
  }
  
  // ═══════════════════════════════════════════════════════════════
  //  树初始化
  // ═══════════════════════════════════════════════════════════════
  
  /**
   * 初始化树
   */
  async initTree(): Promise<void> {
    this.treeLoading.value = true
    try {
      if (this.treeConfig.lazy) {
        // 懒加载：只加载根节点
        const rootItems = await this.loadTree(this.treeConfig.rootParentCode)
        this.treeData.value = this.buildTreeFromItems(rootItems)
        // 为根节点设置懒加载配置
        this.treeData.value.forEach(node => {
          if (!node.isLeaf) {
            node.lazyLoadConfig = {
              enabled: true,
              childNodeType: this.inferChildNodeType(node),
              loaded: false
            }
          }
        })
      } else {
        // 全量加载
        const items = await this.loadTree()
        this.treeData.value = this.buildTreeFromItems(items)
      }
      this.onTreeLoaded(this.treeData.value)
    } finally {
      this.treeLoading.value = false
    }
  }
  
  /**
   * 懒加载子节点
   */
  async loadChildren(parentNode: TreeNode): Promise<void> {
    if (!parentNode.lazyLoadConfig?.enabled || parentNode.lazyLoadConfig.loaded) return
    if (parentNode.isLoading) return
    
    parentNode.isLoading = true
    try {
      // ★ 调用固定方法名接口
      const result = await this.apiPost<{ items: any[] }>('/getChildren', {
        parentCode: parentNode.code,
        parentNodeType: parentNode.nodeType,
        level: parentNode.level + 1,
        childNodeType: parentNode.lazyLoadConfig.childNodeType
      })
      
      const children = result.items.map(item => {
        const node = this.convertEntityToNode(item, parentNode.level + 1)
        node.parentCode = parentNode.code
        // 递归设置懒加载配置
        if (!node.isLeaf) {
          node.lazyLoadConfig = {
            enabled: true,
            childNodeType: this.inferChildNodeType(node),
            loaded: false
          }
        }
        return node
      })
      
      parentNode.children = children
      parentNode.lazyLoadConfig.loaded = true
    } finally {
      parentNode.isLoading = false
    }
  }
  
  /**
   * 推断子节点类型（子类可覆盖）
   */
  protected inferChildNodeType(node: TreeNode): string {
    return 'default'
  }
  
  // ═══════════════════════════════════════════════════════════════
  //  节点点击 → 联动表格
  // ═══════════════════════════════════════════════════════════════
  
  /**
   * 节点点击
   */
  async onNodeClick(node: TreeNode): Promise<void> {
    // 清除之前的选中
    if (this.selectedNode.value) {
      this.selectedNode.value.selected = false
    }
    
    this.selectedNode.value = node
    node.selected = true
    
    // 检查是否可选择
    if (this.treeConfig.onlyLeafSelectable && !node.isLeaf) {
      return
    }
    
    // 重置分页并加载表格
    this.pagination.page = 1
    await this.loadDataWithTreeCondition(node)
  }
  
  /**
   * 带树条件的分页查询
   */
  async loadDataWithTreeCondition(node: TreeNode): Promise<void> {
    this.loading.value = true
    try {
      const conditions = {
        ...this.buildConditions(),
        [this.relateFieldToCondition()]: node.code
      }
      const res = await this.apiPost<{ rows: V[]; total: number }>('/page', {
        page: this.pagination.page,
        rows: this.pagination.pageSize,
        sort: undefined,
        order: undefined,
        conditions
      })
      this.rows.value = res.rows
      this.pagination.total = res.total
    } finally {
      this.loading.value = false
    }
  }
  
  // ═══════════════════════════════════════════════════════════════
  //  树节点 CRUD（增量更新）
  // ═══════════════════════════════════════════════════════════════
  
  /**
   * 新增节点
   */
  async addTreeNode(parentNode: TreeNode | null, entity: Partial<T>): Promise<TreeNode | null> {
    // 设置父编码
    const data = {
      ...entity,
      [this.treeConfig.parentCodeField]: parentNode?.code ?? this.treeConfig.rootParentCode
    }
    // 后端保存
    const saved = await this.apiPost<T>('/add', data)
    // 构造新节点
    const newNode = this.convertEntityToNode(saved, (parentNode?.level ?? -1) + 1)
    newNode.parentCode = parentNode?.code ?? this.treeConfig.rootParentCode
    // 增量更新树
    TreeUtils.addNode(this.treeData.value, parentNode, newNode)
    if (parentNode) {
      parentNode.isExpanded = true
      parentNode.isLeaf = false
    }
    return newNode
  }
  
  /**
   * 修改节点名称
   */
  async updateTreeNodeName(node: TreeNode, newName: string): Promise<void> {
    const entity = this.treeNodeToEntity(node)
    entity[this.treeConfig.nameField] = newName
    await this.apiPost('/update', entity)
    TreeUtils.updateNodeName(node, newName)
  }
  
  /**
   * 删除节点
   */
  async deleteTreeNode(node: TreeNode): Promise<void> {
    // 删除策略检查
    if (!this.treeConfig.allowDeleteWithChildren && node.children.length > 0) {
      throw new Error('该节点包含子节点，无法删除')
    }
    // 递归删除所有子孙的 code
    const codes = TreeUtils.getDescendantsWithSelf(node).map(n => n.code)
    await this.apiPost('/delete', codes)
    // 增量更新树
    TreeUtils.removeNode(this.treeData.value, node)
    // 如果当前选中节点被清除
    if (this.selectedNode.value?.code === node.code) {
      this.selectedNode.value = null
    }
  }
  
  // ═══════════════════════════════════════════════════════════════
  //  勾选/框选
  // ═══════════════════════════════════════════════════════════════
  
  /**
   * 节点勾选变更
   */
  onCheckChange(node: TreeNode, checked: boolean): void {
    if (!this.treeConfig.checkStrictly) {
      TreeUtils.setChildrenChecked(node, checked)
      TreeUtils.updateParentChecked(node, this.treeData.value)
    }
    node.checked = checked
    this.checkedNodes.value = TreeUtils.getCheckedNodes(this.treeData.value)
  }
  
  /**
   * 获取所有勾选节点的 code
   */
  getCheckedCodes(): string[] {
    return this.checkedNodes.value.map(n => n.code)
  }
  
  // ═══════════════════════════════════════════════════════════════
  //  辅助方法
  // ═══════════════════════════════════════════════════════════════
  
  /** 表格查询条件字段名（camelCase → snake_case） */
  private relateFieldToCondition(): string {
    return this.relation.relateField.replace(/([A-Z])/g, '_$1').toLowerCase()
  }
  
  /** 构建查询条件 */
  protected buildConditions(): any[] {
    return Object.entries(this.searchParams)
      .filter(([, v]) => v != null && v !== '')
      .map(([field, value]) => ({ field, value, operator: 'eq' }))
  }
  
  /** API POST */
  protected async apiPost<R = any>(path: string, body?: any): Promise<R> {
    const url = `/api/${this.controllerName}${path}`
    const { yzhApi } = await import('@yzh-core/api/client')
    return yzhApi.post<R>(url, body)
  }
  
  /** API GET */
  protected async apiGet<R = any>(path: string): Promise<R> {
    const url = `/api/${this.controllerName}${path}`
    const { yzhApi } = await import('@yzh-core/api/client')
    return yzhApi.get<R>(url)
  }
}
```

```typescript
/**
 * 认证业务树 Logic
 * 
 * 演示多表组合树的构造
 */
export class CertTreeLogic extends TreeTableLogic<CertTreeNode, AuditTask> {
  
  controllerName = 'CertTree'
  
  treeConfig: TreeConfig = {
    codeField: 'code',
    nameField: 'name',
    parentCodeField: 'parentCode',
    typeField: 'nodeType',
    rootParentCode: null,
    lazy: true,
    checkStrictly: false,
    onlyLeafSelectable: false,
    allowDeleteWithChildren: false,
    defaultExpandAll: false,
    maxLevel: 0
  }
  
  relation = { relateField: 'certCode' }
  
  /**
   * ★ 覆盖 virtual 方法：手动构造异构树
   */
  protected buildTreeFromItems(items: CertTreeNode[]): TreeNode[] {
    // 1. 按类型分组
    const orgs = items.filter(i => i.nodeType === 'org')
    const standards = items.filter(i => i.nodeType === 'standard')
    const stages = items.filter(i => i.nodeType === 'stage')
    
    // 2. 手动组装树
    return orgs.map(org => {
      const orgNode = this.entityToTreeNode(org, 0)
      orgNode.children = standards
        .filter(s => s.parentCode === org.code)
        .map(s => {
          const stdNode = this.entityToTreeNode(s, 1)
          stdNode.children = stages
            .filter(st => st.parentCode === s.code)
            .map(st => this.entityToTreeNode(st, 2))
          return stdNode
        })
      return orgNode
    })
  }
  
  async loadTree(parentCode?: string | null): Promise<CertTreeNode[]> {
    const res = await this.apiGet<{ items: CertTreeNode[] }>('/tree', { parentCode })
    return res.items
  }
  
  entityToTreeNode(entity: CertTreeNode, level: number): TreeNode {
    return {
      code: entity.code,
      name: entity.name,
      parentCode: entity.parentCode,
      level,
      isLeaf: entity.nodeType === 'stage',
      isExpanded: level === 0,
      isLoading: false,
      loaded: false,
      disabled: false,
      checked: false,
      indeterminate: false,
      selected: false,
      nodeType: entity.nodeType,
      icon: this.getIconByType(entity.nodeType),
      children: [],
      raw: entity,
      lazyLoadConfig: level < 2 ? {
        enabled: true,
        childNodeType: this.getChildType(entity.nodeType),
        loaded: false
      } : null
    }
  }
  
  treeNodeToEntity(node: TreeNode): Partial<CertTreeNode> {
    return {
      code: node.code,
      name: node.name,
      parentCode: node.parentCode ?? '',
      nodeType: node.nodeType
    }
  }
  
  private getIconByType(type: string): string {
    const map = { org: 'School', standard: 'Document', stage: 'Flag' }
    return map[type] || 'Folder'
  }
  
  private getChildType(type: string): string {
    const map = { org: 'standard', standard: 'stage', stage: '' }
    return map[type] || ''
  }
}
```
