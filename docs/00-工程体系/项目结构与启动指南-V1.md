## 2. 新架构路径（✅唯一开发目标）

### 2.1 后端

| 组件 | 路径 | 说明 |
|------|------|------|
| **解决方案** | `CertPlatform.sln` | 根目录，包含所有后端项目（yzh-core + certplatform-api） |
| **启动入口** | `src/yzh-core/YZH.Core.Web/` | Program.cs、中间件、模块注册（UseYzhCore） |
| **框架核心** | `src/yzh-core/YZH.Core.Stand/` | 基础模型、接口、枚举、常量 |
| **数据访问** | `src/yzh-core/YZH.Core.DataBase/` | SqlSugar ORM、EntityService、Queue |
| **API 基类** | `src/yzh-core/YZH.Core.Api/` | YzhControllerBase、TreeTableControllerBase、中间件 |
| **业务共享层** | `src/certplatform-api/CertPlatform.Shared/` | 实体、DTO、业务枚举 |
| **管理员端 API** | `src/certplatform-api/CertPlatform.Admin/` | 管理员端控制器、Service、EntityConfig |
| **审核员端 API** | `src/certplatform-api/CertPlatform.Auditor/` | 审核员端控制器 |
| **企业端 API** | `src/certplatform-api/CertPlatform.Enterprise/` | 企业端控制器 |

> **注**：yzh-core 正处于架构完善阶段，允许且需要修改以支撑新架构演进。

**后端启动（标准脚本）**：
```bash
# 编译 + 启动（停旧进程 → 编译 → 启动）
./scripts/backend/restart-backend.sh

# 或分步执行
./scripts/backend/run-backend.sh build   # 仅编译
./scripts/backend/run-backend.sh run     # 仅启动（不编译）
./scripts/backend/stop-backend.sh       # 停止
```

**后端启动（直接 CLI）**：
```bash
cd src/yzh-core/YZH.Core.Web
dotnet run --urls "http://0.0.0.0:9992"
```

- 服务地址：http://localhost:9992
- Swagger：http://localhost:9992/swagger
- 日志：`/tmp/yzh_backend_9992.log`

### 2.2 前端

| 组件 | 路径 | 端口 | UI 框架 |
|------|------|------|---------|
| **核心组件库** | `src/certplatform-web/yzh.vue.core/` | - | YzhTable/YzhForm/YzhApiClient |
| **业务共享层** | `src/certplatform-web/cert/cert-share/` | - | API/类型/工具函数 |
| **管理员端** | `src/certplatform-web/cert/cert-admin/` | 9990 | Element Plus |
| **审核员端** | `src/certplatform-web/cert/cert-auditor/` | 9991 | Naive UI |
| **企业端** | `src/certplatform-web/cert/cert-enterprise/` | 9993 | - |

**前端启动**：
```bash
# 管理员端
cd src/certplatform-web/cert/cert-admin && npm run dev

# 审核员端
cd src/certplatform-web/cert/cert-auditor && npm run dev

# 企业端
cd src/certplatform-web/cert/cert-enterprise && npm run dev

# 或使用脚本批量启动
./scripts/frontend/start.sh admin start
./scripts/frontend/start.sh all start
```

## 6. 快速开始

### 6.1 启动后端
```bash
./scripts/backend/run-backend.sh
```

### 6.2 启动前端（管理员端）
```bash
cd src/certplatform-web/cert/cert-admin
npm install  # 首次安装依赖
npm run dev
```

### 6.3 访问
- 后端 Swagger：http://localhost:9992/swagger
- 管理员端：http://127.0.0.1:9990
