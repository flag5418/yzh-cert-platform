# 前端架构设计（V1）— 原子化组件 + 基类继承

> **版本**：V1.0 | **日期**：2026-09-07 | **状态**：设计中
>
> 本文档定义：前端（admin + auditor）的组件原子化策略、页面基类设计、与后端约定。
> **本文件为前端架构的唯一权威表述**；后续前端编码必须对齐本文。

## 一、核心理念

```
┌─────────────────────────────────────────────────────────────────────�
│                         前端架构核心理念                              │
├─────────────────────────────────────────────────────────────────────┤
│  1. 原子化组件    → 组件与接口无关，通过 props 接收数据、emit 事件    │
│  2. 配置驱动      → 表格列、表单字段由后端 GridConfig 统一提供        │
│  3. 基类继承      → 80% 逻辑由 CrudPageLogic 基类提供，子类可覆盖   │
│  4. ID 唯一性     → 动态生成组件唯一 ID，支持级联和多实例场景        │
│  5. Enable 控制   → 外部带入数据自动 disabled，前端零判断            │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.1 yzh.vue.core 页面定位律

> **核心原则**：yzh.vue.core 中的页面是「元能力」，承载的是标准化 CRUD 骨架；admin/auditor
> 中的「机构-用户管理」等菜单入口，**不是新建页面**，而是对 yzh.vue.core 页面的场景化调用。

**场景参数控制差异**：

```typescript
// admin/router.ts 中注册菜单
{
  path: '/system/org-admin',
  component: () => import('@yzh-core/pages/system-org-user'),
  meta: { scene: 'platform_admin' }  // 控制列/按钮/查询条件
}

// auditor/router.ts 中注册菜单
{
  path: '/system/org-virtual',
  component: () => import('@yzh-core/pages/system-org-user'),
  meta: { scene: 'virtual_org' }    // 同一页面，不同数据范围
}
```

**判断页面放哪里的规则**：

| 判断条件 | 页面应放位置 | 示例 |
|---------|-------------|------|
| 多端共用的系统管理 CRUD | `yzh.vue.core/pages/` | 机构管理、角色管理、菜单管理、用户管理 |
| admin + auditor 共用但非 yzh 核心 | `share/` | 端共享 API、类型 |
| 仅 admin 存在 | `admin/pages/` | 审批流、认证配置中心 |
| 仅 auditor 存在 | `auditor/pages/` | 审核工作台、NC 管理 |

### 2.2 前后端 Controller 命名对应规则

> **核心原则**：后端 Controller 与前端页面文件夹建立映射，方便 AI 和人工查找。

| 后端 Controller | 前端文件夹 | 存放位置 | 说明 |
|----------------|-----------|---------|------|
| `OrganizationController` | `system-org-user/org/` | yzh.vue.core | 机构 CRUD |
| `SysUserController` | `system-org-user/user/` | yzh.vue.core | 人员 CRUD |
| `SysRoleController` | `system-role/` | yzh.vue.core | 角色 CRUD |
| `SysMenuController` | `system-menu/` | yzh.vue.core | 菜单 CRUD |
| `RoleMenuController` | `system-role-menu/` | yzh.vue.core | 角色-菜单绑定 |
| `ISOClauseController` | `iso-clause/` | admin | ISO 条款（管理员独有） |

**注意**：如果后端 API 有明确文件夹分类（如 `Controllers/Admin/Platform/Cert/`），
前端 pages 下也应建立对应文件夹分类（如 `admin/pages/platform/cert/`）。

## 三、原子化组件设计

### 3.1 设计原则

| 原则 | 说明 |
|------|------|
| **接口无关** | 组件不直接调用 API，通过 props 接收数据 |
| **事件驱动** | 组件通过 emit 向父组件传递事件 |
| **独立可用** | 每个组件可独立使用，也可组合使用 |

## 四、页面基类设计

### 4.1 后端接口约定

后端 `YzhControllerBase<T>` 提供：

| 接口 | 方法 | 请求体 | 响应 |
|------|------|--------|------|
| `/api/{Controller}/config` | GET | - | `GridConfig` |
| `/api/{Controller}/page` | POST | `PageRequest` | `PageResult<T>` |
| `/api/{Controller}/add` | POST | `T` | `T` |
| `/api/{Controller}/update` | POST | `T` | `T` |
| `/api/{Controller}/delete` | POST | `string[]` | `void` |
| `/api/{Controller}/action/{name}` | POST | `T` | `any` |

### 4.2 GridConfig 数据结构

```typescript
interface GridConfig {
  configName: string              // 配置名称
  tableName: string               // 表名
  primaryKey: string              // 主键（默认 Id）
  title: string                   // 页面标题
  layoutColumns: number           // 表单列数（默认 2）
  columns: DefineColumn[]         // 列定义
  toolbar: ToolbarConfig          // 工具栏配置
  rowButtons: RowButtonConfig     // 行按钮配置
}

interface DefineColumn {
  fieldName: string               // 字段名（PascalCase）
  desName: string                 // 显示标题
  width: number                   // 宽度
  type: ControlType               // 控件类型
  xsFlag: boolean                 // 表格显示标志
  bcFlag: boolean                 // 保存标志
  yxk: boolean                    // 允许空（true = 非必填）
  enable: boolean                 // 是否可编辑（false = disabled）
  sortable: boolean               // 可排序
  fixed: string                   // 固定列：left/right/null
  align: string                   // 对齐：left/center/right
  dictCode: string                // 字典编码
  options: SelectOption[]         // 下拉选项
  format: string                  // 格式化字符串
}
```

### 4.3 CrudPageLogic 基类

```typescript
// share/src/logic/CrudPageLogic.ts

export class CrudPageLogic<T extends Record<string, any>> {
  // ==================== 页面标识 ====================
  readonly controllerName: string
  readonly pageId: string
  
  // ==================== 后端配置 ====================
  config = ref<GridConfig | null>(null)
  
  // ==================== 表格状态 ====================
  rows = ref<T[]>([])
  loading = ref(false)
  selectedRows = ref<T[]>([])
  
  // ==================== 分页状态 ====================
  pagination = reactive({ page: 1, pageSize: 20, total: 0 })
  
  // ==================== 搜索状态 ====================
  searchParams = reactive<Record<string, any>>({})
  
  // ==================== 排序状态 ====================
  sortField = ref<string | undefined>()
  sortOrder = ref<'asc' | 'desc' | undefined>()
  
  // ==================== 弹窗状态 ====================
  dialogVisible = ref(false)
  dialogMode = ref<'add' | 'edit'>('add')
  submitting = ref(false)
  formData = reactive<Partial<T>>({})
  
  // ==================== 计算属性 ====================
  
  /** 表格列配置 */
  get columns(): YzhTableColumn<T>[] {
    return this.config.value?.columns
      ?.filter(c => c.xsFlag)
      ?.map(c => ({
        prop: this.toCamelCase(c.fieldName),
        label: c.desName,
        width: Number(c.width) || undefined,
        sortable: c.sortable || undefined,
        fixed: c.fixed as any,
        align: c.align as any,
        dictCode: c.dictCode,
        formatter: c.format ? (v: any) => this.formatValue(v, c.format) : undefined
      })) || []
  }
  
  /** 表单字段配置 */
  get formFields(): YzhFormField[] {
    return this.config.value?.columns
      ?.filter(c => c.bcFlag)
      ?.map(c => ({
        prop: this.toCamelCase(c.fieldName),
        label: c.desName,
        type: this.mapControlType(c.type),
        required: !c.yxk,
        disabled: !c.enable,           // ← enable 控制
        span: 24 / (this.config.value?.layoutColumns || 2),
        dictCode: c.dictCode,
        options: c.options,
        fieldProps: { id: this.fieldId(c.fieldName) }  // ← 动态 ID
      })) || []
  }
  
  /** 工具栏按钮 */
  get toolbarButtons(): ToolbarButton[] {
    const tb = this.config.value?.toolbar
    const btns: ToolbarButton[] = []
    if (tb?.add !== false) btns.push({ key: 'add', text: '新增', type: 'primary' })
    if (tb?.delete !== false) btns.push({ key: 'delete', text: '批量删除', type: 'danger' })
    if (tb?.export !== false) btns.push({ key: 'export', text: '导出', type: 'success' })
    return btns
  }
  
  // ==================== 构造函数 ====================
  
  constructor(controllerName: string) {
    this.controllerName = controllerName
    this.pageId = `${controllerName.replace(/Controller$/, '')}_${this.randomId()}`
  }
  
  // ==================== 初始化 ====================
  
  async init() {
    await this.loadConfig()
    await this.loadData()
  }
  
  protected async loadConfig() {
    this.config.value = await yzhApi.get<GridConfig>(
      `/api/${this.controllerName}/config`
    )
  }
  
  // ==================== 数据操作（可覆盖） ====================
  
  async loadData() {
    this.loading.value = true
    try {
      const res = await yzhApi.post<PageResult<T>>(`/api/${this.controllerName}/page`, {
        page: this.pagination.page,
        rows: this.pagination.pageSize,
        sort: this.sortField.value,
        order: this.sortOrder.value,
        conditions: this.buildConditions()
      })
      this.rows.value = res.rows
      this.pagination.total = res.total
      this.onDataLoaded(res.rows)
    } finally {
      this.loading.value = false
    }
  }
  
  protected async add(entity: Partial<T>): Promise<void> {
    await yzhApi.post(`/api/${this.controllerName}/add`, entity)
  }
  
  protected async update(entity: Partial<T>): Promise<void> {
    await yzhApi.post(`/api/${this.controllerName}/update`, entity)
  }
  
  protected async delete(codes: string[]): Promise<void> {
    await yzhApi.post(`/api/${this.controllerName}/delete`, codes)
  }
  
  async executeAction(actionName: string, row: T) {
    await yzhApi.post(`/api/${this.controllerName}/action/${actionName}`, row)
    await this.loadData()
  }
  
  // ==================== 钩子方法（子类可覆盖） ====================
  
  protected onDataLoaded(rows: T[]) {}
  protected onBeforeAdd(entity: Partial<T>) {}
  protected onAfterAdd(entity: Partial<T>) {}
  protected onBeforeUpdate(entity: Partial<T>) {}
  protected onDelete(codes: string[]): boolean | Promise<boolean> { return true }
  protected onPrepareAdd(entity: Partial<T>) {}
  
  protected buildConditions() {
    return Object.entries(this.searchParams)
      .filter(([, v]) => v != null && v !== '')
      .map(([field, value]) => ({ field, value, operator: 'eq' }))
  }
  
  // ==================== 事件处理 ====================
  
  onSearch(params: Record<string, any>) {
    Object.assign(this.searchParams, params)
    this.pagination.page = 1
    this.loadData()
  }
  
  onPageChange(page: number) {
    this.pagination.page = page
    this.loadData()
  }
  
  onSizeChange(size: number) {
    this.pagination.pageSize = size
    this.pagination.page = 1
    this.loadData()
  }
  
  onSortChange(prop: string, order: 'asc' | 'desc') {
    this.sortField.value = prop
    this.sortOrder.value = order
    this.loadData()
  }
  
  onSelectionChange(rows: T[]) {
    this.selectedRows.value = rows
  }
  
  // ==================== 弹窗操作 ====================
  
  openAddDialog() {
    this.dialogMode.value = 'add'
    Object.keys(this.formData).forEach(k => delete this.formData[k])
    this.onPrepareAdd(this.formData)
    this.dialogVisible.value = true
  }
  
  openEditDialog(row: T) {
    this.dialogMode.value = 'edit'
    Object.assign(this.formData, row)
    this.dialogVisible.value = true
  }
  
  async cancelDialog() {
    this.dialogVisible.value = false
  }
  
  async submitForm() {
    this.submitting.value = true
    try {
      if (this.dialogMode.value === 'add') {
        this.onBeforeAdd(this.formData)
        await this.add(this.formData)
        this.onAfterAdd(this.formData)
      } else {
        this.onBeforeUpdate(this.formData)
        await this.update(this.formData)
      }
      ElMessage.success('保存成功')
      this.dialogVisible.value = false
      await this.loadData()
    } finally {
      this.submitting.value = false
    }
  }
  
  async confirmDelete(rows?: T[]) {
    const targets = rows || this.selectedRows.value
    if (targets.length === 0) return
    
    const pk = this.config.value?.primaryKey?.toLowerCase() || 'code'
    const codes = targets.map(r => r[pk]).filter(Boolean)
    
    const canDelete = await this.onDelete(codes)
    if (!canDelete) return
    
    await ElMessageBox.confirm(`确定删除 ${codes.length} 条记录？`, '删除确认')
    await this.delete(codes)
    ElMessage.success('删除成功')
    await this.loadData()
  }
  
  // ==================== ID 生成 ====================
  
  /** 生成组件唯一 ID */
  id(type: string, suffix?: string): string {
    return suffix ? `${this.pageId}_${type}_${suffix}` : `${this.pageId}_${type}`
  }
  
  /** 生成字段 ID */
  fieldId(fieldName: string): string {
    return `${this.pageId}_field_${fieldName}`
  }
  
  get tableId(): string { return this.id('table') }
  get searchBarId(): string { return this.id('searchbar') }
  get formId(): string { return this.id('form') }
  get dialogId(): string { return this.id('dialog') }
  get paginationId(): string { return this.id('pagination') }
  get toolbarId(): string { return this.id('toolbar') }
  
  // ==================== 工具方法 ====================
  
  protected toCamelCase(str: string): string {
    return str.charAt(0).toLowerCase() + str.slice(1)
  }
  
  private mapControlType(type: ControlType): YzhFieldType {
    const map: Record<ControlType, YzhFieldType> = {
      TextBox: 'text',
      TextArea: 'textarea',
      NumberBox: 'number',
      DatePicker: 'date',
      DateTimePicker: 'datetime',
      ComboBox: 'select',
      DropDownList: 'select',
      RadioButtonList: 'radio',
      CheckBox: 'checkbox',
      Switch: 'switch',
      Upload: 'upload',
      TreeSelect: 'treeSelect',
      Cascader: 'cascader'
    }
    return map[type] || 'text'
  }
  
  private formatValue(value: any, format: string): string {
    // TODO: 实现日期/数字格式化
    return value
  }
  
  private randomId(len = 8): string {
    return Math.random().toString(36).slice(2, 2 + len)
  }
}
```

```typescript

import { CrudPageLogic } from '@share/logic/CrudPageLogic'
import { ElMessage } from 'element-plus'
import type { SysUser } from '@share/types/user'

export class UserPageLogic extends CrudPageLogic<SysUser> {
  
  // ===== 覆盖钩子 =====
  
  /** 新增默认值 */
  override onPrepareAdd(entity: Partial<SysUser>) {
    entity.enable = 1
  }
  
  /** 禁止删除管理员 */
  override onDelete(codes: string[]): boolean {
    if (codes.includes('admin')) {
      ElMessage.warning('不能删除系统管理员')
      return false
    }
    return true
  }
  
  /** 数据加载后脱敏处理 */
  override onDataLoaded(rows: SysUser[]) {
    rows.forEach(r => {
      if (r.phoneNo) {
        r.phoneNo = r.phoneNo.replace(/(\d{3})\d{4}(\d{4})/, '$1****$2')
      }
    })
  }
  
  // ===== 扩展方法 =====
  
  /** 重置密码 */
  async resetPassword(userId: number) {
    await ElMessageBox.confirm('确定重置该用户密码？')
    await this.executeAction('ResetPassword', { id: userId } as SysUser)
    ElMessage.success('密码已重置')
  }
}
```
