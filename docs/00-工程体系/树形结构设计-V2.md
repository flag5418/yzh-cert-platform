# 树形结构设计（V2）— 视图驱动的统一树架构

> **版本**：V2.1 | **日期**：2026-09-07 | **状态**：已定稿
>
> V2 相对 V1 的核心改动：
> 1. TreeNode 去掉所有 UI 状态（isExpanded/checked/isLoading 等），只承载业务数据 + 结构元数据
> 2. TreeUtils 拆分为 `treeUtils`（只读查询）+ `treeOps`（不可变变换）
> 3. 新增 `ActionPipeline` 接口标准化动作分发
> 4. 后端新增 `ITreeNode` 接口 + `TreeControllerBase` 基类
> 5. 懒加载配置从节点移入 TreeConfig，由组件 lazy 机制驱动
> 6. 统一后端返回 `isLeaf` 事实，前端决定加载模式
> 7. **【V2.1 新增】视图驱动多表树** — MySQL VIEW 统一单表/多表树结构，Controller 代码统一
> 8. **【V2.1 新增】前端只关心 List→Tree** — 后端返回扁平列表，前端 treeUtils.buildTree 组装

---

## 一、核心原则

```
┌─────────────────────────────────────────────────────────────────────┐
│                      树形结构核心理念（V2）                           │
├─────────────────────────────────────────────────────────────────────┤
│  1. Code 统一关联   → 去掉 id，所有节点关联统一用 code/parentCode    │
│  2. UI 状态分离     → TreeNode 不含 UI 状态，由组件持有              │
│  3. 不可变变换      → treeOps 返回新树，便于 Vue reactive 替换       │
│  4. 纯函数工具集    → treeUtils 只读查询，无副作用                   │
│  5. 懒加载标准化    → 组件 lazy 驱动，节点不存加载状态              │
│  6. 复杂树手动构造  → 基类 buildTreeFromItems 为 virtual，支持覆盖   │
│  7. 后端返回事实    → isLeaf 由后端批量计算，前端决定模式            │
│  8. 动作管线        → onNodeAction + before/run/after 分发          │
└─────────────────────────────────────────────────────────────────────┘
```

## 二、分层架构

```
┌────────────────────────────────────────────────────────────────┐
│  业务层（消费树，不实现树）                                        │
│  页面视图 / 路由守卫 / 导出模块 / 权限计算 / Job                    │
├────────────────────────────────────────────────────────────────┤
│  编排层（仅 UI 场景需要）                                         │
│  TreeTableLogic<V>：后端 API + ActionPipeline + treeOps 组合      │

│  ★ 树核心域（业务无关、零框架依赖）                                 │
│  前端：TreeNode / TreeConfig / treeUtils / treeOps                 │
│  后端：ITreeNode / TreeControllerBase                              │
└────────────────────────────────────────────────────────────────┘
```

## 三、TreeNode 结构（V2 核心改动）

### 3.1 核心 TreeNode（业务数据 + 结构元数据）

```typescript
/**
 * 前端标准树节点（V2：去掉 UI 状态）
 * 
 * ★ 只承载业务数据 + 结构元数据
 * ★ UI 状态由组件/视图层持有（UiTreeNode 扩展类型）
 */
export interface TreeNode<T = any> {
  // 核心标识
  code: string
  name: string
  parentCode: string | null

  // 结构元数据（后端返回或工具函数计算）
  nodeType?: string
  isLeaf?: boolean          // 后端事实：是否有子级
  sort?: number
  extra?: Record<string, any>  // 扩展字段（图标/颜色/badge）

  // 层级结构
  children: TreeNode<T>[]

  // 原始数据引用（可选）
  raw?: T
}
```

### 3.2 视图层扩展类型（UI 状态不进核心模型）

```typescript
/**
 * UI 状态扩展类型（由组件持有）
 * 
 * 使用场景：
 * - el-tree 的选中/勾选状态
 * - 组件内部的加载/展开状态
 */
export type UiTreeNode<T = any> = TreeNode<T> & {
  checked?: boolean
  indeterminate?: boolean
  selected?: boolean
  isExpanded?: boolean
  isLoading?: boolean
}
```

### 3.3 V1 → V2 字段变化对照

| V1 字段 | V2 处置 | 理由 |
|---------|---------|------|
| level | 移除（需要时由 treeUtils.getAncestors 计算）| 不存储可计算的数据 |
| isExpanded | → UiTreeNode.isExpanded | UI 状态 |
| isLoading | 移除（组件 lazy 内部管理）| 与组件机制重复 |
| loaded | 移除 | 同上 |
| disabled | → UiTreeNode | UI 状态 |
| checked | → UiTreeNode.checked | UI 状态 |
| indeterminate | → UiTreeNode.indeterminate | UI 状态 |
| selected | → UiTreeNode.selected | UI 状态 |
| icon/color/badge | → TreeNode.extra | 归入扩展字段 |
| lazyLoadConfig | 移除（移入 TreeConfig）| 配置级，非节点级 |
| nodeType | 保留 | 业务数据 |
| isLeaf | 保留 | 后端事实 |
| raw | 保留（改为可选）| 提交时使用 |

## 五、treeUtils（只读查询函数）

### 5.1 设计原则

- **纯函数**：无副作用，输入确定则输出确定
- **只读**：不修改入参，返回新数据或计算结果
- **通用**：不依赖特定框架，可在任意模块 import 使用

### 5.2 API 列表

```typescript
export const treeUtils = {
  // 构造
  buildTree<T>(items: T[], config: TreeConfig, options?): TreeNode<T>[]
  entityToNode<T>(entity: T, config: TreeConfig, level: number): TreeNode<T>
  nodeToEntity<T>(node: TreeNode<T>, config: TreeConfig): Partial<T>
  flattenTree<T>(roots: TreeNode<T>[]): TreeNode<T>[]

  // 遍历/查询
  getDescendants<T>(node: TreeNode<T>): TreeNode<T>[]
  getDescendantsWithSelf<T>(node: TreeNode<T>): TreeNode<T>[]
  getAncestors<T>(node: TreeNode<T>, rootNodes: TreeNode<T>[]): TreeNode<T>[]
  getPath<T>(rootNodes: TreeNode<T>[], node: TreeNode<T>): string[]
  getPathNames<T>(rootNodes: TreeNode<T>[], node: TreeNode<T>): string[]
  findNode<T>(rootNodes: TreeNode<T>[], code: string): TreeNode<T> | null
  findNodeBy<T>(rootNodes: TreeNode<T>[], predicate): TreeNode<T> | null
  findNodesBy<T>(rootNodes: TreeNode<T>[], predicate): TreeNode<T>[]
  getParent<T>(rootNodes: TreeNode<T>[], node: TreeNode<T>): TreeNode<T> | null

  // 过滤/搜索
  filterByType<T>(rootNodes: TreeNode<T>[], nodeType: string): TreeNode<T>[]
  search<T>(rootNodes: TreeNode<T>[], keyword: string): TreeNode<T>[]
  searchWithAncestors<T>(rootNodes: TreeNode<T>[], keyword: string): TreeNode<T>[]
  filterTree<T>(roots: TreeNode<T>[], predicate): TreeNode<T>[]

  // 统计
  getChildrenCount<T>(node: TreeNode<T>): number
  getDepth<T>(roots: TreeNode<T>[]): number
  getTotalCount<T>(roots: TreeNode<T>[]): number
  getNodesAtLevel<T>(roots: TreeNode<T>[], targetLevel: number): TreeNode<T>[]

  // 验证
  validate<T>(roots: TreeNode<T>[]): { valid: boolean; errors: string[] }
  hasCycle<T>(roots: TreeNode<T>[]): boolean
}
```

### 5.3 使用示例

```typescript

// 构建树

// 查找节点

// 获取所有子孙

// 搜索并保留祖先（高亮+展开）

// 验证
```

## 六、treeOps（不可变变换函数）

### 6.1 设计原则

- **不可变**：输入旧树，返回新树，从不修改入参
- **纯函数**：无副作用，便于测试和并发安全
- **错误安全**：危险操作返回 `{ tree, error? }` 元组

### 6.2 API 列表

```typescript
export const treeOps = {
  // 构造/转换
  buildTree: typeof treeUtils.buildTree  // 同 treeUtils
  flatten<T>(roots: TreeNode<T>[]): TreeNode<T>[]

  // 节点变更（不可变）
  addNode<T>(roots: TreeNode<T>[], parentCode: string | null, node: TreeNode<T>): TreeNode<T>[]
  removeSubtree<T>(roots: TreeNode<T>[], code: string): { tree: TreeNode<T>[]; removed: TreeNode<T>[] }
  moveSubtree<T>(roots: TreeNode<T>[], code: string, newParentCode: string | null, maxDepth?: number): { tree: TreeNode<T>[]; error?: string }
  updateNode<T>(roots: TreeNode<T>[], code: string, patch: Partial<TreeNode<T>>): TreeNode<T>[]
  mergeRoots<T>(...rootLists: TreeNode<T>[][]): TreeNode<T>[]

  // 差异
  diff<T>(oldTree: TreeNode<T>[], newTree: TreeNode<T>[]): TreePatch<T>

  // 校验
  validate<T>(roots: TreeNode<T>[]): { valid: boolean; errors: string[] }
}
```

### 6.3 使用示例

```typescript
import { treeOps } from '@share/utils'

// 新增节点
treeData.value = treeOps.addNode(treeData.value, 'D001', newNode)

// 删除子树（返回被删除的节点供后端批量删除）
const { tree, removed } = treeOps.removeSubtree(treeData.value, 'D001')
treeData.value = tree
await api.delete(removed.map(n => n.code))

// 移动节点（内置防环/防深度校验）
const result = treeOps.moveSubtree(treeData.value, 'D001', 'C002', 5)
if (result.error) {
  ElMessage.error(result.error)
} else {
  treeData.value = result.tree
}

// 多树合并（异构树聚合）
const merged = treeOps.mergeRoots(orgTree, stdTree)
const rows = treeOps.flatten(merged)
```

## 八、ActionPipeline（动作分发管线）

### 8.1 接口定义

```typescript
/**
 * 动作上下文
 */
export interface ActionCtx<T = any> {
  node?: TreeNode<T>
  parent?: TreeNode<T>
  payload?: any
  cancelled?: boolean
}

/**
 * Action Pipeline 接口
 * 
 * 用于标准化节点操作的分发和联动：
 * - before: 前置处理（返回 false 中止）
 * - run: 实际执行
 * - after: 后置联动
 */
export interface ActionPipeline<T = any> {
  before(action: TreeNodeAction, ctx: ActionCtx<T>): Promise<boolean> | boolean
  run(action: TreeNodeAction, ctx: ActionCtx<T>): Promise<void>
  after(action: TreeNodeAction, ctx: ActionCtx<T>): void
}
```

### 8.2 默认实现

```typescript
export class DefaultActionPipeline<T> implements ActionPipeline<T> {
  async before(_action: TreeNodeAction, _ctx: ActionCtx<T>): Promise<boolean> {
    return true // 默认不中止
  }

  async run(action: TreeNodeAction, ctx: ActionCtx<T>): Promise<void> {
    // 默认实现为空，业务可覆盖
  }

  after(action: TreeNodeAction, ctx: ActionCtx<T>): void {
    // 默认实现为空
  }
}
```

## 九、TreeTableLogic<V> 基类

### 9.1 设计说明

```typescript
/**
 * 左树右表 Logic 基类（V2）
 * 
 * V2 变化：
 * - 去 T 泛型，弱化实体类型约束
 * - 底层使用 treeOps 不可变变换
 * - 内置 ActionPipeline 支持 before/run/after
 * - 支持同构树和异构树
 */
export abstract class TreeTableLogic<V extends Record<string, any>> {
  // 配置
  abstract controllerName: string
  abstract treeConfig: TreeConfig
  abstract relation: { relateField: string }

  // 树状态
  treeData = ref<TreeNode[]>([])
  treeLoading = ref(false)
  selectedNode = ref<TreeNode | null>(null)
  checkedNodes = ref<TreeNode[]>([])

  // 表格状态
  rows = ref<V[]>([])
  loading = ref(false)
  pagination = reactive({ page: 1, pageSize: 20, total: 0 })
  searchParams = reactive<Record<string, any>>({})

  // 动作管线
  protected actionPipeline: ActionPipeline = new DefaultActionPipeline()

  // 抽象方法
  abstract loadTree(parentCode?: string | null): Promise<any[]>
  abstract entityToTreeNode(entity: any, level: number): TreeNode
  abstract treeNodeToEntity(node: TreeNode): Record<string, any>

  // Virtual 方法
  protected buildTreeFromItems(items: any[]): TreeNode[] {
    return treeUtils.buildTree(items, this.treeConfig as any)
  }
  protected convertEntityToNode(entity: any, level: number): TreeNode {
    return this.entityToTreeNode(entity, level)
  }
  protected onTreeLoaded(treeData: TreeNode[]): void {
    this.treeConfig.onTreeLoaded?.(treeData)
  }
  protected inferChildNodeType(_node: TreeNode): string {
    return 'default'
  }

  // 核心方法
  async init(autoLoadTable = false): Promise<void>
  async initTree(): Promise<void>
  async loadChildren(parentNode: TreeNode): Promise<TreeNode[]>
  async onNodeClick(node: TreeNode): Promise<void>
  onCheckChange(node: TreeNode, checked: boolean): void
  async loadDataWithTreeCondition(node: TreeNode): Promise<void>
  async loadData(): Promise<void>

  // 树 CRUD（增量更新，使用 treeOps）
  async addTreeNode(parentNode: TreeNode | null, entity: Record<string, any>): Promise<TreeNode | null>
  async updateTreeNode(node: TreeNode, newName: string): Promise<void>
  async deleteTreeNode(node: TreeNode): Promise<boolean>
  async batchDelete(codes: string[]): Promise<boolean>
  async moveTreeNode(node: TreeNode, newParentCode: string | null): Promise<boolean>

  // 辅助
  getCheckedCodes(): string[]
  async refreshTree(): Promise<void>
  async refreshChildren(node: TreeNode): Promise<void>
}
```

### 9.2 使用示例

```typescript
// index.ts
export class DeptPageLogic extends TreeTableLogic<SysUser> {
  controllerName = 'SysDept'
  
  treeConfig: TreeConfig = {
    codeField: 'deptCode',
    nameField: 'deptName',
    parentCodeField: 'parentCode',
    rootParentCode: null,
    lazy: true,
    allowDeleteWithChildren: false
  }
  
  relation = { relateField: 'deptCode' }

  async loadTree(parentCode?: string | null): Promise<any[]> {
    const res = await this.apiGet<{ items: any[] }>('/tree', { parentCode })
    return res.items
  }
  
  entityToTreeNode(entity: any, level: number): TreeNode {
    return {
      code: entity.deptCode,
      name: entity.deptName,
      parentCode: entity.parentCode,
      isLeaf: entity.isLeaf,
      children: [],
      raw: entity
    }
  }
  
  treeNodeToEntity(node: TreeNode): Record<string, any> {
    return {
      deptCode: node.code,
      deptName: node.name,
      parentCode: node.parentCode
    }
  }
  
  // ★ 覆盖 ActionPipeline
  protected actionPipeline: ActionPipeline = {
    async before(action, ctx) {
      if (action === 'delete') {
        // 删除前确认
        await ElMessageBox.confirm('确定删除？')
      }
      return true
    },
    async run(action, ctx) {
      // 执行逻辑...
    },
    after(action, ctx) {
      // 刷新/联动
      ElMessage.success('操作成功')
    }
  }
}

// index.vue
const page = new DeptPageLogic()
await page.init()
```

## 十、后端 TreeControllerBase

### 10.1 设计说明

```csharp
/// <summary>
///     树形结构 Controller 基类（V2）
///     
///     定位：单表同构树专用薄基类
///     - 同构树：部门、菜单、数据字典分类等（单表自关联）
///     - 异构树不继承此基类
/// </summary>
[ApiController]
[Route("api/[controller]")]
public abstract class TreeControllerBase<T> : YzhControllerBase<T>
    where T : BaseEntity, ITreeNode, new()
{
    // 树查询
    [HttpGet("tree")]
    virtual Task<ActionResult<ApiResponse<List<T>>>> GetTree([FromQuery] string? parentCode = null)
    
    [HttpPost("getChildren")]
    virtual Task<ActionResult<ApiResponse<GetChildrenResponse>>> GetChildren([FromBody] GetChildrenRequest request)

    // 树增删改（含级联）
    [HttpPost("add")]
    override Task<ActionResult<ApiResponse<T>>> Add([FromBody] T entity)
    
    [HttpPost("update")]
    override Task<ActionResult<ApiResponse<T>>> Update([FromBody] T entity)
    
    [HttpPost("delete")]
    override Task<ActionResult<ApiResponse>> Delete([FromBody] string[] codes)  // 含子树级联

    // 抽象方法
    protected abstract Task<List<T>> GetTreeItems(string? parentCode);
    protected abstract Task<List<T>> GetChildrenItems(GetChildrenRequest request);

    // Virtual 方法
    protected virtual Task<string> GetNodeType(T entity) => Task.FromResult(string.Empty);
}
```

## 十一、懒加载契约

### 11.1 后端约定

1. **isLeaf 批量计算，杜绝 N+1**：
   - GetTreeItems 查出当前层后，对这批 code 执行一次：
     ```sql
     SELECT parentCode, COUNT(*) FROM t 
     WHERE parentCode IN (...) AND is_deleted = 0 
     GROUP BY parentCode
     ```
   - 得到 hasChildren 映射，不逐节点 EXISTS

2. **tree 接口只返回直接子级**，不做整树递归

3. **前端判断是否懒加载**：`treeConfig.lazy === true && !node.isLeaf`

### 11.2 组件 lazy 选型

- **推荐路径**：YzhTree 打开 `lazy` + 提供 `load(node, resolve)` 回调
- 组件内部维护 loaded/loading，业务模型不重复存储
- el-tree：`props.leaf = 'isLeaf'`

## 十六、视图驱动多表树（V2.1 新增）

### 16.1 设计背景

**问题**：之前的 TreeControllerBase 仅支持单表自关联树（如同构的部门表）。对于多表组合的异构树（如 机构→标准→阶段），需要大量定制代码。

**解决方案**：使用 MySQL VIEW 将多表 JOIN/UNION 后的数据统一为树结构标准字段，Controller 代码与单表树完全一致。

### 16.5 优化后的 TreeControllerBase

```csharp
[ApiController]
[Route("api/[controller]")]
public abstract class TreeControllerBase<T> : YzhControllerBase<T>
    where T : TreeNodeViewBase, new()
{
    protected TreeControllerBase(EntityService<T> entityService, IUserContext userContext)
        : base(entityService, userContext)
    {
    }

    // ========================================================
    // 一、树查询（核心：返回扁平列表 + 批量计算 isLeaf）
    // ========================================================

    /// <summary>
    ///     获取树（扁平列表，前端 buildTree 组装）
    ///     GET api/{controller}/tree?parentCode=xxx
    /// </summary>
    [HttpGet("tree")]
    public virtual async Task<ActionResult<ApiResponse<List<T>>>> GetTree(
        [FromQuery] string? parentCode = null)
    {
        try
        {
            var items = await Entity.GetViewList(parentCode);
            
            // ★ 批量计算 isLeaf（一次 GROUP BY）
            await FillIsLeafBatch(items);
            
            return Ok(ApiResponse.Ok(items));
        }
        catch (Exception ex)
        {
            return BadRequest(ApiResponse.Fail($"获取树失败：{ex.Message}"));
        }
    }

    /// <summary>
    ///     懒加载子节点
    ///     POST api/{controller}/getChildren
    /// </summary>
    [HttpPost("getChildren")]
    public virtual async Task<ActionResult<ApiResponse<GetChildrenResponse>>> GetChildren(
        [FromBody] GetChildrenRequest request)
    {
        try
        {
            var items = await Entity.GetViewList(request.ParentCode);
            await FillIsLeafBatch(items);
            
            return Ok(ApiResponse.Ok(new GetChildrenResponse { Items = items }));
        }
        catch (Exception ex)
        {
            return BadRequest(ApiResponse.Fail($"加载子节点失败：{ex.Message}"));
        }
    }

    // ========================================================
    // 二、树增删改（含级联）
    // ========================================================

    [HttpPost("add")]
    public override async Task<ActionResult<ApiResponse<T>>> Add([FromBody] T entity)
    {
        // 校验 parentCode 存在性
        if (!string.IsNullOrEmpty(entity.ParentCode))
        {
            var parent = await Entity.GetByCode(entity.ParentCode);
            if (!parent.Success || parent.Data == null)
                return BadRequest(ApiResponse.Fail($"父节点 {entity.ParentCode} 不存在"));
        }
        return await base.Add(entity);
    }

    [HttpPost("update")]
    public override async Task<ActionResult<ApiResponse<T>>> Update([FromBody] T entity)
    {
        // 防环校验
        if (!string.IsNullOrEmpty(entity.ParentCode))
        {
            if (entity.ParentCode == entity.Code)
                return BadRequest(ApiResponse.Fail("不能将父节点设为自己"));
            
            var descendants = await GetDescendantCodes(entity.Code);
            if (descendants.Contains(entity.ParentCode))
                return BadRequest(ApiResponse.Fail("不能将父节点设为自己的后代"));
        }
        return await base.Update(entity);
    }

    /// <summary>
    ///     移动节点（专用接口）
    ///     POST api/{controller}/move
    /// </summary>
    [HttpPost("move")]
    public virtual async Task<ActionResult<ApiResponse<T>>> Move(
        [FromBody] MoveNodeRequest request)
    {
        // 1. 校验节点存在
        var node = await Entity.GetByCode(request.Code);
        if (!node.Success || node.Data == null)
            return BadRequest(ApiResponse.Fail("节点不存在"));

        // 2. 校验目标父节点存在
        if (!string.IsNullOrEmpty(request.NewParentCode))
        {
            if (request.NewParentCode == request.Code)
                return BadRequest(ApiResponse.Fail("不能移动到自己"));
            
            var newParent = await Entity.GetByCode(request.NewParentCode);
            if (!newParent.Success || newParent.Data == null)
                return BadRequest(ApiResponse.Fail("目标父节点不存在"));
            
            var descendants = await GetDescendantCodes(request.Code);
            if (descendants.Contains(request.NewParentCode))
                return BadRequest(ApiResponse.Fail("不能移动到自己的子树下"));
        }

        // 3. 防深度越限
        if (MaxDepth > 0)
        {
            var nodeDepth = await GetSubtreeDepth(request.Code);
            var newParentLevel = string.IsNullOrEmpty(request.NewParentCode) 
                ? 0 
                : await GetNodeLevel(request.NewParentCode);
            if (newParentLevel + 1 + nodeDepth > MaxDepth)
                return BadRequest(ApiResponse.Fail($"移动后深度将超过限制 ({MaxDepth})"));
        }

        // 4. 执行移动
        node.Data.ParentCode = request.NewParentCode;
        return await base.Update(node.Data);
    }

    [HttpPost("delete")]
    public override async Task<ActionResult<ApiResponse>> Delete([FromBody] string[] codes)
    {
        // 收集所有子孙 code
        var allCodes = new List<string>(codes);
        foreach (var code in codes)
        {
            var descendants = await GetDescendantCodes(code);
            allCodes.AddRange(descendants);
        }
        allCodes = allCodes.Distinct().ToList();

        var result = await Entity.DeleteBatch(allCodes, hardDelete: HardDelete, clientIp: UserContext.ClientIp);
        return result.Success 
            ? Ok(ApiResponse.Ok($"已删除 {result.Data} 个节点（含子节点）"))
            : BadRequest(ApiResponse.Fail(result.Error));
    }

    // ========================================================
    // 三、抽象方法（子类实现）
    // ========================================================

    /// <summary>获取树节点列表（视图查询）</summary>
    protected abstract Task<List<T>> GetViewList(string? parentCode);

    // ========================================================
    // 四、Virtual 方法
    // ========================================================

    /// <summary>最大层级深度（0=不限）</summary>
    protected virtual int MaxDepth => 0;

    // ========================================================
    // 五、辅助方法
    // ========================================================

    /// <summary>
    ///     批量计算 isLeaf（一次 SQL GROUP BY）
    /// </summary>
    protected virtual async Task FillIsLeafBatch(List<T> items)
    {
        if (items.Count == 0) return;

        var codes = items.Select(i => i.Code).Distinct().ToList();
        var childrenCounts = await Entity.GetChildrenCountBatch(codes);
        
        foreach (var item in items)
        {
            item.IsLeaf = !childrenCounts.ContainsKey(item.Code) || childrenCounts[item.Code] == 0;
        }
    }

    /// <summary>获取所有子孙 code（递归）</summary>
    protected virtual async Task<List<string>> GetDescendantCodes(string code)
    {
        var result = new List<string>();
        await CollectDescendants(code, result);
        return result;
    }

    private async Task CollectDescendants(string parentCode, List<string> result)
    {
        var children = await Entity.GetViewList(parentCode);
        foreach (var child in children)
        {
            result.Add(child.Code);
            await CollectDescendants(child.Code, result);
        }
    }

    /// <summary>获取子树深度</summary>
    protected virtual async Task<int> GetSubtreeDepth(string code)
    {
        var descendants = await GetDescendantCodes(code);
        return descendants.Count == 0 ? 1 : descendants.Max(d => GetNodeLevel(d)) + 1;
    }

    /// <summary>获取节点层级</summary>
    protected virtual async Task<int> GetNodeLevel(string code)
    {
        int level = 0;
        var current = await Entity.GetByCode(code);
        while (current.Success && current.Data != null && !string.IsNullOrEmpty(current.Data.ParentCode))
        {
            level++;
            current = await Entity.GetByCode(current.Data.ParentCode);
        }
        return level;
    }
}
```

```csharp
/// <summary>
///     从视图获取树节点列表（扁平）
/// </summary>
public virtual async Task<List<T>> GetViewList(string? parentCode)
{
    if (string.IsNullOrEmpty(parentCode))
    {
        return await _dbOrm.GetListAsync<T>(e => e.ParentCode == null);
    }
    return await _dbOrm.GetListAsync<T>(e => e.ParentCode == parentCode);
}

/// <summary>
///     批量获取子节点数量（一次 SQL）
/// </summary>
public virtual async Task<Dictionary<string, int>> GetChildrenCountBatch(List<string> parentCodes)
{
    if (parentCodes.Count == 0) return new Dictionary<string, int>();
    
    var sql = $"SELECT parent_code AS ParentCode, COUNT(*) AS Cnt " +
              $"FROM {GetViewName()} " +
              $"WHERE parent_code IN @codes " +
              $"GROUP BY parent_code";
    
    var result = await _dbOrm.QueryAsync<(string ParentCode, int Cnt)>(sql, new { codes = parentCodes });
    return result.ToDictionary(x => x.ParentCode, x => x.Cnt);
}

private string GetViewName()
{
    var attr = typeof(T).GetCustomAttribute<ViewNameAttribute>();
    return attr?.ViewName ?? typeof(T).Name;
}
```
