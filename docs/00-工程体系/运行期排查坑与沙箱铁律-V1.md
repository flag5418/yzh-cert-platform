## 3. 进程 / 缓存假象（★★ 最容易误判的一类）

- ★ **新增控制器后必须重建 + 重启** —— 症状 = 打接口 **404** + 后端日志出现 `end of the middleware pipeline`（⛔ 不是路由写错）。
- ★★ **`lsof` 有监听 ⛔ ≠ 正在跑 HEAD 代码** ⇒ 任何 **A/B 对照必须重建**，否则对照的是同一份旧二进制。
- ★★ **多会话并发写同一工作区** ⇒ ⛔ 判「这改动是谁的」**先问，别推理**；闸门结果只代表**某一瞬间**。
- 「**陈旧进程**」判据：① 先看值是否 `null`（JSON 序列化**省略** `null`）；② 先确认路由前缀（打错报同一句 404）；③ 枚举列序列化成**字符串** ⇒ 前端 ⛔ 按 `number` 写。
- **MinIO 被代理毒死**（SDK 继承 `HTTP_PROXY`）⇒ 文件功能**全线失败却报「文件不存在」**（假象）→ 详见 `skill yzh-diagnose-file-failure`。

## 4. ORM（SqlSugar）过滤与写回

- **过滤双路径**（判「列为什么被剔除」看这里）：
  - `GetPageAsync` 用 `GetColumnName<T>`
  - `GetListAsync` / `CountAsync` / `GetOneAsync` 用 `IsDeclaredOnType<T>`（⚠️ T+V 形态的 **V 不过滤**）
  - `IsIgnore` **两路都跳过** ⇒ 视图列**从 SELECT 就被剔除**（不是查完再滤）
- `GetOneIgnoreValidAsync` **只绕 `IsValid`**（`IsDeleted == 0` 照加）⇒ **含已删行的查重 / 复活** 必须**裸 `Queryable`**。
- ★ **写操作 ⛔ 不许丢 `Result`** —— 否则接口回「已保存 N 项」而库里**零变化**。
- **内部模型 ≠ 对外 DTO**（DTO 没有的字段**静默丢弃**）⇒ 加内部字段**必须同步改 DTO + 投影**。
- ★ **「写了没人看」类缺陷判据**：先问「**这字段有没有渲染方 / 消费方**」，再问「值对不对」。
  - **同族**：配置写**契约表**、编排器读**目录表** ⇒ 还要多问一句「**读的是不是同一列**」→ `67` 号 §10.4。
  - 且**响应恒 PascalCase** ⇒ ⛔ 每个跨边界消费点都要**显式归一化**（`...s` 展开**不算**归一化）。
- R17 **只数生产代码**引用（⛔ 不含 `Admin.Tests`）；判「实体被谁引用」**必须词边界 + 排除注释行**。
