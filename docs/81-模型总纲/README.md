# 81 · 模型总纲

这个目录放**纯模型**，不放实现。全章不出现表名、字段名、代码名。

## 为什么单独开这个目录

80-v4 是"怎么修现有系统"，讲的是表、字段、函数、排期。
但那些东西对 vibe coding 的人没有意义——你不需要知道表叫什么，你需要知道**模型长什么样、它们怎么连、每一步谁说了算**。

这个目录就是回答那个问题。
