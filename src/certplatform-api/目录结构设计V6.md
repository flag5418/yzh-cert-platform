## 一、核心思想

```
┌──────────────────────────────────────────────────────────────────────┐
│                          YZH.Core.Web（唯一种子项目）                  │
│                                                                       │
│  内置能力：                                                           │
│  Program.cs → builder.UseYzhCore() → JWT → 中间件 → 控制器扫描       │
│  GlobalData.AppPath = ContentRootPath                                │
│  运行时从 {AppPath}/Assest/GridConfigs/ 读取 UI 配置                  │
│  appsettings.json（框架默认配置，可被项目覆盖）                         │
│                                                                       │
│  自动 CopyToOutput：Assest/ + appsettings.json                        │
└──────────────────────────────────────────────────────────────────────┘
          │ 引用
          ▼
┌──────────────────────────────────────────────────────────────────────┐
│                     CertPlatform 业务项目                             │
│                                                                       │
│  appsettings.json             ← 项目专属配置（覆盖框架同名Key）        │
│  Assest/GridConfigs/*.json    ← 项目专属 UI 配置                      │
│  Assest/tmp/                  ← 项目临时文件                          │
│  CertPlatform.Shared/         ← 共享层                                │
│  CertPlatform.Admin/          ← 管理员端                              │
│  CertPlatform.Auditor/        ← 审核员端                              │
│  CertPlatform.Enterprise/     ← 企业端                                │
│                                                                       │
│  自动 CopyToOutput：appsettings.json + Assest/ _bin/Debug/net8.0/     │
└──────────────────────────────────────────────────────────────────────┘
```

**设计关键**：每个项目目录自带 `appsettings.json` 和 `Assest/` 资源文件夹，编译时自动复制到输出目录，运行时被 YZH.Core.Web 的 `GlobalData.AppPath` 发现。

## 三、运行时资源发现机制

```
编译时（自动 CopyToOutput）：
  certplatform-api/Assest/GridConfigs/*.json
  → bin/Debug/net8.0/Assest/GridConfigs/*.json

  certplatform-api/appsettings.json
  → bin/Debug/net8.0/appsettings.json

运行时加载：
  GlobalData.AppPath = builder.Environment.ContentRootPath
  → 对于 Web 项目：AppPath = bin/Debug/net8.0/
  → 对于 IIS：AppPath = 网站根目录

  UI 配置加载路径：
  {AppPath}/Assest/GridConfigs/{configName}.json

  Appsettings 加载（）：
  framework: YZH.Core.Web/appsettings.json  → 提供默认 Key
  project:    certplatform-api/appsettings.json → 覆盖同名 Key
```

**效果**：
- 框架提供 `JWT:Secret` 默认值
- 项目 appsettings.json 可覆盖为 `"JWT:Secret": "my-project-secret"`
- 项目添加自定义 Key：`"MinIO:Endpoint": "127.0.0.1:9000"`

## 四、GridConfig 放置位置决策

| 场景 | 位置 | 生命周期 |
|------|------|---------|
| 框架默认的通用配置 | `yzh-core/YZH.Core.Web/Assest/` | 随框架更新 |
| 认证平台专属 UI 配置 | `certplatform-api/Assest/GridConfigs/` | 独立部署更新 |
| 运行时动态创建/修改 | `certplatform-api/Assest/tmp/` | 每次可清理 |

**流程**：
```
页面请求 GridConfig → 
  先查数据库（YzhPageConfig 表）→
    未找到 → 从磁盘 Assest/GridConfigs/{name}.json 加载 → 回写数据库 → 返回
```

## 七、实施路径

```
Phase 1: YZH.Core 框架独立验证
  ✅ 创建 Stand / DataBase / Web 三个项目
  ✅ 确保 YZH.Core.Web 可独立启动（返回 200 OK）

Phase 2: CertPlatform 项目填充
  ① 创建 certplatform-api 项目结构（Shared/Admin/Auditor/Enterprise）
  ② 填充 appsettings.json + Assest/GridConfigs/
  ③ 移植 Entities/Controllers 到 Shared
  ④ 移植 Queue/WorkflowEngine 到 Shared
  ⑤ 创建 AdminModule/AuditorModule 注册入口

Phase 3: 编译集成验证
  ① dotnet build certplatform-api.sln
  ② 启动 YZH.Core.Web
  ③ 验证所有角色 API 可调用
  ④ 验证 GridConfig 从 Assest/GridConfigs/ 加载
```
