## 三、YZH.Core.Web 唯一启动机制

### 3.1 Program.cs 示例

```csharp
using YZH.Core.Web.Configuration;

var builder = WebApplication.CreateBuilder(args);

// YZH Core 框架基础服务（JWT/中间件/DI注册）
builder.UseYzhCore(options =>
{
    options.ConnectionString = builder.Configuration.GetConnectionString("Default");
});

// 注册业务模块（每个 ClassLibrary 提供 AddXxxModule 扩展）
builder.Services
    .AddSharedModule()      // CertPlatform.Shared
    .AddAdminModule()       // CertPlatform.Admin
    .AddAuditorModule();    // CertPlatform.Auditor

builder.MapControllers();   // 自动扫描所有程序集的 Controller

var app = builder.Build();
app.UseYzhCoreMiddleware(); // 注册异常/认证/路由中间件
app.Run();
```

### 3.2 业务模块注册示例

```csharp
// CertPlatform.Admin/AdminModule.cs
namespace CertPlatform.Admin;

public static class AdminModule
{
    public static IServiceCollection AddAdminModule(this IServiceCollection services)
    {
        // 注册 Admin 特有的服务
        services.AddScoped<IAdminCertService, AdminCertService>();
        services.AddScoped<IAuditorMgmtService, AuditorMgmtService>();
        return services;
    }
}

// CertPlatform.Shared/SharedModule.cs
namespace CertPlatform.Shared;

public static class SharedModule
{
    public static IServiceCollection AddSharedModule(this IServiceCollection services)
    {
        // 注册共享服务
        services.AddScoped<ICertBodyService, CertBodyService>();
        services.AddScoped<IISOStandardService, ISOStandardService>();
        services.AddScoped<IQueueManager, QueueManager>();
        services.AddScoped<IWorkflowEngine, WorkflowEngine>();
        return services;
    }
}
```

### 3.3 控制器自动发现

```csharp
// YzhWebBuilder.cs 中自动扫描所有程序集
builder.Services.AddControllers()
    .AddApplicationPart(typeof(CertPlatform.Admin.AdminModule).Assembly)
    .AddApplicationPart(typeof(CertPlatform.Shared.SharedModule).Assembly)
    .AddApplicationPart(typeof(CertPlatform.Auditor.AuditorModule).Assembly);
```

## 七、关键设计决策

### 7.1 为什么 YZH.Core.Web 是唯一入口？

- 框架已经是一个完整的 Web 应用（带 Program.cs）
- 框架引用业务类库，通过 `AddXxxModule()` 注册服务
- MVC 的 `AddApplicationPart` 自动发现所有程序集的 Controller
- 业务项目只需提供 Module.cs + 自己的 Controller/Service 实现

### 7.2 业务项目是什么？

- 全部是 **Class Library**（类库），不是 Web 项目
- 包含 Controller、Service、Repository、Entity
- 通过 Module.cs 暴露注册入口
- 不直接运行，由 YZH.Core.Web 加载

### 7.3 未来新项目接入方式？

```csharp
// 新建 yzh-project-X 解决方案
// 1. 引用 YZH.Core.Web
// 2. 创建 XModule.cs
// 3. Program.cs: builder.UseYzhCore().AddXModule()
```
