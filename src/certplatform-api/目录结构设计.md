# CertPlatform 新项目目录结构设计

## 一、问题说明

当前 `certplatform-api/` 存在的问题：

```
certplatform-api/
├── Cert.Platform.Entities/        ← 散落在根目录
├── Cert.Platform.Infrastructure/  ← 命名带点，不规范
├── Cert.Platform.Sys/             ← 散落在根目录
├── Cert.Platform.Business/        ← 散落在根目录
├── Cert.Platform.Builder/         ← 散落在根目录
├── Cert.Platform.Api/             ← 散落在根目录
├── Admin/                         ← 角色目录，但内容缺失
├── Auditor/                       ← 空
└── Enterprise/                    ← 空
```

**三个问题**：
1. `Cert.Platform.Xxx` 命名不规范，.NET 对带点的文件夹名敏感
2. 基础设施项目散落根目录，没有按角色归类
3. Admin/Auditor/Enterprise 角色目录没有内容

---

## 二、目标结构设计

```
certplatform-api/
│
├── CertPlatform.sln                           ← 解决方案文件
│
├── CertPlatform.Api/                          ← 【启动项目】Program.cs + 全部Controllers
│   ├── Program.cs
│   ├── Startup.cs
│   ├── Controllers/
│   │   ├── Hubs/                              ← SignalR Hub
│   │   ├── Builder/                           ← 代码生成器控制器
│   │   ├── OSS/                               ← 阿里云OSS控制器
│   │   ├── Admin/                             ← 管理员端控制器（原Vol Admin目录）
│   │   ├── Auditor/                           ← 审核员端控制器
│   │   ├── Enterprise/                        ← 企业端控制器
│   │   └── ApiHomeController.cs 等通用控制器
│   ├── appsettings.json
│   ├── Dockerfile
│   └── Properties/
│
├── CertPlatform.System/                       ← 【系统模块】User/Role/Menu/Dictionary
│   ├── Controllers/                           ← YZH.System 的控制器（已有）
│   ├── Entities.cs                            ← SysUser/SysRole 等干净POCO
│   ├── DomainService.cs                       ← 通用数据服务
│   ├── CrudController.cs                      ← 通用CRUD控制器基类
│   ├── SystemBuilder.cs                       ← DI注册扩展
│   ├── SystemDbContext.cs                     ← 系统数据库上下文
│   └── Contracts.cs
│
├── CertPlatform.Business/                     ← 【业务服务】认证机构/标准/审核/工作流
│   ├── IRepositories/                         ← 业务仓储接口
│   │   ├── Admin/Platform/Cert/
│   │   ├── Admin/Platform/Wf/
│   │   ├── Admin/Platform/Audit/
│   │   └── ...
│   ├── IServices/                             ← 业务服务接口
│   ├── Repositories/                          ← 业务仓储实现
│   ├── Services/                              ← 业务服务实现（含Partial文件夹）
│   ├── Extensions/                            ← UniqueValidationExtensions 等
│   └── WorkflowEngine/                        ← 工作流引擎（节点执行器/解释器）
│
├── CertPlatform.Shared/                       ← 【共享基础设施】
│   ├── Entities/                              ← 所有业务实体
│   │   ├── Platform/                          ← 认证平台业务实体
│   │   │   ├── Base/YZHBaseEntity.cs
│   │   │   ├── Cert/
│   │   │   ├── Audit/
│   │   │   ├── Wf/
│   │   │   └── ...
│   │   └── System/                            ← 系统实体（DomainModels/System/）
│   │       ├── Sys_User.cs
│   │       ├── Sys_Role.cs
│   │       └── ...
│   │
│   └── Framework/                             ← VOL核心框架（YZH.Core）
│       ├── BaseProvider/                      ← ServiceBase/RepositoryBase
│       ├── Controllers/Basic/                 ← VolController/ApiBaseController
│       ├── Middleware/                        ← ExceptionHandler/HttpRequest
│       ├── Filters/                           ← ApiAuthorizeFilter/ActionExecuteFilter
│       ├── EFDbContext/                       ← VOLContext/BaseDbContext
│       ├── Extensions/                        ← Autofac/String/lambda扩展
│       ├── CacheManager/                      ← Redis/Memory缓存
│       ├── AI/                                ← LLM客户端/Provider
│       ├── Extractor/                         ← 文件提取器
│       ├── Queue/                             ← 队列框架
│       ├── Workflow/                          ← 工作流Skill/SkillRegistry
│       └── ...
│
├── CertPlatform.Builder/                      ← 【代码生成器】
│   ├── Services/Core/                         ← TableInfo服务
│   ├── Services/CertPlatform/                 ← 工作流Skills
│   └── Utility/
│
├── CertPlatform.Admin/                        ← 【管理员角色专属】
│   └── (当前阶段为空，未来放管理员特有的Controller/Service)
│
├── CertPlatform.Auditor/                      ← 【审核员角色专属】
│   └── AuditorController/                     ← 审核员专用控制器
│
└── CertPlatform.Enterprise/                   ← 【企业角色专属】
    └── EnterpriseController/                  ← 企业专用控制器
```

## 三、命名规则

| 原名称 | 新名称 | 说明 |
|--------|--------|------|
| `Cert.Platform.Entities` | `CertPlatform.Shared/Entities` | 实体归入Shared |
| `Cert.Platform.Infrastructure` | `CertPlatform.Shared/Framework` | 框架归入Shared |
| `Cert.Platform.Sys` | `CertPlatform.System` | 改为无点格式 |
| `Cert.Platform.Business` | `CertPlatform.Business` | 去掉点号 |
| `Cert.Platform.Builder` | `CertPlatform.Builder` | 去掉点号 |
| `Cert.Platform.Api` | `CertPlatform.Api` | 去掉点号 |

---

## 四、项目引用关系

```
CertPlatform.Api
    ├──→ CertPlatform.System
    ├──→ CertPlatform.Business
    ├──→ CertPlatform.Shared (Entities + Framework)
    └──→ CertPlatform.Builder

CertPlatform.Business
    ├──→ CertPlatform.Shared (Entities + Framework)
    └──→ CertPlatform.Builder

CertPlatform.System
    └──→ (仅依赖EF Core + Pomelo)

CertPlatform.Shared.Framework
    └──→ CertPlatform.Shared.Entities

CertPlatform.Builder
    └──→ CertPlatform.Shared (Entities + Framework)

CertPlatform.Admin / Auditor / Enterprise
    └──→ CertPlatform.Business + Shared
```
