# 全量移植实施计划

## 当前代码规模
- 总计 682 个 .cs 文件
- 11 个主要项目/模块
- 涉及后端框架 + 业务逻辑

## 移植策略

### 核心原则
1. **不拆散原有功能**：移植后所有业务逻辑不变
2. **逐步推进**：按层移植，每层编译通过后再进下一层
3. **保留兼容**：新结构中暂时保留对Vol框架的引用，稳定后再行替换

### 移植优先级

```
阶段1: 实体层 (YZH.Entity + VOL.Entity → Cert.Platform.Entities)
阶段2: 仓储层 (VOL.Core/RepositoryBase → Cert.Platform.Repositories)
阶段3: 服务层 (Cert.Platform/Services + Partial)
阶段4: 控制器层 (Controllers → Admin/Auditor/Enterprise/)
阶段5: 框架移植 (VOL.Core/BaseProvider → yzh-core完善)
阶段6: 启动整合 (VOL.WebApi/Program.cs → Cert.Platform.Api)
```
