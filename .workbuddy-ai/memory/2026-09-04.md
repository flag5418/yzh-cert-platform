## 分析方法沉淀（下次评估"某模块能否剥离 Vol"时复用）
1. 继承链判定：grep `class XService : YService` 统计基类分布 → 区分"框架自带服务"与"我们写的服务"。
2. 依赖密度：`grep -rhoE "using VOL\.[A-Za-z.]+" <dir> | sort | uniq -c | sort -rn` → 硬绑定(继承基类/泛型约束) vs 软依赖(用个工具类)。
3. 死代码判定三连：是否在 .sln/.csproj 中 → 是否被启动脚本引用 → 与活跃项目是否有大量同名文件（副本特征）。
4. 前端隐式耦合要查 `main.js` 的**全局注册**（app.component/globalProperties），只 grep import 会严重低估耦合度。
