- 构建报 `YZHRowDiff.ts:78 Unexpected ")"`：`rows.forEach((r, i) => console.warn(\`...\`))` 这种"箭头函数体就是一条 console"的情况，脚本只剔除了 console.warn 表达式，留下悬空 `rows.forEach((r, i) => )`。

- 可复用教训（写 skill）：自动化删除 console 时，对 `arr.forEach(x => console.xxx(...))` / `promise.then(x => console.xxx())` 这类"console 即回调唯一体"的情况，必须整行/整表达式删除，不能只剔 console 调用本身。检测法：console 调用若是一行中 `=> ` 之后唯一内容，删除整条语句。
